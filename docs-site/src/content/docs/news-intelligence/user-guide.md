# 📖 用户指南

> 版本: v2.7.0 | 最后更新: 2026-06-16

## 快速开始

### 1. 启用消息智能

消息智能默认启用。在左侧导航栏点击 **📰 新闻** 即可进入新闻面板。

### 2. 设置关注标的

在 **自选股** 中添加您关注的股票，系统会自动推送相关新闻。

### 3. 查看每日早报

每天早上打开 DW，**AI 每日早报** 会自动展示您的持仓和自选的隔夜新闻摘要。

---

## 功能详解

### 📰 价格异动归因 (免费)

**是什么**: 当您的持仓或自选股涨跌超过 5%，AI 自动分析关联新闻并生成一句话原因。

**如何使用**:
1. 无需配置，自动运行
2. 在个股页面看到异动标记时，点击展开归因面板
3. 显示: 涨跌幅度 + 一句话原因 + 新闻来源链接

**示例**:
```
🟢 AAPL +6.2%
💡 Apple reports record iPhone sales, beating analyst estimates by 15%.
   └─ 来源: Reuters · 2小时前
```

---

### ⚡ 突发新闻警报 (免费)

**是什么**: 黑天鹅、财报、政策变动等突发事件第一时间桌面推送。

**分级**:
| 级别 | 说明 | 颜色 |
|:---:|------|:---:|
| P0 | 黑天鹅/系统风险 | 🔴 红色弹窗 + 声音 |
| P1 | 财报/政策/重大公告 | 🟡 黄色通知 |
| P2 | 行业动态/一般消息 | 🔵 蓝色标记 |

**如何使用**:
1. 设置 → 通知 → 启用新闻警报
2. 可选: 仅推送自选股相关、静音时段

---

### 🤖 AI 每日早报 (1U/天)

**是什么**: 每天一份定制摘要，涵盖持仓、自选和市场的隔夜重要新闻。

**内容**:
- 📊 市场概况 (主题 + 恐贪指数 + 行业热力)
- 💼 持仓新闻摘要 (每持仓 1-2 句)
- 👀 自选股信号 (多空方向 + 关联新闻)
- 🔥 今日头条 (8 条最重要新闻)

**费用**: 每天首次查看扣除 1U

---

### 🛡️ 持仓风险扫描 (1U/次)

**是什么**: 突发利空消息自动评估对持仓的影响，给出操作建议。

**输出**:
```
🔴 TSLA — 高风险 (65/100)
   新闻: "Tesla recalls 2M vehicles over safety concerns"
   建议: REDUCE (考虑减仓或对冲)
   影响: 短期负面，供应链修复需2-4周
```

**如何使用**:
1. 交易页面 → 风险扫描
2. 点击 **扫描持仓** (1U)
3. 查看风险报告，一键执行建议操作

---

### 🏭 供应链传导 (1U/次)

**是什么**: 当某公司发生重大事件，自动分析对上下游供应商和客户的影响。

**示例**:
```
🔧 TSM 火灾影响传导:
   → 上游: ASML (设备供应商) 🟡 轻微影响
   → 下游: AAPL (客户) 🟡 潜在供应延迟
   → 下游: NVDA (客户) 🟡 芯片交付周期延长
   → 同行: SAMSUNG 🟢 可能受益
```

**如何使用**:
1. 新闻详情页 → 供应链传导
2. 点击 **分析传导** (1U)
3. 查看上下游影响网络

---

### 🔍 新闻选股器 (免费)

**是什么**: 基于新闻情绪和成交量变化筛选符合特定条件的股票。

**预设策略**:

| 策略 | 条件 |
|------|------|
| 情绪改善 | 连续 3 天情绪上升 + 成交量放大 50% |
| 反转信号 | 极度悲观后首次出现正面新闻 |
| 高关注 | 新闻量激增 3 倍 + 成交量放大 |
| 海量预警 | 负面新闻集中爆发 |
| 共振 (V2) | 跨市场/加密/商品/社交多维度共振 |

**如何使用**:
1. 新闻面板 → 选股器
2. 选择预设策略或自定义条件
3. 查看筛选结果，点击股票查看详情

---

### 📋 监管政策追踪 (免费)

**是什么**: 自动追踪 SEC、PBOC、ESMA 等监管机构的新规和公告。

**覆盖机构**:
- SEC (美国)
- PBOC/CSRC (中国)
- ESMA (欧盟)
- FCA (英国)

**如何使用**:
1. 新闻面板 → 政策追踪
2. 查看按行业归类的政策动态
3. 系统自动匹配受影响的持仓

---

### 📊 新闻回测 (1.5U/次)

**是什么**: 基于历史 3 年新闻数据，回测特定事件类型对股价的影响。

**配置参数**:

| 参数 | 范围 | 说明 |
|------|:---:|------|
| Lookback | 1-90 天 | 事件前观察窗口 |
| Hold | 1-60 天 | 持仓周期 |
| Stop Loss | 1-20% | 止损线 |
| Take Profit | 1-50% | 止盈线 |

**输出**:
- 总收益 / 胜率 / 平均收益
- Sharpe 比率 / 最大回撤
- 每次事件的收益曲线
- 每标的独立分析

**如何使用**:
1. 新闻面板 → 回测
2. 选择事件类型 (财报/政策/社交/自定义)
3. 配置参数 → 运行回测 (1.5U)

---

### 🎯 事件驱动策略 (1.5U/次)

**是什么**: 针对财报、并购、分红等事件，AI 建议策略参数调整。

**支持事件**:
- 财报发布 (Earnings)
- 并购公告 (M&A)
- 分红/回购 (Dividend/Buyback)
- IPO
- 监管裁决

**输出**:
```
📅 AAPL 财报事件策略:
   方向: LONG
   建议持仓: 5-10 天
   止损: -3%
   止盈: +8%
   理由: AAPL 过去8次财报后5天平均收益+2.3%
```

**如何使用**:
1. 事件日历 → 选择即将发生的事件
2. 点击 **生成策略** (1.5U)
3. 查看 AI 建议，一键应用到回测或实盘

---

### 💬 新闻讨论区 (免费)

**是什么**: 每条策略关联的新闻下自动生成讨论线程。

**功能**:
- 💬 评论 + 回复
- 👍 点赞排序
- 📌 创作者置顶回复
- 🔔 新回复通知

---

### 📝 创作者素材 (免费)

**是什么**: 撰写策略分析时，AI 自动推选相关新闻作为引证材料。

**如何使用**:
1. 策略编辑器 → 分析模式
2. 右侧自动显示相关新闻列表
3. 点击新闻可快速引用到策略说明中

---

### 👥 跟单增强 (免费)

**是什么**: 跟单高手调仓时，自动显示关联新闻作为决策参考。

**如何使用**:
1. 跟单确认弹窗底部显示关联新闻
2. 风险信号: 🟢 绿灯 / 🟡 黄灯 / 🔴 红灯
3. 点击新闻标题查看详情

**跟单弹窗示例**:
```
📊 TraderX 买入 100 AAPL @ $182.50

📰 Apple reports record iPhone sales (Reuters)
💡 创作者可能基于财报超预期买入

🟢 风险信号: 低 | 相关新闻: 3条

[取消] [确认跟单]
```
