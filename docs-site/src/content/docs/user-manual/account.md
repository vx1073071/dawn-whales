## 安装与启动

### 系统要求

| 组件 | 最低要求 |
|------|---------|
| OS | Win10+ / macOS 12+ |
| RAM | 8 GB |
| 磁盘 | 2 GB 可用空间 |
| Node.js | v18+ (开发者模式) |

### 安装方式

**方式一: 发行版安装包 (推荐)**
从 <https://QuantMoo.app/download> 下载最新安装包。

**方式二: 源码运行 (开发者)**
```bash
git clone https://github.com/quant-moo/quant-moo.git
cd quant-moo
npm install
npm start
```

### OTA 自动更新

QUANT MOO 默认每 4 小时自动检查更新。可用通道:

- **stable** — 稳定版 (推荐)
- **beta** — 测试版 (提早体验新功能)
- **nightly** — 每日构建 (最新, 可能不稳定)

更新通知会在有新版本时弹出。重要安全补丁会强制安装。

更新系统包含回滚机制 — 如果新版本出现问题, 自动恢复到上一个稳定版本, 零数据丢失。

## 账户与券商

### 添加券商连接

1. 打开 **设置 → 券商管理**
2. 点击 **添加券商**
3. 选择券商类型
4. 填入连接参数 (IP/端口/账户ID)
5. OAuth 券商 (eToro/Schwab) 会弹出授权页面
6. 连接成功后状态指示灯变绿

### 健康监控

每个券商连接实时监控:
- 连接延迟
- 心跳状态
- 数据质量
- 订单超时

绿色(80+) = 正常 | 黄色(50-80) = 降级 | 红色(<50) = 需关注

### 多账户管理

通过 `MultiAccountManager` 统一管理多个券商账户。支持:
- 跨券商资产总览
- 持仓合并视图
- 统一风控限额

## 策略配置

### 选择策略模板

QUANT MOO 内置 **196 个策略模板**, 按市场分类:

1. 进入 **策略 → 模板市场**
2. 按市场筛选 (美股/港股/...)
3. 点击模板查看详情:
   - 因子组成
   - 历史回测表现
   - 适合市场环境
4. 点击 **使用此模板** 创建策略实例

### 调整参数

每个模板有 3-5 个可调参数:

| 参数 | 说明 | 范围 |
|------|------|------|
| 因子权重 | 各因子的配比 | 0-100% |
| 止损比例 | 最大可承受亏损 | 0-20% |
| 止盈比例 | 目标收益 | 0-50% |
| 持有天数 | 持仓周期 | 1-30天 |
| 仓位大小 | 单策略资金占比 | 0-100% |

### 策略对比

在 **策略 → 对比** 中可以并排比较 2-3 个策略:
- 因子雷达图
- 收益曲线叠加
- 风险指标对比

## 因子分析

### 因子热力图

**策略 → 因子分析 → 热力图**

展示 12 个市场 × 18 个类别 = 240 因子的实时强度:
- 🔥 红色 = 信号强烈
- 🟡 黄色 = 中性
- 🔵 蓝色 = 信号减弱

每个因子有 14 天迷你趋势线。

### 因子详情

点击任一因子查看:
- 当前信号值 (0-100)
- 14 天历史走势
- 关联策略模板
- 适用范围

## 交易执行

### 手动交易

**交易 → 下单面板**:

1. 选择品种 (股票/ETF/加密货币)
2. 选择方向 (买入/卖出)
3. 选择订单类型 (市价/限价/止损)
4. 输入数量
5. 确认下单

### 自动交易

策略配置完成后, 系统自动:
1. 在出信号时生成交易指令
2. 通过券商适配器执行
3. 实时监控订单状态
4. 记录到审计日志

### 跟单交易

**交易 → 跟单**:
- 选择要跟单的创作者
- 设置跟单比例
- 系统自动复制交易

## 回测系统

### 运行回测

**回测 → 新建回测**:

1. 选择策略模板
2. 设置回测区间 (起始日期 → 结束日期)
3. 设置初始资金
4. 点击 **开始回测**

### 回测结果

| 指标 | 说明 |
|------|------|
| 累计收益 | 回测期间的绝对收益率 |
| 年化收益 | 归一化年化收益率 |
| 夏普比率 | 风险调整后收益 |
| 最大回撤 | 最大峰值到谷底亏损 |
| 胜率 | 盈利交易占比 |
| 交易次数 | 总信号触发次数 |

### Walk-Forward 验证

步进前移 (Walk-Forward) 测试策略在不同市场环境下的稳定性, 防止过拟合。

## 风险管理

### 全局风控

**设置 → 风控设置**:

| 设置 | 说明 | 默认值 |
|------|------|--------|
| 单策略最大仓位 | 单个策略占总资金比例上限 | 20% |
| 日最大亏损 | 单日超过此限额停止交易 | 5% |
| 总杠杆上限 | 所有策略总杠杆倍数 | 3x |
| 止损模式 | 硬止损/移动止损/时间止损 | 硬止损 |

### 实时告警

异常检测 (`AnomalyAlertPanel.tsx`):
- 异常大单
- 价格剧烈波动
- 策略偏离
- 连接中断

## 常见问题

**Q: 数据会丢失吗?**
A: 不会。所有数据通过 ReliableIPC 传输 + SQLite WAL 模式持久化, 断网恢复零丢失。

**Q: 如何撤销操作?**
A: 支持 undo/redo, Ctrl+Z / Cmd+Z 撤销策略参数修改。

**Q: 费用如何计算?**
A: 详见费用目录 `QuantMoo-收费目录-v17.9.txt`。AI 服务按使用量计费。

**Q: 数据安全吗?**
A: API Key 加密存储 (AES-256-GCM), 敏感字段脱敏, 所有操作有审计日志追踪。
