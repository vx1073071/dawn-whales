## 第一部分: SourceSwitch — 手动切换行情源 UX

### 1.1 设计理念

```
自动选择 → 手动覆盖 → 用户信任

默认: broker priority 自动选最佳源（富途 > 华盛 > Tiger...）
用户: 右击 → 选择 "Tiger" → 该标的锁定使用 Tiger
      页面显示 "锁定: Tiger · 100ms" → 用户知道用的是哪个源
```

### 1.2 交互流程

```
┌─ 自选列表行 ──────────────────────────────────────────┐
│  HK.00700  腾讯  385.60  +2.30   🐂 富途·35ms  ···  │
│                                          ↑           │
│                                    点击源标签          │
│                                    或右键菜单          │
└──────────────────────────────────────────────────────┘
                        ↓
┌─ 行情源选择 Dropdown ─────────────────────────────────┐
│                                                      │
│  ○ 自动选择 (推荐)                                    │
│     → 富途 · 35ms                                     │
│                                                      │
│  ● 锁定: Tiger · 100ms        ← 当前选中              │
│                                                      │
│  ● 锁定: IBKR · 80ms           🔴 离线               │
│                                                      │
│  ● 锁定: 华盛 · 200ms                                 │
│                                                      │
│  ─────────────────────────────                        │
│  ⚠ 手动锁定将跳过自动故障切换                          │
│  [恢复自动选择]                                       │
└──────────────────────────────────────────────────────┘
```

### 1.3 状态流转

```
[自动]  broker priority 自动选           ← 默认
   │
   ├── 用户选 "Tiger" → [锁定:Tiger]
   │                       │
   │                       ├── Tiger 断开 → ⚠ "Tiger 已离线, 是否切回自动?"
   │                       │       ├── [是] → 回到 [自动]
   │                       │       └── [否] → 保持 [锁定:Tiger] + 🔴 无数据
   │                       │
   │                       └── 用户点 "恢复自动" → 回到 [自动]
   │
   └── 自动故障切换 (富途→备选) → [自动:备选] + 淡入动画
```

### 1.4 UI 组件约定

```typescript
// src/components/market/WatchlistRow 行内

// 每行尾部操作区:
const SourceTag = ({ item }: { item: WatchlistItem }) => {
  if (!item.brokerId) {
    // 自动模式 → 显示当前实际源 (来自 useQuoteSource)
    return <Tag color="green">🐂 富途 · 35ms</Tag>;
  }
  // 手动锁定模式 → 显示锁定图标
  return <Tag color="blue">🔒 {brokerName} · {latency}ms</Tag>;
};

// 右击菜单:
const ContextMenu = ({ item, onSelectSource, onResetAuto }) => (
  <Dropdown menu={{ items: buildSourceMenu(item) }}>
    <SourceTag item={item} />
  </Dropdown>
);
```

### 1.5 SourceSwitchAnimation — 切换动画

```typescript
// 已在 QuoteSourceBadge.tsx 中实现
// 触发条件: 主源超时/断连/手动切换/偏好切换

动画流程:
  0ms:     底部浮窗出现 "🐂 富途 → 🐯 Tiger  · 主源超时"
  0-2000ms: 淡入动画 (opacity 0→1, translateY)
```

## 第三部分: 新增交互行为说明

### 3.1 #6 添加后自动选中 K 线

```
行为: 用户点击 [+] 添加标的 → handleAddStock 调用后
      → setSelectedSymbol(code) 自动触发
      → K线图立即开始加载 (loadKlines)
      → 用户不需要再手动点击行

代码变更 (MarketPage.tsx):
  function handleAddStock(code: string) {
    addWatch(code);                     // 加入自选
    setShowSearch(false);               // 关闭搜索
    setSelectedSymbol(code);            // 🆕 自动选中 K 线
  }
```

### 3.2 #10 搜索结果带实时价格

```
搜索结果行新增:
┌─────────────────────────────────────────────────┐
│ HK.00700  腾讯控股  港股  HKEX                   │
│ 💰 385.60  🟢 +2.30 (+0.6%)    Vol: 45.2M       │← 🆕 价格预览
│ 🐂 富途·35ms  🐯 Tiger  🔴 IBKR                  │
│                                    [+] 添加     │
└─────────────────────────────────────────────────┘

实现: 搜索结果渲染前调用 GET /api/symbol/quote-preview?q=00700
      → 从 quote-cache 读取最新报价
      → 缓存命中(<100ms) → 即时显示
      → 缓存未命中 → 显示 '--' + 后台 fetch
```

### 3.3 #12 搜索历史

```
搜索框聚焦 → 下拉显示最近10条历史:

┌──────────────────────────────────────────────┐
│ 🔍 搜索代码或名称                              │
├──────────────────────────────────────────────┤
│ 🕐 腾讯 (HK.00700)    · 2分钟前              │
│ 🕐 AAPL (US.AAPL)     · 15分钟前             │
│ 🕐 BTC (CRYPTO.BTC)   · 1小时前              │
│ 🕐 9988 (HK.09988)    · 昨天                 │
├──────────────────────────────────────────────┤
│ [清除历史]                                    │
└──────────────────────────────────────────────┘

存储: localStorage['quant-moo-search-history']
      格式: [{query, symbol, market, timestamp}]
      上限: 10条 (FIFO)
      点击历史条目 → 自动填充搜索 → 执行搜索
```

### 3.4 #17 添加后即时反馈

```
click [+] → 3件事并行发生:
  1. addWatch(code)           → zustand store 更新 → 行立即出现
  2. fetchQuote(code)         → 实时价格填充        (100-500ms)
  3. setSelectedSymbol(code)  → K线图加载           (200-800ms)

中间状态:
  [0ms]       行出现在表格中, 价格显示 '--' (骨架闪烁)
  [150ms]     价格更新为上次缓存价 (如有)
  [300ms]     实时 WS 价格到达 → 价格从灰变绿 🔄
  [500ms]     K线图加载完成

不允许用户看到空白行超过 500ms
```
