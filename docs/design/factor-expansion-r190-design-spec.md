# Part A: 因子社交证明UI

## A.1 设计哲学

```
问题: 68个🟡因子，用户怎么挑？读75页说明书？
答案: "别人在用什么"是最快的决策依据。

社交证明三定律:
1. 从众 → "1,247人在用这个因子 = 它大概率有用"
2. 专家 → "验证用户推荐这个 = 它经得起考验"
3. 趋势 → "本周飙升 = 有新的因子被发现有效"
```

## B.5 推荐引擎算法 (UX视角)

```
推荐逻辑树:

用户进入 →
├─ 注册<30天 → 🌱新手 → 推荐场景包(牛市/熊市/震荡)
│  ├─ 市场🇭🇰 → 港股场景包(5🇭🇰因子)
│  ├─ 市场🇺🇸 → 美股场景包(5🇺🇸因子)
│  └─ 市场🪙 → 加密场景包(5🪙因子)
│
├─ 注册30-180天 → 🔧进阶 → 推荐热门因子+已用类似
│  ├─ 最近看了价值因子 → 推荐其他价值因子
```
