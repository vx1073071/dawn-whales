## 一、设计目标

建立一个量化指标，衡量用户对AI分析的"信任程度"以及AI对用户的"靠谱程度"，双向迭代提升AI顾问的粘性和可靠性。

## 二、双向信任模型

```
            用户对AI的信任 ←→ AI对用户的靠谱度
            
┌──────────────────┐       ┌──────────────────┐
│  用户AI信任分     │       │  AI靠谱指数       │
│  (User Trust AI)  │  ←→  │  (AI Reliability) │
│                  │       │                  │
│  用户越信任AI     │       │  AI越被验证准确   │
│  → 使用越频繁     │       │  → AI越被信任     │
│  → 付费意愿越高   │       │  → 留存越高       │
└──────────────────┘       └──────────────────┘
```

## 三、用户AI信任分 (User AI Trust Score 0-1000)

### 3.1 评分维度 (5维度 × 200分)

```
┌──────────────┬──────────────────────────────────────┐
│ 维度          │ 含义                满分            │
├──────────────┼──────────────────────────────────────┤
│ 使用频率(40%) │ 多频繁使用AI       200分            │
│ 采纳率(25%)   │ AI建议被采用了多少   200分           │
│ 验证率(15%)   │ 用户事后验证了多少   200分           │
│ 满意度(10%)   │ 👍👎反馈趋势        200分           │
│ 付费意愿(10%) │ 付费次数+金额       200分           │
└──────────────┴──────────────────────────────────────┘

总分 = freq×0.4 + adoption×0.25 + verify×0.15 + satisfaction×0.1 + payment×0.1
```

### 3.2 每维计分规则

#### 使用频率 (0-200, weight 40%)

```
指标: 最近30天AI交互次数 + 连续使用天数

  日交互≥3次 + 连续30天 → 200
  日交互1-2次 + 连续15-29天 → 150
  日交互0.5-1次 + 连续7-14天 → 100
  周交互2-3次 + 连续<7天 → 50
  偶尔使用 (<1次/周) → 25
  从未使用 → 0

衰减: 7天未使用 → -20分/天 (直到100)
```

#### 采纳率 (0-200, weight 25%)

```
指标: AI推荐了因子/权重 → 用户实际采用了多少

  采纳率 ≥80% → 200
  采纳率 50-79% → 150
  采纳率 20-49% → 100
  采纳率 5-19% → 50
  采纳率 <5% → 0

"采纳"定义:
  · 采用AI推荐的因子组合 (一键导入)
  · 按AI建议调整了权重
  · 点击"回测验证"后继续使用
```

#### 验证率 (0-200, weight 15%)

```
指标: 用户主动验证AI输出的频率

  验证行为:
  · 点击"看引擎数据"验证IC (每次+5分, 上限100)
  · 跑回测验证AI推荐 (每次+10分, 上限100)
  · 对比AI建议vs自己的策略 (每次+5分, 上限50)
  · 查看因子来源和数据日期 (每次+2分, 上限30)

满分200 = 持续核对 + 深入验证
```

#### 满意度 (0-200, weight 10%)

```
指标: 👍/👎 反馈 + NPS

  👍率 ≥90% → 200
  👍率 70-89% → 150
  👍率 50-69% → 100
  👍率 30-49% → 50
  👍率 <30% → 0

  踩后行为加权:
  踩了但继续使用 → +10 修正
  踩了且离开 → -20 惩罚
  连续5次👍 → +30 bonus
```

#### 付费意愿 (0-200, weight 10%)

```
指标: AI付费次数 + 金额

  付费≥20次 → 200
  付费5-19次 → 150
  付费1-4次 → 100
  免费但活跃 → 50
  从不付费 → 0

  付费金额加权:
  · 单次>5 USDT → ×1.2
  · 月度总消费>20 USDT → ×1.1
```

### 3.3 信任分等级

```
🟣 深度信任  (800-1000): "AI顾问已经是你的副驾驶了"
  → 解锁: 高级AI功能优先体验 + 99U包月AI无限使用

🔵 高度信任  (600-799): "你觉得AI挺靠谱的"
  → 解锁: 多轮对话 + 自定义AI模板

🟢 中度信任  (400-599): "将信将疑，但愿意试试"
  → 标准功能 (当前所有用户)

🟡 初阶信任  (200-399): "偶尔问问，不太当真"
  → 引导: 免费迷你诊断 + 新手教程

⚪ 未建立信任 (0-199): "还没用过AI或体验很糟"
  → 引导: 首次免费全功能体验
```

## 四、AI靠谱指数 (AI Reliability Index 0-100)

### 4.1 评分维度 (4维度)

```
┌──────────────┬──────────────────────────────────────┐
│ 维度          │ 含义                权重            │
├──────────────┼──────────────────────────────────────┤
│ 预测准确(35%) │ AI说IC=0.045, 验证确实是        35% │
│ 策略回测(30%) │ AI推荐的回测vs实际表现           30% │
│ 用户反馈(20%) │ 👍率                            20% │
│ 一致性(15%)   │ 上次建议和这次建议不矛盾         15% │
└──────────────┴──────────────────────────────────────┘
```

### 4.2 预测准确度 (0-100, weight 35%)

```
每次AI输出后:
  引擎交叉验证 → 偏差% = |AI值 - 引擎值| / max(|AI值|, |引擎值|)

  偏差 <5%  → +5
  偏差 5-10%→ +2
  偏差 10-20% → +0
  偏差 20-50% → -5
  偏差 >50% → -10 (触发拦截)

滚动30天平均值 → AI靠谱度的"预测准确"维度分
```

### 4.3 策略回测验证 (0-100, weight 30%)

```
AI推荐因子组合后30天:
  · 实际Sharpe vs 预测Sharpe偏差 <10% → +10
  · 实际MaxDD vs 预测MaxDD 偏差 <20% → +10
  · 实际IC vs 预测IC 偏差 <20% → +5

用户在每个策略30天后看到验证报告:
  "30天前AI预测Sharpe=1.42, 实际=1.38 (偏差-2.8%) ✓ 在预期范围内"
```

### 4.4 用户反馈 (0-100, weight 20%)

```
滚动30天 👍率 → 直接映射 0-100
👍率 = 👍总数 / (👍总数 + 👎总数)
```

### 4.5 一致性 (0-100, weight 15%)

```
连续3次对同一用户的推荐:
  · 核心因子推荐一致 → +10
  · 权重漂移 <15% → +5
  · 截然矛盾 → -20

目的: 防止AI"反复横跳"降低用户信任
```

## 六、后端数据结构

```typescript
interface UserAITrustProfile {
  userId: string;
  
  // 用户信任分
  trustScore: number;  // 0-1000
  trustLevel: 'deep' | 'high' | 'moderate' | 'beginner' | 'none';
  
  // 5维度细分
  dimensions: {
    frequency: { score: number; dailyAvg3D: number; streakDays: number };
    adoption: { score: number; totalAdopted: number; totalRecommended: number; rate: number };
    verification: { score: number; verifyActions30d: number };
    satisfaction: { score: number; thumbsUp30d: number; thumbsDown30d: number; };
    payment: { score: number; paidCount: number; totalPaidUSDT: number };
  };
  
  // AI靠谱指数 (用户视角)
  aiReliability: {
    score: number;  // 0-100
    predictionAccuracy: number;
    backtestAccuracy: number;
    feedbackRate: number;
    consistency: number;
  };
  
  // 决策日志
  decisions: Array<{
    id: string;
    timestamp: number;
    intent: string;
    recommendation: string;
    adopted: boolean;
    verificationResult?: { 
      predicted: number; actual: number; deviation: number; 
    };
    trustDelta: number;
  }>;
  
  lastUpdated: number;
}
```

## 七、信任分生命周期

```
新用户 (0分)
  │
  ├→ 首次AI使用 → +10 (完成知情确认)
  ├→ 第一次采纳 → +30 (信任的起点)
  ├→ 连续7天使用 → +50 (养成习惯)
  │
  ├→ ...
  │
  ├→ 100分: 解锁免费迷你诊断
  ├→ 200分: 解锁验证提示 ("看看引擎数据")
  ├→ 400分: 多轮对话
  ├→ 600分: 自定义AI模板
  ├→ 800分: 高级功能优先体验
  └→ 900分: 99U包月AI无限使用

衰减:
  30天未使用 → 分数减半
  60天未使用 → 重置为50分
  踩后连续3次 → -30分
```

## 九、隐私保护

```
1. 信任分是用户个人数据 → 不对其他用户可见
2. 决策日志 → 仅用户自己可查看
3. AI靠谱指数 → 脱敏后可用于团队统计 (不关联具体用户)
4. 不与任何第三方共享信任数据
5. 用户可随时在设置中删除所有AI交互历史 → 信任分重置为0
```
