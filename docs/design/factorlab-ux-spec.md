## 二、拖放交互规范

### 2.1 拖放源: 因子库

**可拖放元素**: 每个因子卡片(或列表项)

```
┌────────────────────┐
│ 🟢 动量 MOM_12M    │  ← 拖放手柄 (6px grip dots 左侧)
│ IC: 0.045 机械     │
└────────────────────┘
```

**拖放状态**:
1. **待机**: 正常因子卡片样式
2. **Hover**: 边框高亮金色(#d4a574), 手柄出现
3. **拖拽中 (Drag)**: 半透明(0.6 opacity)+ 尺寸缩小 → 跟随鼠标的影子
4. **拖拽有效 (DragOver)**: 目标区域显示蓝色虚线框 + 闪烁提示
5. **拖拽无效 (DragOver invalid)**: 目标区域显示红色虚线框 + 禁止图标
6. **放下 (Drop)**: 插入动画(放大+淡入, 200ms ease-out)

**拖放规则**:
- ✅ 可拖放到: 工作区 (权重列表)
- ❌ 不可拖放到: 因子库自身 (同一因子不重复添加)
- ❌ 不可拖放到: 反馈面板、操作面板
- 已存在的因子: 灰色禁用, 显示"已添加"标记
- 最多添加: 8个因子 (超出提示 "最多添加8个因子")

### 2.2 拖放目标: 工作区

**放下区域状态**:
- **空状态**: "拖放因子到这里开始构建策略" (大号占位提示+箭头动画)
- **有内容**: 因子权重列表, 每个因子可拖拽排序
- **Accept indicator**: 鼠标进入时边框脉冲动画 (2s循环)

**因子卡片 (在工作区中)**:
```
┌──────────────────────────────────────────────┐
│ ⋮⋮  🟢 动量 (MOM_12M)              [× 移除] │  ← 顶部栏
│                                              │
│  权重: ═══════●═══════  30%    [+][-]       │  ← 权重滑块
│                                              │
│  IC: 0.045 | IR: 0.72 | 半衰期: ~38天       │  ← 底部信息
└──────────────────────────────────────────────┘
```

### 2.3 排序拖放

在工作区内可以拖放因子卡片调整顺序:
- 拖拽手柄: 左侧 ⋮⋮ (6px grip dots)
- 插入指示器: 蓝色水平线显示目标位置
- 放置后: 所有卡片平滑位移 (transition: transform 200ms)

## 五、撤销/重做系统

### 5.1 可撤销操作

| 操作 | 撤销行为 |
|------|----------|
| 添加因子 | 移除该因子 |
| 移除因子 | 恢复该因子 (含原权重) |
| 修改权重 | 恢复原权重值 |
| 拖放排序 | 恢复原顺序 |
| 批量操作 | 一步撤销整个批量 |
| 应用预设 | 恢复应用前的配置 |

### 5.2 实现要求

```
┌─────────────────────────────────────────┐
│ 撤销历史 (最多10步)                      │
│                                         │
│  当前: [0] 动量 30% / 质量 25%...       │
│                                         │
│  [1] 添加"低贝塔" 权重15%    ← 可撤销   │
│  [2] 修改动量权重 25%→30%    ← 可撤销   │
│  [3] 应用"均衡型"预设         ← 可撤销   │
│  [4] ... (超过10步自动丢弃最早)          │
│                                         │
│  Ctrl+Z 撤销  |  Ctrl+Y 重做            │
└─────────────────────────────────────────┘
```

**技术规范**:
- 撤销栈: `Array<WorkspaceSnapshot>` (max 10)
- 重做栈: 执行撤销时推入, 任何新操作清空重做栈
- 存储内容: `{ factors: FactorWeight[], timestamp: number }`
- 去抖: 权重滑块拖动时200ms内不记录中间状态 (记录最终值)

## 八、工作区交互细节

### 8.1 新增因子 (3种方式)

1. **拖放**: 因子库 → 工作区 (2.1节)
2. **双击**: 因子库中双击因子卡片 → 自动添加到工作区末尾, 权重=均分
3. **右键菜单**: 因子库右键 → "添加到工作区"

### 8.2 移除因子 (3种方式)

1. **点击×按钮**: 因子卡片右上角
2. **右键 → 移除**
3. **选中 + Delete键**

移除后权重自动重新均分给剩余因子 (如果只有一个, 移除后无法均分→提示)

### 8.3 权重调整

```
滑块拖拽规则:
- 拖拽一个滑块 → 其余同比例缩放 (保持 sum=100%)
- 手动输入数值 → 其余同比例缩放
- +/- 按钮 (1%步长) → 其余同比例缩放
- 锁定因子 (右键 → 固定权重) → 被锁定的权重不变, 其余同比例缩放
```

**锁定因子**:
- 显示 🔒 图标
- 滑块变灰, 不可拖拽
- 其他因子调整时, 锁定因子权重不变
- 再次右键 → "解锁"

### 8.4 权重异常处理

- 总和 < 100%: 底部显示橙色 "当前权重总和 92%, 建议调整到100%"
- 总和 < 80%: 底部显示红色 "权重严重不足, 大量资金未分配"
- 单一因子 > 60%: 该因子卡片高亮橙色 "该因子占比过高, 风险集中"
- 无因子: "至少添加2个因子开始" (禁用回测按钮)

## 十、移动端适配

### 10.1 移动端 (<768px)

- 因子库: 底部Tab栏切换 (📊因子库 | ⚙️配置 | 📈结果)

- 快捷键: 不可用 (提示 "桌面端支持更多快捷键操作")

- 拖放: 支持 (但不显示动画以减少性能开销)
- 快捷键: 部分支持 (需要外接键盘)
