### 分润计算逻辑 (仅盈利时显示)

```typescript
function calculatePreview(config: CopyTradeConfig, price: number, qty: number) {
  const total = price * qty;
  const commission = getCommission(config.brokerId, total);  // 券商佣金
  const secFee = getSECFee(total);                            // SEC规费
  const platformFee = total * getPlatformRate(config.brokerId); // 平台费
  // 分润仅在平仓盈利时计算，开仓不显示
  return { total, commission, secFee, platformFee, grandTotal: total + commission + secFee + platformFee };
}
```

## 二、撤单交互

```
信号队列 → 待处理信号列表 → 每条有操作按钮

┌──────────────────────────────────────────────────────┐
│ ⏳ 待处理信号                                        │
│                                                      │
│ ┌──────────────────────────────────────────────────┐ │
│ │ 🔴 P0 止损  BTC/USDT SELL 0.1                    │ │
│ │ 信号源: AlphaQuant · 价格: $65,000 · 3秒前        │ │
│ │                              [撤单] [确认执行]    │ │
│ └──────────────────────────────────────────────────┘ │
│ ┌──────────────────────────────────────────────────┐ │
│ │ 🟡 P1 跟单  ETH/USDT BUY 1.5                     │ │
│ │ 信号源: BetaTrend · 价格: $3,200 · 12秒前         │ │
│ │                              [撤单] [确认执行]    │ │
│ └──────────────────────────────────────────────────┘ │
└──────────────────────────────────────────────────────┘

点击[撤单]:
  → 弹出确认: "确定取消此跟单? 信号可能仍有效。"
  → [确定取消] [返回]
  → 调 PATCH /api/signal/:id/cancel
  → 状态变为 cancelled

确认执行(含5秒倒计时):
  → 弹出试算弹窗
  → 5秒倒计时
  → [确认下单] 可点击
```

## 三、手动模式 vs 自动模式

```
用户选择:
  ○ 自动执行 — 信号到达→自动下单(仅需首次配置)
  ● 手动确认 — 每个信号弹出试算弹窗, 需人工确认

默认: 新用户手动确认, 老用户可切自动
```
