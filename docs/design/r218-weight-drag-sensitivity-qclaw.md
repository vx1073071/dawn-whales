### 1.2 拖拽行为规则

| 规则 | 行为 | 说明 |
|------|------|------|
| 拖拽增重 | 拖出一块扇形→该因子+5%, 其他按比例缩 | 实时归一化 |
| 拖拽减重 | 拖入一块扇形→该因子-5%, 其他按比例扩 | 最少保留1% |
| 双击锁定 | 双击因子→切换🔒锁定状态 | 锁定后不可拖拽 |
| 权重<5% | 橙色警告 "权重过低，建议移除" | 可继续保留 |
| 权重>50% | 红色警告 "过度依赖单一因子" | ⚠️提醒但不禁用 |
| 恢复默认 | 一键恢复铁律定义的默认权重 | 确认对话框 |

### 1.3 自动归一化逻辑

```typescript
// 用户拖动因子i到新权重newWeight
function normalizeWeights(weights: number[], locked: boolean[], i: number, newWeight: number): number[] {
  const oldOthers = weights.filter((_, idx) => idx !== i && !locked[idx]);
  const totalOthers = oldOthers.reduce((a, b) => a + b, 0);
  const remaining = 100 - newWeight - locked.reduce((s, l, idx) => s + (l ? weights[idx] : 0), 0);

  return weights.map((w, idx) => {
    if (locked[idx]) return w;
    if (idx === i) return newWeight;
    return Math.round((w / totalOthers) * remaining);
  });
}
```

### 1.4 颜色编码

| 状态 | 颜色 | 含义 |
|------|------|------|
| 正常 (5%-50%) | 主题色 | 合理权重 |
| 锁定 🔒 | 灰色 + 🔒图标 | 铁律锁定不可改 |
| 过低 (<5%) | 🟠橙色脉冲 | 建议移除 |
| 过重 (>50%) | 🔴红色闪烁 | 过度依赖风险 |

## 二、参数敏感性热力图说明

### 2.1 核心概念（人话）

> 💬 **一句话**: "热力图告诉你：调哪个参数影响最大，哪个参数无所谓。"

```
比喻:
  你有一台收音机，上面有3个旋钮(参数)
  - 调频率旋钮→声音立刻变(NOT sensitive)
  - 调音量旋钮→声音变化明显(BUT expected)
  - 调音调旋钮→有的位置完美，偏离一点点就全是噪音(OVERFIT! 🔴)
  
  第三个旋钮就是过拟合参数——你在历史数据上恰好调到了最佳位置，
  但市场稍微变一点，这个"最佳位置"就不存在了。
```

### 2.2 色阶含义

```
🟢 绿色 (稳定区)
  "参数在一定范围内变化，策略表现保持稳定。策略健壮，实盘可期。"

🟡 黄色 (敏感区)
  "参数变化对策略表现有中等影响。需要关注，但不致命。"

🔴 红色 (过拟合区)
  "参数微调→结果剧变！说明策略在这个参数上过度优化了。
   实盘这个'最优值'很可能失效。建议简化此参数。"
```
