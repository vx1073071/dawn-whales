## 📋 概述

v17.6 是一次**全面重写**的盈利模型。与 v15 相比，所有核心计费维度都发生了变化。v17.6 是 quant-moo 的永久收费规则，不可再修改。

## 🔄 变更详情 (v15 → v17.6)

### 一、交易手续费: 从 Taker/Maker/Stop 分离 → 5 类资产统一

| 维度 | v15 (旧) | v17.6 (新) |
|------|---------|-----------|
| 分类方式 | 按订单类型 (taker/maker/stop) | 按资产类型 (5类) |
| 股票 Taker | 0.1% | → 股票/ETF 统一 0.1% |
| 股票 Maker | 0.02% | → 合并到 0.1% |
| Stop 订单 | 0.04% | → 取消独立费率 |
| 加密现货 | 0.1% | 0.1% (不变) |
| 加密合约 | 0.02% | 0.02% (不变) |
| 最低费 | 无明确定义 | 股票/期货/期权/现货: 2 U; 合约: 0.5 U |
| 新增 | — | 期权交易 (0.1%, min 2 U) |
| 免费交易 | Futu 基础订单免费 | ❌ 取消。所有交易收费 |

**影响**: 无法再通过 limit order 节省 80% 手续费 (0.02% → 0.1%)。简化计费逻辑。

### 三、创作者市场: 从订阅者数 + 收入升级 → 纯销量升级

| 维度 | v15 (旧) | v17.6 (新) |
|------|---------|-----------|
| L1 条件 | 默认 | 默认 |
| L2 条件 | ≥100 订阅者 **或** ≥1,000 U 收入 | **≥100 笔累计销量** |
| L3 条件 | ≥1,000 订阅者 **或** ≥10,000 U 收入 | **≥1,000 笔累计销量** |
| L1 平台抽成 | 30% (创作者得 70%) | 30% (不变) |
| L2 平台抽成 | 10% (创作者得 90%) | **20% (创作者得 80%)** |
| L3 平台抽成 | 5% (创作者得 95%) | **10% (创作者得 90%)** |
| 升级方式 | 订阅者数 OR 收入 (自动) | **纯销量 (自动)** |

**影响**:
- **L2/L3 平台抽成增加了**: L2 从 10%→20%, L3 从 5%→10% (平台多赚)
- **升级条件从两选一变为单一维度**: 不再看粉丝数，只看销售实绩
- v15 抽成方向与 v17.6 相反! v15 是 L1 平台最多(30%) → v17.6 也是 L1 平台最多(30%)

### 四、转账 vs 打赏: 从模糊 → 完全分离

| 维度 | v15 (旧) | v17.6 (新) |
|------|---------|-----------|
| 转账发送方 | 0.3% | 0.3% (不变) |
| 转账接收方 | 0.3% | 0.3% (不变) |
| 打赏逻辑 | **未定义 (与转账混淆)** | 按创作者等级抽成 L1:30%/L2:20%/L3:10% |
| 内部转账 | 免费 | **取消免费，走转账费** |

**影响**: 打赏和转账现在是两套完全独立的计费管道。打赏由「发送方付全额→平台抽成→创作者得剩余」。转账由「发送方和接收方各付 0.3%」。

## ⚠️ 破坏性变更 (Breaking Changes)

1. **Limit order 不再有 80% 折扣**: maker 0.02% → 统一 0.1%
2. **AI 不再有免费额度**: 新用户 3 次免费 → 0 次
3. **AI 不再有月费上限**: 无法设置 5/10/50/100 U 月度预算
4. **创作者 L2/L3 平台抽成增加**: L2 10%→20%, L3 5%→10%
5. **创作者升级条件变更**: 订阅者数不再计入，只看销量
6. **内部转账取消免费**: 内部转账也要收 0.3%×2
7. **打赏从创作者等级抽成**: 发送方不再额外付费，平台从金额中抽
8. **提现最低费从 10 U 降至 2 U**: 对小额提现更友好
