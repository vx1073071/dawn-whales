> 制定: QClaw(设计虾) | 版本: v1.0 | 日期: 2026-06-14
> 任务: R172 B1辅助 | 工时: 3h | 配合: ML B1前端实现

---

## 一、设计目标

让一个**完全不懂因子投资的新手**在3分钟内完成:
1. 找到适合自己的投资风格
2. 理解推荐了哪些因子以及为什么
3. 看到这些因子组合的预期表现

**3分钟时间预算**:
- 步骤1 (选风格): 60秒 — 5选1, 直觉驱动
- 步骤2 (确认因子): 90秒 — 展示结果+可调整
- 步骤3 (回测预览): 30秒 — 信心确认

## 二、5种投资风格定义

### 风格1: 稳健型 (Conservative)

```
┌──────────────────────────────────────────────┐
│  🛡️ 稳健型                                   │
│                                              │
│  "不求大赚，但求不亏。适合资金量大、           │
│   风险承受低、希望稳定增值的投资者。"           │
│                                              │
│  关键词: 低波动 · 高质量 · 低回撤 · 分红稳定  │
│                                              │
│  典型年化: 8-12%                             │
│  典型回撤: <10%                              │
│  适合: 退休金、大额资金、保守型投资者          │
│                                              │
│  ⚠️ 风险提示: 牛市可能跑输大盘，不适合追求     │
│     高收益的年轻投资者                        │
└──────────────────────────────────────────────┘
```

**推荐因子** (权重):
- 低波动 (VOL_60D) — 30%
- 质量 (ROE_TTM) — 25%
- 股息率 (DivYield) — 20%
- 低Beta (neg BETA) — 15%
- 流动性 (Turnover) — 10%

**一句话**: "不追求最高收益，但追求最稳定的增长——适合'睡得着觉'的投资"

---

### 风格2: 成长型 (Growth)

```
┌──────────────────────────────────────────────┐
│  🚀 成长型                                   │
│                                              │
│  "寻找高增长潜力的公司，愿意承受短期波动       │
│   来换取更高的长期收益。"                       │
│                                              │
│  关键词: 高增长 · 盈利加速 · 研发投入· 新经济  │
│                                              │
│  典型年化: 15-25%                            │
│  典型回撤: 15-25%                            │
│  适合: 年轻投资者、长期持有、看好科技赛道       │
│                                              │
│  ⚠️ 风险提示: 高估值回调风险大，加息周期        │
│     表现差，不适合临近用钱的投资者              │
└──────────────────────────────────────────────┘
```

**推荐因子** (权重):
- 盈利增长 (EPS_Growth) — 30%
- 营收增长 (RevGrowth) — 25%
- 研发强度 (R&D/Sales) — 15%
- 动量 (MOM_12M) — 20%
- 毛利率 (GrossMargin) — 10%

**一句话**: "赌未来高增长——押注那些今天还小、明天可能很大的公司"

---

### 风格3: 价值型 (Value)

```
┌──────────────────────────────────────────────┐
│  💰 价值型                                   │
│                                              │
│  "买便宜货。等待市场发现被低估的好公司，        │
│   耐心持有到价值回归。"                         │
│                                              │
│  关键词: 低估值 · 高安全边际 · 逆向投资· 耐心  │
│                                              │
│  典型年化: 10-18%                            │
│  典型回撤: 10-20%                            │
│  适合: 有耐心的投资者、逆向思维、熊市表现好     │
│                                              │
│  ⚠️ 风险提示: 可能长期不涨(价值陷阱)，          │
│     牛市跑输，需要极强耐心(1-3年等待)           │
└──────────────────────────────────────────────┘
```

**推荐因子** (权重):
- 低市盈率 (E/P) — 30%
- 低市净率 (B/P) — 25%
- 低市销率 (S/P) — 15%
- 高股息率 (DivYield) — 15%
- 低波动 (VOL_20D) — 15%

**一句话**: "去打折区淘宝——买的是便宜，等的是均值回归"

---

### 风格4: 动量型 (Momentum)

```
┌──────────────────────────────────────────────┐
│  🏄 动量型                                   │
│                                              │
│  "强者恒强。追涨的比抄底的赚得多，             │
│   跟随市场趋势而不是对抗它。"                   │
│                                              │
│  关键词: 趋势跟踪 · 追涨杀跌 · 快速交易· 灵活  │
│                                              │
│  典型年化: 18-30%                            │
│  典型回撤: 20-35%                            │
│  适合: 趋势交易者、技术分析派、牛市中表现强     │
│                                              │
│  ⚠️ 风险提示: 趋势反转时大幅回撤，             │
│     震荡市频繁止损，不适合长期静态持有          │
└──────────────────────────────────────────────┘
```

**推荐因子** (权重):
- 动量 (MOM_12M) — 35%
- 短期动量 (MOM_1M) — 25%
- 波动率调整动量 (VOL_20D) — 20%
- 成交额 (Turnover) — 10%
- 资金流向 (NetFlow) — 10%

**一句话**: "跟着趋势冲浪——不预测顶和底，只跟随市场的方向"

---

### 风格5: 高股息型 (High Dividend)

```
┌──────────────────────────────────────────────┐
│  💸 高股息型                                 │
│                                              │
│  "稳定收租。寻找持续高分红的好公司，            │
│   享受被动现金流收入。"                         │
│                                              │
│  关键词: 高分红 · 现金流 · 防御型 · 长期持有  │
│                                              │
│  典型年化: 6-10% (含分红)                     │
│  典型回撤: <15%                              │
│  适合: 退休人士、追求被动收入、熊市避险         │
│                                              │
│  ⚠️ 风险提示: 成长性不足，牛市中大幅跑输，      │
│     低利率环境可能被高收益债替代                │
└──────────────────────────────────────────────┘
```

**推荐因子** (权重):
- 股息率 (DivYield) — 35%
- 股息稳定性 (DivStability) — 25%
- 自由现金流 (FCFYield) — 15%
- 低波动 (VOL_60D) — 15%
- 质量 (ROE_TTM) — 10%

**一句话**: "像收房租一样收股息——不问股价涨跌，每月有钱进账"
