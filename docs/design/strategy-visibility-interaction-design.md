# TradingEasy 策略可见性交互设计规范

> 版本: v1.0 | 日期: 2026-06-15 | 作者: QClaw(设计虾)
> 任务: R179 P1 UX安全收尾 | 工时: 2h
> 范围: FactorLab可见性控制 + 分享导出 + 市场发布 + 权限流转

---

## 一、设计目标

让用户在**创作时自由、分享时安全、发布时可控**。不增加认知负担，但杜绝策略泄露。

### 核心原则
- **默认最安全**: 新建策略默认为"创作模式"(仅自己可见)
- **有意识分享**: 每次分享需用户主动确认，不允许静默分享
- **渐进披露**: 陌生人→购买者→创作者，逐步看到更多
- **最小暴露**: 默认只展示"证明实力"需要的最少信息

## 四、分享导出交互

### 4.1 导出按钮

```
│ 📱 分享图片 (PNG) │  ← 自动加水印+模糊权重
│ 🔗 复制分享链接    │  ← 生成临时链接(7天有效)
│ 📋 复制策略摘要    │  ← 纯文本，无精确数据
│ 📄 导出完整数据    │  ← JSON (仅创作模式, 需确认)
└──────────────────┘
```

### 4.2 分享图片 (PNG) 自动处理

```
导出PNG自动应用以下规则 (无需用户操作):

原始策略数据 → 分享安全处理:
  • 因子名: 全部显示 (MOM_12M, ROE_TTM, VOL_60D)
  • 权重: 前3个正常显示，其余显示 "···"
  • 回测曲线: 显示但Y轴不标数值，仅显示形状
  • Sharpe: 显示范围 (1.0-1.5) 而非精确 1.34
  • 年化收益: 显示范围 (15%-20%) 而非精确 17.8%
  • MaxDD: 显示范围 (-15%~-10%) 而非精确 -12.3%

自动叠加:
  • 水印: "仅供展示 · 非完整策略" (40% opacity, 45°倾斜, 平铺)
  • 品牌: "TradingEasy" logo (右下角, 30% opacity)
  • 创作者: @AlphaQuant (左下角)
  • 日期: 2026-06-15 (左下角)
  • 声明: "完整策略请访问 TradingEasy 策略市场" (底部居中)
```

## 六、分享链接安全

### 6.1 链接生成规则

```
分享链接格式:
  https://tradingeasy.io/share/strat_{shortId}

安全属性:
  • 7天有效期 (可配置)
  • 单次点击验证码 (防爬虫批量)
  • 查看计数 (创作者可见: 123人看过)
  • 不可预测ID (UUID v4 前8位)
  • 若策略已下架或删除 → 显示 "此策略已不可用"
  • CloudFlare rate limiting: 同一IP 10次/分钟
```

### 6.2 链接失效处理

```
失效原因 → 用户看到的:

策略已删除:
  "该策略已被创作者删除。"

分享已撤回:
  "该分享链接已失效。创作者收回了分享权限。"

链接过期:
  "该分享链接已过期 (7天)。请向创作者获取新链接。"

策略已下架:
  "该策略已从市场下架，不再出售。"
```

## 七、市场发布流程安全

### 7.1 上架风控

```
上架前自动检查:
  1. ✅ 策略名称不含违规词
  2. ✅ 策略描述 ≥ 10字符
  3. ✅ 定价在允许范围 ($9.9 - $999)
  4. ✅ 因子数量 ≥ 2
  5. ✅ 策略未被其他创作者锁定
  6. ✅ 创作者身份已验证

上架后:
  7. 7天内不可更改定价 (防 bait-and-switch)
  8. 已有购买者保留访问权 (永远)
```

### 7.2 下架处理

```
下架: 创作者主动 / 平台审核
已购买者: 保留永久访问权 (已支付费用)
新用户: 不可再购买
市场列表: 移除
搜索结果: 不显示
```

## 九、异常场景处理

### 9.1 竞对抓取防护
- 分享链接需人机验证 (CloudFlare Turnstile)
- 单IP 10次/分钟
- 异常高频访问 → 临时限流 + 审计告警

### 9.2 策略抄袭举报
- 公开模式页面增加 [🚩 举报抄袭] 按钮
- 举报入口: 策略详情页 → 更多 → 举报
- 平台人工审核 → 确认后下架

### 9.3 API直接调用 (非UI路径)
- 引擎层: 策略数据API返回前检查调用者的可见性权限
- 不信任前端传的"mode"参数 → 服务端根据userId+策略归属+购买状态决定返回什么
