## 一、核心概念 · 一句话版

| 概念 | 一句话 |
|------|--------|
| 因子衰减 | "因子的预测能力会随时间流逝——今天有效的因子,明天可能就失效了" |
| 机械因子 | "由客观数据计算出来的因子(动量/波动/价值),失效是渐进的、可预测的" |
| 判断因子 | "涉及人主观判断的因子(情绪/分析师/宏观),失效可能是突然的" |
| 双曲衰减 | "机械因子的衰减像曲线一样先快后慢——第一周降最快,之后逐渐平稳" |

## 三、L2 面板解释 (详情面板, ~80字/条)

### 3.1 机械因子是什么？

> 机械因子完全由客观数据计算:价格、成交量、财报数字...
> 它们不依赖任何人的主观判断。
> 因为底层数据不会'撒谎',机械因子的衰减是可预测的:
> 刚开始几天失效最快,之后衰减速度逐渐放缓。
>
> 例子: 动量(MOM)、波动率(VOL)、市值(SMB)、账面市值比(HML)

### 3.2 判断因子是什么？

> 判断因子涉及人:分析师预测、新闻情绪、宏观判断...
> 人的认知会突然改变 — 一个黑天鹅事件、
> 一篇重磅新闻、一次政策转向,能瞬间让判断因子失效。
> 所以判断因子的衰减不如机械因子那么平滑可预测,
> 需要更频繁的监控和更快的反应。
>
> 例子: 分析师评级、新闻情绪、宏观预期、社交媒体热度

### 3.3 双曲衰减怎么理解？

> 想象一杯热咖啡的降温:
> 刚倒出来时凉得最快(因为跟室温温差大),
> 越接近室温,凉得越慢。
>
> 因子的预测能力也是类似的——
> 今天刚发现的因子最'新鲜',预测力最强;
> 过了一周,大部分额外信息已经被市场定价,
> 剩余的有效期可以持续很久,但贡献越来越小。
>
> 这就是双曲衰减: 先快后慢,永不完全归零。

## 四、L3 技术解释 (展开面板, 给有基础的投资者)

```
┌─────────────────────────────────────────────────────┐
│ 双曲衰减公式                                        │
│                                                     │
│  IC(t) = IC₀ / (1 + k·t)                           │
│                                                     │
│  IC₀  = 因子当前的IC值                               │
│  k    = 衰减速率 (机械因子k<判断因子k)                │
│  t    = 距离因子发现的天数                           │
│                                                     │
│  半衰期 t½ = 1/k  (IC跌到一半所需天数)              │
│  • 动量因子: t½ ≈ 30-60天                           │
│  • 波动因子: t½ ≈ 20-40天                           │
│  • 新闻情绪: t½ ≈ 3-7天  (衰减极快!)               │
│                                                     │
│  机械 vs 判断因子的衰减差异:                         │
│  ┌──────────┬──────────────┬──────────────┐         │
│  │          │  机械因子    │  判断因子    │         │
│  ├──────────┼──────────────┼──────────────┤         │
│  │ 衰减模式 │ 平滑双曲     │ 阶梯式/突变  │         │
│  │ 可预测性 │ 高 (R²>0.8) │ 低 (R²<0.4) │         │
│  │ 半衰期   │ 20-60天      │ 3-14天       │         │
│  │ 监控频率 │ 周级别即可    │ 日级别必须   │         │
│  └──────────┴──────────────┴──────────────┘         │
└─────────────────────────────────────────────────────┘
```

## 五、因子分类对照表 (44因子分类)

### 5.1 机械因子 (数据驱动, 双曲衰减模型适用)

| 分类 | 因子 | 典型半衰期 | 衰减特点 |
|------|------|-----------|----------|
| **动量** | MOM_12M, MOM_6M, MOM_1M | 30-60天 | 中速衰减,受市场趋势影响 |
| **波动** | VOL_60D, VOL_20D, LowVol | 20-40天 | 较快衰减,受市场情绪影响 |
| **价值** | B/P, E/P, S/P, DivYield | 40-80天 | 慢衰减,基本面变化慢 |
| **质量** | ROE, ROA, 毛利率, 负债率 | 50-90天 | 最慢衰减,财报季度更新 |
| **规模** | SMB, 市值 | 30-50天 | 中等衰减 |
| **流动性** | Amihud, Turnover | 15-30天 | 较快衰减,跟随交易量 |
| **杠杆** | Debt/Equity, InterestCover | 40-60天 | 慢衰减 |
| **加密** | FundingRate, OIDelta, NVT | 5-15天 | 极快衰减,加密市场节奏快 |

### 5.2 判断因子 (认知驱动, 双曲衰减模型仅参考)

| 分类 | 因子 | 典型有效期 | 衰减特点 |
|------|------|-----------|----------|
| **情绪** | 新闻Sentiment, 社交媒体热度 | 1-5天 | 突变衰减,极易受事件冲击 |
| **分析师** | 评级变化, 盈利预测修正 | 7-14天 | 跟随研报发布周期 |
| **宏观** | GDP预期, 利率预期, 政策判断 | 不定 | 低频变化,但变化时幅度大 |
| **拥挤度** | 持仓拥挤, 因子拥挤 | 3-10天 | 快速衰减,跟随资金流 |
