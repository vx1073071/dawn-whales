## 一、设计目标

用户在使用因子分析、策略回测等功能时，需要明确知道：
- **这个数据是真实的还是模拟的？**
- **模拟数据不能用于实盘决策** ← 关键认知

当前问题：大量 `isSimulated=true` 的因子数据被标记在引擎层，但**前端完全不展示**，用户无法判断数据可靠性。

### 设计原则
1. **诚实 > 好看** — 先确保信息传达，再追求美观
2. **不打扰但不可忽视** — 正常使用时不碍眼，但绝不让用户错过
3. **渐进教育** — 第一次看到时解释含义，后续简洁显示

## 二、三色标签定义

### 2.1 标签规格

| 等级 | 颜色 | 色值 | 图标 | 含义 | 场景 |
|------|------|------|------|------|------|
| 🟢 REAL | 绿色 | `#4CAF50` | ✓ 实盘数据 | 来自真实行情源/API/本地缓存，可用于实盘决策 | 券商API接入、真实ETF价格、实时行情 |
| 🟡 SIMULATED | 琥珀色 | `#FF9800` | ◇ 模拟数据 | 基于历史统计建模生成，仅供研究参考，不可用于实盘 | 因子IC估算、未接入券商的历史数据、统计推断 |
| 🔴 MOCK | 红色 | `#F44336` | ✗ 占位数据 | 硬编码/固定值/随机值，纯占位，不应在任何场景使用 | 未完成的功能、TODO标记、临时占位 |

### 2.2 色值详细规范

```
🟢 REAL (#4CAF50)
   bg: rgba(76, 175, 80, 0.12)    // 半透明绿底
   border: 1px solid rgba(76, 175, 80, 0.3)
   text: #4CAF50
   dot: 8px solid #4CAF50 (圆点)

🟡 SIMULATED (#FF9800)
   bg: rgba(255, 152, 0, 0.10)
   border: 1px solid rgba(255, 152, 0, 0.25)
   text: #FF9800
   dot: 8px solid #FF9800

🔴 MOCK (#F44336)
   bg: rgba(244, 67, 54, 0.10)
   border: 1px solid rgba(244, 67, 54, 0.25)
   text: #F44336
   dot: 8px solid #F44336
```

### 2.3 暗色主题适配 (TradingEasy 暗色主题)

```
页面背景: #1a1a2e (深蓝黑) / 卡片: #16213e
REAL bg: rgba(76, 175, 80, 0.15)  — 色调略深以配合暗底
SIMULATED bg: rgba(255, 152, 0, 0.12)
MOCK bg: rgba(244, 67, 54, 0.12)
text保持原色值不变（暗底上绿色/琥珀/红可读性已足够）
```

## 三、标签形态（3种尺寸）

### 3.1 标准标签（策略详情页、因子卡片）

```
┌──────────────────┐
│ 🟢 实盘数据       │  ← 24px高，带圆点+文字
└──────────────────┘
   ┌──────────────────┐
   │ 🟡 模拟数据       │
   └──────────────────┘
      ┌──────────────────┐
      │ 🔴 占位数据       │
      └──────────────────┘
```

尺寸：`height: 24px, padding: 2px 10px, border-radius: 12px, font: 12px/20px`

### 3.2 紧凑标签（表格单元格、因子列表）

```
🟢 实盘 | 🟡 模拟 | 🔴 占位
```

尺寸：`height: 20px, padding: 1px 8px, border-radius: 10px, font: 11px/18px`

### 3.3 微小圆点（内联、K线图标注）

```
● 绿色圆点 = 实盘  |  ◉ 琥珀圆点 = 模拟  |  ● 红色圆点 = 占位
```

尺寸：`width: 8px, height: 8px, border-radius: 50%`, 仅圆点无文字

## 四、显示位置与规则

### 4.1 全局 — 页面级数据来源总览

位置：工作台顶部状态栏

```
┌─────────────────────────────────────────────────────┐
│ 📊 数据来源: 实盘85%  |  模拟12%  |  占位3%         │
│ "你的实盘接入: Binance ✅ | OKX ✅ | 富途 (未接入)"    │
└─────────────────────────────────────────────────────┘
```

### 4.2 策略详情页 — 逐因子标注

```
策略: MA金叉+动量增强
因子列表:
  ┌──────────────────────────────────────────┐
  │ 动量因子 (MOM_12M)    IC: 0.045  🟢 实盘  │
  │ 市值因子 (SMB)        IC: 0.012  🟡 模拟  │
  │ 低波因子 (VOL_60D)    IC: 0.038  🟢 实盘  │
  │ 质量因子 (ROE_TTM)    IC: 0.022  🟡 模拟  │
  └──────────────────────────────────────────┘
```

**关键规则**：任何一个因子为🟡或🔴 → 回测结果顶部显示横幅：
```
⚠️ 本回测包含模拟数据（2/4因子），结果仅供参考，不可用于实盘决策
```

### 4.3 回测结果页 — 数据声明

```
回测报告:
  ┌─────────────────────────────────────────┐
  │  数据可信度: 🟡 模拟数据                    │
  │                                          │
  │  以下指标基于模拟数据计算:                  │
  │  • MOM_12M 因子收益 (模拟ETF替代)          │
  │  • SMB 因子收益 (模拟ETF替代)              │
  │  ⚠️ 实盘表现可能与此结果有显著偏差           │
  └─────────────────────────────────────────┘
```

### 4.4 因子发现向导 — 步骤中标注

在FactorDiscoveryWizard的因子选择步骤中，每个因子卡片右下角放置紧凑标签。

### 4.5 因子对比仪表板 — 表头

热力图/对比表格中，每行/列对应因子标注来源。

## 五、交互规范

### 5.1 Hover tooltip（桌面端）

```
hover 🟡 "模拟数据":
  ┌──────────────────────────────────────┐
  │ 模拟数据                             │
  │                                     │
  │ 该因子数据基于历史统计模型估算，      │
  │ 非来自真实行情源。                  │
  │                                     │
  │ 为什么是模拟？                       │
  │ → 该因子所需的数据源未接入           │
  │    (如: 富途OpenD未连接)             │
  │                                     │
  │ 如何切换到实盘？                     │
  │ → 接入对应券商或API数据源            │
  │    [去接入]                          │
  └──────────────────────────────────────┘
```

### 5.2 点击行为

- 点击标签 → 打开数据来源详情面板，列出该因子依赖的数据源及接入状态
- 点击"去接入" → 跳转到数据源管理/Broker接入页面

### 5.3 移动端适配

- 移动端紧凑标签下方加小字 "模" / "实" / "占"
- Hover改为点击展开tooltip
- 微圆点改为12px（移动端可触控）

## 六、教育性引导（首次使用）

### 6.1 首次看到模拟数据标签

用户第一次在页面上看到 🟡 标签时，弹出引导提示：

```
┌──────────────────────────────────────────┐
│  💡 什么是"模拟数据"？                    │
│                                          │
│  TradingEasy 用三种方式提供因子数据：      │
│  🟢 实盘数据 — 来自券商API，可直接交易     │
│  🟡 模拟数据 — 统计模型估算，仅用于研究    │
│  🔴 占位数据 — 临时占位，等待开发完成      │
│                                          │
│  了解不同数据来源，帮你判断分析结果可信度。 │
│                                          │
│  [知道了]  [了解更多 →]                   │
└──────────────────────────────────────────┘
```

### 6.2 重复显示规则

- 第一次：显示完整引导
- 第2-5次：显示简化tooltip（仅"模拟数据"+"为什么?")
- 5次后：仅显示标签，不再自动弹出解释

## 七、组件属性接口

```typescript
// 给ML的组件props参考
interface DataSourceBadgeProps {
  /** 数据来源等级 */
  level: 'real' | 'simulated' | 'mock';
  /** 显示尺寸 */
  size?: 'standard' | 'compact' | 'dot';
  /** 数据来源详情（hover显示） */
  detail?: {
    sourceName: string;       // 如 "Binance API"
    reason: string;           // 模拟原因，如 "券商未接入"
    upgradePath?: string;     // 升级为实盘的路径
  };
  /** 是否显示可点击（跳转接入） */
  clickable?: boolean;
  /** 点击回调 */
  onClick?: () => void;
}

interface PageSourceSummaryProps {
  /** 各级别来源占比 */
  breakdown: {
    real: number;         // 0-100
    simulated: number;    // 0-100
    mock: number;         // 0-100
  };
  /** 已接入券商列表 */
  connectedBrokers: string[];
}
```
