## 一、问题诊断

### 1.1 核心冲突矩阵

```
当前系统中至少3套独立的色彩语义在并行运行:

┌──────────────┬──────────────┬──────────────┬──────────────┐
│   场景        │ 正面/上升    │ 负面/下降    │ 中性         │
├──────────────┼──────────────┼──────────────┼──────────────┤
│ K线 (US)     │ 🟢 绿色      │ 🔴 红色      │ 灰色         │
│ K线 (CN/A)   │ 🔴 红色      │ 🟢 绿色      │ 灰色         │
│ 策略对比     │ 🔵 蓝色#3b82f6│ 🟠 琥珀#f59e0b│ 灰色         │
│ 因子IC       │ 🟢 翠绿      │ 🔴 红色      │ 黄色         │
│ 盈亏数字     │ 🟢 翠绿      │ 🔴 红色      │ 白色         │
│ 置信度标签   │ 🟢 翠绿      │ 🔴 红色      │ 黄色         │
│ 品牌主色      │ 🟡 金色#d4a574│ —           │ 深色背景     │
│ 排行榜排名   │ 🥇金 🥈银 🥉铜│ —           │ 灰色         │
└──────────────┴──────────────┴──────────────┴──────────────┘

冲突:
  1. 蓝/橙(策略A/B) vs 红/绿(K线) = 用户需要两次"色彩翻译"
  2. 红/绿在中美市场含义相反 = K线颜色本身就是混乱源
  3. 红绿8%男性色觉障碍用户无法区分 = 信息完全丢失
  4. 无任何纹理/图案/形状做双重编码 = 纯色依赖
```

### 1.2 色觉障碍影响面

```
全球约8%男性有红绿色觉障碍 (Deuteranopia/Protanopia)。
中国男性: ~6-8%，约5500万人。
quant-moo预估目标用户中男性>80%。
→ 约5-6%用户无法区分红/绿 → 无法正确解读K线、盈亏、因子方向。

模拟效果:
  正常视觉:  🟢盈利=绿色  🔴亏损=红色  — 一眼分辨
  Deuteranopia: 🟤盈利=棕色  🟤亏损=棕色 — 看不出区别
  Protanopia:   🟡盈利=暗黄  🟡亏损=暗黄 — 分辨困难
```

## 二、解决方案总览

### 色彩 + 纹理 + 数字 = 三重编码

```
原则: 任何通过颜色传递的信息，必须同时通过以下至少一种方式传递:
  1. 纹理/图案 (pattern)        — 色盲友好
  2. 数字标记 (numeric label)   — 所有人都能读
  3. 位置/方向 (position/direction) — 与生俱来的直觉

目标: 把颜色开关关闭，信息仍然完整可读。
```

## 三、统一色彩语义系统 v2.0

### 3.1 主语义轴

```
放弃  红/绿 = 涨/跌  (中美冲突)
改用  橙金/青灰 = 涨/跌  (全球统一，色盲友好)

┌─────────────────────────────────────────────────────┐
│ 语义      主色(正常)   辅色(夜用)   纹理       数字  │
├─────────────────────────────────────────────────────┤
│ 上涨/盈利  #F19345▊🟧  #FF8A65    ↗条纹       +15% │
│ 下跌/亏损  #5B7A9A▊🟦  #6B8299    ↘斜线       -12% │
│ 正面/利好  #22C55E▊🟩  #4ADE80    ↑三角       + ✓  │
│ 负面/利空  #D32F2F▊🟥  #EF4444    ↓三角       - ✗  │
│ 警告/注意  #F7931A▊🟠  #FB923C    ⚠波纹       ⚠   │
│ 中性/平坦  #6B7280▊⬜  #9CA3AF    无纹理       —   │
│ 品牌/互动  #D4A853▊🟡  #C9A046    —           —   │
└─────────────────────────────────────────────────────┘
```

### 3.2 为什么选这些颜色

```
🟧 #F19345 (橙金/暖调):
  · 与品牌金色(#D4A853)同暖调家族，视觉和谐
  · 与K线红/绿/蓝/橙都不冲突，色盲可辨(亮度差明显)
  · 对应中文"涨"="红火"的心理映射
  · 辅助亮度: Luminance = 0.45

🟦 #5B7A9A (青灰/冷调):
  · 自然联想到"冷却/收水"，与熊市心理一致
  · 与涨色暖冷对比，色盲即使看不出色相也能感知饱和度差异
  · 与深色背景搭配保持7:1对比度 (WCAG AAA)
  · 辅助亮度: Luminance = 0.18

为何不用纯红纯绿:
  #22C55E 和 #D32F2F → 只用于"状态"标签(正面/负面)，不用于涨跌
  涨跌是方向(↑↓)，正负是判断(✓✗)，两者语义不同，不应共享颜色
```

### 3.3 WCAG对比度验证

```
背景: #0D0D14 (深色主题)

上涨色 #F19345 vs 背景: 对比度 7.2:1 ✓ AAA
下跌色 #5B7A9A vs 背景: 对比度 5.8:1 ✓ AA
正面色 #22C55E vs 背景: 对比度 8.1:1 ✓ AAA
负面色 #D32F2F vs 背景: 对比度 5.4:1 ✓ AA
警告色 #F7931A vs 背景: 对比度 6.8:1 ✓ AA
中性色 #6B7280 vs 背景: 对比度 4.8:1 ✓ AA
```

## 五、各组件改造规范

### 5.1 K线图 (KLineChart / CandleStick)

```
当前:  阳线=🟢/🔴 (取决于中美市场)  阴线=🔴/🟢
问题:  1. 中美颜色相反 → 用户手动切换 → 混乱
      2. 色盲用户区分困难
      3. 无纹理 → 纯色判断

方案:
  默认: 阳线=透明实心(或暖调)，阴线=填充冷调
  纹理: 阴线实体区域加↘斜纹 (SVG pattern)
  线型: 阳线边框=暖调(#F19345), 阴线边框=冷调(#5B7A9A)
  可选: 在K线底部/顶部标注 "+2.5%"/"-1.3%" (开启"数值K线"模式)

实现:
  · 阳线: fill="none", stroke="#F19345", strokeWidth=1.5
  · 阴线: fill="url(#falling-stripe)", stroke="#5B7A9A", strokeWidth=1.5
  · 十字星: fill="none", stroke="#6B7280"
  · 用户可切换"经典红绿"模式(需明确选择，非默认)
```

### 5.2 策略对比图 (StrategyComparer)

```
当前:
  策略A曲线: 🔵 #3b82f6 (蓝色)  + 蓝色圆点标记
  策略B曲线: 🟠 #f59e0b (琥珀) + 琥珀圆点标记
  正面值:     🟢 text-emerald-400
  负面值:     🔴 text-red-400
  牛市标签:   🟢 bg-emerald-500/10
  熊市标签:   🔴 bg-red-500/10

问题: 蓝/橙冲突K线红绿 + 正面/负面共享红绿容易混淆

方案:
  策略A曲线: 🟧 #F19345 (橙金)  + ◇菱形标记
  策略B曲线: 🟦 #5B7A9A (青灰)  + ○圆形标记
  差值>0:    ↑ 箭头 + 颜色 + "+"前缀
  差值<0:    ↓ 箭头 + 颜色 + "-"前缀
  
  对比表:
  ┌──────────────┬─────────────┬──────────────┐
  │ 指标          │ A (橙金)    │ B (青灰)      │
  ├──────────────┼─────────────┼──────────────┤
  │ Sharpe       │ 2.1 ◇      │ 1.8 ○        │
  │ 年化收益     │ +35% ↑     │ +28% ↑       │
  │ 最大回撤     │ -12% ↓     │ -18% ↓       │
  │ 胜率         │ 58% ◇      │ 52% ○        │
  ├──────────────┼─────────────┼──────────────┤
  │ 总优胜方     │ 🏆 A领先    │              │
  └──────────────┴─────────────┴──────────────┘
```

### 5.3 因子卡片 (FactorCard / FactorDiscoveryWizard)

```
当前:
  正值IC: text-emerald-400
  负值IC: text-red-400  
  无纹理、无箭头

方案:
  IC ≥ 0.03:  ↑ 箭头 + 绿色(#22C55E) + 数值 + "强"徽章
  IC 0.01-0.03: → + 黄色(#F7931A) + 数值 + "中"徽章
  IC < 0.01:  ↓ + 红色(#D32F2F) + 数值 + "弱"徽章
  IC < 0:     ↓↓ + 红色 + 数值 + "反向"

示例卡片渲染:
  ┌─────────────────────────────────┐
  │ ↑ 12月动量                      │
  │ IC 0.045  🟢 强                 │
  │ IR 0.52   稳定性好              │
  │ 📅 实时                         │
  │ 🔗 查看引擎数据                  │
  └─────────────────────────────────┘
```

### 5.4 盈亏数字显示

```
当前:
  +收益: text-emerald-400  (绿色)
  -亏损: text-red-400      (红色)
  背靠深色背景 (深色主题)

方案:
  +收益: ↑ #22C55E + "+"前缀 + 数值 → "+12,350 (+3.2%↑)"
        └ 方向箭头在数字前，不依赖颜色
  
  -亏损: ↓ #D32F2F + "-"前缀 + 数值 → "-8,400 (-2.1%↓)"
        └ 方向箭头在数字前，不依赖颜色
        └ 括号备用，色盲看到"+" "-"也能判断
  
  无变化: → #6B7280 + "±0%" → "±0.0%→"
```

### 5.5 置信度标签

```
当前:
  高置信: 🟢 
  中置信: 🟡
  低置信: 🔴

方案: 颜色 + 图标 + 文字 (三重编码)
  🟢✅ 高置信度 (>80%)
  🟡⚠️ 中置信度 (50-80%)
  🔴❌ 低置信度 (<50%)
  
  色盲视角:
  (✅) 高置信度 (>80%)
  (⚠️) 中置信度 (50-80%)
  (❌) 低置信度 (<50%)
  → 即使分不清颜色，✅/⚠️/❌ 图标也能传达信息
```

### 5.6 热力图 (HeatmapView)

```
当前: 仅颜色编码 → 色盲不可用

方案:
  三重编码: 颜色 + 数字 + 纹理
  
  正格 (>0):
    颜色: 橙金渐变 (浅→深)
    数字: 单元格内标注 "+0.045"
    纹理: ↗上升斜纹 (密度随数值增大)
    
  负格 (<0):
    颜色: 青灰渐变 (浅→深)
    数字: 单元格内标注 "-0.032"
    纹理: ↘下降斜纹 (密度随绝对值增大)
    
  零值格:
    无纹理 + 白色/灰色 + "0"
```

## 八、迁移路径

### Phase 1: 新增纹理 (不破坏现有) — 2h
```
- 添加 SVG pattern定义 (全局styles)
- K线图加纹理选项 (默认关闭, 用户可开启)
- 盈亏数字加箭头 (始终显示)
```

### Phase 2: 策略对比改色 — 1h
```
- StrategyComparer: 蓝→橙金, 琥珀→青灰
- 雷达图: 两线加线型区分 (实线 vs 虚线)
```

### Phase 3: 全面色盲模式 — 2h
```
- 全局开关: 设置 → 显示 → 无障碍模式
- 一键切换: 开启后所有颜色+纹理+数字三重编码
- 图标系统: ✅⚠️❌替换纯色圆点
```

### Phase 4: 热力图+因子卡 — 1h
```
- FactorDiscoveryWizard 热力图加纹理
- FactorCard 加箭头+数字双重显示
```
