**目标**: 用户在正式激活前全面了解策略

**展示内容**:

2. 四铁律 (humanLine / stopLossRule / marketScope / failureCheck)
3. 因子组合 (factorCombo - 饼图或权重条)
4. AI触发点 (aiTriggerPoints - 每个点费用标注)
5. 风险等级 (conservative/balanced/aggressive)
6. 持有天数 (holdingDays)

## 二、风险揭示书规范

### 2.1 法律合规最低要求

| 要求 | 实现 | 状态 |
|------|------|------|
| 明确风险声明 | item1: 自动化交易可致全损 | ✅ |
| 过去不保证未来 | item2: 沙盒模拟≠未来收益 | ✅ |
| 用户知情确认 | item3: 已测试+接受风险 | ✅ |
| 主动确认机制 | 滑块 (非简单按钮) | ✅ |
| 不可跳过 | 3条全勾+滑块到底才可激活 | ✅ |

### 2.2 滑块交互规范

```
状态1: 未勾选全部3条 → 滑块灰色不可拖动
状态2: 3条全勾选 → 滑块变亮, 可拖动
状态3: 滑块拖至100% → 弹出"已确认，正在激活策略..."
状态4: 激活完成 → 跳转策略列表页, 显示"已激活"标签
```

颜色:
- 未激活: #d1d5db (灰色滑块)
- 可拖动: #f59e0b (金色高亮)
- 拖动中: #f59e0b → #10b981 (金色→绿色渐变)
- 已完成: #10b981 (绿色确认)

### 2.3 不可跳过机制

```
1. 必须有3条check全部checked → minCheckCount = 3 (硬编码)
2. 滑块必须到达100% → progress === 100
3. 不可通过URL直接跳步骤 → Step4需检查Step1-3 cookie/state
4. 不可通过console绕过 → 滑块完成状态服务端验证
```
