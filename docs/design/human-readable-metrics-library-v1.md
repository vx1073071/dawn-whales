## 指标1: IC (信息系数 Information Coefficient)

**专业定义**: Factor return cross-sectional rank correlation with future returns.

**L1 一句话**: "因子预测方向有多准。越接近1越准"

**L2 大白话**: 
"IC衡量的是：按照这个因子排序买股票，实际能赚到钱的概率有多高。
比如动量因子IC=0.05，意味着你按动量排名买入的股票，大概率跑赢平均。
IC>0.03就算有效因子，IC>0.05是优秀因子，IC<0.01基本是随机猜。"

**L3 速判标准**:
- 🟢 IC≥0.05 → 强有效 ("这个因子很准，历史上经常预测对")
- 🟡 0.02≤IC<0.05 → 中等有效 ("方向大体对，但有不确定性")
- 🔴 IC<0.02 → 弱有效 ("预测能力接近随机，需要结合其他因子使用")

**人类比喻**: "IC像天气预报准确率—IC=0.8说明预报几乎全对，IC=0.01说明跟瞎猜差不多"

---

## 指标2: IR (信息比率 Information Ratio)

**专业定义**: IC / σ(IC), measures consistency of factor performance.

**L1 一句话**: "因子预测稳定性。越大越稳定"

**L2 大白话**:
"IR告诉你这个因子是不是'稳定的准'。
有些因子偶尔很准（高IC）、大部分时候瞎蒙（高波动），IR会很低。
有些因子每次都准一点点，IR会很高。
IR>0.5算稳定因子，IR>1.0是非常可靠的因子。"

**L3 速判标准**:
- 🟢 IR≥1.0 → 非常稳定 ("这个因子表现很稳，不靠运气")
- 🟡 0.3≤IR<1.0 → 较稳定 ("大部分时候有效，偶尔失效")
- 🔴 IR<0.3 → 不稳定 ("时灵时不灵，需要择时使用")

**人类比喻**: "IC是考试平均分，IR是成绩稳不稳定。学霸每科都考80分（低波动，高IR）；偏科生一科100一科60（高波动，低IR）"

## 指标3: 夏普比率 (Sharpe Ratio)

**专业定义**: (Rp - Rf) / σp, risk-adjusted return.

**L1 一句话**: "每承担1块钱风险，能赚多少钱"

**L2 大白话**:
"夏普衡量的是性价比：冒了多大风险换来了多少收益。
夏普=1.0 意思是每承受1块钱的波动，赚到1块钱超额收益。
夏普=2.0 意思是冒1块钱风险赚2块钱，性价比很高。
夏普<0.5 意思是波动大收益小，策略风险收益不匹配。"

**L3 速判标准**:
- 🟢 夏普≥1.5 → 优秀 ("风险收益比非常好，值得加大仓位")
- 🟡 0.5≤夏普<1.5 → 合格 ("正常的风险收益比")
- 🔴 夏普<0.5 → 差 ("冒的风险比赚的钱多，需要优化")

**人类比喻**: "夏普像网购评分—5星但价格贵(收益高波动大)可能夏普一般；3星但超便宜(收益稳波动小)可能夏普更高"

## 指标4: 最大回撤 (Max Drawdown)

**专业定义**: Maximum peak-to-trough decline in portfolio value.

**L1 一句话**: "历史上亏最惨的一次，跌了多少"

**L2 大白话**:
"最大回撤告诉你最糟情况有多糟。
你的策略从最高点到最低点最多亏过多少钱。
如果最大回撤=20%，意味着你要赚25%才能回本（因为本金少了）。
回撤<15%是保守策略，回撤<30%是正常水平，回撤>50%说明策略有巨大风险。"

**L3 速判标准**:
- 🟢 回撤<15% → 低风险 ("最糟情况也没有大幅亏损")
- 🟡 15%≤回撤<30% → 中等风险 ("可以接受的亏损范围")
- 🔴 回撤≥30% → 高风险 ("历史最大亏损很严重，心理压力大")

**人类比喻**: "最大回撤像开车的最糟事故记录—哪怕平时开得再好，只要出过一次大事故就要警惕"

---

## 指标5: 胜率 (Win Rate)

**专业定义**: Percentage of trades/periods with positive return.

**L1 一句话**: "历史上的交易/月份，赚钱的占多少"

**L2 大白话**:
"胜率只是概率，不代表赚钱。
50%胜率+每次赚100每次亏50=稳定盈利。
80%胜率+每次赚10每次亏100=最终还是亏。
所以胜率要结合盈亏比一起看。胜率>55%就算好，但低胜率+高盈亏比也可以很赚。"

**L3 速判标准**:
- 🟢 胜率≥60% → 高胜率 ("多数交易是盈利的，心理体验好")
- 🟡 40%≤胜率<60% → 中等 ("需要盈亏比配合")
- 🔴 — 不要单看胜率下定论（低胜率可以是好策略）

**人类比喻**: "胜率像婚姻幸福率—不是不吵架就好，是吵完架后收获大于损失"

---

## 指标6: 年化收益率 (Annualized Return)

**专业定义**: Geometric mean return, annualized.

**L1 一句话**: "平均每年收益多少（复利计算）"

**L2 大白话**:
"年化收益率把你所有年份的收益折合成'平均每年赚多少'。
10%年化=每年资产平均增长10%，7年翻倍（72法则）。
但年化不代表每年都赚这么多——可能今年+30%、明年-10%，平均+10%。
要结合最大回撤看：年化20%回撤50%不如年化10%回撤5%。"

**L3 速判标准**:
- 🟢 年化≥15% → 优秀
- 🟡 8%≤年化<15% → 不错
- 🔴 年化<5% → 偏弱（需考虑是否跑赢大盘）

---

## 指标7: 波动率 (Volatility / Standard Deviation)

**专业定义**: Standard deviation of returns, measures price variability.

**L1 一句话**: "收益的'颠簸程度'。越大越颠簸"

**L2 大白话**:
"波动率衡量你的收益有多'跳'。
波动率=10%的意思是，你的月收益大概在平均值±10%的范围内跳动。
高波动率意味着坐过山车——有时大赚有时大亏。
低波动率意味着平稳——赚钱不多但稳定。
波动率本身没有好坏，看你的承受能力。"

**L3 速判标准**:
- 🟢 年化波动<15% → 低波动 ("平稳，适合保守型投资者")
- 🟡 15%≤波动<30% → 中等波动 ("有起伏，需要一定承受力")
- 🔴 波动≥30% → 高波动 ("像坐过山车，小心心脏")

---

## 指标8: Beta (β·贝塔)

**专业定义**: Cov(Ri, Rm) / Var(Rm), market sensitivity.

**L1 一句话**: "你的策略跟大盘多同步。β=1跟大盘一样"

**L2 大白话**:
"Beta衡量你的策略多'像'大盘。
β=1.0=大盘涨1%你涨1%。
β=1.5=大盘涨1%你涨1.5%（涨跌都放大）。
β=0.5=大盘涨1%你涨0.5%（涨跌都温和）。
β<0=大盘涨你跌（反向策略，做空型）。"

**L3 速判标准**:
- 🟡 β≈1.0 → 跟大盘一致
- 🟡 0.5<β<1.5 → 正常范围
- 🔴 β>2.0 → 杠杆型高波动 ("比大盘波动大一倍")
- 🔴 β<0 → 反向型 ("大盘涨你亏")

---

## 指标9: Alpha (α·阿尔法)

**专业定义**: Return not explained by market (β), excess/skill return.

**L1 一句话**: "去掉大盘的影响后，你的策略多赚了多少钱"

**L2 大白话**:
"Alpha是策略的'真本事'——去掉大盘涨跌（β收益）后剩下的纯能力。
α=5%意味着你的策略每年比'跟着大盘走'多赚5%。
α>0说明有真正的选股/择时能力。
α<0说明不如直接买指数基金。"

**L3 速判标准**:
- 🟢 α>5% → 超额能力明显
- 🟡 0<α≤5% → 有超额但不多
- 🔴 α<0 → 不如买指数 ("策略没有提供额外价值")

**人类比喻**: "β是大盘给你免费的午餐，α是你自己赚来的外卖"

---

## 指标10: R² (决定系数)

**专业定义**: Proportion of variance explained by the model (0-1).

**L1 一句话**: "策略收益有多少是跟着大盘走的。越高越依赖大盘"

**L2 大白话**:
"R²告诉你策略的独立性。
R²=0.8 → 策略80%涨跌是因为大盘涨跌，只有20%是你自己的选股能力。
R²=0.2 → 策略跟大盘关系不大，靠的是自己的判断。
过高R²说明你在'假装择股'（其实只是买大盘）；过低R²说明你很有独立想法。"

**L3 速判标准**:
- 🟡 R²≈0.5 → 一半大盘一半自身（常见配置）
- 🔴 R²>0.8 → "策略几乎就是买大盘，没有发挥主动管理价值"
- 🟢 — 没有绝对好坏（主动型想要低R²，指数型想要高R²）

## 指标11: t-Stat (t统计量)

**专业定义**: Estimate / standard error, tests statistical significance.

**L1 一句话**: "这个因子的预测能力不是巧合。>2.0才可靠"

**L2 大白话**:
"t统计量回答：'你的IC不是凭运气吧？'
样本越小、波动越大，t越小→越可能是碰巧。
|t|>2.0意味着只有5%的概率是巧合（统计学上算'显著'）。
|t|>3.0意味着只有0.3%的概率是巧合。"

**L3 速判标准**:
- 🟢 |t|≥2.0 → 统计显著 ("因子效果是真实的，不是巧合")
- 🟡 1.6≤|t|<2.0 → 边缘显著 ("接近可靠，需更多数据验证")
- 🔴 |t|<1.6 → 不显著 ("该因子效果可能是碰巧")

## 指标12: p-Value (p值)

**专业定义**: Probability of observing result if null hypothesis true.

**L1 一句话**: "纯凭运气得到这个结果的概率。越小越好"

**L2 大白话**:
"p值告诉你：如果这个因子完全没用（纯随机），你看到这个结果的可能性有多大。
p=0.05=只有5%概率是撞大运 → 95%概率是真的有用。
p=0.01=只有1%概率是撞大运 → 99%概率是真的有用。
p=0.5=50%概率是撞大运 → 可能没用。"

**L3 速判标准**:
- 🟢 p<0.01 → 非常显著 ("几乎不可能凭运气")
- 🟡 0.01≤p<0.05 → 显著 ("有统计学意义")
- 🔴 p≥0.05 → 不显著 ("不能排除碰巧的可能")

## 指标13: 因子暴露 (Factor Exposure)

**专业定义**: Loading/sensitivity of portfolio to a given factor.

**L1 一句话**: "你的策略对这个因子的依赖程度。绝对值越大越依赖"

**L2 大白话**:
"因子暴露告诉你：你的策略本质上是'买了什么'。
动量暴露0.45 → 你策略收益的45%来自动量因子。
价值暴露-0.20 → 你的策略偏成长股，不喜欢便宜股。
暴露太高=对这个因子的押注太重，风险集中。"

**L3 速判标准**:
- 🟡 |暴露|<0.3 → 轻度依赖 ("该因子对策略影响不大")
- 🟡 0.3≤|暴露|<0.6 → 中度依赖 ("策略明显受该因子影响")
- 🔴 |暴露|≥0.6 → 重度依赖 ("策略几乎就是赌这个因子")

## 指标14: 相关性 (Correlation)

**专业定义**: Pearson's r, measures linear relationship between two variables.

**L1 一句话**: "两个因子/策略的涨跌有多同步。1=完全同步，0=不相关"

**L2 大白话**:
"相关性衡量两个东西有多像。
ρ=0.8=两个因子几乎一起涨跌→你同时用它们，并不能分散风险。
ρ=-0.3=一个涨另一个跌→组合在一起可以降低风险。
ρ≈0=两个因子互不影响→组合在一起可以分散风险。
理想的多因子组合：选相关性低的因子互相补充。"

**L3 速判标准**:
- 🟢 |ρ|<0.3 → 低相关 ("这两个可以一起用，互相补充")
- 🟡 0.3≤|ρ|<0.7 → 中等相关 ("有一定同步性")
- 🔴 |ρ|≥0.7 → 高相关 ("高度重叠，没必要两个都选")

## 指标15: Calmar比率 (Calmar Ratio)

**专业定义**: Annualized return / Max drawdown (absolute value).

**L1 一句话**: "每亏1块钱，能赚多少。衡量赚钱效率"

**L2 大白话**:
"Calmar比率是收益÷最大回撤。
Calmar=1.0=每承受1块钱亏损，赚1块钱 → 盈亏平衡。
Calmar=2.0=每承受1块钱亏损，赚2块钱 → 效率不错。
Calmar=3.0=每承受1块钱亏损，赚3块钱 → 效率很高。
这个指标很直观：关注最糟情况下的赚钱效率。"

**L3 速判标准**:
- 🟢 Calmar≥1.5 → "承受亏损的效率高，策略更值得投入"
- 🟡 0.5≤Calmar<1.5 → "正常水平"
- 🔴 Calmar<0.5 → "最大回撤远超收益，风险收益不匹配"

**人类比喻**: "Calmar像投资回报率——开店投入100万，一年只赚10万，Calmar=0.1，不值得；投入100万赚200万，Calmar=2.0，很棒"
