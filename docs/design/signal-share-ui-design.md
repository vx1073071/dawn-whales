## 一、商业背景

v15 模型：创作者提供交易信号 → 用户跟单 → 创作者分成(70/80/90%)

当前缺口：
- signal-push-engine ✅ (后端信号推送就绪)
- 分享入口 ❌ (创作者无法分享信号)
- 分享链接 ❌ (无URL生成机制)
- 跟单入口 ❌ (用户看不到可跟单的信号)

---

## 二、信号分享流程

```
创作者端                          用户端
─────────                        ─────────

1. 看到信号结果
   ├─ SignalDashboard
   └─ 交易历史记录

2. 点击 "分享" ────────→  生成分享链接
   │                        ├─ URL (quant-moo://signal/xxx)
   │                        └─ 二维码
   │
   │  复制链接 / 扫码 ──→  ──→  3. 打开链接
   │                                 ├─ App已安装: 直接打开
   │                                 └─ 未安装: 跳落地页下载
   │
   └──────────────────────→  4. 看到信号详情页
                                ├─ 信号源名称+头像
                                ├─ 30天收益率
                                ├─ 风险等级
                                ├─ 分润比例(15%)
                                └─ [开始跟单] 按钮
```

## 四、技术实现

### 4.1 IPC 接口

```
signal:share          → 生成分享链接 + Token
signal:get-shared     → 通过token获取信号详情
signal:copy-trade     → 开始跟单
signal:stop-copy      → 停止跟单
signal:get-copies     → 获取我的跟单列表
```

### 4.2 Deep Link 协议

```
quant-moo://signal/{shareToken}

App 处理:
1. 解析 deep link → 提取 shareToken
2. 调 signal:get-shared(shareToken) → 获取信号详情
3. 渲染 SignalPreviewCard
4. 用户确认 → 调 signal:copy-trade → 开始跟单
```

### 4.3 分享 Token 设计

```typescript
interface SignalShareToken {
  providerId: string;      // 信号源ID
  createdAt: number;       // 创建时间
  expiresAt?: number;      // 过期时间(默认30天)
  permissions: {
    showHistory: boolean;  // 是否显示历史交易
    liveUpdate: boolean;   // 是否实时更新
  };
}
```
