## 一、设计目标

当AI因子顾问返回分析结果时，同时生成两版回复（A/B），让真实用户选择偏好，以此持续优化AI输出的语气、详略、实用性。

---

## 二、对比维度

| 维度 | 变体A | 变体B | 适用场景 |
|------|-------|-------|---------|
| **详略** | 简洁版 (≤150字) | 详细版 (≤400字) | 所有回复 |
| **语气** | 数据驱动 (列数字) | 故事驱动 (打比方) | 因子解释 |
| **结构** | 列表式 (要点) | 叙述式 (段落) | 策略建议 |
| **风险强调** | 中性 (利弊各半) | 保守 (先讲风险) | 交易建议 |
| **行动导向** | 给结论 | 给选择题 | 因子推荐 |

---

## 三、流程设计

```
用户触发AI分析
    │
    ▼
AI生成2版回复 (A/B)
    │
    ├─→ 存储 (A/B pair ID + 元数据)
    │
    ▼
用户看到A版 (默认)
    │
    ├─ [👍 有用] [👎 没用] [🔀 看看另一个版本]
    │
    ├─ 点击"看看另一个版本" →
    │   ┌─────────────────────────────────────┐
    │   │ 切换到B版回复                        │
    │   │ [👍 B更好] [👎 A更好] [📊 差不多]    │
    │   └─────────────────────────────────────┘
    │
    ▼
记录: 用户选择 + 维度 + 时间
    │
    ▼
汇总: 每维度A/B偏好比 → 调优AI模板
```

## 四、数据结构

```typescript
interface ABTestPair {
  pairId: string;              // "ab_factor_momentum_20260615_001"
  sessionId: string;           // 用户会话ID
  intent: string;              // AI intent类型
  dimension: ABDimension;      // 对比维度
  
  variantA: {
    text: string;              // A版完整文本
    templateId: string;        // 使用的模板ID
    tokenCount: number;        // Token消耗
    generationMs: number;      // 生成耗时
  };
  
  variantB: {
    text: string;
    templateId: string;
    tokenCount: number;
    generationMs: number;
  };
  
  // 用户反馈
  userChoice?: {
    shownFirst: 'A' | 'B';           // 先展示哪个
    preferred: 'A' | 'B' | 'equal';  // 用户偏好
    ratedUseful: boolean;            // 是否标记有用
    clickedActions: string[];        // 点击了哪些CTA
    timeToChoiceMs: number;          // 选择耗时
    timestamp: number;
  };
}

type ABDimension = 
  | 'verbosity'      // 详略
  | 'tone'           // 语气
  | 'structure'      // 结构
  | 'risk_emphasis'  // 风险强调
  | 'action_style';  // 行动导向
```

## 五、A/B变体生成规则

### 5.1 详略维度 (verbosity)

```
A: 简洁版 — 只给结论+1个理由+1个CTA
   示例: "动量12M(IC 0.045)近期表现最强。
          因为资金在持续流入强势板块。建议权重35%。
          [看详细分析]"

B: 详细版 — 结论+3个理由+风险+替代+CTA
   示例: "动量12M(IC 0.045, IR 0.52)是当前最优选择:
          ① 最近30天IC持续>0.04 ② 因子拥挤度仅42%
          ③ 与你的持仓相关性0.3(不会重叠)
          ⚠️ 但这个因子在财报季容易反转。
          🔄 替代: 盈利动量(IC 0.041, 拥挤度更低)。
          建议权重30-35%。[一键应用] [看对比]"
```

### 5.2 语气维度 (tone)

```
A: 数据驱动 — 引用具体数字
   "IC=0.045, Sharpe=1.42, MaxDD=-12.3%"

B: 故事驱动 — 人类化比喻
   "就像赛跑选手，过去12个月领先的，接下来几个月大概率还领先"
```

### 5.3 结构维度 (structure)

```
A: 列表式
   • 推荐: 动量12M
   • 权重: 35%
   • 理由: IC持续高

B: 叙述式
   "根据你的高成长偏好，我首先推荐动量12M因子...
   在分析了44个因子后，它的IC和拥挤度是最优组合..."
```

### 5.4 风险强调 (risk_emphasis)

```
A: 中性 — 先讲好处再讲风险
   "推荐因子A。理由: ① ② ③。风险: ① ②"

B: 保守 — 先讲风险再讲好处
   "在使用这个因子前，请注意: ① ②。
   如果可以接受这些风险，因子A的理由是: ① ② ③"
```

### 5.5 行动导向 (action_style)

```
A: 给结论 — "建议权重: 动量35%, 质量25%, 低波动20%"

B: 给选择 — "你可以选择:
   🅰 激进: 动量40%+成长30%  (Sharpe 1.2, 波动高)
   🅱 均衡: 动量30%+质量25%+低波20%  (Sharpe 1.4, 波动中)
   © 保守: 质量35%+低波30%+股息15%  (Sharpe 1.1, 波动低)"
```

## 六、实验设计原则

### 6.1 随机化

```
- 每个用户看到A/B的顺序随机 (50/50)
- 同用户同intent连续3次 → 维度轮换
- 不重复对比同一维度直到覆盖全部5个
```

### 6.2 统计显著性

```
最小样本: 每维度≥100次对比 → 判断偏好
停止规则: p<0.05且样本≥100 → 锁定胜者
持续: 直到5个维度全部有显著结果
```

### 6.3 避免偏差

```
- 不显示"A版"/"B版"标签 (用户在不知情下选择)
- 调用"看看另一个版本"按钮文案不带倾向性
- 不给A/B质量打分 → 只问"哪个更好"
```

## 十、验收标准

| # | 标准 | 验证方式 |
|---|------|---------|
| 1 | A/B配对生成 | 同intent生成2版不同回复 |
| 2 | 随机首显 | A/B首显概率各≈50% |
| 3 | 切换流畅 | 点击🔀瞬间切换到另一版 |
| 4 | 偏好记录 | 选择后数据写入DB |
| 5 | 分析面板 | Dashboard显示各维度偏好比 |
| 6 | 不影响付费 | A/B对比不额外扣费 |
| 7 | 零性能影响 | 生成双版耗时<1.5×单版 |
