## B.1 设计原则

> "不要让用户在10个市场面前不知所措。先用本地市场建立信任，再逐步拓展视野。"

### 核心策略: **One Market → One Win → Explore More**
- 第一步: 选最熟悉的市场 → 快速成功体验
- 第二步: 发现本地因子 → "原来如此!" moment
- 第三步: 跨市场对比 → 拓展视野

## C.5 一致性的达成关键

### 颜色 — CSS变量体系
```css
/* 全局变量 = 100%一致性基石 */
:root {
  --brand-primary: #D4A574;      /* 品牌金 */
  --brand-bg: #0D1117;           /* 深色背景 */
  --brand-card: #161B22;         /* 卡片 */
  --brand-border: #30363D;       /* 边框 */
  --brand-text: #E6EDF3;         /* 正文 */
  --brand-muted: #8B949E;        /* 弱文字 */
}
/* 每市场叠加专属变量 (--{market}-*) */
```

### 排版 — Tailwind统一
- 标题: `text-xl font-bold` / `text-lg font-semibold`
- 正文: `text-sm text-secondary`
- 数值: `font-mono tabular-nums`
- 因子名: `font-medium tracking-wide`

### 交互 — 统一模式
- Hover: `hover:bg-opacity-80 transition-colors duration-200`
- Active: `active:scale-95 transition-transform`
- Focus: `focus:ring-2 focus:ring-brand-primary focus:outline-none`
- Disabled: `opacity-50 cursor-not-allowed`

### 文案 — 人话规范
- 因子解释: "就像..." 开头的生活比喻
- 信号解读: "这个因子在帮你赚钱" / "它在亏钱"
- CTA: 动宾结构 "解锁完整分析" / "跑一次回测"
- 付费: 明确价格+价值对比 "1U = 省30分钟研究"

### 动画 — GPU加速
- 入场: `animate-fadeIn` (opacity 0→1, 300ms ease-out)
- 列表: `animate-slideUp` + `staggerChildren: 50ms`
- 数字: `animate-countUp` (requestAnimationFrame)
- 加载: 品牌金色脉冲 `animate-pulse-gold`
- ⚠️ 禁用: `transform: rotate()` 大量元素 (CPU fallback)

### 响应式 — 断点统一
| 断点 | 宽度 | 布局 | 列数 |
|------|:---:|------|:---:|
| Mobile | <768px | 单列堆叠 | 1 |
| Tablet | 768-1024px | 双列 | 2 |
| Desktop | 1024-1440px | 三列网格 | 3 |
| Wide | >1440px | 四列+侧栏 | 4 |
