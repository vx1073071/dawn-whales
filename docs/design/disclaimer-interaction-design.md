## 一、问题诊断

### 1.1 当前状态

```
现状: AI输出底部统一显示
  "⚠️ AI分析仅供参考，不构成投资建议。投资有风险，入市需谨慎。"
  
问题:
  1. 大段免责文字成为"墙纸"——用户视而不见
  2. 首次使用无确认——用户可能不知道AI≠人类顾问
  3. 无差异化——策略建议/健康检查/宏观预测风险级别不同，免责却一样
  4. 无行为跟踪——平台不知道用户是否真的理解了免责
```

### 1.2 行业对标

| 平台 | 免责方式 | 借鉴点 |
|------|---------|--------|
| **Bloomberg** | 所有AI输出标注"AI-Generated"，可禁用的toggle | 标签而非墙纸 |
| **Robinhood** | 首次使用AI导航时弹出确认弹窗 + 勾选框 | 主动确认 |
| **富途牛牛** | 牛牛AI底部固定"内容由AI生成，仅供参考" + 链接到详细说明 | 内联标签 |
| **ChatGPT** | 页面底部固定 "ChatGPT can make mistakes" | 持久可见但不占空间 |
| **Perplexity** | 每条回答独立标注来源+AI标签 | 每条独立标注 |
| **Coinbase** | 首次使用高级功能弹窗 + 勾选"我已阅读风险声明" | 风险分层 |

## 二、三层交互设计

### Layer 1: 首次使用 — 知情确认 (First-Time Consent)

#### 触发条件
```
- 用户第一次点击任何AI功能按钮
- 触发时机: AI请求发送前 (before API call)
```

#### 弹窗设计

```
┌─────────────────────────────────────────────────────────┐
│                                                         │
│  🤖 AI因子顾问 — 使用前须知                              │
│                                                         │
│  ┌─────────────────────────────────────────────────┐    │
│  │ 📊 AI可以帮你做的事情:                            │    │
│  │   • 分析你的持仓因子暴露和风险                    │    │
│  │   • 推荐因子组合方案 (基于历史数据回测)            │    │
│  │   • 解读回测结果和策略健康度                      │    │
│  │                                                  │    │
│  │ ⚠️ AI不能做的事情:                                │    │
│  │   • 预测未来股价 (没人能做到)                     │    │
│  │   • 保证收益 (任何保证都是骗人的)                  │    │
│  │   • 替代你自己的判断 (最终决定权永远在你手里)       │    │
│  └─────────────────────────────────────────────────┘    │
│                                                         │
│  ┌─────────────────────────────────────────────────┐    │
│  │ 📖 重要声明:                                      │    │
│  │                                                  │    │
│  │ 1. AI分析的置信度标注表示历史数据上的统计规律，     │    │
│  │    不能保证未来表现相同。                          │    │
│  │                                                  │    │
│  │ 2. AI建议不是投资建议。所有投资决策的风险由您       │    │
│  │    自行承担。TradingEasy不承担由此产生的任何损失。  │    │
│  │                                                  │    │
│  │ 3. AI可能出错。我们使用多层幻觉检测(偏差>50%会     │    │
│  │    拦截)，但不能保证100%正确。                     │    │
│  │                                                  │    │
│  │ 4. 您可以随时在设置中关闭AI功能，或调整AI的        │    │
│  │    建议强度(保守/中等/激进)                        │    │
│  └─────────────────────────────────────────────────┘    │
│                                                         │
│  □ 我已阅读并理解以上声明                                │
│  □ 我理解AI建议不是投资建议，最终决定由我自行做出          │
│                                                         │
│  [上一步]  [取消]  [我知道了，开始使用 →]                │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

#### 交互规则

```
1. 两个复选框必须都勾选，"我知道了"按钮才可点击
2. "我知道了"click → 记录consent时间戳到localStorage + 后端用户profile
3. "取消" → 回到上一个页面，AI功能暂不激活
4. 从设置页可重新查看此弹窗 (入口: 设置 → AI → 查看AI使用声明)
5. 用户可在弹窗中点击"了解更多"链接到完整的AI政策页面
```

#### 状态存储

```typescript
interface AIConsentState {
  consented: boolean;           // 是否已同意
  consentedAt: number;          // 同意时间戳
  consentedVersion: string;     // 同意时的免责版本 (用于日后更新重签)
  aiAdviceStrength: 'conservative' | 'moderate' | 'aggressive';  // 建议强度
}
```

### Layer 2: 内联标签体系 (Inline Badge System)

替代统一的底部免责文字，用内联标签嵌入AI回复中。

#### 2.1 AI回复结构带标签

```
AI回复渲染结构:
┌─────────────────────────────────────────────┐
│ [🤖 AI分析] · 🟢 高置信度 · 📅 2026-06-15  │  ← 顶部标签行
│                                             │
│ 你的策略健康评分 72/100 (B级)...             │
│ 动量因子IC: 0.045 [📊 引擎验证 ✓]           │  ← 内联验证标签
│                                             │
│ 建议增加质量因子权重至25%                    │
│  [⚠️ 此建议基于历史数据，未来可能不同]        │  ← 内联风险提示
│                                             │
│ ┌─ 更多 ───────────────────────────────┐    │
│ │ 🔗 本分析使用4个Agent联合生成         │    │  ← 可折叠来源面板
│ │ 📊 数据源: 因子引擎v3.2 / 2026-06-15 │    │
│ │ ⚙️ AI分析免责 | 隐私设置             │    │
│ └──────────────────────────────────────┘    │
│                                             │
│ 🔍 继续深入这个方案                           │  ← 后续建议问题
│ · 这些因子在过去3个月表现如何？               │
│ · 如果市场跌20%，会亏多少？                   │
└─────────────────────────────────────────────┘
```

#### 2.2 标签类型定义

```typescript
type InlineBadgeType = 
  | 'ai-generated'        // AI生成标记
  | 'engine-verified'     // 引擎验证通过
  | 'engine-mismatch'     // 引擎验证不一致 → 升级为警告
  | 'historical-only'     // 仅基于历史数据
  | 'low-confidence'      // 低置信度
  | 'time-sensitive'      // 时间敏感 (超24h需重分析)
  | 'simulated-only'      // 仅模拟回测 (非实盘)
  | 'third-party'         // 涉及第三方数据源
  | 'no-guarantee';       // 不保证未来表现

interface InlineBadge {
  type: InlineBadgeType;
  icon: string;           // emoji 图标
  labelCN: string;         // 中文标签
  labelEN: string;         // 英文标签
  position: 'inline' | 'block' | 'footer';  // 显示位置
  severity: 'info' | 'warning' | 'caution';  // 严重程度 → 颜色
  tooltip: string;         // hover 解释
}
```

#### 2.3 标签规格表

| 标签类型 | 图标 | 中文 | 位置 | 严重度 | 触发条件 |
|---------|------|------|------|--------|---------|
| `ai-generated` | 🤖 | AI分析 | 顶部 | info | 所有AI回复 |
| `engine-verified` | 📊 | 引擎验证 ✓ | 内联 | info | 数值经引擎交叉校验通过 |
| `engine-mismatch` | ⚠️ | 数据待确认 | 内联 | warning | 偏差20-50% |
| `historical-only` | 📜 | 历史数据 | 内联 | info | 分析仅基于回测历史 |
| `low-confidence` | 🔴 | 低置信度 | 顶部 | caution | 置信度<50% |
| `time-sensitive` | ⏰ | 时效性提醒 | 顶部 | warning | 分析>24h未更新 |
| `simulated-only` | 🧪 | 模拟回测 | 内联 | info | 非实盘回测结果 |
| `no-guarantee` | 📋 | 不保证未来 | 底部 | warning | 涉及预测性陈述时 |

#### 2.4 颜色方案

```
info     → 灰色 (#6B7280) — 中性信息，无警告含义
warning  → 琥珀金 (#D4A853) — 与品牌金色一致的警告，不引起恐慌
caution  → 柔橙 (#F7931A) — 明确需要注意但不等于红色(危险)
```

### Layer 3: 场景化免责 (Context-Aware Disclaimer)

不同AI场景 → 不同风险级别 → 不同免责文案。

#### 3.1 场景分级

| 场景 | 风险等级 | 免责策略 |
|------|:---:|------|
| 因子解释/教育 | 🟢 低 | 仅AI生成标签 |
| 策略健康检查 | 🟢 低 | AI标签 + "基于历史" |
| 因子推荐 | 🟡 中 | 完整标签行 + 内联历史提示 |
| 因子组合建议 | 🟡 中 | 同上 + "不构成建议" |
| 权重自动调整 | 🟠 中高 | + "调整后请回测验证" |
| 自动交易信号 | 🔴 高 | + 弹窗确认 + 第二次勾选 |
| 杠杆/衍生品建议 | 🔴 高 | + 强制阅读3秒 + 勾选确认 |

#### 3.2 高危场景额外流程

```
🔴 自动交易信号 / 杠杆建议场景:

步骤1: AI分析完成 → 显示结果 + 所有标签
步骤2: 用户点击"应用此方案" →
  ┌───────────────────────────────────────────────┐
  │ ⚠️ 重要操作确认                                │
  │                                               │
  │ 你即将应用AI推荐的 [策略名称]。                 │
  │                                               │
  │ 🔴 自动交易涉及实际资金风险                     │
  │ 🔴 本建议基于历史回测，实盘可能不同              │
  │ 🔴 建议先在模拟环境中验证                       │
  │                                               │
  │ □ 我确认这不是一次性的赌博，我理解风险          │
  │ □ 我已用模拟账户测试过 (或我选择直接使用)        │
  │                                               │
  │ [模拟验证(免费)]  [确认应用]  [取消]            │
  └───────────────────────────────────────────────┘
步骤3: 确认后执行，记录审计日志
```

## 五、实现清单

### autoclaw 实现要点

```
1. AIConsentGate组件 (弹窗)
   - 检测 localStorage AIConsentState
   - 渲染Layer1弹窗
   - 勾选状态 → 启用按钮
   - consent后写 localStorage + server API

2. InlineBadge组件
   - 接收 badgeType + message 渲染标签
   - 颜色/位置/图标按规格表
   - hover 显示 tooltip

3. AIResponseFooter组件
   - 收尾内联标签
   - 可折叠来源面板
   - "不保证未来"标签

4. HighRiskConfirmGate组件
   - 高危场景二次确认弹窗
   - 强制阅读3秒 (仅杠杆场景)
   - 审计日志记录

5. AIConsentService (server)
   - 用户consent记录存储
   - 版本管理 (更新后重签)
   - 审计日志
```

### ML实现要点

```
- AIConsentGate 放入 AIAIAssistantPanel 和 AIFactorAdvisor 入口
- InlineBadge 放入 AIResponseRenderer
- FactorCard 集成标签 (低置信度等)
- 设置页 → AI → "查看AI使用声明"链接
- 设置页 → AI → "建议强度"滑条
```
