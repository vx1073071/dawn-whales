## 二、价值锚定策略

### 2.1 锚定原理

```
锚定价: 按次 1.0 USDT (Basic) ← 用户心理基准
Pro:     0.8 USDT/次 (省20%) ← 第一个"优惠"锚
Elite:   0.65 USDT/次 (省35%) ← 第二个"更省"锚
Ultimate: ~0.50 USDT/次 (省55%) ← 第三个"最省"锚

用户感知: "Pro已经省20%了，Elite更省，Ultimate随便用"
```

### 2.2 三个价值锚点

| 锚点 | 触发方式 | 文案 | 心理效应 |
|------|---------|------|---------|
| **割肉感** | Basic 按次每次都弹出费用预览 | "每次都要手动确认支付" | 用户觉得麻烦→升级 |
| **社交证明** | Pro 标注"最受欢迎" | "⭐ 76%用户选择" | 从众心理→选Pro |
| **单位成本** | Elite 强调"每分析仅0.65U" | "🏆 超值之选·每分析省35%" | 单位成本思维→升级 |

### 2.3 升级诱导文案

```
Pro → Elite:
  "用满10次仅需+2.5U，每分析再省0.15U → 升级至精英版"

Elite → Ultimate:
  "本月已用15次? 升级旗舰版无限用仅10U，直接省到底 → 升级至旗舰版"
```

## 四、定价心理学要点

### 4.1 价格尾数

| 套餐 | 价格 | 尾数策略 |
|------|------|---------|
| Basic | 1.0 USDT | 整数、简单、无歧义（锚定点）|
| Pro | 4.0 USDT | 整除、每分析0.8U的心算友好 |
| Elite | 6.5 USDT | .5尾数暗示"精心计算过" |
| Ultimate | 10.0 USDT | 整数、"一杯咖啡钱"的心理暗示 |

### 4.2 对比效应

```
方案A（默认显示顺序）:
  按次: 1.0U/次
  Pro:  0.8U/次  ← 显眼标注"省20%·最受欢迎"
  Elite: 0.65U/次 ← 标"超值"
  Ultimate: 无限 ← 标"专业"

人眼扫描路径: 按次(贵) → Pro(还不错) → Elite(更便宜) → Ultimate(随便用)
```

### 4.3 中间选项效应

Pro (4U) 和 Elite (6.5U) 是中间选项，预期转换率最高。
- Pro: 第一次购买用户首选（低门槛升级）
- Elite: 回头客升级（省更多）
- Ultimate: 重度用户（锁定期用户粘性）
