## 二、雷达图 · 6维度定义

### 2.1 维度说明

```
六轴雷达图 (蜘蛛网):
- 每个因子一条闭合折线
- 6条轴从中心辐射
- 标度: 每条轴 0→1 归一化

  ┌─────────┬────────────────┬──────────────┬──────────────┐
  │ 维度     │ 原始指标        │ 归一化规则    │ 单位          │
  ├─────────┼────────────────┼──────────────┼──────────────┤
  │ IC       │ Information Coef│ IC / 0.1    │ 比值          │
  │ IR       │ Information Ratio│ IR / 2.0   │ 比值          │
  │ Sharpe   │ Sharpe Ratio    │ Sharpe / 3.0│ 比值          │
  │ 换手     │ Turnover Cost   │ 1 - cost/2% │ 反转 (低成本好) │
  │ 衰减     │ Half-Life (天)  │ hl / 90     │ 天数          │
  │ 拥挤     │ Crowding Score  │ 1 - crowd   │ 反转 (低拥挤好) │
  └─────────┴────────────────┴──────────────┴──────────────┘
```

**归一化边界**:
- IC: 0→0.1 (IC=0.1 → 归一化=1.0，实际多为0.01-0.07)
- IR: 0→2.0 (IR=2.0 → 归一化=1.0)
- Sharpe: 0→3.0
- 换手: 2%→0% (换手成本越低越接近1.0)
- 衰减: 0→90天 (半衰期越长越接近1.0)
- 拥挤: 100%→0% (拥挤越低越接近1.0)

### 2.2 颜色主题

```
每条折线颜色 (从因子主题色):
  动量 🟠 #FF9800
  质量 🟢 #4CAF50
  价值 🔵 #2196F3
  低波 🟣 #9C27B0
  股息 🟡 #FFC107
  增长 🔴 #F44336
  规模 🟤 #795548
  流动性 ⚪ #607D8B
  (支持最多8条折线同时显示)

雷达图底色: 透明 #1a1a2e
网格线: #333355 (虚线)
轴线标签: 白色 #e0e0e0
填充: 折线下方半透明 (同一颜色 15% opacity)
```

### 2.3 交互

```
- Hover 数据点 → 显示具体数值 tooltip
- Hover 图例 → 高亮对应折线 (其他变灰 30% opacity)
- 点击图例 → 隐藏/显示该因子
- 雷达图ECharts配置:
  radar.shape: 'circle' (不用polygon)
  radar.splitNumber: 5
  series.symbol: 'circle' | symbolSize: 6
  series.lineStyle.width: 2
```

## 三、IC热力图

### 3.1 颜色标度

```
IC值 → 颜色映射:

  IC ≥ 0.07    #004D40 (深绿 — 极强)
  IC ≥ 0.05    #1B5E20 (中绿 — 强有效)
  IC ≥ 0.04    #388E3C (浅绿 — 有效)
  IC ≥ 0.03    #689F38 (黄绿 — 边际有效)
  IC ≥ 0.02    #F57F17 (琥珀 — 较弱)
  IC ≥ 0.01    #E65100 (深橙 — 弱)
  IC <  0.01   #BF360C (红 — 无效/反向)

反向IC (负值):
  IC < 0       #B71C1C (深红 — 反向预测)
  (负IC在热力图中用红色标注, 表示因子方向相反)
```

### 3.2 热力图单元格

```
┌────────┐
│  🟢    │  ← 背景色 = 颜色标度
│  0.052 │  ← 数值 (白色, 加粗)
│  ▲+0.3%│  ← 变化量 (小字, 绿色=升 红色=降)
└────────┘

单元格尺寸: 48x32px
圆角: 4px
hover: 边框#d4a574 + 放大105%
```

### 3.3 热力图配置

```
行: 因子 (最多20)
列: 时间窗口 [1周, 1月, 3月, 6月, 1年]
单元格: IC值 + 颜色 + 变化箭头

底部汇总行: 平均IC (粗体)
右侧汇总列: 该因子所有窗口均值

排序: 默认按平均IC降序
过滤: "只看异常" → 仅显示有🔴黄/红色的行
```

## 四、3组默认对比场景

### 场景1: 🛡️ 防御 vs 🏄 动量

```
用途: 风险偏好决策 — 保守型 vs 激进型因子对比

对比因子:
  防御组: 低波(VOL_60D) + 质量(ROE_TTM) + 股息(DivYield) + 低Beta
  动量组: 动量(MOM_12M) + 短期动量(MOM_1M) + 波动率调整动量 + 资金流向

预期发现:
  - 雷达图: 防御组在"衰减"和"拥挤"维度占优; 动量组在"IC"和"Sharpe"占优
  - 热力图: 防御组IC稳定(小波动); 动量组IC波动大(牛市极高/震荡市低)
  - 关键洞察: "动量组合在牛市年化高15%, 但回撤也高20%"

AI一句话解读:
  "防御像定存, 动量像炒股——没有绝对的哪个好, 看市场的脸色。"
```

### 场景2: 💰 价值 vs 🚀 成长

```
用途: 风格判断 — 当前市场偏好价值还是成长

对比因子:
  价值组: E/P + B/P + S/P + DivYield
  成长组: EPS_Growth + RevGrowth + R&D/Sales + GrossMargin

预期发现:
  - 热力图: 历史IC交替领先 (价值股在2000-2006领先, 成长股在2015-2020领先)
  - 雷达图: 价值在"半衰期"维度更长 (价值因子衰减慢); 成长在"IC"更高
  - 关键洞察: "当前周期价值因子IC=0.023(弱), 成长因子IC=0.048(强), 市场仍偏好成长"

AI一句话解读:
  "价值和成长像龟兔赛跑——价值走得慢但稳, 成长跑得快但容易跌跤。"
```

### 场景3: 📊 自定义对比 (默认空, 用户自选)

```
用途: 用户自由选择任意2-8个因子进行对比

交互:
  1. 顶部因子选择器多选 (checkboxes)
  2. 实时更新雷达图+热力图+指标卡片
  3. [保存对比配置] → 下次一键加载

默认状态: 无选中 → 显示 "选择至少2个因子开始对比"
```

## 五、时间窗口切换

### 5.1 全局时间选择

```
[1月] [3月] [6月] [1年] [全部历史]

切换影响:
- 雷达图: 所有维度重新计算 (按所选窗口)
- 热力图: 列数不变, 数值更新
- IC趋势图: X轴范围变化
- 指标卡片: 数值更新

默认: 6月
```

### 5.2 更新动画

```
切换窗口 → 
  1. 数据加载 (骨架屏替代, 200ms)
  2. 雷达图: 折线平滑过渡到新位置 (transition 400ms)
  3. 热力图: 颜色渐变过渡 (transition 300ms)
  4. 摘要卡片: 数值翻转动画 (数字滚动效果, 300ms)
```

## 十、数据刷新策略

```
- 页面初始加载: 全量数据获取 (IPC: 'factor:compare' with 8 factor IDs)
- 时间窗口切换: 仅更新IC/IR/Sharpe数值 (复用缓存)
- 因子增删: 全量重新获取
- 轮询: 不自动刷新 (用户手动操作)
- 数据新鲜度提示: "数据更新于 2026-06-15 09:30" (底部状态栏)
```
