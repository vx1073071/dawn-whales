### 1.3 解锁逻辑

```typescript
type UserLevel = 'beginner' | 'experienced' | 'professional';

function getUserLevel(tradeCount: number, manualOverride?: UserLevel): UserLevel {
  if (manualOverride) return manualOverride; // 手动切换优先
  if (tradeCount >= 20) return 'professional';
  if (tradeCount >= 5) return 'experienced';
  return 'beginner';
}
```

## 二、5星难度体系

### 2.1 星级定义

| ⭐ | 标签 | 适用人群 | 特征 | 示例模板 |
|----|------|---------|------|---------|
| ⭐ | 非常简单 | 所有人 | 单一规则，无需参数调整 | HODL定投, 指数ETF |
| ⭐⭐ | 简单 | 新手+ | 1-2个因子，少量参数 | 高股息, BTC趋势 |
| ⭐⭐⭐ | 中等 | 有经验+ | 2-3个因子，需理解市场 | AH套利, 资金追踪 |
| ⭐⭐⭐⭐ | 较难 | 老手 | 多因子+跨市场+衍生品 | 窝轮方向, 期现套利 |
| ⭐⭐⭐⭐⭐ | 专家 | 专业 | 高复杂度/高杠杆/事件驱动 | 沽空挤压, 清算猎杀 |

### 2.2 难度判断矩阵

| 因子 | ⭐权重 | ⭐⭐ | ⭐⭐⭐ | ⭐⭐⭐⭐ | ⭐⭐⭐⭐⭐ |
|------|--------|-----|------|------|------|
| 因子数 | 1 | 1-2 | 2-3 | 3-5 | 5+ |
| 参数数 | 0-1 | 1-2 | 2-3 | 3-5 | 5+ |
| 市场跨度 | 单市场 | 单市场 | 跨板块 | 跨市场 | 跨资产 |
| 是否含衍生品 | ❌ | ❌ | ❌ | ⚠️可选 | ✅必须 |
| 最大杠杆 | 0x | 0x | 1x | 1-2x | 2x+ |
| 交易频率 | 月/季 | 周/月 | 周 | 日/周 | 日/小时 |
