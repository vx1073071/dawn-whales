# Part A: 一键诊断模式UX (1U/次)

## A.1 设计哲学

```
传统的因子分析: 选市场→选分析维度→选因子→看结果→不理解→选更多
                    ↑ 新手在这里就放弃了

一键诊断: 输代码 → 等10秒 → 看结论
          "这个股票最强的5个信号是什么？"
          像体检报告一样简单。
```

# Part B: 深度服务付费引导设计

## B.1 设计哲学

```
问题: 用户看到"1U/次"就想关掉。怎么让他愿意付？
答案: "免费预览=勾起好奇心 → 付费=给完整答案"

三部曲:
1. 免费预览 (免费) → "哇，看起来有用"
2. 看到刀刃 (模糊) → "但差一点就看不到了..."
3. 1U解锁 (付费) → "才1U，试试"
```
