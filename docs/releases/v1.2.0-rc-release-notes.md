# DAWN WHALES v1.2.0-rc Release Notes

**发布日期**: 2026-06-09  
**版本**: v1.2.0-rc  
**前置版本**: v1.2.0-beta  

---

## 🎉 版本概述

v1.2.0-rc 是 v1.2.0 正式版前的最后一个候选版本，聚焦于**性能收敛 + 商业化准备**。

### 关键成就

- ✅ **缓存命中率 ≥95%** (vs R57 的 90%)
- ✅ **单 Agent <8s, 4 Agent <25s** (vs R57 的 10s/30s)
- ✅ **单次成本 $0.011** (vs R57 的 $0.016)
- ✅ **创作者配置面板** (LLM 选型 + 预算管理)
- ✅ **成本监控仪表板** (实时告警 + 趋势分析)
- ✅ **测试数 4700+** (vs R57 的 4609)

---

## ✨ 新增功能

### 1. 创作者配置面板

- 11 家 LLM 提供商选择
- 月预算设置 + 告警
- 实时余额显示
- 成本预估工具

### 2. 成本监控仪表板

- 7 天/30 天成本趋势
- 按 Agent/模型维度统计
- 缓存命中率实时显示
- 折后过期预警

### 3. 缓存优化

- 命中率 90% → 95%
- 跨 Agent 缓存共享
- 热门标的预热
- 成本降低 31%
