## 快速部署

```bash
# 服务端
cd server && npm ci && npm run build && npm start

# 落地页
cp site/index.html /var/www/dawnwhales.com/

# 桌面端打包
npm run dist:win   # Windows
npm run dist:mac   # macOS
npm run dist:linux # Linux
```

### 环境变量

```
DEEPSEEK_API_KEY=  NODE_ENV=production
JWT_SECRET=        PORT=3000
```
