# DAWN WHALES v0.8.0 Release Notes

**版本**: v0.8.0
**发布日期**: 2026-06-07
**代号**: Autonomous Intelligence
**上一版本**: v0.7.0 (2026-06-06)

---

## 概述

v0.8.0 是 DAWN WHALES 的**自主智能**版本。本版本通过 8 个核心新引擎 + 6 个新 UI 面板，
将交易系统从"执行"层提升到"自主决策"层。系统现在具备：

- **在线参数自适应** (AdaptiveParamEngine) — 实时调整策略参数
- **强化学习奖励** (RewardEngine) — PnL + Sharpe 多目标奖励
- **K 线回放** (BacktestReplayEngine) — 倍速/断点/区间回放
- **策略优化** (StrategyOptimizer) — 网格/随机/贝叶斯三模式优化
- **多周期协调** (MultiTimeframeEngine) — 7 周期信号融合
- **组合风险** (PortfolioRiskEngine) — VaR/CVaR/相关性/压力测试
- **实盘桥接** (LiveTradeBridge) — 模拟→实盘统一桥
- **健康面板** (SystemHealthPanel) — 10 引擎实时监控

**测试覆盖率**: 1775 passed / 0 failed / 9 skipped (125 文件)
**代码增长**: 引擎总代码 4865L + UI 1340L + 文档 30.8KB

## 新增功能 (Highlights)

### 1. Phase 4.1-4.2 — 闭环 + 风险 (R29-R33)
- **ClosedLoopExecutor** (620L) — 信号→订单→对账 闭环
- **RebalanceEngine** (400L) — 组合再平衡（目标权重驱动）
- **Risk Engine v2** (10 个检查项) — VaR/CVaR 实时计算
- **PerformanceDashboard** — KPI 实时监控
- **TradingCalendar** — 节假日 + 交易日感知

### 2. Phase 4.3 — 集成与边界 (R34-R36)
- **5 模块联动**: ClosedLoop + Rebalance + Risk + Calendar + Executor
- **测试扩量**: 487 → 1484 (+997, 3× 增长)
- **稳定性**: 3 轮 0 fail

### 3. Phase 4.4 — 自主决策引擎 (R37-R38)
- **AdaptiveParamEngine** (1296L) — 在线学习
  - 网格搜索 / 随机 / 贝叶斯 三种模式
  - 15+ tests 覆盖
- **RewardEngine** (655L) — 强化学习奖励
  - PnL + Sharpe 多目标
  - 10+ tests 覆盖
- **BacktestReplayEngine** (745L) — K 线回放
  - 倍速 0.5x/1x/2x/MAX
  - 断点续播
  - 23+ tests 覆盖
- **SystemHealthPanel** — Dashboard 实时健康监控
  - 10 引擎心跳
  - 内存/CPU/错误率
- **AdaptiveParamPanel** (≥400L) — 4 策略类型自适应 UI

### 4. Phase 5.0 — 智能决策 (R39-R40)
- **StrategyOptimizer** (814L) — 策略优化
  - 网格 / 随机 / 贝叶斯 三模式
  - 27+ tests 覆盖
- **MultiTimeframeEngine** (656L) — 多周期
  - 7 周期: 1m/5m/15m/30m/1h/4h/1d
  - 信号融合与协调
  - 37+ tests 覆盖
- **PortfolioRiskEngine** (695L) — 组合风险
  - VaR / CVaR
  - 相关性矩阵
  - 压力测试 (含 wildcard)
  - 27+ tests 覆盖
- **LiveTradeBridge** (731L) — 实盘桥接
  - paper → live 同步
  - dry-run 模式
  - 仓位对账 + 审计追踪
- **3 个新 UI 面板**:
  - StrategyOptimizerPanel (≥400L)
  - PortfolioAnalyticsPanel (≥400L)
  - MultiTimeframePanel (≥400L)

## 已知限制

1. **v0.8.0 仅 paper 模式**: 实盘交易需用户显式启用 dry-run=false
2. **3 个 R40 提案被砍**: MultiSourceAggregator/RealtimeStream/PerformanceMonitor 留 R41+
3. **回放引擎仅支持 0-based 索引**: 未来或加 1-based 兼容层
