## 部署步骤

```bash
# Step 1: 拉取代码
git clone <repo-url> && cd dawn-whales
git checkout v1.8.1

# Step 2: 安装依赖
npm ci --production

# Step 3: 配置环境
cp .env.example .env
nano .env  # 填入上述变量

# Step 4: 构建
npm run build:server

# Step 5: 数据库迁移
npm run db:migrate
npm run db:seed    # 初始数据（可选）

# Step 6: 启动 (PM2)
pm2 start dist/server/api.js --name dawn-whales-api -i 2
pm2 start dist/server/admin.js --name dawn-whales-admin -i 1
pm2 save
pm2 startup

# Step 7: Nginx 配置
sudo cp nginx/dawn-whales.conf /etc/nginx/sites-available/
sudo ln -s /etc/nginx/sites-available/dawn-whales.conf /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx

# Step 8: SSL (Let's Encrypt)
sudo certbot --nginx -d api.dawnwhales.com -d admin.dawnwhales.com
```

## 常见打包问题

### Q1: 打包产物 > 150MB
- 检查 `node_modules` 是否包含 devDependencies
- 启用 Tree Shaking: `"treeShaking": true` in `electron-builder.yml`
- 排除不需要的文件: `"files": ["dist/**/*", "package.json"]`

### Q2: macOS 无法打开（未签名）
- 用户需: 系统偏好设置 → 安全性与隐私 → 仍要打开
- 长期: 申请 Apple Developer ID ($99/年)

### Q3: Linux AppImage 权限错误
- `chmod +x dist/dawn-whales-1.8.1.AppImage`
