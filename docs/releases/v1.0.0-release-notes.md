## 📖 升级指南

### 从 v0.13.0 升级

#### 步骤 1: 备份数据

```bash
# 备份配置
dawn-whales --backup-config

# 备份数据
dawn-whales --backup-data
```

#### 步骤 2: 下载新版本

- Windows: `DAWN-WHALES-Setup-1.0.0.exe`
- macOS: `DAWN-WHALES-1.0.0.dmg`
- Linux: `DAWN-WHALES-1.0.0.AppImage`

#### 步骤 3: 安装

**Windows**:
```powershell
.\DAWN-WHALES-Setup-1.0.0.exe
```

**macOS**:
```bash
open DAWN-WHALES-1.0.0.dmg
# 拖拽到 Applications
```

**Linux**:
```bash
chmod +x DAWN-WHALES-1.0.0.AppImage
./DAWN-WHALES-1.0.0.AppImage
```

#### 步骤 4: 验证

```bash
# 检查版本
dawn-whales --version
# 应输出: 1.0.0

# 运行健康检查
dawn-whales --health-check
```

### API 变更

#### 新增 API

1. **风险评分 API**
   ```typescript
   interface GetRiskScoreRequest {
     portfolioId: string;
   }
   
   interface GetRiskScoreResponse {
     score: number;
     level: 'low' | 'medium' | 'high';
     factors: RiskFactor[];
   }
   ```

2. **审计日志 API**
   ```typescript
   interface GetAuditLogsRequest {
     startDate: string;
     endDate: string;
     action?: string;
   }
   
   interface GetAuditLogsResponse {
     logs: AuditLog[];
     total: number;
   }
   ```

#### 废弃 API

无废弃 API，所有 v0.13.0 API 在 v1.0.0 中继续支持。

### 配置变更

#### 新增配置

```json
{
  "riskControl": {
    "enabled": true,
    "threshold": 0.8,
    "alertDelay": 500
  },
  "audit": {
    "enabled": true,
    "retentionDays": 90
  }
}
```

#### 配置迁移

v0.13.0 配置自动迁移到 v1.0.0，无需手动修改。
