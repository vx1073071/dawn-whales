## 🎉 v1.5.0-alpha：v15 业务基建

v1.5.0-alpha 实现 v15 商业模型的 5 项核心缺失基建，打通平台资金流动链路。

### 新增功能

- **P2P 积分转账**：0.3% 双向，14 天冻结期
- **申诉系统**：4 种类型，买方取消自动解锁
- **管理员解锁**：后台隐藏按钮，系统异常专用
- **黑名单**：手动管理，冻结 P2P+提现
- **2FA 安全**：TOTP 绑定，登录+提现验证

### 业务风控

- 大额告警 (>1000 USDT)
- 高频限制 (单日 >10 笔)
- 新账户限制 (注册 <7 天，≤500 USDT)

### 支付规则 (永久)

**仅 USDT 积分**。充值 0 手续费 / 提现 0.1%。
