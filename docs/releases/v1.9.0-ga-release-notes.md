## 🆕 v1.9.0 新功能

### 增长与运营
- 📊 **用户漏斗**: 注册→激活→AI→充值→付费 全链路追踪
- 📈 **7 日留存**: Day1/Day3/Day7 自动统计

- 📧 **邮件通知**: 注册确认 · 信号更新 · 收益周报

### 引擎补全
- 📡 **信号回测引擎** (27L→260L): 历史信号与K线对齐 · PnL/夏普/最大回撤
- 📰 **实时新闻引擎** (40L→300L): NewsAPI+东方财富双源 · 情绪打分
- 💰 **P2P 4引擎拆分**: 转账/申诉/冻结管理/黑名单 独立引擎

### 质量与安全
- 🔒 安全沙箱: child_process 命令注入防护 + 30s 超时
- 🛡️ CSRF/XSS/CSP: API 端 helmet + 输入净化 + CSP header
- 🌐 i18n: 9 语言 463 keys 对齐 (zh-HK 5 section 补全)
- ♿ a11y: WCAG AA 达标 · aria-label · 键盘导航 · 深色对比度
- 📏 ESLint + Prettier: pre-commit hook · CI 集成

### 部署优化
- 🐳 **Docker**: Dockerfile + docker-compose (app + postgres + redis)
- 📦 **PWA**: manifest + service worker · 离线缓存
- ⚡ **Bundle**: <150MB (TreeShaking + CodeSplit)
