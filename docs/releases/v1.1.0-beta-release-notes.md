
- Windows: `DAWN-WHALES-Setup-1.1.0-beta.exe` (90MB)

```powershell

.\DAWN-WHALES-Setup-1.1.0-beta.exe /S
```

```bash

open DAWN-WHALES-1.1.0-beta.dmg

# 拖拽到 Applications 文件夹
cp -R "DAWN WHALES.app" /Applications/
```


### API 变更

#### 新增 API

1. **交易员 API**
   ```typescript
   // 交易员注册
   POST /api/social/traders/register
   {
     nickname: string;
     avatar: string;
     bio: string;
   }
   
   // 交易员认证
   POST /api/social/traders/{id}/certify
   
   // 交易员主页
   GET /api/social/traders/{id}
   ```

2. **信号 API**
   ```typescript
   // 发布信号
   POST /api/social/signals
   {
     symbol: string;
     action: 'BUY' | 'SELL';
     entryPrice: number;
     stopLoss?: number;
     takeProfit?: number;
     confidence: number;
   }
   
   // 信号列表
   GET /api/social/signals
   
   // 信号详情
   GET /api/social/signals/{id}
   ```

3. **跟随交易 API**
   ```typescript
   // 跟随交易
   POST /api/social/signals/{id}/follow
   {
     positionSize: number;
     stopLoss?: number;
     takeProfit?: number;
   }
   
   // 我的跟随
   GET /api/social/follows
   
   // 取消跟随
   DELETE /api/social/follows/{id}
   ```

4. **收益 API**
   ```typescript
   // 查看收益
   GET /api/social/earnings
   
   // 提现
   POST /api/social/earnings/withdraw
   {
     amount: number;
     method: 'bank' | 'alipay';
   }
   ```

#### 废弃 API

无废弃 API，所有 v1.1.0-alpha API 在 v1.1.0-beta 中继续支持。

### 配置变更

#### 新增配置

```json
{

```

#### 配置迁移

v1.1.0-alpha 配置自动迁移到 v1.1.0-beta，无需手动修改。

## ⚠️ 已知问题

### 轻微问题

1. **移动端部分页面未完全适配**
   - 影响: 部分页面在移动端显示不完整
   - 计划: v1.1.0-rc 修复
   - 临时方案: 使用桌面端

2. **信号推送偶尔延迟**
   - 影响: 信号推送偶尔超过 500ms
   - 计划: v1.1.0-rc 优化
   - 临时方案: 刷新页面重新连接

3. **收益报表导出格式**
   - 影响: 仅支持 CSV 格式
   - 计划: v1.1.0-rc 添加 Excel/PDF
   - 临时方案: 使用 CSV

### 限制

1. **交易员认证需要 1-3 天**
   - 限制: 认证时间较长
   - 缓解: 提前申请
   - 计划: v1.1.0-rc 优化审核流程

2. **收益提现仅支持银行卡和支付宝**
   - 限制: 不支持其他支付方式
   - 缓解: 使用银行卡或支付宝
   - 计划: v1.1.0-rc 添加更多支付方式

3. **跟随交易最大数量限制**
   - 限制: 最多跟随 50 个信号
   - 缓解: 选择性跟随
   - 计划: v1.1.0-rc 提高限制
