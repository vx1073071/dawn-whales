## 🚀 升级指南

### 从 v0.11.0 升级

1. **备份数据**
   ```bash
   # 备份配置和数据
   cp -r ~/.dawn-whales ~/.dawn-whales.backup
   ```

2. **下载新版本**
   - Windows: DAWN-WHALES-Setup-0.12.0.exe
   - macOS: DAWN-WHALES-0.12.0.dmg
   - Linux: DAWN-WHALES-0.12.0.AppImage

3. **安装新版本**
   - Windows: 双击安装程序
   - macOS: 拖拽到 Applications
   - Linux: chmod +x && ./DAWN-WHALES-0.12.0.AppImage

4. **验证升级**
   - 检查版本号: 帮助 → 关于
   - 验证功能: PWA 离线、Marketplace、移动端手势

###  breaking changes
- **TypeScript strict 模式**: 如果有自定义插件，需要修复类型错误
- **PWA 缓存策略**: 首次加载可能需要重新缓存
