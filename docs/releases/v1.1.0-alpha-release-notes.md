## 📖 升级指南

### 从 v1.0.1 升级

#### 步骤 1: 备份数据

```bash
# 备份配置
dawn-whales --backup-config

# 备份数据
dawn-whales --backup-data
```

#### 步骤 2: 下载新版本

- Windows: `DAWN-WHALES-Setup-1.1.0-alpha.exe` (88MB)
- macOS: `DAWN-WHALES-1.1.0-alpha.dmg` (95MB)
- Linux: `DAWN-WHALES-1.1.0-alpha.AppImage` (81MB)

#### 步骤 3: 安装

**Windows**:
```powershell
# 双击运行安装程序
.\DAWN-WHALES-Setup-1.1.0-alpha.exe

# 或使用命令行静默安装
.\DAWN-WHALES-Setup-1.1.0-alpha.exe /S
```

**macOS**:
```bash
# 打开 DMG 文件
open DAWN-WHALES-1.1.0-alpha.dmg

# 拖拽到 Applications 文件夹
cp -R "DAWN WHALES.app" /Applications/
```

**Linux**:
```bash
# 添加执行权限
chmod +x DAWN-WHALES-1.1.0-alpha.AppImage

# 运行
./DAWN-WHALES-1.1.0-alpha.AppImage
```

#### 步骤 4: 验证

```bash
# 检查版本
dawn-whales --version
# 应输出: 1.1.0-alpha

# 运行健康检查
dawn-whales --health-check

# 检查性能
dawn-whales --performance-check
```

#### 步骤 5: 恢复数据（如需要）

```bash
# 恢复配置
dawn-whales --restore-config

# 恢复数据
dawn-whales --restore-data
```

### API 变更

#### 新增 API

1. **策略市场 API**
   ```typescript
   // 策略发布
   POST /api/marketplace/strategies
   {
     name: string;
     description: string;
     code: string;
     category: string;
     tags: string[];
     price: number;
   }
   
   // 策略搜索
   GET /api/marketplace/strategies/search?q={query}&category={category}&tags={tags}
   
   // 策略订阅
   POST /api/marketplace/strategies/{id}/subscribe
   
   // 策略评价
   POST /api/marketplace/strategies/{id}/reviews
   {
     rating: number;
     comment: string;
   }
   ```

2. **收益 API**
   ```typescript
   // 查看收益
   GET /api/marketplace/earnings
   
   // 提现
   POST /api/marketplace/earnings/withdraw
   {
     amount: number;
     method: 'bank' | 'alipay';
   }
   ```

#### 废弃 API

无废弃 API，所有 v1.0.1 API 在 v1.1.0-alpha 中继续支持。

### 配置变更

#### 新增配置

```json
{
  "marketplace": {
    "enabled": true,
    "autoUpdate": true,
    "notificationEnabled": true
  },
  "earnings": {
    "minWithdrawAmount": 100,
    "platformShare": 0.3,
    "authorShare": 0.7
  }
}
```

#### 配置迁移

v1.0.1 配置自动迁移到 v1.1.0-alpha，无需手动修改。

## ⚠️ 已知问题

### 轻微问题

1. **策略市场移动端未适配**
   - 影响: 移动端用户体验
   - 计划: v1.2.0 修复
   - 临时方案: 使用桌面端

2. **策略代码编辑器性能**
   - 影响: 大文件编辑时卡顿
   - 计划: v1.1.0-beta 优化
   - 临时方案: 分段编辑

3. **收益报表导出格式**
   - 影响: 仅支持 CSV 格式
   - 计划: v1.1.0-beta 添加 Excel/PDF
   - 临时方案: 使用 CSV

### 限制

1. **策略市场仅支持桌面端**
   - 限制: 移动端无法访问策略市场
   - 缓解: 使用桌面端
   - 计划: v1.2.0 添加移动端支持

2. **收益提现仅支持银行卡和支付宝**
   - 限制: 不支持其他支付方式
   - 缓解: 使用银行卡或支付宝
   - 计划: v1.1.0-beta 添加更多支付方式

3. **策略审核需要 1-3 天**
   - 限制: 审核时间较长
   - 缓解: 提前提交
   - 计划: v1.1.0-beta 优化审核流程
