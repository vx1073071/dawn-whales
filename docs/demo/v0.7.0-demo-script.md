# v0.7.0 内部演示脚本

## 演示目标
展示 DawnWhales v0.7.0 核心功能：行情 → 选股 → 回测 → 下单 → 风控 → 持仓监控

## 环境准备
- OpenD 已启动（127.0.0.1:11111）
- 应用已编译（npm run build 通过）
- 演示账户有充足资金

---

## 常见问题 & 备用方案

| 问题 | 备用方案 |
|------|---------|
| OpenD 未连接 | 使用 mock 数据模式，演示功能不受影响 |
| 回测超时 | 减少回测数据量（100条 → 50条） |
| 下单失败 | 使用 PaperTrader（模拟盘）演示 |
| 行情推送延迟 | 展示手动刷新按钮功能 |

## 验收标准
- [ ] 8 个演示环节全部通过
- [ ] 0 个阻塞性 bug
- [ ] 截图完整（8张）
- [ ] 演示时长 8-12 分钟

## Fallback 计划

| 步骤 | 失败场景 | 备用方案 |
|------|----------|----------|
| 1 启动连接 | OpenD 未运行 | 手动启动 OpenD 或展示 Settings 连接页面 |
| 2 行情中心 | 无实时数据 | 展示 K 线图缓存数据 + Demo K线生成器 |
| 3 策略回测 | DeepSeek API 不可用 | 使用预置策略模板 + 本地回测 |
| 4 交易下单 | 账户未登录 | 切换到模拟盘模式 (PaperTrader) |
| 5 风控仪表盘 | 引擎未初始化 | 展示静态配置页面 + 说明初始化步骤 |
| 6 持仓管理 | 无实际持仓 | 展示模拟持仓数据 |
| 7 多语言切换 | 缺少翻译 | 展示英文版本（覆盖最全） |
| 8 紧急停止 | 无明显效果 | 说明策略状态变化 + 日志记录 |

## 风险提示

- 止损止盈可能触发实际交易
- API Key 不要暴露在截图中
