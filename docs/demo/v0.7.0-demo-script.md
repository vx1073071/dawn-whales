# v0.7.0 内部演示脚本

## 演示目标
展示 DawnWhales v0.7.0 核心功能：行情 → 选股 → 回测 → 下单 → 风控 → 持仓监控

## 环境准备
- OpenD 已启动（127.0.0.1:11111）
- 应用已编译（npm run build 通过）
- 演示账户有充足资金

---

## 演示流程（预计 10 分钟）

### 1. 启动 & 连接（1分钟）
**操作：** 启动应用
**检查点：**
- [ ] OpenD 健康检查面板显示 "健康"（绿色）
- [ ] 状态栏显示 "Push 模式 · <50ms"
- [ ] 侧边栏正确加载，语言为中文

**截图：** 启动完成后的 Dashboard 总览

### 2. 行情中心（2分钟）
**操作：** 点击「行情中心」
**检查点：**
- [ ] 自选股列表实时更新（价格闪烁动画）
- [ ] K 线图正确加载（日K/周K切换）
- [ ] 点击股票代码进入个股诊断

**截图：** MarketPage 实时行情 + K线图

### 3. 智能选股（1分钟）
**操作：** 点击「智能选股」
**检查点：**
- [ ] 预设策略列表：高ROE低PE / 小市值成长股 / 行业龙头
- [ ] 选股结果表格正确渲染
- [ ] 点击股票可添加到自选

**截图：** StockScreenerPage 选股结果

### 4. 策略回测（2分钟）
**操作：** 点击「策略」→ 选择「双均线突破策略」→ 点击回测
**检查点：**
- [ ] 回测参数面板正确显示
- [ ] 回测执行中显示进度条
- [ ] 回测结果：收益曲线图、回撤图、月度热力图
- [ ] 关键指标：总收益率 / 夏普比率 / 最大回撤 / 胜率

**截图：** BacktestReportPage 回测结果

### 5. 交易台下单（2分钟）
**操作：** 点击「交易」→ TradingDesk
**检查点：**
- [ ] 3列布局：订单簿 / 交易执行 / 盈亏+持仓
- [ ] 订单簿实时更新（买卖5档）
- [ ] 输入股票代码 → 显示实时价格
- [ ] 选择买入/卖出 → 选择限价/市价 → 输入数量 → 点击下单
- [ ] 订单确认弹窗正确显示
- [ ] 下单成功后订单出现在「 active orders」列表

**截图：** TradingDesk 下单流程

### 6. 风控监控（1分钟）
**操作：** 点击「风控」
**检查点：**
- [ ] 风险仪表盘显示组合 VaR / CVaR
- [ ] 持仓风险敞口分解（行业/市场/因子）
- [ ] 如果有风险告警，显示告警卡片

**截图：** RiskDashboardPage 风险监控

### 7. 多语言切换（30秒）
**操作：** 点击 Header 右上角语言切换器
**检查点：**
- [ ] 切换到 English → 所有文本变为英文
- [ ] 切换到 日本語 → 所有文本变为日文
- [ ] 切换回 简体中文

**截图：** 多语言对比

### 8. 紧急停止（30秒）
**操作：** 点击 Header 右上角 ⏸️ 紧急停止按钮
**检查点：**
- [ ] 所有运行中的策略立即停止
- [ ] Toast 通知："紧急停止已触发，所有策略已停止"
- [ ] 状态栏显示策略状态为「已停止」

**截图：** 紧急停止后的状态

## 常见问题 & 备用方案

| 问题 | 备用方案 |
|------|---------|
| OpenD 未连接 | 使用 mock 数据模式，演示功能不受影响 |
| 回测超时 | 减少回测数据量（100条 → 50条） |
| 下单失败 | 使用 PaperTrader（模拟盘）演示 |
| 行情推送延迟 | 展示手动刷新按钮功能 |
