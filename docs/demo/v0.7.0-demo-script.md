# DAWN WHALES v0.7.0 — 内部演示脚本

> 日期: 2026-06-05 | 演示者: 主龙虾 | 时长: ~15分钟

---

## 演示流程

### 1. 启动 & 连接 (60s)

**操作:**
1. 启动 DAWN WHALES 桌面应用
2. 检查状态栏 — "OpenD 已连接 ✅ 实时数据"
3. 确认 Sidebar 显示账户余额 (~1760万HKD)

**截图点:** 状态栏 + Sidebar 账户概览

**检查项:**
- [ ] OpenD 自动连接成功
- [ ] 账户余额正确显示
- [ ] 连接状态绿色指示

---

### 2. 行情中心 → 选股 (90s)

**操作:**
1. 导航 → 行情中心
2. 搜索 "TQQQ" → 添加到自选
3. 查看 TQQQ K线图 (日K/60分钟切换)
4. 确认实时报价更新 (Push模式 <50ms)

**截图点:** TQQQ K线图 + 报价面板

**检查项:**
- [ ] 搜索功能正常
- [ ] K线数据显示正确
- [ ] 周期切换 (1m→5m→15m→60m→日K→周K)
- [ ] 实时价格更新

---

### 3. 策略工坊 → 回测 (120s)

**操作:**
1. 导航 → 策略工坊
2. 使用自然语言创建策略:
   > "MA5上穿MA20买入TQQQ，止损5%，止盈15%"
3. 点击 "解析策略" → AI自动填充参数
4. 点击 "运行回测" → 查看回测结果

**截图点:** NL解析结果 + 回测报告(权益曲线/绩效指标)

**检查项:**
- [ ] NL解析正确识别: MA5、MA20、TQQQ、SL5%、TP15%
- [ ] 回测引擎运行成功
- [ ] 权益曲线渲染
- [ ] 绩效指标: 总收益率、夏普比率、最大回撤、胜率

---

### 4. 交易台 → 下单 (90s)

**操作:**
1. 导航 → 交易台 (TradingDesk)
2. 确认左侧订单簿显示 (模拟5档)
3. 快速下单面板: 选择 "买入" → "限价" → 输入价格/数量
4. 点击 "提交订单"
5. 确认风控通过 (无拦截)
6. 查看订单在 "当前委托" 中出现

**截图点:** TradingDesk 全貌 + 下单确认弹窗

**检查项:**
- [ ] 订单簿渲染
- [ ] 下单面板交互正常
- [ ] 风控检查 (日亏损限制、持仓限制)
- [ ] 订单提交成功

---

### 5. 风控仪表盘 (60s)

**操作:**
1. 导航 → 风控仪表盘
2. 查看全局风险指标:
   - VaR (风险价值)
   - 总敞口
   - 日亏损限额使用率
3. 确认告警面板显示 (如有)

**截图点:** 风控仪表盘概览

**检查项:**
- [ ] 风险指标数据正确
- [ ] 图表渲染
- [ ] 告警系统工作

---

### 6. 持仓管理 (60s)

**操作:**
1. 导航 → 持仓管理
2. 查看持仓列表 (TQQQ/SOXL等)
3. 确认 盈亏/市值/占比 正确
4. 查看资产配置饼图

**截图点:** 持仓列表 + 资产配置图

**检查项:**
- [ ] 持仓数据与 OpenD 一致
- [ ] PnL 计算正确 (红涨绿跌)
- [ ] 资产配置图表

---

### 7. i18n 多语言切换 (30s)

**操作:**
1. 设置 → 语言切换: 中文 → English → 日本語
2. 确认 TradingDesk/StrategyPage 文本正确翻译

**截图点:** 英文/日文 TradingDesk

**检查项:**
- [ ] 8种语言切换正常
- [ ] 核心页面翻译覆盖

---

### 8. 紧急停止 (30s)

**操作:**
1. 点击 Header "紧急停止 🛑"
2. 确认所有策略暂停、订单取消

**截图点:** 紧急停止后的状态
