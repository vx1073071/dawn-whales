## 3. 连接券商

DAWN WHALES 支持多券商同时连接，一键切换。

### 3.1 Futu OpenD（推荐新手）

**支持市场**: 港股、美股、A股（沪/深）、新加坡、日本

**连接步骤**:
1. 下载 [Futu OpenD](https://www.futunn.com/download/openAPI)
2. 启动 OpenD → 在 GUI 中登录你的富途账号
3. 在 OpenD GUI 中**手动解锁交易密码**（安全规定，禁止程序解锁）
4. 桌面端 → **设置 → 券商管理 → 添加** → 选择「Futu OpenD」
5. 输入地址 `127.0.0.1` 和端口 `11111`
6. 点击「连接」→ 看到 ✅ 即成功

**验证连接**:
- 行情页搜索任意港股代码（如 `HK.00700`），应返回实时报价
- 持仓页应显示你的 Futu 持仓

### 3.2 Interactive Brokers (IBKR)

**支持市场**: 全球 150+ 市场，含美股、港股、欧股、日股

**前置条件**:
- IBKR 账户已开通
- IB Gateway 或 TWS 已安装

**连接步骤**:
1. 启动 IB Gateway → 登录 → 配置 API 设置
2. 勾选「启用 ActiveX 和套接字客户端」
3. 设置端口（默认 7497 for TWS / 4002 for Gateway）
4. 桌面端 → **设置 → 券商管理 → 添加** → 选择「IBKR」
5. 输入 IP + 端口 + Client ID
6. 点击「连接」

**费率说明**:
| 市场 | 佣金 | 平台费 | 印花税 |
|------|------|--------|--------|
| 美股 | $0.005/股 (最低$1) | - | - |
| 港股 | 0.03% (最低HKD 3) | HKD 15/笔 | 0.13% |
| A股 | 0.025% (最低CNY 5) | - | 0.05%(卖方) |

### 3.3 多券商切换

在**券商管理**页面，你可以添加多个券商配置。顶部下拉框一键切换活跃券商。所有持仓和订单按券商分组显示。

## 4. 策略创建与管理

### 4.1 模板创建（最快，30 秒）

1. 点击 **策略工场** → **套用模板**
2. 选择模板（按市场环境推荐）：
   - **动量策略**: 追涨杀跌，适合单边牛市
   - **均值回归**: 低买高卖，适合震荡市
   - **双均线策略**: 金叉买/死叉卖，适合趋势市
   - **MACD 策略**: 柱线反转，适合中短线
   - **RSI 超买超卖**: 顺势而为，适合反转捕捉
   - **布林带策略**: 突破上/下轨，适合高波动
   - **成交量突破**: 量价配合，适合确认趋势
3. 选择市场和标的（单只或一组）
4. 调整参数（或直接用默认值）
5. 点击 **回测** → 查看绩效

### 4.2 AI 语音创建

1. 策略工场 → **🎤 说出你的策略**
2. 用自然语言描述，例如：
   - "MA5 升穿 MA20 买入 TQQQ，止损 5%，止盈 15%"
   - "帮我做一个 A 股高股息防守型策略"
   - "当 RSI 低于 30 且成交量放大时买入"
3. AI 自动将自然语言解析为可执行策略配置
4. 在配置页面确认和微调 → 回测 → 发布

### 4.3 手动创建（完全自定义）

1. 策略工场 → **新建策略** → **自定义**
2. 依次设置：
   - **选股范围**: 市场、板块、市值范围、排除 ST 等
   - **入场条件**: 技术指标组合（AND/OR 逻辑）
   - **出场条件**: 止盈、止损、时间止损、信号反转
   - **仓位管理**: 固定仓位、凯利公式、波动率调整
   - **风控规则**: 单日上限、最大回撤、黑名单
3. 保存策略 → 回测 → 迭代优化

### 4.4 策略管理

- **编辑**: 随时修改已保存策略的参数
- **克隆**: 复制策略作为新策略的起点
- **启用/禁用**: 暂停策略的信号生成
- **删除**: 永久删除策略（不可恢复）
- **导出/导入**: JSON 格式，方便备份和分享

## 5. 回测与优化

### 5.1 运行回测

1. 在策略编辑页点击 **回测**
2. 设置回测参数：
   - **时间范围**: 开始和结束日期
   - **初始资金**: 默认 100,000
   - **基准指数**: 用于对比（如恒生指数、标普 500）
3. 点击「开始回测」→ 等待计算完成（通常 1-3 秒）

### 5.2 回测报告指标

| 指标 | 说明 | 参考标准 |
|------|------|----------|
| 总收益率 | 期末资金/期初资金 - 1 | >0 盈利 |
| 年化收益率 | 按年折算的收益 | >10% 优秀 |
| 夏普比率 | 风险调整后收益 | >1.0 良好, >2.0 优秀 |
| 最大回撤 | 最大峰谷跌幅 | <20% 可接受 |
| 胜率 | 盈利交易占比 | >50% |
| 盈亏比 | 平均盈利/平均亏损 | >1.5 良好 |
| 卡玛比率 | 年化收益/最大回撤 | >1.0 良好 |
| 索提诺比率 | 下行风险调整收益 | 越高越好 |

### 5.3 参数优化

1. 回测结果页 → **参数优化**
2. 选择要优化的参数（如 MA 周期、RSI 阈值）
3. 设定参数范围和步长
4. 点击「运行优化」→ 系统自动搜索最佳参数组合
5. 对比优化前后绩效 → 确认是否应用

### 5.4 前向分析 (Walk-Forward)

避免过拟合的高级技术：
1. 将历史数据分为训练期和测试期
2. 在训练期优化参数 → 在测试期验证
3. 滚动窗口多次验证 → 评估策略稳定性

**交互**: AI 画线后，用户可以拖拽修正、删除、手动添加。AI 画的线会显示置信度。

### 6.4 AI 助手

## 7. 交易执行

### 7.1 实盘交易

**前置条件**:
- 券商已连接且交易密码已解锁
- 策略已回测且结果满意
- 风控参数已设置

**启动自动交易**:
1. 策略详情页 → **实盘执行** → 开启开关
2. 选择交易环境（模拟/实盘）
3. 确认风控参数
4. 点击「确认启动」
5. 策略产生的信号会自动通过券商 API 下单

### 7.2 手动交易

1. **交易面板** → **手动下单**
2. 选择标的、方向（买入/卖出）、数量、价格类型（市价/限价）
3. 确认 → 下单
4. 在 **订单簿** 中查看订单状态

### 7.3 持仓管理

- **实时持仓**: 查看所有账户的当前持仓和盈亏
- **持仓分析**: 按行业/市值/风格分组展示
- **盈亏计算**: 含佣金、印花税、平台费的精确盈亏

### 7.4 碎股交易

A 股支持 **100 股起**（1 手起），美股支持 **1 股起**。

## 8. 钱包与 USDT

### 8.1 钱包概述

DAWN WHALES 使用 USDT（TRC-20）作为平台内唯一支付货币。无需信用卡或法币。

### 8.2 充值

1. 桌面端 → **钱包** → **充值**
2. 复制系统生成的 TRC-20 充值地址
3. 在你的交易所/钱包中向该地址转账 USDT
4. 等待 19 个区块确认（约 3-5 分钟）
5. 余额自动更新

**充值规则**:
- 最低充值金额: 10 USDT
- 网络: 仅 TRC-20（TRON）
- 平台手续费: 0%（链上矿工费由你承担）

### 8.3 提现

1. 钱包 → **提现**
2. 输入目标 TRC-20 地址和金额
3. 输入交易密码（6 位数字）
4. 确认 → 等待处理（通常 10-30 分钟）

**提现规则**:
- 最低提现金额: 20 USDT
- 平台手续费: 0.1%
- 首次提现需通过 2FA 验证（如已启用）

### 8.4 消费记录

钱包 → **账单** → 查看所有充值、提现、消费记录。每条记录包含时间、金额、类型、状态。

### 8.5 创作者收入

- 策略被订阅 → 收入按分成比例自动入账
- 每月 1 日结算上月收入
- 收入明细在钱包 → 收入记录中查看

## 9. P2P 转账

### 9.1 转账步骤

1. 钱包 → **P2P 转账**
2. 输入对方钱包地址
3. 输入转账金额（USDT）
4. 确认转账（含 0.3% 手续费）
5. 对方收到 USDT

### 9.2 冻结期

所有 P2P 转账有 **14 天冻结期**：
- 转账后 14 天内，接收方资金处于冻结状态（不能提现和转出）
- 14 天后自动解冻
- 冻结期内双方可以发起申诉

### 9.3 申诉机制

如果转账出现问题（未收到、金额不对、对方不回复）：
1. 在冻结期（14 天）内提交申诉
2. 选择申诉原因：收款未确认 / 未按约定 / 账号异常 / 其他
3. 提交证据（截图等）
4. 管理员审核后判定：
   - 买方申诉成功 → 资金解冻退回
   - 买方申诉失败 → 冻结继续直到期满

### 9.4 黑名单

管理员可以将恶意用户加入黑名单。黑名单用户禁止 P2P 转账和提现。

## 11. 信号广场

### 11.1 什么是信号广场

信号广场展示所有已发布策略的实时交易信号（买/卖/持有），不需要订阅策略即可浏览。

### 11.2 信号筛选

- 按市场筛选（港股/美股/A股...）

## 17. 常见问题

### Q: 完全免费吗？
A: 下载和基础功能（策略创建/回测/信号广场）免费。AI 分析和策略上架使用 USDT 付费。新人注册赠送 3 次免费 AI 分析。

### Q: 我的策略安全吗？
A: 策略代码存储在你的本地。发布到市场时自动脱敏，订阅者只能收到交易信号，看不到你的具体参数。

### Q: 能连接多个券商吗？
A: 可以。设置 → 券商管理 → 添加多个配置 → 一键切换。

### Q: 支持哪些市场？
A: 港股、美股、A股（沪/深）、新加坡、日本、澳洲、加拿大 — 共 7 个市场。

### Q: 自动交易有风险吗？
A: 有。量化交易不保证盈利，历史回测收益不代表未来。请务必设置风控参数，从小资金开始。

### Q: AI 分析用的是什么模型？
A: 我们使用多种 AI 模型（包括 DeepSeek、Qwen 等），通过缓存和降级链确保高可用和低成本。

### Q: USDT 充值后能退款吗？
A: 充值的 USDT 可以提现回你的钱包。已消费的 USDT（AI 分析、策略购买）不支持退款。

### Q: P2P 转账冻结期能取消吗？
A: 不能。14 天冻结期是固定规则，用于保护交易双方。冻结期内可申诉。

### Q: 策略模板从哪里来？
A: 平台提供 20+ 预设模板。你也可以将自己的策略设为私有模板（不公开到市场）。
