# DAWN WHALES · 道鲸 — 用户指南

## 🚀 安装

1. 从 [GitHub Releases](https://github.com/vx1073071/dawn-whales/releases) 下载最新 `.exe` 安装包
2. 双击运行安装程序，选择安装目录
3. 安装完成后桌面会出现 **DAWN WHALES** 快捷方式

## ⚙️ 前置条件

### 安装并运行富途 OpenD

道鲸需要富途 OpenD 作为行情和交易网关：

1. 下载 [富途 OpenD](https://openapi.futunn.com/futu-api-doc/opend/opend-cmd.html)
2. 启动 OpenD（默认端口 `11111`）
3. 确保 OpenD 已登录你的富途/moomoo 账户

### 连接道鲸

1. 打开 DAWN WHALES
2. 首次启动会自动弹出引导向导
3. 点击 **连接 OpenD** 按钮
4. 连接成功后左侧侧栏会显示你的账户余额

## 📊 行情中心

### 查看行情
- 默认自选股：TQQQ, SOXL, QQQ, SPY, AAPL, NVDA, SQQQ, SOXS
- 点击任意股票查看 K 线图

### 添加自选股
1. 点击右上角 **+ 添加自选**
2. 搜索股票代码或名称（支持 24 只热门美股/ETF）
3. 点击添加到自选列表

### K 线周期
选中股票后，K 线图上方有周期切换按钮：
- **1分** — 超短线
- **5分** — 日内交易
- **15分** — 短波段
- **60分** — 中波段
- **日K** — 日线（默认）
- **周K** — 周线

### 回测结果

回测完成后会显示：
- **总收益** / **年化收益** — 策略整体表现
- **夏普比率** — 风险调整后收益（>1 为良好，>2 为优秀）
- **最大回撤** — 策略最大亏损幅度
- **胜率** — 盈利交易占比
- **盈亏比** — 平均盈利/平均亏损
- **权益曲线** — 资金变化可视化
- **交易明细** — 每笔交易的进出场详情

### 启动实盘

1. 在策略详情页点击 **⚡ 启动实盘**
2. 策略引擎开始实时监控行情
3. 当满足买入条件时自动下单
4. 止损/止盈自动触发
5. 所有信号和交易通过通知系统推送

## 💼 持仓管理

- **总资产** — 账户总市值
- **今日盈亏** — 当日盈亏金额
- **持仓市值** — 当前持仓总市值
- **可用资金** — 可用于买入的现金
- **购买力** — 考虑保证金后的最大购买额
- **资产配置** — 彩色条形图展示各持仓占比
- 自动刷新（30 秒，可关闭）

## 📋 委托订单

- **当前委托** — 未成交/部分成交的订单，可一键撤单
- **历史委托** — 已成交/已撤销/已拒绝的订单
- **策略交易记录** — 策略引擎自动生成的交易记录

## 🛡️ 风控设置

在系统设置中可调整：
- **日最大亏损** — 当日亏损达到此比例时停止交易（默认 5%）
- **单品种最大仓位** — 单个标的最大占比（默认 20%）
- **总持仓上限** — 总持仓最大占比（默认 95%）
- **每分钟最大下单** — 下单频率限制（默认 10 笔）

## ⚙️ 系统设置

- **OpenD 连接** — 修改地址/端口，连接/断开
- **券商选择** — 富途/moomoo（未来支持更多券商）
- **交易环境** — 实盘 / 模拟盘
- **系统信息** — 版本、平台、Electron/Node/Chrome 版本

## ❓ 常见问题

**Q: 连接 OpenD 失败怎么办？**
确保 OpenD 已启动并登录。默认地址 `127.0.0.1:11111`。道鲸支持自动重连，断线后会每 1-30 秒重试。

**Q: 行情数据收费吗？**
LV1 基础行情通过 OpenD 免费获取。如有 LV3 行情订阅也可直接使用。

**Q: 策略数据安全吗？**
所有策略在本地运行，数据不上传服务器。你的代码、你的数据、你的策略。

**Q: 支持自动更新吗？**
是的。道鲸启动后 10 秒检查更新，之后每 4 小时检查一次。有新版本时会弹窗通知。
