## 1. OpenD 安装与配置

### 系统要求
- Windows 10+ / macOS 10.15+
- 至少 4GB RAM
- 需有富途账户

### 安装步骤

1. 下载 [Futu OpenD](https://www.futunn.com/download/openAPI)
2. 安装并启动 OpenD
3. 默认端口: `127.0.0.1:11111`
4. 在 TradingEasy 中配置:
   ```
   设置 → 券商 → 添加 Futu OpenD
   地址: 127.0.0.1
   端口: 11111
   ```

### 验证连接
```bash
# TradingEasy 中检查 OpenD 状态
设置 → 券商 → 连接状态: 🟢 已连接
```

## 2. 模拟盘 → 实盘切换

### 默认模式: 模拟盘

所有新创作者默认为模拟盘，不涉及真实资金。

### 切换到实盘

1. LiveExecutionConsole → 点击「真实执行」
2. 系统弹出**双重确认**:
   - 步骤 1: 策略确认（确认 AI 分析结果）
   - 步骤 2: 仓位确认（确认交易数量/价格）
3. 确认后执行真实下单

### 安全机制

| 机制 | 说明 |
|-----|------|
| 默认模拟 | 新创作者默认模拟模式 |
| 手动切换 | 真实执行需主动点击 |
| 二次确认 | 策略+仓位双重确认 |
| 可取消 | 5 秒倒计时可取消 |

## 3. 风控说明

### 滑点保护
- **市价单**: 滑点上限 2%，超过则拒绝
- **限价单**: 超过 60s 未成交自动撤单

### 持仓限制
| 限制项 | 阈值 |
|-------|------|
| 单标的 | ≤ 20% 可用资金 |
| 单日亏损 | ≤ 总资产 5% 熔断 |
| 连续亏损 | 3 次→冷却 30 分钟 |
| 下单频率 | < 2 次/秒 |

### 熔断断路器
```
连续 3 次亏损 → ⚡ 熔断触发
→ 冷却 30 分钟
→ 手动恢复
```

## 4. 费率说明

### 每笔交易费用

| 费用项 | 费率 | 归属 |
|-------|------|------|
| AI 分析费 | 按档位 (1.0/1.5/2.0 USDT) | 平台+创作者 |
| 交易佣金 | 港股 0.1%+交易所+印花税 | 券商 |
| 平台交易费 | maker 0.02% / taker 0.1% | 平台 100% |

### 费用示例 (港股买入 10,000 HKD)

```
AI 分析: 2.0 USDT ≈ 14.4 HKD
交易佣金: 10 (0.1%) + 交易所 + 印花税 ≈ 35 HKD
平台费: 10,000 × 0.1% ≈ 10 HKD (taker)
总费用: ~59.4 HKD
```
