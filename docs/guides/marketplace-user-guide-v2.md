## Marketplace 概述

### 什么是 Marketplace？

Marketplace 是 DAWN WHALES 的策略市场，允许用户：

- **发布策略**: 将自己的量化策略发布到市场
- **订阅策略**: 订阅其他用户发布的策略
- **评价策略**: 对使用的策略进行评分和评论
- **获得收益**: 通过策略订阅获得收益分成

### Marketplace 特性

| 特性 | 说明 | 状态 |
|-----|------|------|
| 策略发布 | 提交策略代码和文档 | ✅ R45 实现 |
| 策略订阅 | 免费/付费订阅 | ✅ R45 实现 |
| 评价系统 | 评分 + 评论 | ✅ R45 实现 |
| 搜索筛选 | 多维度搜索和筛选 | ✅ R46 实现 |
| 收益分成 | 70/30 分成 | ✅ R45 实现 |
| 策略排名 | 按评分/下载量排名 | ✅ R46 实现 |

## 策略发布流程

### 第一步：准备策略

在发布策略前，请确保：

- ✅ 策略代码完整且可运行
- ✅ 提供完整的回测报告
- ✅ 编写详细的策略文档
- ✅ 设置合理的订阅价格
- ✅ 准备策略截图/视频

### 第二步：提交策略

1. 登录 DAWN WHALES
2. 进入 **Marketplace** 页面
3. 点击 **发布策略**
4. 填写策略信息：

```
基本信息:
- 策略名称: 双均线交叉策略
- 策略描述: 基于 10 日和 30 日均线的交叉策略
- 策略类型: 趋势跟踪
- 适用市场: A股/港股/美股
- 适用周期: 日线

回测结果:
- 回测期间: 2023-01-01 至 2024-12-31
- 总收益率: 32.5%
- 年化收益率: 15.8%
- 夏普比率: 1.85
- 最大回撤: -12.3%
- 胜率: 58%

订阅设置:
- 订阅价格: 99 HKD/月
- 免费试用期: 7 天
- 最大订阅数: 100
```

5. 上传策略代码和文档
6. 点击 **提交审核**

### 第三步：等待审核

审核流程：

```
提交 → 自动审核 (1天) → 人工审核 (2天) → 上架/退回
```

**自动审核**：
- 代码语法检查
- 回测结果验证
- 风险指标检查

**人工审核**：
- 策略逻辑审查
- 文档完整性检查
- 风险评估

### 第四步：策略上架

审核通过后，策略将上架到市场：

- ✅ 策略在市场列表中显示
- ✅ 用户可以查看策略详情
- ✅ 用户可以订阅策略
- ✅ 开始获得订阅收益

## 策略订阅

### 订阅类型

| 类型 | 说明 | 价格 |
|-----|------|------|
| 免费 | 永久免费使用 | 0 HKD |
| 试用 | 7 天免费试用 | 0 HKD (7天) |
| 月度 | 按月订阅 | 策略设定 |
| 年度 | 按年订阅 (8折) | 策略设定 × 12 × 0.8 |

### 订阅流程

1. 浏览 Marketplace
2. 选择策略
3. 查看策略详情：
   - 策略描述
   - 回测结果
   - 用户评价
   - 订阅价格
4. 点击 **订阅**
5. 选择订阅类型
6. 完成支付
7. 策略已添加到您的策略库

### 订阅管理

#### 查看订阅

1. 进入 **我的订阅** 页面
2. 查看已订阅策略列表
3. 查看订阅状态：
   - 生效中
   - 即将到期
   - 已过期

#### 取消订阅

1. 进入 **我的订阅** 页面
2. 找到目标策略
3. 点击 **取消订阅**
4. 确认取消
5. 订阅将在当前周期结束后停止

#### 续订订阅

1. 进入 **我的订阅** 页面
2. 找到即将到期的策略
3. 点击 **续订**
4. 选择续订时长
5. 完成支付

### 订阅退款政策

| 情况 | 退款政策 |
|-----|---------|
| 订阅后 24 小时内 | 全额退款 |
| 订阅后 7 天内 | 50% 退款 |
| 订阅后 7 天以上 | 不退款 |
| 策略下架 | 按比例退款 |

## 评价机制

### 评分系统

用户可以对订阅的策略进行评分：

| 评分 | 说明 |
|-----|------|
| ⭐⭐⭐⭐⭐ (5星) | 优秀，强烈推荐 |
| ⭐⭐⭐⭐ (4星) | 良好，推荐 |
| ⭐⭐⭐ (3星) | 一般，中立 |
| ⭐⭐ (2星) | 较差，不推荐 |
| ⭐ (1星) | 很差，强烈不推荐 |

### 评论系统

用户可以发表评论：

```
评论内容:
- 文字评价 (最多 500 字)
- 使用体验
- 收益情况
- 改进建议

评论规则:
- 必须订阅后才能评论
- 禁止恶意评论
- 禁止广告
- 评论需经过审核
```

### 评价管理

#### 发表评价

1. 进入 **我的订阅** 页面
2. 找到目标策略
3. 点击 **发表评价**
4. 选择评分
5. 填写评论
6. 点击 **提交**

#### 修改评价

1. 进入 **我的评价** 页面
2. 找到目标评价
3. 点击 **修改**
4. 修改评分/评论
5. 点击 **保存**

#### 删除评价

1. 进入 **我的评价** 页面
2. 找到目标评价
3. 点击 **删除**
4. 确认删除

## 收益分成

### 分成比例

| 角色 | 分成比例 |
|-----|---------|
| 策略发布者 | 70% |
| 平台 | 30% |

### 收益计算

```
月收益 = 订阅数 × 订阅价格 × 70%

示例:
- 订阅数: 50
- 订阅价格: 99 HKD/月
- 月收益: 50 × 99 × 0.7 = 3,465 HKD
```

### 收益提现

#### 提现条件

- ✅ 收益余额 ≥ 100 HKD
- ✅ 已完成实名认证
- ✅ 已绑定银行卡

#### 提现流程

1. 进入 **收益中心** 页面
2. 查看可提现余额
3. 点击 **提现**
4. 输入提现金额
5. 选择提现方式（银行卡/支付宝/微信）
6. 确认提现
7. 等待到账（1-3 个工作日）

#### 提现手续费

| 提现方式 | 手续费 |
|---------|--------|
| 银行卡 | 0 HKD |
| 支付宝 | 0 HKD |
| 微信 | 0 HKD |

### 收益报表

进入 **收益中心** 页面，查看：

- **今日收益**: 当日订阅收益
- **本月收益**: 当月订阅收益
- **累计收益**: 历史总收益
- **收益趋势**: 收益变化图表
- **订阅明细**: 每笔订阅详情

## 常见问题

### Q1: 策略发布需要收费吗？

**A**: 不需要。策略发布完全免费，平台仅在您获得订阅收益时收取 30% 分成。

### Q2: 策略审核需要多长时间？

**A**: 通常需要 3 个工作日（1 天自动审核 + 2 天人工审核）。

### Q3: 策略被退回怎么办？

**A**: 查看退回原因，修改策略后重新提交。可以无限次重新提交。

### Q4: 如何获得更多订阅？

**A**: 
- 提供详细的策略文档
- 展示优秀的回测结果
- 积极回复用户评论
- 定期更新策略

### Q5: 收益什么时候到账？

**A**: 提现申请提交后，1-3 个工作日到账。

### Q6: 可以下架自己的策略吗？

**A**: 可以。进入策略管理页面，点击下架。下架后现有订阅者可以继续用到订阅到期。

### Q7: 策略被盗用怎么办？

**A**: 
- 策略代码经过加密存储
- 订阅者只能使用，无法查看源码
- 发现盗用请立即联系平台

### Q8: 可以同时发布多个策略吗？

**A**: 可以。没有策略数量限制。

### Q9: 如何搜索特定类型的策略？

**A**: 使用高级搜索功能，可以按策略类型、适用市场、适用周期等条件筛选。

### Q10: 如何查看策略的详细回测结果？

**A**: 点击策略详情页面，可以查看完整的回测报告，包括收益曲线、风险指标、交易记录等。

### 1. 策略文档

```markdown
✅ 推荐：
# 双均线交叉策略

## 策略原理
基于 10 日和 30 日均线的交叉信号进行交易。

## 入场条件
- 快线(10日)上穿慢线(30日) → 买入
- 快线(10日)下穿慢线(30日) → 卖出

## 风控规则
- 止损: 5%
- 止盈: 10%
- 仓位: 每次 10%

## 回测结果
- 期间: 2023-01-01 至 2024-12-31
- 收益: 32.5%
- 夏普: 1.85
- 回撤: -12.3%

## 使用说明
1. 适用于日线级别
2. 建议配合大盘趋势使用
3. 不建议在震荡市使用
```
