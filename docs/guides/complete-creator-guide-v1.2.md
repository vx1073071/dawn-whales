## 1. 4 Agent 使用指南

### 基本面分析师

**用途**: 评估公司内在价值，识别低估/高估股票

**使用方法**:
- 策略编辑页 → AI 协作 → 选择「基本面分析」
- 输入标的代码（如 00700.HK）
- 系统自动获取 PE/PB/ROE/营收增长等数据
- LLM 生成分析报告（含估值模型 DCF/PEG/Graham）

**输出示例**:
```
基本面: 8.2/10 (推荐)
PE 25.3 vs 行业 22.1 (略高)
ROE 18.5% (优秀)，营收 +15.2% YoY
建议: BUY, 目标价 185.00
```

### 技术面分析师

**用途**: 识别交易信号，判断入场/出场时机

**支持指标**: MA5/10/20/60/120/250, RSI, MACD, 布林带, 形态识别

**输出示例**:
```
技术面: 7.5/10
MA20>MA60 (上升趋势), RSI 65 (偏强)
支撑 175.50, 阻力 185.00
建议: BUY @ 178.50, 止损 175.00
```

### 情绪分析师

**用途**: 判断市场情绪，避免逆势交易

**数据来源**: 新闻情绪 + 社交情绪 + 分析师评级 + 内部交易

**输出示例**:
```
情绪面: 6.8/10
恐惧贪婪指数: 22 (低恐慌)
新闻正面率 65%, 社交热度上升
建议: 偏多, 但注意短期波动
```

### 宏观分析师

**用途**: 评估宏观经济环境影响

**分析维度**: GDP/CPI/PMI, 利率/汇率, 经济周期定位

**输出示例**:
```
宏观面: 7.0/10
GDP +3.2%, CPI 2.1% (温和)
利率稳定, 周期扩张后期
建议: 谨慎看多, 关注政策转向
```

## 3. 预算管理与成本预估

### 预算设置

```
设置 → AI 协作 → 预算管理

月预算: [____] USDT (默认 50)
告警阈值: [80%] (达80%发邮件提醒)
超额行为: [停用] / [仅告警]
```

### 成本预估公式

```
单次成本 = 输入token × 输入价格 + 输出token × 输出价格

4 Agent 旗舰档:
- 输入约 2000 tokens × 4 Agent × 2 轮 = 16000 tokens
- 缓存命中 95%: 800 tokens 未命中, 15200 tokens 命中
- 成本: 800 × $0.435/M + 15200 × $0.003625/M + 输出 4000 × $0.87/M
     ≈ $0.011
```

### 成本对比 (4 Agent 旗舰)

|-----------|---------|--------------|

## 4. 缓存命中率说明

### 什么是缓存命中率

系统对相同输入（标的+日期+Agent）的 LLM 调用结果进行缓存。命中率 = 命中次数 / 总请求。

### 当前状态 (R58 目标)

```
缓存命中率: ≥95% (vs R57 ≥90%)
缓存命中: 950 次 / 1000 次
节省成本: ~15 USDT/月 (vs 无缓存)
```
