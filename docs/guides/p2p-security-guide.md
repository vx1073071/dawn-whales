## 1. P2P 积分转账

### 概览

用户间 USDT 积分转账，用于购买策略/订阅/打赏等创作者变现场景。

### 规则 (永久)

| 规则 | 值 |
|------|-----|
| 手续费 | **0.3%** 双向收取 |
| 平台分成 | 100%（P2P 手续费不参与创作者分成） |
| 冻结期 | **14 天** |
| 限额 | 默认不限额（后台可调） |
| 新账户限制 | 注册 < 7 天，单笔 ≤ 500 USDT |
| 大额告警 | > 1000 USDT 通知 PM |
| 高频限制 | 单日 > 10 笔临时限制 |

### 交易流程

```
发起转账 → 双方确认 → 14天冻结 → 到期自动放款
                              ↓
                          申诉期可申诉
```

### 冻结状态

| 状态 | 说明 |
|------|------|
| pending | 等待接收方确认 |
| frozen | 14 天冻结中 |
| released | 冻结到期，已放款 |
| cancelled | 买方取消，解冻返还 |
| disputed | 申诉中，永久冻结 |

### 转账记录

交易明细包含：方向、金额、费率、状态、冻结剩余时间。

## 2. 申诉系统

### 4 种申诉类型

| # | 类型 | 说明 |
|---|------|------|
| 1 | 收款未确认 | 接收方未确认收款 |
| 2 | 未按约定 | 对方未履行约定服务 |
| 3 | 账号异常 | 对方账号可疑/异常 |
| 4 | 其他 | 需填写详细描述 |

### 申诉规则

- **冻结期内可申诉**：14 天内任一方可申诉
- **申诉效果**：冻结变为永久冻结（disputed）
- **买方取消**：冻结直接解冻返还
- **平台不仲裁**：只通知双方+冻结资金，不判断对错

### 管理员解锁

- 仅系统异常时使用
- 后台隐藏按钮
- 操作全链路审计日志

## 4. 2FA 安全认证

### 绑定

```
安全中心 → 开启 2FA → 扫码绑定 → 验证码确认 → 备份码保存
```

- TOTP 协议，兼容 Google Authenticator
- 备用码 × 8，一次性使用
- 触发场景：登录 + 提现

### 恢复

```
登录页 → 忘记 2FA → 输入备份码 → 重新绑定
```
