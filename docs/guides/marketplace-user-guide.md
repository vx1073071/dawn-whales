## 策略市场概述

### 什么是策略市场？

策略市场是 TradingEasy v1.1.0 引入的核心功能，允许用户：

- **发布策略**: 将自己的量化策略分享到市场
- **搜索策略**: 通过关键词、标签、筛选条件找到需要的策略
- **订阅策略**: 订阅感兴趣的策略，获取最新更新
- **评价策略**: 对使用过的策略进行评分和评论
- **获得收益**: 通过付费策略获得收益分成

interface Strategy {

## 发布策略

### 发布流程

```
1. 创建策略草稿
   ↓
2. 填写策略信息
   ↓
3. 上传策略代码
   ↓
4. 预览和测试
   ↓
5. 提交审核
   ↓
6. 等待审核 (1-3天)
   ↓
7. 审核通过 → 发布到市场
   审核拒绝 → 修改后重新提交
```

### 步骤 1: 创建策略草稿

1. 打开 TradingEasy 应用
2. 点击左侧导航栏的 "策略市场"
3. 点击右上角的 "发布策略" 按钮
4. 选择 "创建新策略"

### 步骤 2: 填写策略信息

**必填信息**:
- **策略名称**: 简洁明了，不超过 50 字符
- **策略描述**: 详细说明策略逻辑，不少于 100 字
- **策略分类**: 选择最匹配的分类
- **标签**: 添加 3-5 个相关标签

**可选信息**:
- **策略价格**: 0 = 免费，>0 = 付费 (HKD/月)
- **策略截图**: 上传 1-5 张策略截图
- **策略文档**: 上传详细的使用文档

**策略分类**:
- **趋势跟踪**: 跟随市场趋势的策略
- **均值回归**: 基于均值回归的策略
- **动量策略**: 基于动量因子的策略
- **套利策略**: 基于套利机会的策略
- **其他**: 其他类型的策略

**标签示例**:
```
#均线 #MACD #RSI #布林带 #趋势 #震荡 #短线 #长线
#股票 #期货 #外汇 #加密货币 #A股 #港股 #美股
```

### 步骤 3: 上传策略代码

**代码要求**:
- 使用 TypeScript 编写
- 遵循 TradingEasy 策略接口规范
- 包含完整的注释
- 通过代码质量检查

**策略接口规范**:

```typescript
interface IStrategy {
  // 策略初始化
  init(context: StrategyContext): void;
  
  // 每根K线触发
  onBar(bar: Bar, context: StrategyContext): Signal | null;
  
  // 策略参数
  params: Record<string, number>;
}

interface StrategyContext {
  // 获取指标
  indicator(name: string, params?: any): number;
  
  // 获取历史数据
  history(period: number): Bar[];
  
  // 获取当前持仓
  position(): Position | null;
  
  // 发送信号
  signal(type: 'BUY' | 'SELL', quantity: number): Signal;
}

interface Bar {
  time: number;
  open: number;
  high: number;
  low: number;
  close: number;
  volume: number;
}

interface Signal {
  type: 'BUY' | 'SELL';
  quantity: number;
  price?: number;
}
```

**示例策略代码**:

```typescript
/**
 * 双均线交叉策略
 * 当短期均线上穿长期均线时买入，下穿时卖出
 */
export class DualMAStrategy implements IStrategy {
  params = {
    fastPeriod: 10,
    slowPeriod: 30,
    quantity: 100,
  };

  init(context: StrategyContext): void {
    // 初始化指标
    context.indicator('SMA', { period: this.params.fastPeriod });
    context.indicator('SMA', { period: this.params.slowPeriod });
  }

  onBar(bar: Bar, context: StrategyContext): Signal | null {
    const fastMA = context.indicator('SMA', { period: this.params.fastPeriod });
    const slowMA = context.indicator('SMA', { period: this.params.slowPeriod });
    const prevFastMA = context.indicator('SMA', { period: this.params.fastPeriod }, -1);
    const prevSlowMA = context.indicator('SMA', { period: this.params.slowPeriod }, -1);

    // 金叉买入
    if (prevFastMA <= prevSlowMA && fastMA > slowMA) {
      return context.signal('BUY', this.params.quantity);
    }

    // 死叉卖出
    if (prevFastMA >= prevSlowMA && fastMA < slowMA) {
      return context.signal('SELL', this.params.quantity);
    }

    return null;
  }
}
```

### 步骤 4: 预览和测试

1. 点击 "预览" 按钮查看策略页面效果
2. 点击 "回测" 按钮运行策略回测
3. 检查回测结果是否符合预期
4. 调整参数优化策略表现

### 步骤 5: 提交审核

1. 确认所有信息填写完整
2. 确认策略代码通过质量检查
3. 点击 "提交审核" 按钮
4. 等待审核结果 (1-3天)

### 步骤 6: 审核结果

**审核通过**:
- 策略自动发布到市场
- 收到审核通过通知
- 策略开始接受订阅

**审核拒绝**:
- 收到审核拒绝通知
- 查看拒绝原因
- 修改策略后重新提交

**常见拒绝原因**:
- 策略代码存在安全问题
- 策略描述不够详细
- 策略回测结果异常
- 策略分类或标签不准确

## 评价和反馈

### 评价策略

**评价条件**:
- 必须订阅该策略
- 每个策略只能评价一次
- 可以修改已有评价

**评价内容**:
- **评分**: 1-5 星
- **评论**: 文字评论 (10-500 字)

**评价步骤**:
1. 在策略详情页点击 "评价" 按钮
2. 选择评分 (1-5 星)
3. 填写评论内容
4. 点击 "提交评价"

### 评价规范

**好的评价**:
- 客观描述使用体验
- 说明策略的优缺点
- 提供具体的使用建议
- 分享回测或实盘结果

**不好的评价**:
- 恶意攻击或辱骂
- 虚假评价
- 与策略无关的内容
- 泄露个人隐私

**评价示例**:

**好的评价**:
```
⭐⭐⭐⭐⭐
这个双均线策略非常简单实用。我在A股回测了3年，
年化收益率达到18%，最大回撤15%。建议将快线参数
调整为12，慢线参数调整为26，效果更好。
```

**不好的评价**:
```
⭐
垃圾策略，亏死了！
```

### 修改评价

1. 在策略详情页找到你的评价
2. 点击 "修改" 按钮
3. 修改评分或评论
4. 点击 "保存"

### 删除评价

1. 在策略详情页找到你的评价
2. 点击 "删除" 按钮
3. 确认删除

### 反馈问题

如果发现问题或需要帮助：

1. 在策略详情页点击 "反馈" 按钮
2. 选择问题类型 (Bug/建议/其他)
3. 详细描述问题
4. 提交反馈

**反馈处理流程**:
```
提交反馈 → 审核 → 分配 → 处理 → 回复 → 关闭
```

## 收益和提现

### 收益计算

**免费策略**:
- 无收益

**付费策略**:
- 平台分成: 30%
- 作者分成: 70%
- 收益按月结算

**收益计算公式**:
```
月收益 = 订阅数 × 价格 × 70%
```

**示例**:
```
策略价格: 100 HKD/月
订阅数: 50
月收益 = 50 × 100 × 70% = 3,500 HKD
```

### 查看收益

1. 点击左侧导航栏的 "策略市场"
2. 点击 "我的策略" 标签
3. 点击 "收益" 标签
4. 查看收益详情

**收益信息**:
- 本月收益
- 累计收益
- 待提现收益
- 收益明细

### 提现

**提现条件**:
- 待提现收益 ≥ 100 HKD
- 已绑定银行卡或支付宝
- 已完成实名认证

**提现步骤**:
1. 在收益页面点击 "提现" 按钮
2. 输入提现金额
3. 选择提现方式 (银行卡/支付宝)
4. 确认提现
5. 等待到账 (1-3个工作日)

**提现限制**:
- 最低提现金额: 100 HKD
- 每日提现次数: 3次
- 每月提现次数: 30次

### 收益明细

**收益明细包含**:
- 日期
- 策略名称
- 订阅数
- 收益金额
- 状态 (已结算/待结算)

## 常见问题FAQ

### Q1: 如何发布策略？

**A**: 
1. 打开策略市场
2. 点击 "发布策略"
3. 填写策略信息
4. 上传策略代码
5. 提交审核
6. 等待审核通过 (1-3天)

### Q2: 策略审核需要多长时间？

**A**: 
- 一般 1-3 个工作日
- 复杂策略可能需要更长时间
- 审核结果会通过通知告知

### Q3: 策略被拒绝怎么办？

**A**: 
1. 查看拒绝原因
2. 根据原因修改策略
3. 重新提交审核
4. 可以无限次重新提交

### Q4: 如何订阅策略？

**A**: 
1. 浏览策略市场
2. 查看策略详情
3. 点击 "订阅" 按钮
4. 确认订阅 (付费策略需支付)

### Q5: 免费策略和付费策略有什么区别？

**A**: 
- **免费策略**: 完全免费，可以随意使用
- **付费策略**: 需要付费订阅，通常功能更强大

### Q6: 如何取消订阅？

**A**: 
1. 进入 "我的订阅"
2. 找到要取消的策略
3. 点击 "取消订阅"
4. 确认取消

### Q7: 取消订阅后可以退款吗？

**A**: 
- 免费策略：无需退款
- 付费策略：
  - 订阅后 24 小时内：全额退款
  - 订阅后 7 天内：50% 退款
  - 订阅后 7 天以上：不退款

### Q8: 如何评价策略？

**A**: 
1. 必须订阅该策略
2. 在策略详情页点击 "评价"
3. 选择评分 (1-5 星)
4. 填写评论内容
5. 提交评价

### Q9: 如何获得收益？

**A**: 
1. 发布付费策略
2. 用户订阅你的策略
3. 获得 70% 的收益分成
4. 收益 ≥ 100 HKD 时可以提现
