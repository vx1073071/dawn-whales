## 1. 邀请裂变系统

### 如何邀请

1. **生成邀请码**: 设置 → 邀请好友 → 复制你的专属邀请链接
2. **分享**: 通过任意渠道发送链接给朋友
3. **奖励**: 朋友通过你的链接注册并完成首次 AI 分析，双方各得 **1 次免费 AI 分析**（标准档，价值 1.5 USDT）

### 防刷规则

| 规则 | 说明 |
|------|------|
| 同设备限制 | 同一设备 24h 内最多 3 个有效邀请 |
| 同 IP 限制 | 同一 IP 24h 内最多 5 个有效邀请 |
| 有效邀请 | 被邀请人必须完成注册 + 首次 AI 分析 |
| 僵尸检测 | 7 天未登录 = 流失，不计入有效邀请 |

### 邀请排行榜

系统记录你的累计邀请数，未来将开放排行榜和额外奖励（R81+）。

## 2. 用户漏斗解读

### 全链路漏斗

```
注册 100% → 激活(首次登录) ~80% → 首次AI分析 ~50% → 首次充值 ~25% → 首次付费 ~15%
```

### 各阶段优化建议

| 阶段 | 流失原因 | 优化方向 |
|------|----------|----------|
| 注册→激活 | 注册后未打开桌面端 | 注册成功页引导下载 |
| 激活→AI | 不知道 AI 怎么用 | 新手引导 5 步强引导 |
| AI→充值 | 免费次数用完未续费 | AI 用完后弹窗 → "立即充值解锁更多" |
| 充值→付费 | 价格感知高 | 新人首充 8 折（R81 规划） |

## 3. 留存优化

### 提升首日留存

1. **信号推送**: 策略产生买入/卖出信号 → 桌面通知

3. **成就系统**: 完成里程碑解锁成就徽章（见创作者增长指南）

### 挽回流失用户

1. **7 天未登录**: 发送 "你的策略最近产生了 3 个信号，回来看看？"

## 从零到月入 1000 USDT 路径

### 第 1 周: 建立基础
1. 注册 → 连接 OpenD → 完成新手引导
2. 用"模板创建"发布 **3 个策略**（动量/均值回归/双均线各一）
3. 每个策略跑回测 → 确保胜率 > 50%
4. 白银等级解锁 → 分成升至 75/25

### 第 2-4 周: 积累订阅
1. 持续优化策略参数 → 目标夏普 > 1.0
2. 在社区活跃 → 回复评论 → 积累关注者

1. 扩展到跨市场策略（港股+美股+新加坡）
2. 创建策略组合包 → 一次订阅获得多个策略
3. 利用 AI 形态识别优化入场时机
4. 铂金/钻石 → 分成 85/15+

### 收入公式

```
月收入 = 策略数 × 平均订阅数 × 策略价格 × 分成比例
```

**示例**（黄金创作者）:
- 15 个策略 × 平均 15 个订阅 × 200 USDT 均价 × 80% = **3,600 USDT/月**
