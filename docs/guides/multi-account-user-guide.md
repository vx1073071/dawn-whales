## 多账户概述

### 什么是多账户？

多账户功能允许您在同一个 DAWN WHALES 应用中管理多个交易账户，每个账户的数据完全隔离，互不影响。

### 适用场景

| 场景 | 说明 |
|-----|------|
| 个人 + 工作 | 分离个人交易和工作交易 |
| 实盘 + 模拟 | 同时管理实盘和模拟盘 |
| 多策略测试 | 不同账户测试不同策略 |
| 团队管理 | 团队成员各自独立账户 |

### 核心特性

1. **数据隔离**: 每个账户的策略、回测、持仓完全独立
2. **快速切换**: 一键切换账户，无需重新登录
3. **独立配置**: 每个账户可设置独立的 Broker 和参数
4. **安全加密**: 账户凭证 AES-256-GCM 加密存储

## 快速开始

### 第一步：创建第一个账户

1. 打开 DAWN WHALES 应用
2. 点击右上角 **账户图标** 👤
3. 选择 **添加账户**
4. 填写账户信息：
   - **账户名称**: 例如 "个人实盘"
   - **账户类型**: 选择 "personal" / "business" / "demo"
   - **Broker**: 选择您的券商（富途/Moomoo/模拟盘）
   - **凭证**: 输入 API Key 和 Secret
5. 点击 **保存**

### 第二步：切换到新账户

1. 点击右上角 **账户图标** 👤
2. 在下拉列表中选择目标账户
3. 应用会自动切换到该账户的数据视图

### 第三步：验证数据隔离

1. 在账户 A 创建一个策略
2. 切换到账户 B
3. 确认账户 B 看不到账户 A 的策略
4. 切换回账户 A，确认策略仍然存在

## 账户管理

### 添加账户

#### 方法 1: UI 添加

1. 点击右上角 **账户图标** 👤
2. 选择 **添加账户**
3. 填写账户信息
4. 点击 **保存**

#### 方法 2: 快捷键

```
Ctrl/Cmd + Shift + A
```

### 编辑账户

1. 点击右上角 **账户图标** 👤
2. 选择 **管理账户**
3. 找到目标账户，点击 **编辑**
4. 修改账户信息
5. 点击 **保存**

### 删除账户

⚠️ **警告**: 删除账户会清除该账户的所有数据（策略、回测、持仓），此操作不可恢复！

1. 点击右上角 **账户图标** 👤
2. 选择 **管理账户**
3. 找到目标账户，点击 **删除**
4. 输入账户名称确认
5. 点击 **确认删除**

### 导出账户

您可以导出账户配置（不包含敏感凭证）：

1. 点击右上角 **账户图标** 👤
2. 选择 **管理账户**
3. 找到目标账户，点击 **导出**
4. 选择导出格式（JSON/YAML）
5. 保存配置文件

### 导入账户

从配置文件导入账户：

1. 点击右上角 **账户图标** 👤
2. 选择 **添加账户** → **从文件导入**
3. 选择配置文件
4. 输入凭证信息
5. 点击 **导入**

## 数据隔离

### 隔离范围

以下数据按账户隔离：

| 数据类型 | 隔离说明 |
|---------|---------|
| 策略列表 | 每个账户独立的策略集合 |
| 回测结果 | 每个账户独立的回测历史 |
| 持仓数据 | 每个账户独立的持仓信息 |
| 订单记录 | 每个账户独立的订单历史 |
| 账户设置 | 每个账户独立的配置参数 |
| 通知规则 | 每个账户独立的通知设置 |

### 共享数据

以下数据在所有账户间共享：

| 数据类型 | 说明 |
|---------|------|
| 应用设置 | 主题、语言、通知偏好 |
| 用户偏好 | UI 布局、快捷键 |
| 全局日志 | 应用级别的日志记录 |

### 数据存储位置

```
用户数据目录/
├── accounts/
│   ├── account-1/
│   │   ├── strategies.json
│   │   ├── backtests.json
│   │   ├── positions.json
│   │   └── settings.json
│   ├── account-2/
│   │   ├── strategies.json
│   │   ├── backtests.json
│   │   ├── positions.json
│   │   └── settings.json
│   └── accounts.json          # 账户列表
├── credentials.enc             # 加密的凭证文件
└── app-settings.json           # 共享的应用设置
```

## 账户切换

### 切换方法

#### 方法 1: 账户图标

1. 点击右上角 **账户图标** 👤
2. 在下拉列表中选择目标账户
3. 等待切换完成（约 1-2 秒）

#### 方法 2: 快捷键

```
Ctrl/Cmd + 1-9    # 切换到第 1-9 个账户
Ctrl/Cmd + Tab    # 切换到下一个账户
```

#### 方法 3: 命令面板

```
Ctrl/Cmd + P → 输入 "switch account" → 选择账户
```

### 切换动画

账户切换时会显示过渡动画：

```
┌─────────────────────┐
│   切换中...         │
│   ⟳                 │
│   正在加载数据      │
└─────────────────────┘
```

### 切换后验证

切换完成后，检查以下内容：

1. ✅ 账户名称显示正确
2. ✅ 策略列表已更新
3. ✅ 持仓数据已更新
4. ✅ 通知规则已更新

## 安全机制

### 凭证加密

所有账户凭证使用 AES-256-GCM 加密存储：

```typescript
// 加密过程
const encrypted = aes256gcm.encrypt(
  credentials,
  masterKey,
  iv
);

// 存储
{
  "accountId": "acc-123",
  "encryptedCredentials": encrypted.data,
  "iv": encrypted.iv,
  "tag": encrypted.tag
}
```

### 主密钥管理

主密钥用于加密所有账户凭证：

1. **生成**: 首次启动时自动生成
2. **存储**: 操作系统密钥链（Windows Credential Manager / macOS Keychain）
3. **访问**: 需要系统权限（指纹/密码）

### 会话隔离

每个账户有独立的会话：

```typescript
interface Session {
  accountId: string;
  token: string;
  expiresAt: number;
  permissions: string[];
}

// 每个账户独立的会话
const sessions = new Map<string, Session>();
```

### 权限控制

基于角色的访问控制 (RBAC)：

| 角色 | 权限 |
|-----|------|
| Owner | 完全控制（读写删除） |
| Admin | 管理账户（读写） |
| Trader | 交易操作（读写策略/订单） |
| Viewer | 只读查看 |

### 审计日志

所有账户操作记录审计日志：

```json
{
  "timestamp": "2026-06-07T06:16:00+08:00",
  "action": "account.switch",
  "fromAccount": "acc-123",
  "toAccount": "acc-456",
  "userId": "user-789",
  "ipAddress": "192.168.1.100"
}
```

## 常见问题

### Q1: 如何备份账户数据？

**A**: 使用导出功能：

1. 点击右上角 **账户图标** 👤
2. 选择 **管理账户**
3. 点击 **导出**
4. 保存配置文件

建议定期备份到云存储。

### Q2: 账户数据可以迁移吗？

**A**: 可以，使用导出/导入功能：

1. 在源设备导出账户
2. 将配置文件传输到目标设备
3. 在目标设备导入账户
4. 重新输入凭证信息

### Q3: 删除账户后能恢复吗？

**A**: **不能**。删除账户会永久清除所有数据。建议：

1. 删除前导出账户配置
2. 确认不再需要该账户数据
3. 输入账户名称二次确认

### Q4: 最多可以创建多少个账户？

**A**: 理论上无限制，但建议：

- 个人使用：3-5 个账户
- 团队使用：10-20 个账户
- 超过 20 个账户可能影响性能

### Q5: 账户切换很慢怎么办？

**A**: 可能的原因和解决方案：

| 原因 | 解决方案 |
|-----|---------|
| 数据量大 | 清理历史回测数据 |
| 网络延迟 | 检查网络连接 |
| 磁盘慢 | 使用 SSD 存储 |
| 账户过多 | 删除不常用账户 |

### Q6: 如何在不同设备间同步账户？

**A**: 目前不支持自动同步，手动操作：

1. 在设备 A 导出账户
2. 将配置文件传输到设备 B
3. 在设备 B 导入账户
4. 重新输入凭证

未来版本将支持云同步。

### Q7: 账户凭证泄露怎么办？

**A**: 立即采取以下措施：

1. **撤销凭证**: 在券商后台撤销 API Key
2. **删除账户**: 在 DAWN WHALES 中删除该账户
3. **生成新凭证**: 在券商后台生成新的 API Key
4. **重新添加**: 使用新凭证重新添加账户

### Q8: 如何查看账户操作历史？

**A**: 查看审计日志：

1. 点击右上角 **设置** ⚙️
2. 选择 **安全** → **审计日志**
3. 筛选账户和操作类型
4. 查看操作详情

## 最佳实践

### 账户命名规范

使用清晰的命名规范：

```
{类型}-{用途}-{环境}

示例:
personal-trading-prod      # 个人实盘交易
business-backtest-test     # 工作回测测试
demo-strategy-dev          # 演示策略开发
```

### 账户类型选择

| 类型 | 适用场景 | 特点 |
|-----|---------|------|
| personal | 个人交易 | 完整功能 |
| business | 工作交易 | 审计日志 |
| demo | 演示/测试 | 模拟数据 |

### 定期维护

建议每月进行一次账户维护：

1. **清理历史数据**: 删除 6 个月前的回测结果
2. **检查凭证**: 确认 API Key 仍然有效
3. **备份配置**: 导出所有账户配置
4. **审计日志**: 检查异常操作

### 安全建议

1. **强密码**: 使用强密码保护主密钥
2. **定期更换**: 每 3 个月更换 API Key
3. **最小权限**: 仅授予必要的 API 权限
4. **监控日志**: 定期检查审计日志
5. **备份数据**: 定期备份账户配置

### 性能优化

1. **限制账户数**: 保持 10 个以内账户
2. **清理历史**: 定期删除旧的回测数据
3. **关闭不活跃账户**: 长期不用的账户可以删除
4. **使用 SSD**: 将应用数据存储在 SSD 上
