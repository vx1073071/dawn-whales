# 多模型竞技场使用说明

**版本**: v1.2.0-beta  
**更新时间**: 2026-06-09  
**作者**: youdao  

---

## 概述

模型竞技场（Model Arena）是 v1.2.0-beta 的新功能，允许创作者使用 **3 个不同 LLM 模型**对同一问题进行分析，对比结果后加权投票，获得更可靠的决策建议。

---

## 使用方式

1. 进入策略编辑页 → 点击「AI 协作」
2. 选择「模型竞技场」
3. 勾选 3 个对比模型
4. 输入分析需求
5. 点击「开始对比」

---

## 结果解读

- **加权投票**: 各模型按置信度加权，最终输出操作建议
- **差异分析**: 高亮展示不同模型的意见分歧
- **排行榜**: 按准确率（历史数据）排名模型
