## 1. IBKR 接入

### 前置条件

- Interactive Brokers 账户
- IB Gateway 或 TWS 已安装运行
- API 权限已开启

### 配置

```
桌面端 → 设置 → 券商 → 添加 IBKR
Host: 127.0.0.1
Port: 4002 (IB Gateway) / 7497 (TWS)
Client ID: 1-999 (任意唯一值)
```

### 连接状态

| 状态 | 说明 |
|------|------|
| 已连接 | 绿灯，可交易 |
| 连接中 | 黄灯，等待确认 |
| 未连接 | 红灯，检查 IB Gateway |

## 3. 碎股交易 (v1.7.0 增强)

| 市场 | 规则 |
|------|------|
| A 股 | 1-99 股碎股，100 股起整手 |
| 美股 | 任意数量，1 股以下碎股 |
| 港股 | 按每手单位，不支持碎股 |

### 部分成交

100 股订单 → 只成交 63 股 → 剩余 37 股继续挂单 → 碎股费率按比例计算。
