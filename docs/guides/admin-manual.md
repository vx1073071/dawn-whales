## 1. /admin 概述

`/admin` 是独立的管理员 Web 后台（URL 不公开），2FA 强制登录，与落地页和桌面端完全隔离。

### 功能

| 模块 | 功能 |
|------|------|
| 数据看板 | DAU/收入/交易量/新注册 |
| 用户管理 | 创作者等级调整/认证审核 |
| 黑名单 | 手动添加/移除/批量操作 |
| 解冻操作 | P2P 异常解冻（隐藏按钮） |
| 费率管理 | 分成调整/AI 定价 |
| 审计日志 | 全链路操作审计 |

---

## 2. 登录 (2FA)

```
/admin/login → 邮箱+密码 → TOTP 6位码 → 进入后台
```

- TOTP 兼容 Google Authenticator
- 会话超时：30 分钟无操作自动退出

---

## 3. 数据看板

### 指标

| 指标 | 说明 |
|------|------|
| DAU/MAU | 日活/月活用户 |
| 收入 | 今日/本月/总 USDT |
| 交易量 | P2P 笔数/金额 |
| 新注册 | 今日/本月 |

### 时间筛选

日 / 周 / 月 / 自定义范围

## 4. 用户管理

### 创作者管理

| 操作 | 说明 |
|------|------|
| 查看 | 创作者列表：等级/收益/订阅数 |
| 等级调整 | L1↔L2↔L3 手动升降 |
| 认证审核 | 审批创作者认证申请 |
| 批量操作 | 批量调整等级/导出 CSV |

---

## 5. 黑名单

### 规则 (永久)

- **0 自动**：不自动触发
- **手动操作**：管理员添加/移除
- **效果**：冻结 P2P + 提现功能

### 操作

```
黑名单页 → 添加（用户ID+原因）→ 确认 → 生效
黑名单页 → 选中移除 → 确认 → 解封
```

---

## 6. 解冻操作

### 规则

- **仅系统异常**时使用
- 隐藏按钮（需要确认弹窗）
- 操作全链路审计日志

### 操作

```
P2P 记录 → 隐藏解冻按钮 → 输入原因 → 确认 → 审计记录
```

## 8. 审计日志

### 记录内容

| 字段 | 说明 |
|------|------|
| 操作人 | 管理员 ID |
| 时间 | UTC 时间戳 |
| 操作类型 | 登录/黑名单/解冻/等级调整/费率修改 |
| 详情 | JSON 操作明细 |
| IP | 操作来源 IP |

### 检索

按操作人/时间范围/操作类型筛选，90 天保留。
