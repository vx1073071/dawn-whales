## 什么是 AI 协作

AI 协作是 DAWN WHALES v1.2.0 推出的核心功能，通过 **4 个专业 AI Agent** 协作分析，帮助创作者生成高质量交易策略。

### 核心优势

- 🤖 **多 Agent 协作**: 4 个专业 Agent 分工协作，模拟真实交易公司决策流程
- 💰 **成本可控**: 单次分析成本低至 0.016 USDT（约 0.12 元人民币）
- 🔄 **智能降级**: 主模型不可用时自动切换到备用模型
- 📊 **高质量输出**: 多维度分析，生成可执行的交易策略

### 工作原理

```
创作者输入策略需求
    ↓
┌─────────────────────────────────────┐
│  4 Agent 协作分析                    │
│  ├─ 基本面分析师 (基本面分析)        │
│  ├─ 情绪分析师 (市场情绪分析)        │
│  ├─ 新闻分析师 (新闻影响分析)        │
│  └─ 技术分析师 (技术指标分析)        │
└─────────────────────────────────────┘
    ↓
多轮辩论 (2 轮)
    ↓
生成交易策略信号
    ↓
创作者审核并保存
```

## 4 Agent 智能体介绍

### 1. 基本面分析师 (Fundamentals Analyst)

**职责**: 分析公司基本面数据，评估内在价值

**分析维度**:
- 📊 财务指标: PE/PB/ROE/营收增长率
- 💼 业务模式: 核心竞争力、市场份额
- 📈 成长性: 营收/利润增长趋势
- ⚠️ 风险因素: 负债率、现金流、行业风险

**输出示例**:
```
基本面分析结果:
- PE: 25.3 (行业平均 22.1, 略高)
- ROE: 18.5% (优秀)
- 营收增长: +15.2% YoY (强劲)
- 负债率: 35% (健康)
- 综合评分: 8.2/10 (推荐)
```

### 2. 情绪分析师 (Sentiment Analyst)

**职责**: 分析市场情绪，判断短期市场情绪倾向

**数据来源**:
- 📰 新闻标题: 主流财经媒体
- 💬 社交媒体: StockTwits、Reddit
- 📊 情绪指标: 恐慌/贪婪指数
- 🔍 搜索热度: Google Trends

**输出示例**:
```
情绪分析结果:
- 新闻情绪: 0.65 (偏正面)
- 社交情绪: 0.72 (正面)
- 恐慌指数: 22 (低恐慌)
- 综合情绪: 0.68 (偏多)
- 情绪趋势: 上升 ↗
```

### 3. 新闻分析师 (News Analyst)

**职责**: 分析重大新闻事件对市场的潜在影响

**分析维度**:
- 📰 宏观经济: 利率决议、GDP、就业数据
- 🏢 公司事件: 财报、并购、管理层变动
- 🌍 地缘政治: 贸易政策、地缘冲突
- 📅 事件日历: 即将发布的重要数据

**输出示例**:
```
新闻分析结果:
- 重大事件: 美联储加息 25bp (利空)
- 公司事件: Q3 财报超预期 (利好)
- 地缘风险: 中美贸易谈判 (中性)
- 影响评估: 短期震荡，中期偏多
- 建议关注: 10/25 美联储会议
```

### 4. 技术分析师 (Technical Analyst)

**职责**: 分析技术指标，识别交易机会

**分析指标**:
- 📈 趋势指标: MA/EMA/MACD
- 💪 动量指标: RSI/KDJ/ROC
- 📊 波动指标: 布林带/ATR
- 📉 成交量: 量价关系

**输出示例**:
```
技术分析结果:
- 趋势: 上升趋势 (MA20 > MA60)
- 动量: RSI 65 (中性偏强)
- 支撑位: 175.50 (强支撑)
- 阻力位: 185.00 (前高)
- 交易信号: 买入 @ 178.50, 止损 175.00, 目标 185.00
```

## 降级链机制

### 什么是降级链

当主 LLM 模型不可用（网络问题、配额用尽、服务故障）时，系统会自动切换到备用模型，确保服务不中断。

### 默认降级链

```
1. DeepSeek V4 Pro (折后) ← 默认 (99% 缓存折扣)
   ↓ (不可用时)
2. DeepSeek V4 Pro (原价) ← 备用 1 (96.6% 毛利)
   ↓ (不可用时)
3. DeepSeek V4 Flash ← 备用 2 (99.5% 毛利)
   ↓ (不可用时)
4. MiniMax-M3 ← 兜底 (0 成本, 自家模型)
```

### 降级触发条件

- **网络超时**: 请求超时 > 10 秒
- **服务不可用**: HTTP 5xx 错误
- **配额用尽**: HTTP 429 错误
- **认证失败**: HTTP 401/403 错误

### 降级通知

当触发降级时，系统会在界面显示提示：

```
⚠️ 正在使用备用模型 (DeepSeek V4 Flash)
原因: 主模型 (DeepSeek V4 Pro) 暂时不可用
影响: 分析质量可能略有下降
```

### 自定义降级链

创作者可以在设置中自定义降级链：

```
设置 → AI 协作 → 降级链配置

主模型: [DeepSeek V4 Pro (折后) ▼]
备用 1: [DeepSeek V4 Pro (原价) ▼]
备用 2: [DeepSeek V4 Flash ▼]
兜底:   [MiniMax-M3 ▼]
```

## 使用流程

### 步骤 1: 选择档位

在策略编辑页面，点击 "AI 协作" 按钮，选择档位：

```
┌─────────────────────────────────────┐
│  选择 AI 协作档位                    │
│                                     │
│  ○ 标准档 (1.0 USDT)               │
│    2 Agent, 快速分析                │
│                                     │
│  ● 高级档 (1.5 USDT)  ← 推荐       │
│    3 Agent, 多维度分析              │
│                                     │
│  ○ 旗舰档 (2.0 USDT)               │
│    4 Agent, 深度分析                │
│                                     │
│         [开始分析]                   │
└─────────────────────────────────────┘
```

### 步骤 2: 输入策略需求

描述你的策略需求：

```
示例:
"我想创建一个基于均线交叉的港股交易策略，标的为腾讯 (00700.HK)，
使用 20 日均线和 60 日均线，当 20 日均线上穿 60 日均线时买入，
下穿时卖出。请分析该策略的可行性。"
```

### 步骤 3: 等待分析

系统会显示分析进度：

```

✓ 技术分析师分析完成

🔄 多轮辩论中 (2/2)...

✅ 分析完成！
```

### 步骤 4: 查看结果

查看 4 Agent 的分析结果和最终策略建议：

```
📊 分析结果

基本面分析: 8.2/10 (推荐)
情绪分析: 0.68 (偏多)
新闻分析: 短期震荡，中期偏多
技术分析: 买入信号

🎯 最终建议:
- 操作: 买入
- 入场价: 178.50
- 止损价: 175.00
- 目标价: 185.00
- 置信度: 85%

[保存策略] [重新分析]
```

### 步骤 5: 保存策略

点击 "保存策略"，策略将保存到策略库。

## 常见问题

### Q1: 为什么选择 DeepSeek V4 Pro 折后？

**A**: 
- **性价比高**: 折后价格仅为原价的 25%
- **质量优秀**: 推理能力强，适合复杂分析
- **缓存折扣**: 99% 缓存折扣，进一步降低成本
- **降级保障**: 有完整的降级链保障

### Q2: 缓存命中率如何达到 90%？

**A**: 
- **模板缓存**: System prompt 和工具结果固定格式，可复用
- **结果缓存**: 相同输入的查询结果可缓存
- **智能预取**: 预测可能的查询，提前缓存

### Q3: 降级会影响分析质量吗？

**A**: 
- **轻微影响**: 备用模型质量略低于主模型
- **可接受**: 降级是临时措施，主模型恢复后自动切回
- **透明提示**: 界面会显示当前使用的模型

### Q4: 如何切换 LLM 提供商？

**A**: 
```
设置 → AI 协作 → LLM 配置

默认 LLM: [DeepSeek V4 Pro (折后) ▼]
API Key: [________________]
```

创作者可以使用自己的 API Key，也可以使用平台统一的 API Key。

### Q5: 分析失败怎么办？

**A**: 
- **自动重试**: 系统会自动重试 3 次
- **降级切换**: 主模型不可用时自动切换备用模型
- **退款机制**: 分析失败不扣费
- **人工支持**: 连续失败可联系客服

### Q6: 如何查看成本明细？

**A**: 
```
设置 → AI 协作 → 成本明细

本月消费: 12.5 USDT
- 标准档: 5 次 × 1.0 = 5.0 USDT
- 高级档: 3 次 × 1.5 = 4.5 USDT
- 旗舰档: 1.5 次 × 2.0 = 3.0 USDT

LLM 成本: 0.2 USDT
平台利润: 12.3 USDT
```

### Q7: 可以批量分析吗？

**A**: 
- **批量分析**: 支持批量分析多个标的
- **批量折扣**: 批量分析享受 9 折优惠
- **批量限制**: 单次最多 100 个标的

### Q8: 分析结果可以导出吗？

**A**: 
- **导出格式**: 支持 JSON、CSV、PDF
- **导出内容**: 4 Agent 分析结果 + 最终建议
- **导出位置**: 策略详情页 → 导出按钮
