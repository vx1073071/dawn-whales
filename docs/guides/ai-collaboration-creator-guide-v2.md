## 辩论模式

### 什么是辩论模式

4 Agent 完成各自分析后，进入**多空辩论**阶段。系统将 Agent 分为 Bull（多方）和 Bear（空方）两大阵营，进行 3 轮辩论。

### 辩论流程

```
分析阶段 (4 Agent 各自分析)
    ↓
辩论阶段 (3 轮)
├─ 第 1 轮: 多方论点 vs 空方论点
├─ 第 2 轮: 反驳与反反驳
└─ 第 3 轮: 最终陈述
    ↓
投票阶段 (加权投票)
    ↓
输出决策
```

### 评分机制

每轮辩论后，系统对双方论点评分：

| 维度 | 权重 | 说明 |
|-----|------|------|
| 逻辑性 | 30% | 论证逻辑是否严密 |
| 数据支撑 | 30% | 是否有数据支撑 |
| 反驳力度 | 20% | 对对方论点的反驳 |
| 风险考量 | 20% | 是否考虑了风险 |

### 辩论日志

所有辩论记录持久化到 SQLite，创作者可随时查看历史辩论。

## 模型竞技场

### 什么是模型竞技场

模型竞技场允许创作者对同一问题使用 **3 个不同 LLM** 同时分析，对比结果。

### 支持模型

| 模型 | 提供方 | 特点 |
|-----|--------|------|
| DeepSeek V4 Pro | DeepSeek | 默认，99% 缓存折扣 |
| DeepSeek V4 Flash | DeepSeek | 快速，成本低 |
| Claude 3.5 Sonnet | Anthropic | 推理强 |
| GPT-4o | OpenAI | 通用强 |
| Gemini 1.5 Pro | Google | 多模态 |

默认 3 模型：**V4 Pro + V4 Flash + Claude 3.5 Sonnet**

### 使用方式

```
策略编辑页 → AI 协作 → 模型竞技场

选择对比模型:
[x] DeepSeek V4 Pro
[x] DeepSeek V4 Flash  
[x] Claude 3.5 Sonnet

[开始对比]
```

## 缓存命中率说明

### 什么是缓存命中率

当创作者多次分析相同标的时，系统会缓存 LLM 响应。缓存命中率 = 缓存命中次数 / 总请求次数。

### 目标

R57 硬指标：缓存命中率 **≥ 90%**

### 如何查看

```
设置 → AI 协作 → 缓存统计

缓存命中率: 92.5% ✅ (目标 ≥90%)
缓存命中: 185 次
缓存未命中: 15 次
总请求: 200 次
节省成本: 3.2 USDT
```

### 优化策略

1. **模板化 Prompt**: System prompt 固定格式，最大化缓存命中
2. **相同输入复用**: 同标的 + 同日期 -> 直接命中
3. **预热机制**: 开盘前预热热门标的

### 降级链

```
1. V4 Pro 缓存 (默认, 99% 折扣)
   ↓ 缓存未命中时
2. V4 Pro 直调 (原价)
   ↓ 不可用时
3. V4 Flash (备用)
   ↓ 不可用时
4. MiniMax-M3 (兜底)
```
