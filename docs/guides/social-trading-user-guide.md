## 社交交易概述

### 什么是社交交易？

社交交易是 DAWN WHALES v1.1.0-beta 引入的核心功能，允许用户：

- **成为交易员**: 分享你的交易策略和信号
- **跟随交易**: 一键跟随优秀交易员的交易
- **收益共享**: 交易员和跟随者共享收益
- **社区学习**: 学习和交流交易经验

## 交易员注册和认证

### 成为交易员

#### 步骤 1: 申请成为交易员

1. 打开 DAWN WHALES 应用
2. 点击左侧导航栏的 "社交交易"
3. 点击右上角的 "成为交易员" 按钮
4. 填写交易员申请表：
   - **昵称**: 你的交易员昵称
   - **头像**: 上传头像图片
   - **简介**: 介绍你的交易风格和经验
   - **交易经验**: 描述你的交易经验
   - **交易风格**: 描述你的交易风格（趋势/震荡/套利等）

#### 步骤 2: 提交认证申请

1. 确认信息填写完整
2. 点击 "提交认证申请"
3. 等待审核 (1-3天)

#### 步骤 3: 认证审核

**审核标准**:
- 交易经验 >= 1 年
- 有明确的交易风格
- 简介描述清晰
- 无违规记录

**审核结果**:
- **通过**: 成为认证交易员，可以发布信号
- **拒绝**: 收到拒绝通知，可以修改后重新申请

### 交易员等级

**认证交易员**:
- 可以发布交易信号
- 可以接受跟随
- 获得收益分成
- 显示认证标识

**普通用户**:
- 可以关注交易员
- 可以跟随交易
- 不能发布信号

### 交易员主页

**交易员主页包含**:
- 头像和昵称
- 简介和交易风格
- 交易统计数据
- 历史信号列表
- 关注者列表
- 关注列表

**交易统计数据**:
- 总信号数
- 成功率
- 总收益
- 关注者数
- 关注数

## 发布交易信号

### 发布流程

```
1. 创建信号
   ↓
2. 填写信号信息
   ↓
3. 设置止损止盈
   ↓
4. 预览和确认
   ↓
5. 发布信号
   ↓
6. 推送给关注者
```

### 步骤 1: 创建信号

1. 打开 DAWN WHALES 应用
2. 点击左侧导航栏的 "社交交易"
3. 点击 "发布信号" 按钮

### 步骤 2: 填写信号信息

**必填信息**:
- **交易标的**: 选择交易标的（如 HK.00700）
- **交易方向**: 买入 (BUY) 或 卖出 (SELL)
- **入场价格**: 当前价格或限价
- **信心度**: 0-100%（你对这个信号的信心）

**可选信息**:
- **止损价格**: 设置止损价格
- **止盈价格**: 设置止盈价格
- **信号说明**: 详细说明你的交易逻辑

**示例**:
```
交易标的: HK.00700 (腾讯)
交易方向: BUY (买入)
入场价格: 380.00
止损价格: 370.00
止盈价格: 400.00
信心度: 85%
信号说明: 腾讯突破关键阻力位，成交量放大，预计继续上涨
```

### 步骤 3: 设置止损止盈

**止损设置**:
- 建议设置止损保护资金
- 止损幅度建议 2-5%
- 可以根据波动率调整

**止盈设置**:
- 可以设置多个止盈目标
- 建议风险收益比 >= 2:1
- 可以根据技术位设置

### 步骤 4: 预览和确认

1. 检查信号信息是否正确
2. 确认止损止盈设置
3. 点击 "确认发布"

### 步骤 5: 发布信号

1. 信号发布成功
2. 自动推送给所有关注者
3. 关注者可以一键跟随

### 步骤 6: 管理信号

**查看信号状态**:
- 活跃 (active): 信号正在执行
- 已关闭 (closed): 信号已平仓
- 已取消 (cancelled): 信号已取消

**关闭信号**:
1. 在信号详情页点击 "关闭信号"
2. 填写出场价格
3. 确认关闭

**取消信号**:
1. 在信号详情页点击 "取消信号"
2. 确认取消

### 信号推送机制

**实时推送**:
- 信号发布后立即推送
- 使用 WebSocket 实时推送
- 推送延迟 < 500ms

**推送内容**:
- 交易标的
- 交易方向
- 入场价格
- 止损止盈
- 信心度

**推送方式**:
- 应用内通知
- 邮件通知（可选）
- 推送通知（可选）

## 跟随交易

### 跟随流程

```
1. 浏览交易员
   ↓
2. 查看信号
   ↓
3. 配置跟随参数
   ↓
4. 确认跟随
   ↓
5. 自动执行交易
   ↓
6. 跟踪交易结果
```

### 步骤 1: 浏览交易员

1. 打开 DAWN WHALES 应用
2. 点击左侧导航栏的 "社交交易"
3. 浏览交易员列表
4. 查看交易员主页和统计数据

### 步骤 2: 查看信号

1. 在交易员主页查看历史信号
2. 查看信号详情和统计数据
3. 评估信号质量

**信号质量指标**:
- 成功率: 信号盈利的比例
- 平均收益: 平均每个信号的收益
- 最大回撤: 最大亏损幅度
- 风险收益比: 平均收益/平均亏损

### 步骤 3: 配置跟随参数

**跟随参数**:
- **仓位大小**: 跟随交易的仓位大小
- **止损设置**: 是否使用交易员的止损
- **止盈设置**: 是否使用交易员的止盈
- **最大跟随数**: 最多跟随多少个信号

**示例配置**:
```
仓位大小: 10000 HKD
止损设置: 使用交易员止损
止盈设置: 使用交易员止盈
最大跟随数: 10
```

### 步骤 4: 确认跟随

1. 在信号详情页点击 "跟随交易"
2. 确认跟随参数
3. 点击 "确认跟随"

### 步骤 5: 自动执行交易

1. 系统自动执行交易
2. 按照配置参数下单
3. 自动设置止损止盈
4. 交易执行完成

### 步骤 6: 跟踪交易结果

**查看跟随交易**:
1. 点击左侧导航栏的 "社交交易"
2. 点击 "我的跟随"
3. 查看所有跟随交易

**交易状态**:
- 活跃 (active): 交易正在执行
- 已关闭 (closed): 交易已平仓
- 已取消 (cancelled): 交易已取消

**交易结果**:
- 入场价格
- 出场价格
- 收益金额
- 收益率

### 跟随交易管理

**取消跟随**:
1. 在跟随交易详情页点击 "取消跟随"
2. 系统自动平仓
3. 确认取消

**修改参数**:
1. 在跟随交易详情页点击 "修改参数"
2. 修改仓位大小等参数
3. 确认修改

### 跟随交易风险

**风险提示**:
- 跟随交易有风险，可能亏损
- 过往表现不代表未来表现
- 建议分散跟随多个交易员
- 建议设置合理的仓位大小

**风险控制**:
- 设置止损保护
- 控制仓位大小
- 分散跟随
- 定期评估交易员表现

## 收益分成

### 收益计算

**收益分成比例**:
- 平台分成: 20%
- 交易员分成: 30%
- 跟随者分成: 50%

**收益计算公式**:
```
跟随交易盈利 = 跟随者收益 × 50%
交易员收益 = 跟随者收益 × 30%
平台收益 = 跟随者收益 × 20%
```

**示例**:
```
跟随者收益: 1000 HKD
跟随者分成: 1000 × 50% = 500 HKD
交易员分成: 1000 × 30% = 300 HKD
平台分成: 1000 × 20% = 200 HKD
```

### 查看收益

**交易员查看收益**:
1. 点击左侧导航栏的 "社交交易"
2. 点击 "我的收益"
3. 查看收益概览和明细

**收益概览**:
- 总收益
- 本月收益
- 待提现收益
- 已提现收益

**收益明细**:
- 日期
- 跟随者
- 收益金额
- 分成比例
- 状态

### 提现

**提现条件**:
- 待提现收益 >= 100 HKD
- 已绑定银行卡或支付宝
- 已完成实名认证

**提现步骤**:
1. 在收益页面点击 "提现"
2. 输入提现金额
3. 选择提现方式
4. 确认提现
5. 等待到账 (1-3个工作日)

**提现限制**:
- 最低提现金额: 100 HKD
- 每日提现次数: 3次
- 每月提现次数: 30次

### 收益结算

**结算周期**:
- 收益按月结算
- 每月 1 号结算上月收益
- 结算后收益变为可提现

**结算流程**:
```
跟随交易平仓
   ↓
计算收益
   ↓
按比例分成
   ↓
计入收益账户
   ↓
月初结算
   ↓
可提现
```
