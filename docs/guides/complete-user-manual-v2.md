## 策略创建

### 方法 1: AI 生成（推荐新手）

1. 点击 "策略" → "新建策略"
2. 选择 "AI 生成"
3. 输入自然语言描述:
   ```
   我想创建一个双均线策略，当 10 日均线上穿 30 日均线时买入，
   下穿时卖出，止损 5%，止盈 10%
   ```
4. AI 自动生成策略代码
5. 点击 "保存"

### 方法 2: 模板选择

1. 点击 "策略" → "新建策略"
2. 选择 "模板库"
3. 选择模板:
   - 双均线交叉
   - RSI 超买超卖
   - MACD 金叉死叉
   - 布林带突破
   - 海龟交易法
4. 调整参数
5. 点击 "保存"

### 方法 3: 手动编写

1. 点击 "策略" → "新建策略"
2. 选择 "手动编写"
3. 编写策略代码:

```typescript
// 双均线策略示例
export default class DualMAStrategy {
  params = {
    fastPeriod: 10,
    slowPeriod: 30,
    stopLoss: 0.05,
    takeProfit: 0.10,
  };

  onBar(bar, context) {
    const fastMA = context.indicators.SMA(this.params.fastPeriod);
    const slowMA = context.indicators.SMA(this.params.slowPeriod);

    if (fastMA.current > slowMA.current && fastMA.previous <= slowMA.previous) {
      return { action: 'BUY', quantity: 100 };
    }

    if (fastMA.current < slowMA.current && fastMA.previous >= slowMA.previous) {
      return { action: 'SELL', quantity: 100 };
    }

    return { action: 'HOLD' };
  }
}
```

4. 点击 "保存"

### 策略参数配置

| 参数 | 说明 | 默认值 |
|-----|------|--------|
| fastPeriod | 快线周期 | 10 |
| slowPeriod | 慢线周期 | 30 |
| stopLoss | 止损比例 | 5% |
| takeProfit | 止盈比例 | 10% |
| positionSize | 仓位大小 | 100 |

## 常见问题

### Q1: 如何更新到最新版本？

**A**: 
1. 打开应用
2. 点击 "帮助" → "检查更新"
3. 如有新版本，点击 "更新"
4. 等待下载完成
5. 重启应用

### Q2: 回测结果与实盘不一致？

**A**: 可能原因:
- 滑点设置不合理
- 手续费计算错误
- 数据源差异
- 市场流动性不足

建议:
- 调整滑点参数
- 检查手续费配置
- 使用相同数据源
- 考虑市场冲击

### Q3: 策略优化后表现下降？

**A**: 可能过拟合。检查:
- Walk-Forward 效率 < 0.5
- 参数过于复杂
- 样本外表现差

建议:
- 简化参数
- 增加样本外数据
- 使用正则化

### Q4: AI 助理未响应？

**A**: 检查:
- 网络连接
- AI 服务状态
- 输入格式

建议:
- 检查网络
- 重启应用
- 简化输入

### Q5: 多账户切换后数据丢失？

**A**: 数据不会丢失，只是隔离显示。检查:
- 是否切换到正确账户
- 数据是否在该账户下创建

建议:
- 确认账户 ID
- 检查数据归属

### Q6: PWA 无法安装？

**A**: 检查:
- 是否使用 HTTPS
- manifest.json 是否正确
- Service Worker 是否注册

建议:
- 使用 HTTPS
- 检查配置
- 清除缓存重试

### Q7: 移动端手势不灵敏？

**A**: 调整:
- 手势灵敏度
- 触摸区域大小
- 手势冲突处理

建议:
- 调整灵敏度
- 避免手势冲突
- 更新到最新版本

### Q8: 如何导出策略代码？

**A**: 
1. 选择策略
2. 点击 "导出"
3. 选择格式 (JSON/TS)
4. 选择保存位置
5. 点击 "导出"

### Q9: 如何查看策略评价？

**A**: 
1. 进入 Marketplace
2. 选择策略
3. 查看 "评价" 标签
4. 查看评分和评论
