# quant-moo 首次使用引导 — 三步上手

> **版本**: v2.1.0 | **目标用户**: 新注册用户 | **预计时间**: 5 分钟
> **核心理念**: 钱包 → 市场 → AI，三步走，快速上手

---

## 📌 欢迎来到 quant-moo！

quant-moo 是一个**量化交易平台**，你可以:
- 🧠 用 AI 自动分析图表、优化策略
- 🛒 购买/出售交易策略赚 USDT
- 🤖 让 Trading Agent 自动执行你的策略
- 📊 连接券商实时交易

下面三步，5 分钟搞定。

---

## 第一步: 💰 充值钱包 (2 分钟)

所有付费功能（AI、策略市场、交易手续费）都用 **USDT 积分** 结算。

### 1.1 打开钱包
```
左侧菜单 → 💰 钱包 → Deposit
```

### 1.2 充值 USDT
```
1. 选择网络: TRC-20（推荐，0 手续费）或 ERC-20
2. 复制显示的充值地址
3. 从你的交易所/钱包向该地址转 USDT
4. 等待确认 (~3 分钟) → 余额自动到账

⚠ 不要手动提交 tx_hash！平台自动监控链上交易。
```

### 1.3 检查余额
```
钱包首页显示:
  💰 余额: XXX.XX USDT
  📊 可用: XXX.XX USDT (余额 - 冻结)

充值 100 USDT → 到账 100 积分 (0 手续费)
```

> 💡 **建议首次充值**: 20-50 USDT 够试用 AI + 买一个策略。

---

## 第二步: 🛒 浏览市场 (1 分钟)

### 2.1 打开市场
```
左侧菜单 → 🛒 Marketplace
```

### 2.2 浏览策略
市场中有三种产品:

| 产品 | 价格 | 说明 |
|------|------|------|
| 📄 策略模板 | ≥ 9.9 USDT | 一次购买，永久使用 |
| 📦 策略组合 | ≥ 9.9 USDT | 2-5 个模板打包 |
| 📡 信号订阅 | ≥ 9.9 USDT/月 | 按月接收交易信号 |

### 2.3 购买策略
```
1. 点开感兴趣的策略 → 查看详情（回测数据、创作者信息）
2. 点击 [购买] → 确认价格 → 余额扣除
3. 策略自动添加到「我的库」→ 可以导入使用了
```

> 💡 **先看再买**: 每个策略页面都显示回测收益、最大回撤、夏普比率。

---

## 第三步: 🤖 使用 AI (2 分钟)

### 3.1 进入图表
```
左侧菜单 → 📈 Market → 选择一个标的 → 进入 K 线图
```

### 3.2 试试 AI 画线
```
在 K 线图页:
1. 点击 [🤖 AI Draw] 按钮
2. 1 USDT 静默扣除（不弹窗）
3. 1-3 秒后 → 趋势线、支撑阻力、K线形态自动标注在图上

标注颜色:
  🟢 高置信度 (≥70%)    — 实线
  🟡 中置信度 (50-69%)   — 虚线
  🟠 低置信度 (30-49%)   — 半透明
```

### 3.3 AI 功能一览

| 功能 | 价格 | 什么时候用 |
|------|------|-----------|
| 🎨 AI 画线 | 1 U | 看盘时自动标注关键位 |
| 💬 AI 对话 | 1 U | 问策略问题、分析市场 |
| 🎯 AI 填参数 | 1 U | 不知道参数怎么设？AI 帮你 |
| 📊 AI 回测解读 | 1 U | 回测结果看不懂？AI 翻译 |
| 🔧 AI 优化 | 1.5 U | 策略表现不好？AI 建议改进 |
| 🩺 AI 健康检查 | 1 U | 检查所有策略是否正常 |
| 🏗️ AI 生成组合 | 2 U | 让 AI 帮你搭配策略组合 |

### 3.4 Trading Agent（自动执行策略）
```
1. 创建一个策略 → 点击 [Run TA]
2. 选择等级: Standard 1U / Advanced 1.5U / Flagship 2U
3. TA 分析市场 → 有信号自动下单 → 你可以在持仓页看到
```

### 常见问题

**Q: AI 会偷偷扣钱吗？**
A: 每次使用 AI 前，界面会显示价格标签（如 `🤖 AI Draw · 1 USDT`）。扣费后有 Toast 提示 `已扣 1 USDT`。

**Q: 余额不够了怎么办？**
A: 任何操作如果余额不足，会弹窗告诉你 `还差 X USDT`，点击可直接跳转充值。

**Q: AI 分析失败了会退钱吗？**
A: 会自动退。失败退费，不退不收费。

**Q: 我买的策略能退款吗？**
A: 策略购买不支持退款。购买前请仔细查看回测数据和详情。
