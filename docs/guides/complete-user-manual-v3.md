## 第二步: 连接券商

TradingEasy 支持两种券商：

### Futu OpenD（推荐）

1. 下载并安装 [Futu OpenD](https://www.futunn.com/download/openAPI)
2. 启动 OpenD → 确认端口 11111
3. 桌面端 → 设置 → 券商 → 添加 → 选择 Futu → 输入 `127.0.0.1:11111`
4. 点击连接 → 看到 "✅ 已连接" 即成功

### Interactive Brokers (IBKR)

1. 在 IBKR Gateway 中开启 API 连接
2. 桌面端 → 设置 → 券商 → 添加 → 选择 IBKR
3. 输入 Gateway 地址和端口（默认 `127.0.0.1:7497`）
4. 点击连接

## 第三步: 创建你的第一个策略

### 最快方式: 模板创建（30 秒）

1. 点击 **策略工场** → **套用模板**
2. 选择一个模板：
   - 🟢 动量策略: 追涨，适合牛市
   - 🟡 均值回归: 抄底，适合震荡市
   - 🔵 双均线: 金叉买入，死叉卖出
3. 选择市场（港股/美股/新加坡...）和标的
4. 调整参数（或直接用默认值）
5. 点击 **回测** → 查看结果
6. 满意？点击 **发布**。不满意？调整参数再回测。

### AI 语音创建（实验功能，🤖收费）

1. 策略工场 → **说出你的策略**
2. 用自然语言描述：*"MA5 升穿 MA20 买入 TQQQ，止损 5%，止盈 15%"*
3. AI 自动解析为可执行策略
4. 回测 → 调整 → 发布

### 手动创建（完全自定义）

1. 策略工场 → **新增策略** → **填表**
2. 精确设定每个参数：选股范围、入场/出场条件、仓位管理、风控
3. 回测 → 发布

## 第七步: 交易执行

### 自动交易

1. 策略设置 → **实盘执行** → 开启
2. 策略产生的信号会自动通过 OpenD/IBKR 下单
3. 你可以在交易记录中查看每一笔成交

### 风控设置

| 参数 | 建议值 | 说明 |
|------|:---:|------|
| 单笔最大仓位 | 10% | 单一标的仓位上限 |
| 日最大亏损 | 5% | 亏损超过此值暂停交易 |
| 止损 | -5% | 单笔止损百分比 |
| 止盈 | +15% | 单笔止盈百分比 |

### ⚠️ 风险提示

量化交易不保证盈利。历史回测收益不代表未来表现。请根据个人风险承受能力设置风控参数。

## 第八步: P2P 转账

### 转账流程

1. 钱包 → P2P 转账
2. 输入对方钱包地址和金额
3. 确认 → 0.3% 手续费
4. 对方收到 USDT（双向 14 天冻结期）

### 冻结期

- 转账后 **14 天内** 资金处于冻结状态
- 14 天后自动解冻
- 冻结期内可发起申诉

### 申诉

如果转账出现问题（未收到币/金额不对/对方不回复），在 14 天内提交申诉。管理员审核后判定。

## 常见问题

### Q: 完全免费吗？
A: 下载免费。AI 分析、策略模板购买需要 USDT。新手注册赠送 3 次免费 AI 分析。

### Q: 我的策略安全吗？
A: 策略代码存储在你的本地。发布到市场时会脱敏（不暴露具体参数），订阅者只能收到交易信号。

### Q: 能连接多个券商吗？
A: 可以。设置 → 券商管理 → 添加多个配置 → 一键切换。

### Q: 支持 A 股吗？
A: 暂不支持。当前支持港股、美股、新加坡、日本、澳洲、加拿大、马来西亚。

### Q: 深度求索 (DeepSeek) API Key 需要我自己申请吗？
A: 不需要。AI 功能通过我们的服务器调用，你不需要管理任何 API Key。

### Q: 邀请朋友有什么奖励？
A: 朋友通过你的邀请链接注册并完成首次 AI 分析后，双方各得 1 次免费标准 AI 分析。
