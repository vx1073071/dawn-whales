## 一、社区社交

### 互动功能

| 功能 | 说明 |
|------|------|
| 评论 | 多级嵌套回复（strategy/signal/creator 下） |
| 点赞 | 策略/信号/评论 |
| 关注 | 创作者 follow/unfollow |
| 分享 | 信号一键分享 |

### 信息流 (Feed)

```
关注动态 → 新策略/新信号/新评论 → 时间线排列
```

### 通知中心

| 类型 | 推送方式 |
|------|---------|
| 被关注/评论/点赞 | 站内通知 + 桌面 toast |
| 订阅到期 | 提前 3 天提醒 |
| 信号更新 | 实时 WebSocket |
| 收益周报 | 每周一推送 |
| 等级晋升 | 即时通知 |

推送：WebSocket 实时 + 离线消息队列。

## 二、高级分析

### 因子研究

| 指标 | 说明 |
|------|------|
| IC | 信息系数（因子与收益相关性） |
| IR | 信息比率（IC 稳定性） |
| 因子暴露 | 组合在各因子上暴露度 |
| 因子收益 | 各因子贡献收益 |
| 因子衰减 | 因子预测力衰减曲线 |
| 拥挤度 | 因子使用拥挤程度 |
| 多空收益差 | Long-Short 分组收益差距 |

### 策略对比

6 维雷达图：收益 / 夏普 / 最大回撤 / 胜率 / 波动率 / Alpha

多策略横向对比 + 相关性矩阵。

### 组合优化

| 工具 | 说明 |
|------|------|
| 有效前沿 | Markowitz 均值方差优化 |
| 风险预算 | 等风险贡献分配 |
| 再平衡建议 | 定期/阈值/混合策略 |
