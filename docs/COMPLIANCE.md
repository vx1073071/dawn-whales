- ❌ 地理位置 (GPS)

## 三、数据保留策略

| 类别 | 活跃 | 归档 | 删除 |
|------|:---:|:---:|:---:|

| 崩溃日志 | 实时 | 自动聚合 | 30天后删除 |

### 数据删除

用户可随时请求删除：`privacy@quant-moo.com`
- 30 天内确认并执行
- 策略市场发布的策略：匿名化（保留策略逻辑，移除作者信息）
- 交易记录：匿名化后保留以满足法定义务

## 四、安全措施

### 传输加密

- HTTPS + TLS 1.3
- WebSocket: wss:// only
- Certificate Pinning (桌面端)

### 存储加密

- PostgreSQL: AES-256 at rest
- USDT 私钥: 独立加密存储，不在代码仓库
- DeepSeek API Key: 仅服务器环境变量

### 访问控制

- 2FA (TOTP) 管理员登录
- JWT 1h 过期 + refresh token
- Rate limiting: 100 req/min per IP
- CSRF Token 每次写操作

### 输入验证

- XSS: DOMPurify sanitize
- SQL 注入: Prisma 参数化查询
- 命令注入: child_process 白名单 + 输入校验
- 文件上传: 类型+大小限制

## 五、事件响应

### 安全事件分级

| 级别 | 定义 | 响应时间 | 通知范围 |
|:---:|------|:---:|------|
| P0 | 数据泄露/私钥泄露 | <1h | 全用户 + 监管机构 |
| P1 | 服务中断 (API不可用) | <4h | Status Page |
| P2 | 非关键功能异常 | <24h | 不通知 |
| P3 | UI瑕疵 | 下版本 | 不通知 |

### 数据泄露响应流程

1. 立即下线受影响服务
2. 轮换所有密钥 (API Key / JWT Secret / Wallet Key)
3. 审计日志确定泄露范围和时间线
4. 72h 内通知受影响用户 (`privacy@quant-moo.com`)
5. 72h 内通知监管机构 (如适用)
6. 发布事后分析报告
