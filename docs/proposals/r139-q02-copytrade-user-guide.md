## 1. 什么是跟单

跟单（CopyTrade）让你自动复制专业信号源（交易员/AI策略）的交易操作，无需盯盘或手动下单。

**双模架构**（v2.1.0）：

```
Cloud 服务器 24h 运行          桌面端（你在线时）
━━━━━━━━━━━━━━━━━━            ━━━━━━━━━━━━━━━━━
  Binance / OKX / Bybit         富途 OpenD / moomoo
  IB / 老虎 / Schwab            港股 / 美股 / A股
  E*TRADE / eToro / MT5
  华盛 / 盈立 / Robinhood     → 共 17 家券商覆盖
```

- **Cloud 券商**（15家）：服务器 7×24 运行，你离线也跟单
- **OpenD 券商**（2家：富途/moomoo）：需要桌面 App 在线

## 2. 快速上手（5分钟）

### 步骤 1：打开跟单中心

点击左侧菜单 **⚡ 跟单中心** → 进入 `CopyTradeHub`。

### 步骤 2：连接券商

```
跟单中心 → 券商标签 → 点击[添加券商]
→ 选择你的券商 → 输入 API Key / 连接配置
→ 点击[测试连接]确认可用
→ 保存
```

支持的券商类型：

| 类型 | 接入方式 | 代表券商 |
|------|---------|---------|
| Cloud API | API Key + Secret | Binance, OKX, Bybit, Bitget, Robinhood |
| OAuth2 | 第三方授权 | E\*TRADE, eToro, Schwab |
| TWS Gateway | 本地网关 | IB |
| Bridge | 券商 SDK | 老虎, 华盛, 盈立, 长桥 |
| OpenD | 本地网关 | 富途, moomoo |
| MetaApi | 云端桥接 | MT5 (1200+券商) |

### 步骤 3：选择信号源

```
跟单中心 → 信号源标签 → 浏览信号源列表
→ 查看收益率 / 胜率 / 夏普比率 / 最大回撤
→ 点击[关注]加入跟单
```

### 步骤 4：配置跟单参数

```
跟单中心 → 配置标签 → 设置跟单参数：
  · 跟单金额：每笔最大投入 (USDT)
  · 跟单模式：固定金额 / 按比例
  · 止损止盈：百分比
  · 滑点容忍：最大接受滑点
→ 点击[启用跟单]
```

### 步骤 5：坐等自动执行 ✅

信号到达 → 自动下单 → 成交回传 → 状态更新。全程无需手动操作。

## 3. 选择信号源

### 如何评估信号源

在信号源列表中，每个信号源展示以下核心指标：

| 指标 | 含义 | 建议值 |
|------|------|--------|
| 总收益 | 历史累计收益率 | >20% |
| 胜率 | 盈利交易占比 | >55% |
| 夏普比率 | 风险调整后收益 | >1.0 |
| 最大回撤 | 从峰值最大跌幅 | <20% |
| 关注者数 | 已有跟单用户数 | >10 更可信 |
| 风险等级 | low / medium / high | 新手选 low |
| 认证状态 | unverified / pending / verified / featured | 优选 verified |

### 信号源等级

| 等级 | 条件 | 分润 |
|------|------|------|
| L1 新人 | 注册即可 | 统一 15% |
| L2 成长 | 月交易量>$10K，胜率>50% | 统一 15% |
| L3 高手 | 月交易量>$50K，胜率>60%，夏普>1.5 | 统一 15% |

> 当前所有信号源统一 15% 利润分成，跟单者保留 75%，平台 10%。

## 4. 配置跟单规则

### 基本配置

| 参数 | 说明 | 默认值 | 范围 |
|------|------|--------|------|
| 跟单金额 | 每笔最大投入 | $1,000 | $10 - $100,000 |
| 跟单模式 | fixed（固定）/ ratio（比例） | fixed | — |
| 跟单比例 | ratio 模式下的复制比例 | 50% | 1-100% |
| 止损 | 单笔亏损上限 | 5% | 0.5-50% |
| 止盈 | 单笔盈利上限 | 10% | 1-100% |
| 滑点容忍 | 最大接受滑点 | 0.5% | 0.1-5% |

### 多券商分配

可以选择多个券商同时跟单：

```
信号源 AlphaQuant → 信号到达
  → Binance: 50% 仓位
  → OKX: 30% 仓位
  → Bybit: 20% 仓位
```

在 **券商标签** 中勾选多个券商即可。

## 5. 连接券商

### Cloud API 券商 (如 Binance)

1. 前往交易所官网 → API 管理 → 创建 API Key
2. 权限选择：**只读 + 交易**（**不要勾选提现！**）
3. 复制 API Key 和 Secret Key
4. 在 TradingEasy 中输入 → 加密存储（AES-256-GCM）
5. 测试连接

### OpenD 券商 (富途/moomoo)

1. 确保桌面端运行中
2. 启动 OpenD 网关（富途牛牛 → 设置 → 开启 OpenD）
3. 在 TradingEasy 中点击「连接 OpenD」
4. 选择交易环境：**模拟盘**（推荐先测试）/ **实盘**

### OAuth 券商 (E\*TRADE/Schwab)

1. 点击「连接」→ 跳转券商授权页面
2. 登录券商账户 → 授权 TradingEasy
3. 回调自动完成 → 无需手动输入密钥

### 测试连接

所有券商连接后建议**先用模拟盘/小额测试**：
- Cloud: 下一笔 $10 市价单
- OpenD: 先在模拟环境验证
- 确认成交 → 再启用跟单

| **券商** | 管理券商连接 / 分配比例 |

### 状态栏实时指标

```
✅ Binance  在线 · 延迟 45ms · 今日成交 12 笔 · PnL +$234.50
✅ OKX      在线 · 延迟 62ms · 今日成交 8 笔  · PnL -$15.30
⚠️ Bybit   降级 · 延迟 320ms · 排队 3 笔
❌ Bitget  离线 · 最后在线 08:30
```

### 🔴 Kill Switch 一键全停

```
跟单中心 → 右上角红色 [⛔ 一键全停]
→ 立即断开所有券商
→ 停止所有排队指令
→ 已成交仓位保持不动（不强制平仓）
```

适用场景：市场暴跌 / 发现信号源异常 / 紧急避险。

## 7. 模拟跟单（新手推荐 ⭐）

> 强烈建议新用户先跑 **至少 2 周** 模拟跟单，验证效果后再切实盘。

### 启动模拟跟单

```
跟单中心 → 配置 → 模式选择「模拟」
→ 信号到达 → 模拟盘执行（不扣真实资金）
→ 实时显示模拟 PnL
```

### 模拟 vs 实盘对比

模拟运行后，系统自动生成对比报告：

```
            模拟盘        实盘
总收益      +$2,300       $0
胜率        68%           N/A
交易次数     15            0
建议: 胜率>60%, 建议切换实盘 ✅
```

### 切换实盘

```
模拟表现满意 → 点击「切换实盘」
→ 确认弹窗（不可逆）
→ 实盘开始跟单
```

> ⚠️ 切换实盘后，模拟记录保留但不影响实盘统计。

## 8. 暂停规则与风控

### 三种暂停规则

**🔥 日亏损限额**
```
今日累计亏损 > $500 → 自动暂停所有跟单
关闭: 切换开关 OFF（不限制）
```

**🔥 连续亏损暂停**
```
连续亏损 3 笔 → 自动暂停
关闭: 切换开关 OFF
```

**🔥 最大回撤暂停**
```
从最高点回撤 8% → 自动暂停
关闭: 切换开关 OFF
```

### 断路器状态

触发暂停后：
```
⛔ 跟单已暂停
原因: 单日亏损 $520 超过限额 $500
冷却至 10:30 (30分钟冷却)
                                     [手动恢复]
```

### 冷却与自动恢复

| 参数 | 说明 | 默认值 | 范围 |
|------|------|--------|------|
| 冷却时间 | 触发后暂停时长 | 30分钟 | 5-240分钟 |
| 自动恢复 | 冷却后自动重启 | 关闭 | 建议手动 |

> ⚠️ 暂停后**已成交的持仓不动**，仅停止新跟单。

## 10. 死信处理

### 什么是死信？

死信（Dead Letter）是指**执行失败且无法自动恢复**的跟单信号，原因包括：

| 原因 | 说明 | 自动恢复 |
|------|------|---------|
| 网络超时 | API 请求超时 | ✅ 自动重试 3 次 |
| 余额不足 | 账户余额不够 | ❌ 需充值 |
| 密钥过期 | API Key 失效 | ❌ 需更新密钥 |
| 交易所限制 | 交易对暂停/维护 | ❌ 需等待 |
| 速率限制 | 请求太频繁 | ✅ 自动排队 |

### 查看死信

```
跟单中心 → 通知 Tab → 筛选「失败」类型
→ 查看失败原因 + 重新执行 / 忽略
```

死信队列角标实时显示未处理数量：
```
🔔 通知 (3) ← 3条未处理死信
```

## 11. 分润与费用

### 分润结构

```
      你的跟单净利润
           │
    ┌──────┼──────┐
    ▼      ▼      ▼
  平台   信号源   你
  10%    15%    75%
```

**示例**：一笔跟单盈利 $1,000

| 分配 | 比例 | 金额 |
|------|------|------|
| 平台费 | 10% | $100 |
| 信号源分润 | 15% | $150 |
| 你的收益 | 75% | **$750** |

### 费用计算器

在 **分润结构** 面板中拖拽滑块：

```
跟单利润: [$10,000] ← 拖动滑块
  → 平台费: $1,000
  → 信号源: $1,500
  → 你得到: $7,500 ✓
```

### 重要规则

- 📌 **分润仅在盈利时计算** — 亏损不分润
- 📌 平台费用于服务器/API/监控运营
- 📌 不同券商佣金另算，不计入分润
- 📌 USDT 积分可用于抵扣平台费

## 12. OpenD 桌面跟单

### 适用券商

- 富途证券 (Futu OpenD)
- moomoo (moomoo OpenD)

### 前置条件

1. 富途牛牛 / moomoo App **必须运行中**
2. OpenD 网关 **必须开启**
3. TradingEasy 桌面端 **必须在线**

### 信号流程

```
信号源产生信号
  → 服务器存储 (SQLite signals 表)
  → 桌面端 OpenDSignalFetcher 定时拉取 (每 3 秒)
  → OpenD 下单执行
  → 成交结果回传服务器
  → 状态更新 / 通知推送
```

### 离线排队

如果你离线时收到信号：

```
信号到达 → 你离线 → 信号排队 (processing)
  → 你上线 → 检查是否超时
  → 未超时 → 自动执行
  → 已超时 → 进入死信队列
```

### OpenD 信号面板

```
信号面板 → 待处理信号列表
  🔴 P0 止损  BTC/USDT SELL 0.1  $65,000  3秒前  [撤单] [确认]
  🟡 P1 跟单  ETH/USDT BUY 1.5  $3,200   12秒前 [撤单]
```

- **[撤单]**：取消该信号（需确认）
- **[确认]**：弹出试算弹窗 → 5秒倒计时 → 确认下单

## 13. 常见问题

### Q1: 跟单亏钱了怎么办？

跟单不能保证盈利。使用**暂停规则**保护自己：
- 设置日亏损限额（如 $500）
- 设置连续亏损暂停（如 3 笔）
- 先用**模拟跟单**测试 2 周

### Q2: 为什么信号没执行？

常见原因：
1. 券商断连 → 检查状态栏
2. 余额不足 → 检查账户
3. API Key 过期 → 重新生成
4. 暂停规则触发 → 查看断路器状态
5. 死信队列 → 查看通知

### Q3: 可以同时跟多个信号源吗？

✅ 可以。在信号源标签中关注多个，每个独立配置。

### Q4: 跟单和手动交易冲突吗？

不冲突。跟单操作的仓位与手动交易独立计算，但**共用同一账户余额**。

### Q5: 如何安全停止跟单？

1. **暂停跟单**：配置 Tab → 关闭「启用跟单」— 信号继续排队不执行
2. **一键全停**：右上角 Kill Switch — 断开所有券商+停止排队
3. **关闭平台**：关闭 App — Cloud 券商继续 24h 运行，OpenD 券商暂停

### Q6: 试算弹窗显示的费用包含什么？

试算弹窗展示完整预估费用：

```
预估总价    $1,805.00    （价格 × 数量）
佣金        $0.00         （券商佣金，免佣时为0）
SEC 规费    $0.01         （仅美股）
平台费      $1.80 (0.1%)  （平台运营费）
创作者分润   $0.00          （仅在平仓盈利时计算）
──────────────────────────
预估总计    $1,806.81
```

### Q7: 跟单延迟多少？

- Cloud 券商：通常 <100ms（服务器与交易所同区域）
- OpenD 券商：~50-200ms（取决于本地网络与 OpenD 响应）
- MT5（MetaApi）：~100-500ms（经过云桥接）

### Q8: 模拟跟单数据是真实的吗？

模拟跟单使用**真实行情价格**执行，但**不实际下单**。模拟 PnL 包含模拟手续费和滑点，尽可能接近真实环境。

## 小结

跟单让你从手动盯盘解放出来，让专业信号源为你工作。记住三个铁律：

1. **先模拟后实盘** — 至少 2 周模拟验证
2. **设好风控再启动** — 日亏损限额 / 连续亏损 / 最大回撤
3. **分散券商风险** — 不要让所有仓位集中在一个券商
