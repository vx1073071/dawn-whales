## 二、人类实际使用习惯 — 行为模式分析

### 2.1 散户的"一天"（基于moomoo/东方财富/雪球用户行为数据）

```
08:30 起床 → 打开APP → 先看热力图（今天红还是绿？）
       → 然后看自选（我的持仓怎么样了？）
       → 然后看资讯（有什么大新闻？）
09:30 开盘 → 盯盘（自选列表实时刷新）
       → 偶尔看看资金流向（主力在买什么？）
       → 偶尔看看异动（什么突然涨了/跌了？）
12:00 午休 → 刷刷社区（别人在讨论什么？）
       → 看看筛选器（有没有符合我条件的？）
15:00 收盘 → 复盘（今天赚了/亏了？为什么？）
       → 看看Level 2（尾盘谁在吃货/出货？）
20:00 晚上 → 研究（回测策略、学新指标、看课程）
```

**核心发现**: 热力图不是"一个功能"，是**散户的第一眼**。不是"涨跌列表"，是"一图看懂今天市场"。

### 2.2 "20秒扫描" 定律

人类打开交易APP的前20秒行为：
| 秒数 | 行为 | QUANT MOO现状 |
|------|------|--------------|
| 0-3s | 看大盘颜色（红/绿/平） | ✅ 驾驶舱快评(R253) |
| 3-8s | 看热力图（哪个板块在动） | ❌ **缺失** |
| 8-12s | 看自选（我的持仓色块） | ⚠️ 有自选列表，但不是色块/热力图形式 |
| 12-20s | 看1-2条推送（异动/信号） | ⚠️ 有推送文案(R247)，未接入引擎 |

**诊断**: 用户在**第3秒就丢了**。打开APP→看到"空白"的首页→切到moomoo。

### 2.3 三类用户的差异化需求

| 用户类型 | 占比 | 核心需求 | 我们满足了吗 |
|----------|:---:|---------|:----------:|
| **看客型** (只看不做) | ~40% | 热力图、热度榜、资讯、社区 | ❌ 热力图=无 |
| **自选型** (买卖自选股) | ~35% | 自选列表、异动提醒、资金流向 | ⚠️ 缺卖空/资金流向 |
| **研究型** (策略驱动) | ~25% | 筛选器、回测、因子、L2深度 | ⚠️ 有因子缺筛选器 |

**关键洞察**: 看客型用户虽然不付费，但他们是**产品传播的引擎**（"你看这个APP的热力图多好用"）。没有看客型用户，你就没有口碑传播。

## 三、竞争对标 — 我们在哪里输

### 3.1 moomoo（富途）— 数据产品化的标杆

moomoo最让散户离不开的3个功能（按使用频率）：

1. **热力图** — Square treemap，按市值比例排列。一图看懂：哪些在涨(绿)、哪些在跌(红)、涨跌幅度(颜色深浅)。
2. **资金流向** — "主力资金今天买了什么"。散户的"抄作业"第一来源。
3. **卖空数据** — 港股特有的"谁在被做空"。散户的"避险"第一信号。

**moomoo怎么赚钱**: Level 2行情收费(NYSE $4.99/月, HK $18/月) + 高级筛选器收费 + IPO认购手续费。**数据本身免费，分析/深度收费。**

### 3.2 TradingView — 图表社区王者

TradingView的3个护城河：
1. **Pine Script** — 用户自己写指标，社区分享。UGC=无限的指标库。
2. **社区图表** — 公开分享策略/分析，形成社交网络效应。
3. **多设备同步** — 手机画的线、电脑看得到。

**TradingView怎么赚钱**: Pro($14.95/月)=更多指标叠加+更多图表布局+无广告。Premium($29.95/月)=第二档。**图表免费，专业功能付费。**

### 3.3 Thinkorswim — 专业交易深度

Thinkorswim的3个护城河：
1. **Scan Hacker** — 500+预设筛选条件，秒级反馈。专业交易者的"鱼群探测器"。
2. **期权分析** — Greeks实时计算+可视化。期权交易者的"X光机"。
3. **条件单** — 复杂条件+OCO+多腿。自动化的"无人值守交易"。

**Thinkorswim怎么赚钱**: 免费（TD Ameritrade通过佣金赚钱）。但功能深度=用户粘性=不换券商。

### 3.4 行业趋势（2025-2026）

| 趋势 | 含义 |
|------|------|
| **Bitget免费L2** | L2数据在加密市场已商品化 — 不再是付费壁垒 |
| **AI筛选器** | 自然语言→筛选条件（"帮我找被低估的AI芯片股"） |
| **社区信号** | TradingView→TikTok化：短视频解盘+一键跟单 |
| **Webhook自动化** | Deepcoin/Gate已接TradingView Webhook自动下单 |

#### 建议 #1: 市场热力图 — "散户的第一眼"

**什么是热力图**: Square treemap。每个方块=一只股票。方块大小=市值/成交额。方块颜色=涨跌(绿涨红跌，深浅=涨跌幅)。

**为什么赚钱**: 
- 热力图是散户打开APP的**第一眼** — 没有热力图=没有第一眼=没有打开APP的理由
- 热力图数据已全部在手（Yahoo Finance WS已有价格+涨跌幅+市值+板块分类）
- 不需要额外数据源成本

**实现方案**:
```
第1层（免费）: 市场总览热力图 — 标普500/HK50成分股，按板块分组
第2层（免费）: 板块热力图 — 点击进入单板块，看到单只股票
第3层（付费 1U/次或解锁）: 热力图联动因子 — "显示出RSI>70的股票"、"标出有主力资金流入的"
```

**技术实现**: 
- 组件已有 `MarketHeatMap.tsx` (17KB) + `HeatmapTreemap.tsx` (13KB)
- 引擎已有 `factor-heatmap-engine.ts` (15KB)
- **只需要前端接入Yahoo Finance数据流即可**

**工作量**: 前端2d (ML) + 数据管道1d (JVS) = **3d**

**预估收入**: 
- 基础热力图免费 → 引流
- 高级热力图（叠加因子/资金流向）1U/次 → 假设日活1000用户×5%使用率×30天 = **150U/月**

---

#### 建议 #2: 智能筛选器 — "散户的选股帮手"

**什么是筛选器**: 自然语言或条件组合筛选股票。"PE<15 + ROE>20% + 连续3年股息增长 + 市值>100亿"

**为什么赚钱**:
- 散户不知道买什么 → 筛选器告诉他 → 他买了 → 他下次还会来
- moomoo的筛选器是Pro用户专属($8.99/月)
- **筛选器是"选股"到"下单"之间的桥梁** — 没有筛选器，用户只能手动浏览。有筛选器，用户直接到自选/下单。

**实现方案**:
```
免费版（引流）: 5个基础筛选条件（PE/ROE/市值/股息率/行业）
Starter(免费): 保存1个筛选方案
Pro(付费 1.5U/月): 20+条件组合 + 保存10个方案 + 每日自动跑
AI(付费 1U/次): 自然语言→筛选（"帮我找AI芯片股但不要太贵的"）
```

**技术实现**:
- 引擎已有 `stock-screener-v2.ts` (20KB) + `screener-presets.ts` (9KB) + `news-stock-screener.ts` (17KB)
- UI已有 `StockScreenerUI.tsx` (12KB) + `StockScreenerPage.tsx` (13KB)
- **已有80%的代码，需要接入数据+完善UI+打通付费**

**工作量**: UI打磨1d (ML) + 数据管道1d (JVS) + 付费管道1d (LOBEHUB) = **3d**

**预估收入**: 1000用户×3%付费率 = 30×1.5U = **45U/月** + AI筛选100次×1U = **100U/月** = **总计145U/月**

## 七、3条"别做"的建议

### ❌ 别做: 自研图表引擎
TradingView已经赢了。与其花3个月写Canvas K线图，不如集成TradingView Widget(免费版)或用lightweight-charts(我们已有)。图表引擎不是我们的差异化。

Bloomberg一年$24K是因为325,000机构用户。散户不会为"1000条/秒的新闻过滤"付费。我们已经有的40新闻源+AI摘要足够了。

### ❌ 别做: 社交媒体式社区
TradingView的社区是10年积累。冷启动一个"QUANT MOO社区"需要3年。与其自建社区，不如让用户把QUANT MOO的分析"分享到Twitter/微信"（社交裂变R249文案已有）。

## 八、结语

**QUANT MOO的行情系统有"骨架"但缺"皮肤"**。

骨架=29市场路由+Bridge+Yahoo WS+QuoteCache+CBBO — 技术基础扎实。
皮肤=热力图+筛选器+卖空+对比+推送 — 散户看不到。

核心矛盾：
- 我们有世界级的行情管道（29市场全免费实时）
- 但散户打开APP看不到"一图看懂市场"
- 所以散户不打开APP
- 所以我们的管道=白建了

**头3天做热力图+筛选器 → 散户有理由每天打开QUANT MOO → 其他收费功能(对比/卖空/深度)才有曝光机会。**
