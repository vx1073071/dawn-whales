## 二、🔴 高价值缺失因子（建议立即补充）

### 2.1 分析师预期修正因子 (Analyst Revision)
**研究支撑**: 卖方分析师一致预期上调是A股最强的alpha信号之一，IC约0.04-0.06。
**适用市场**: A股、港股、美股
```typescript
ANALYST_UPGRADE: {
  nameCN: '分析师预期修正',
  category: '情绪',
  formula: '过去30天EPS预测上调的机构数 - 下调的机构数 / 总覆盖数',
  score: '上调比例>30%=看涨，<10%或净下调=看跌'
}
```

### 2.2 北向/南向资金聪明钱因子 (Smart Money)
**研究支撑**: 2026年A股量化超额收窄(-1%)的背景下，资金流向因子成为少数有效信号。
**适用市场**: A股（北向）、港股（南向已部分覆盖）
```typescript
NORTHBOUND_FLOW: {
  nameCN: '北向聪明钱',
  category: '情绪',
  formula: '近5日北向净买入/日均成交额，正值>0.5%=外资加仓',
  score: '北向资金持续流入=海外机构看好A股'
}
```

### 2.3 拥挤度因子 (Crowding)
**研究支撑**: 2026年6月A股科技板块因"拥挤度过高"出现剧烈回调。拥挤度=最重要的风控因子。
**适用市场**: 全部
```typescript
CROWDING: {
  nameCN: '拥挤度',
  category: '风险',
  formula: '机构持仓重叠度 + 换手率加速 + 估值偏离度 三重加权',
  score: '拥挤度>80%=极度拥挤警惕踩踏，<30%=冷门可能有alpha',
  color: 'lowerBetter'
}
```

### 2.4 盈余惊喜因子 (Earnings Surprise / SUE)
**研究支撑**: 标准化意外盈余(SUE)是学术界最稳健的因子之一，Fama-French六因子中未包含但其alpha显著。
```typescript
SUE: {
  nameCN: '盈余惊喜',
  category: '质量',
  formula: '(实际EPS - 一致预期EPS) / 预期标准差',
  score: 'SUE>1=大幅超预期(看涨)，SUE<-1=大幅低于预期(看跌)'
}
```

### 2.5 低风险异象因子 (Low Risk / BAB)
**研究支撑**: AQR的Betting Against Beta(BAB)因子在全球市场有效。低beta高alpha是市场异象。
```typescript
BAB: {
  nameCN: '低Beta异象',
  category: '价值',
  formula: '杠杆化的低Beta组合收益 - 去杠杆化的高Beta组合收益',
  score: '低Beta股票长期风险调整收益优于高Beta',
  direction: 'long'
}
```

### 2.6 投资者关注度因子 (Attention)
**研究支撑**: 百度指数/Google Trends搜索量上升=散户涌入=短期推高后大概率回落。
```typescript
ATTENTION: {
  nameCN: '关注度',
  category: '情绪',
  formula: '近7日搜索量/均值，>3倍=过度关注(警惕回调)',
  score: '关注度飙升=短期资金涌入但持续性差'
}
```

### 2.7 缺口因子 (Gap)
**研究支撑**: 跳空缺口在A股和加密市场特别有效。突破缺口=趋势确认。
```typescript
GAP: {
  nameCN: '缺口效应',
  category: '趋势',
  formula: '(今日开盘-昨日收盘)/昨日收盘，>2%=突破缺口',
  score: '向上跳空突破=强势信号，连续缺口=加速赶顶'
}
```

## 三、🟡 缺失但可推迟的因子

### 3.1 日内模式因子
- **Amihud非流动性**: 价格冲击/成交量，衡量个股流动性成本
- **隔夜vs日内收益**: 隔夜收益/日内收益比，A股隔夜收益占比高
- **尾盘效应**: 最后30分钟收益/全天收益，尾盘抢筹=机构行为

### 3.2 另类数据因子
- **供应链关系**: 上下游公司股价相关性
- **专利质量**: 专利引用数×技术宽度得分
- **ESG评级变动**: MSCI/FTS ESG评级上调/下调

### 3.3 机器学习衍生因子
- **PCA首主成分**: 多个技术指标PCA降维后的综合动量
- **隐马尔可夫状态**: HMM识别的市场状态（趋势/震荡/恐慌）

## 四、🟢 UX打磨建议（基于人类使用习惯）

### 4.1 因子分组推荐——"场景化因子包"

**人类行为**: 散户不知道38个因子该选哪个。他们想要"牛市用哪几个？熊市用哪几个？"

**建议**: 3个场景预设因子包：

```
📈 牛市进攻包: MOM_12M + QUAL + ANALYST_UPGRADE + GROWTH
   历史特点: 趋势延续+高增长，牛市Sharpe 2.1

🛡️ 熊市防御包: LOW_VOL + HML + YIELD + QUAL
   历史特点: 低波动+高股息，熊市MaxDD仅-8%

🔄 震荡市轮动包: RSI_14 + SECTOR_ROTATION + CROWDING
   历史特点: 超买超卖+板块轮动，震荡市胜率65%
```

### 4.2 因子对比卡片——"一句话说清差异"

现有因子列表是长表格（38行），人类无法快速比较。

**建议**: 并排对比卡片（最多选4个因子）：
```
┌─ 12月动量 ───┬─── 盈利收益率 ───┐
│ IC: +0.045    │  IC: +0.038       │
│ 🔥 很强预测力 │  👍 中等预测力    │
│ 趋势跟踪      │  低估值策略       │
│ 牛市强/熊市弱 │  熊市强/牛市弱    │
│ ★★★★★        │  ★★★☆☆           │
│ → 互补配对！  │  ← 互补配对！     │
└───────────────┴───────────────────┘
        配对建议: 动量+价值=全天候
```

### 4.3 因子衰退倒计时——"离失效还有多久"

**人类行为**: 投资者最怕"因子突然失效了"。需要预警。

**建议**: 在因子卡片上显示衰退天数：
```
12月动量  IC +0.045  [████████░░] 82%
📉 预计32天后IC降至0.03以下
   上次优化: 6月1日 | 建议6月15日前重新评估
```

### 4.4 因子日历热力图——"本月哪些因子好用"

**人类行为**: 投资者想知道"最近什么风格赚钱"。

**建议**: 月度因子收益热力图（类似GitHub贡献图）：
```
       1月 2月 3月 4月 5月 6月
动量    🟢 🟢 🟢 🟡 🔴 🟢
价值    🔴 🔴 🟡 🟢 🟢 🟢
质量    🟢 🟢 🟢 🟢 🟢 🟡
低波    🟢 🟡 🔴 🔴 🔴 🔴
规模    🔴 🟡 🟡 🟡 🟢 🟢
         ↑ 本月动量型回暖！
```

### 4.5 因子冲突检测可视化为"因子婚姻"

**人类行为**: 技术术语"相关性>0.7"太抽象。

**建议**: 用婚姻比喻：
```
12月动量 🤝 市场Beta → 🟢 天生一对 (互补，相关性0.28)
12月动量 💔 6月动量  → 🔴 近亲婚姻 (高度相关0.85，选一个即可)
价值因子 💔 成长因子 → 🔴 水火不容 (相关性-0.42，不同时选)
低波动 🤝 品质因子 → 🟢 最佳搭档 (相关性0.15，1+1>2)
```
