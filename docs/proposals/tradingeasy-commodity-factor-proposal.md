## 二、大宗商品因子体系 — 6 大类 45 因子

### 2.1 🥇 贵金属 (Precious Metals) — 10 个

人类最常交易的避险资产。黄金是"情绪的终极表达"。

```
PM-01. GOLD_REAL_RATE       — 金价 vs 实际利率(10Y TIPS)，负相关 -0.85，最可靠的黄金因子
PM-02. GOLD_USD_INDEX       — 金价 vs DXY，美元弱则金强，"跷跷板关系"
PM-03. GOLD_CENTRAL_BANK    — 央行购金量/季度，"去美元化"趋势指标
PM-04. GOLD_ETF_FLOW        — GLD ETF 持仓变化，西方投资者情绪
PM-05. GOLD_SILVER_RATIO    — 金/银比，>80=恐慌/白银低估，<50=风险偏好
PM-06. GOLD_COPPER_RATIO    — 金/铜比，>500=衰退预期，"铜博士vs金避险"
PM-07. SILVER_INDUSTRIAL    — 白银工业需求(光伏60%占比)，新能源影子商品
PM-08. PLATINUM_DISCOUNT    — 铂金vs黄金折价，>20%=历史极度便宜，均值回归
PM-09. GOLD_FUTURES_POS     — COMEX黄金期货投机净多头，拥挤度指标
PM-10. GOLD_VOLATILITY      — GLD 30日隐含波动率，情绪极端指标
```

**人类故事**:
- GOLD_REAL_RATE: "实际利率每降1%，金价历史上涨约15%。现在是负利率——金价为什么不涨？"
- GOLD_SILVER_RATIO: "历史上每次金/银比突破90后，白银都在12个月内跑赢黄金40%以上"

### 2.2 🛢️ 能源 (Energy) — 12 个

全球最重要的经济周期指标。

```
EN-01. CRUDE_INVENTORY      — EIA原油库存变化，每周三公布，最重要的短期信号
EN-02. CRUDE_BRENT_SPREAD   — Brent-WTI价差，>8$=WTI折扣/页岩油过剩，<3$=正常
EN-03. CRUDE_BACKWARDATION  — 期货近月-远月价差，contango=供过于求，backwardation=紧张
EN-04. CRACK_SPREAD         — 汽油/柴油裂解价差(3-2-1)，炼油利润率，需求热度
EN-05. NATGAS_STORAGE       — EIA天然气库存，冬季前的库存量决定气价走势
EN-06. NATGAS_WEATHER       — HDD/CDD 取暖/制冷度日数，季节性核心驱动力
EN-07. OPEC_COMPLIANCE      — OPEC+减产执行率，>90%=供应收紧
EN-08. RIG_COUNT            — Baker Hughes钻机数，产量领先指标(6个月)
EN-09. CRUDE_OI_PUT_CALL    — 原油期权PCR，>1.2=恐慌底，<0.5=过度乐观
EN-10. ENERGY_SECTOR_STOCK  — XLE vs WTI 背离，股票领先商品2周
EN-11. LNG_JKM_SPREAD       — 亚洲JKM vs 欧洲TTF价差，跨区套利信号
EN-12. CARBON_CREDIT        — EUA碳配额价格，欧洲能源转型成本
```

**人类故事**:
- CRUDE_INVENTORY: "每周三EIA数据公布后，油价在接下来2小时的波动是平时的3倍——这是短线交易者的每周派对"
- CRACK_SPREAD: "炼油厂每加工一桶油能赚多少钱？3-2-1裂解价差从$15涨到$40意味着需求正在爆发"

### 2.3 🔩 工业金属 (Industrial Metals) — 8 个

"铜博士"是经济晴雨表，铝是能源强度的影子，镍锂是新能源核心。

```
IM-01. COPPER_GOLD_RATIO   — 铜/金比，"经济信心指数"，>0.00028=risk-on
IM-02. COPPER_INVENTORY     — LME铜库存，<5万吨=供应极度紧张，半年低位
IM-03. COPPER_TERM_STRUCT   — 铜期货曲线，backwardation=现货溢价=紧缺
IM-04. ALUMINIUM_ENERGY      — 铝价/能源成本，电费占铝成本40%，欧洲能源危机→铝减产
IM-05. NICKEL_EV_DEMAND     — 电池级镍需求增速，新能源金属核心指标
IM-06. LITHIUM_CARBONATE    — 碳酸锂价格(中国现货vs期货)，"白色石油"
IM-07. STEEL_MARGIN         — 热轧卷板-铁矿石-焦煤 利润，钢厂利润=经济热度
IM-08. BASE_METAL_INDEX     — LMEX指数，6种基本金属综合走势，通胀预期
```

**人类故事**:
- COPPER_GOLD_RATIO: "华尔街有句话：铜金比是唯一不会骗人的宏观经济指标。它说经济好就是真的好"
- ALUMINIUM_ENERGY: "欧洲每生产一吨铝需要15兆瓦时电。2022年能源危机导致欧洲铝减产50%——这是为什么铝比铜更敏感"

### 2.4 🌾 农产品 (Agricultural) — 8 个

天气、政策、供应链是三大驱动力。人类最容易理解的市场。

```
AG-01. CORN_SOYBEAN_SPREAD — 玉米/大豆比，美国农民种植选择，"农产品跷跷板"
AG-02. WHEAT_CORN_SPREAD   — 小麦/玉米比，>1.5=小麦替代玉米做饲料，价格收敛
AG-03. WASDE_SURPRISE      — USDA月度供需报告 vs 市场预期，农产品最重要的事件
AG-04. PLANTING_PROGRESS   — 美国种植进度%，延迟=供应担忧，5-6月最受关注
AG-05. CROP_CONDITION       — 优良率%，>70%=丰收，<50%=灾难性
AG-06. WEATHER_INDEX        — 厄尔尼诺/拉尼娜指数，ENSO对全球农产品的影响
AG-07. FERTILIZER_COST      — 化肥价格/作物价格比，种植成本边际
AG-08. BIOFUEL_DEMAND       — 乙醇/生物柴油需求，玉米→能源的桥梁
```

**人类故事**:
- WASDE_SURPRISE: "每个月USDA报告公布的那一刻，CBOT玉米/大豆期货5分钟内可能波动3%。这是农产品交易者的'非农数据'"
- PLANTING_PROGRESS: "5月的每个周一，交易者盯着美国种植进度。如果连续两周下雨导致播种延迟，大豆价格可以在一周内涨15%"

### 2.5 ☕ 软商品 (Soft Commodities) — 4 个

消费趋势的温度计。

```
SC-01. COFFEE_ARABICA_ROB   — 阿拉比卡/罗布斯塔价差，>150=高端消费强，<50=降级
SC-02. COCOA_GRIND          — 可可研磨量(欧洲/亚洲)，巧克力消费先行指标
SC-03. SUGAR_ETHANOL_RATIO  — 糖/乙醇比，>15=巴西转向制糖，<13=转向乙醇
SC-04. COTTON_POLYESTER     — 棉/涤纶比，纺织业原料替代信号
```

**人类故事**:
- COFFEE_ARABICA_ROB: "你喝的星巴克用的是阿拉比卡，速溶咖啡用的是罗布斯塔。两者价差告诉你消费者在升级还是省钱"
- COCOA_GRIND: "全球每季度研磨多少可可豆，直接等于下一个季度的巧克力销量。这是最甜蜜的经济领先指标"

## 三、人类使用习惯 — 因子组织

### 3.1 按交易者类型 (非按数学模型)

```
🏆 黄金交易者 (Gold Bugs)    → PM-01~PM-10 全部
🛢️ 能源交易者 (Oil Traders)  → EN-01~EN-08 + EN-12
⚡ 新能源交易者               → EN-12 + IM-05 + IM-06 + AG-08
🏗️ 宏观交易者                 → PM-01, IM-01, CC-01~CC-03, EN-03
🌾 农产品交易者               → AG-01~AG-08 全部
☕ 消费趋势观察者             → SC-01~SC-04 + PM-06
```

### 3.2 商品特有的"事件驱动"因子

商品与股票最大的不同——**事件影响 > 基本面**:

| 事件 | 频率 | 关键因子 | 典型波动 |
|------|------|---------|---------|
| EIA库存报告 | 每周三 | EN-01 | ±5% |
| USDA月度报告 | 每月第2周 | AG-03 | ±3% |
| OPEC+会议 | 每2月 | EN-07 | ±8% |
| Baker Hughes钻机 | 每周五 | EN-08 | ±2% |
| COT持仓报告 | 每周五 | PM-09 | ±2% |
| 央行利率决议 | 每6周 | PM-01 | ±3% |

### 3.3 商品因子"因果关系卡片"

商品因子的一个关键特性：**多个因子之间有因果链**。这比股票因子更有故事性。

```
原油: 钻机数↓ → (6个月后) 产量↓ → 库存↓ → 价格↑
农产品: 种植延迟 → 优良率↓ → (WASDE) 产量预期↓ → 价格↑
黄金: 实际利率↓ + 美元↓ + 央行买↑ → 金价↑
铜: 库存↓5万吨 + backw → 现货溢价 → 经济信心↑ → 股票↑
```

这个因果链应该做成**交互式因子流图**——这是Bloomberg没有但我们能做的东西。
