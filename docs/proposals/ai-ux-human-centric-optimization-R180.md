## 二、🔴 人类使用习惯摩擦点（需立即修复）

### 2.1 AI面板无操作确认提示

**现状**: `AIAssistantPanel.tsx` (526行) 用户点击AI建议的操作按钮后**无确认弹窗**，直接执行。

**人类行为**: 用户在浏览AI建议时常会"滑手"误触。金融应用必须有确认步骤。

**建议**:
```tsx
// 任何涉及资金/权重的操作按钮前加确认
<Button onClick={() => setConfirmAction('applyWeights')}>
  应用建议权重
</Button>
<ConfirmModal
  title="确认应用AI建议？"
  detail="将替换当前策略权重: 动量22%→30%, Beta20%→25%..."
  onConfirm={handleApply}
/>
```

**优先级**: P0 | 工时: 1h

---

### 2.2 收费不透明——用户不知道AI操作要扣钱

**现状**: AICostDashboard显示扣费信息，但AI助手面板(AIAssistantPanel)的按钮上**无价格标签**。用户点完才知道扣了1U。

**人类行为**: 看不见的价格=被骗的感觉。支付宝/微信支付的经验：任何扣费操作前必须显示金额。

**建议**:
```tsx
<Button>
  🤖 AI权重优化
  <span className="text-[10px] text-[#D4A853] ml-1">1.5 USDT</span>
</Button>
```
- 每个AI功能按钮必须标注价格
- 免费操作标注"免费"
- 余额不足时按钮置灰并显示"余额不足，需充值 X USDT"

**优先级**: P0 | 工时: 2h

---

### 2.3 AI回复时间不可见——用户不知道在等什么

**现状**: AI Advisor加载只有旋转图标，无预计时间、无进度信息。最长可能等30秒。

**人类行为**: 3秒没反应=坏了。用户会重复点击，产生重复扣费。

**建议**:
```
⏳ AI正在分析您的因子组合...
   [████████░░░░] 60%  (约8秒)
   步骤: ①IC计算 ✓ → ②兼容性检查 ✓ → ③权重优化 ⏳ → ④回测验证 ⌛

已有明确的2阶段进度条(BacktestProgressBar)，但AI Advisor未接入。
应将进度条组件复用到所有AI交互场景。
```

**优先级**: P0 | 工时: 1h

---

### 2.4 AI建议与用户偏好脱节——缺乏记忆

**现状**: AI每次推荐都是"从零开始"的通用建议，不考虑：
- 用户上次拒绝了什么
- 用户偏好什么市场/风格/风险水平
- 用户历史上选择了哪些因子

**人类行为**: "这AI根本不了解我"→ 弃用。金融AI必须个性化才有人用。JVS的G6(个人因子画像)已建后端，但前端未接。

**建议**:
1. 第一次使用时显式询问偏好：
```tsx
<OnboardingStep title="让AI了解你">
  你更看重: [收益最大化] [风险控制] [稳定现金流]
  偏好市场: [A股] [港股] [美股] [加密]
  风险承受: [保守 ⬤○○○○ 激进]
  每季度AI优化频率: [每日] [每周] [每月]
</OnboardingStep>
```

2. 后续AI推荐顶部显示：
```
📌 基于你的偏好(稳健型/港股/月度优化)
   你的历史选择: 品质因子(80%) > 价值因子(60%) > 动量因子(30%)
```

3. AI不推荐用户上次拒绝的因子类型

**优先级**: P1 | 工时: 3h

---

### 2.5 AI"过度自信"——不展示不确定性

**现状**: AI因子推荐展示"建议配置 动量22% 做多"——像一个绝对真理。没有置信度。

**人类行为**: 过度自信的AI不可信。用户需要看到"AI也不是100%确定"才能建立健康的使用关系。

**已做**: ICUncertaintyIndicator (R177 H3) 展示IC的95%置信区间 ✅
**缺失**: AI推荐结果本身无置信度展示

**建议**:
```tsx
<div className="ai-recommendation">
  <span>建议: 12月动量 22%</span>
  <ConfidenceBadge level={0.75} />  ← 新增
  <Tooltip>
    基于最近252个交易日的IC=+0.045(±0.010)
    该建议置信度: 75% (中等)
    建议配合其他因子使用
  </Tooltip>
</div>
```

**优先级**: P1 | 工时: 1h

---

### 2.6 AI扣费确认弹窗无"取消"按钮心理学设计

**现状**: 扣费确认弹窗(unlock modal)有"再看看"和"1 USDT 解锁"两个按钮。

**人类行为**: 这可以用"暗模式"(dark pattern)优化转化率：
- "再看看" → 暗示用户会回来 → 低转化
- 更好的设计: "解锁(Save 50% with bundle)" + "不，谢谢(no thanks)"

**建议**:
```
确认解锁完整因子分析

💰 费用: 1.00 USDT/次
📊 包含: 8因子IC解读 + AI建议 + 权重推荐

[ 🔒 1 USDT 解锁 (获得全部洞察) ]
[ 先看看免费的 → ]  ← 正向引导而非否定

或: 批量解锁3次仅 2 USDT (节省33%) [更划算]
```

**优先级**: P2 | 工时: 1h

---

### 2.7 AI推荐缺乏"为什么"——可解释性不足

**现状**: AI推荐显示因子名+权重，但用户看不到推理过程。

**人类行为**: "为什么推荐这个？"是最常见的问题。AI黑盒=不信任。

**建议** (已在AIAdvisorPage L3层做了部分，但不够):
```tsx
<ExpandableSection title="🤔 AI为什么推荐这个？">
  <ReasoningChain>
    <Step>① 扫描了8个可用因子</Step>
    <Step>② 12月动量IC=0.045(前3名)，与当前组合兼容度85%</Step>
    <Step>③ 与已配置的市场Beta相关性0.28 (<0.5阈值，不会冗余)</Step>
    <Step>④ 回测显示最高Sharpe提升+0.15</Step>
    <Step>⑤ 因此推荐配置22%</Step>
  </ReasoningChain>
</ExpandableSection>
```

**优先级**: P1 | 工时: 2h

## 三、🟡 安全防线间隙（R178/R179遗漏）

### 3.1 AIA助理面板缺少免责声明

**现状**: `AIAssistantPanel.tsx` 没有任何免责声明或风险提示——这是R178 G15应该覆盖但遗漏的。

**修复**: 在AIAssistantPanel的AI回复区域底部追加 `AIFinancialDisclaimer` 组件。

**优先级**: P0 | 工时: 0.5h

---

### 3.2 AI回复中精确策略权重仍在泄露

**现状**: 虽然R178 G25做了 `AIResponseSanitizer`（余额/持仓脱敏），但**策略权重数值**（如"建议动量22%、Beta20%"）仍然精确显示。按G32的分享卡片保护标准，非private模式应模糊化到10%档位。

**修复**: 扩展 `sanitizeAIContent()` 覆盖策略权重模糊化。

**优先级**: P1 | 工时: 0.5h

---

### 3.3 AICostDashboard余额展示过于精确

**现状**: AICostDashboard展示了精确的USDT余额（如"250.00 USDT"）。虽然R178 G25做了AI回复脱敏，但这个系统页面**不应该**暴露精确数额。

**人类行为**: 用户截图发朋友圈/群聊时会不小心暴露财务隐私。

**建议**: 
- 默认显示"余额充足"（余额>阈值）
- 点击眼睛图标可查看精确数值（手动显式确认）
- 截图检测：页面被截图时自动模糊敏感数值（技术复杂但高端）

**优先级**: P2 | 工时: 1h

## 四、🟢 打磨建议（体验提升）

### 4.1 首次AI使用引导（Onboarding）

quant-moo目前没有AI功能的首次引导流程。新用户打开AI Advisor看到一堆因子卡牌会感到困惑。

**建议**: 3步引导：
1. "这是AI因子推荐——基于实时IC/IR帮你选最优因子"
2. "点击任意因子卡片查看详细分析（免费）"
3. "解锁完整分析仅需1 USDT——首次免费"

**工时**: 2h

---

### 4.2 AI回复历史/收藏

用户常需要回看之前的AI建议。目前AI回复是一次性的。

**建议**: 
- 自动保存最近10条AI回复（localStorage）
- 支持收藏/取消收藏AI建议
- 历史记录页面（时间线+搜索）

**工时**: 3h

---

### 4.3 AI回复一键转策略

AI推荐权重后，用户需要手动把这组权重输入策略创建页面。

**建议**: AI回复卡片加"一键创建策略"按钮，自动填入因子权重和参数。

**工时**: 2h

---

### 4.4 移动端AI交互优化

移动端AI Advisor的L1/L2/L3卡片层叠太长，小屏难以浏览。

**建议**: 移动端改为可滑动的卡片轮播（类似Tinder），左右滑=忽略/收藏。

**工时**: 3h

---

### 4.5 语音/通知推送AI建议

当AI检测到因子IC突变或衰减时，应主动推送给用户（已建信号管线D4，但前端未做通知接入）。

**建议**: 桌面端系统通知 + 移动端Push通知：
"⚠️ 12月动量IC从0.045降至0.022，建议减仓"

**工时**: 2h
