## 二、致命差距分析（按用户损失优先级排列）

### 🩸 P0 — 直接影响下单决策的因素

#### 2.1 盘口数据缺失 ▶ 用户无法判断买卖时机
**现状**: 个股详情页只有K线+指标，缺少Depth of Market (DOM)  
**用户痛点**: 看到K线想买，但不知道当下bid/ask力量对比，挂单深度如何，导致"买在高点/卖在低点"  
**竞品对标**: Futu牛牛、Webull 都在K线下直接展示 Level 2 买卖盘口  
**损失**: 用户每笔交易滑点更大，盈利概率降低。

#### 2.2 无多周期联动 ▶ 用户只看一周期做决策  
**现状**: 单图单周期，切换周期靠按钮逐步点  
**用户痛点**: 专业Trader至少看3个周期（大周期定方向/中周期定入场/小周期定时机）。富途支持"三周期同列"，TradingView支持多窗口联动。  
**损失**: 用户只用一个周期交易，胜率显著低于多周期共振交易者。

#### 2.3 无新闻/事件标记线 ▶ 用户不知道涨跌原因  
**现状**: K线图上不显示任何新闻/财报/宏观事件标记  
**用户痛点**: 看到一根大阳线/大阴线，不知道为什么。需要切换到其他页面查看新闻。QuiverQuantitative的研究表明：图表上叠加事件标记的trader持仓时间延长40%。  
**竞品对标**: TradingView支持Chart Events & Dividends标记；Futu牛牛支持"大事记"。  
**损失**: 用户追涨杀跌而不自知，亏损后不知道止损位置。

---

### 🟠 P1 — 削弱用户复购意愿的体验缺陷

#### 2.4 无键盘快捷键 ▶ 大户和活跃trader流失
**现状**: 一切操作靠鼠标，无任何快捷键  
**用户痛点**: TradingView有30+快捷键（空格播放下一个股票/数字键切换周期/Tab切换指标），上手后效率碾压鼠标操作。活跃trader平均每天切换股票50+次、切换周期100+次。每换一次多花2秒 = 每天浪费5分钟+情绪frustration。  
**竞品对标**: TradingView快捷键统治了trader肌肉记忆。无快捷键 = 转投TV。

#### 2.5 画线无"吸附/磁吸" ▶ 画不准关键价位
**现状**: 画线靠手动拖动到大致位置，无price-snap和trend-snap  
**用户痛点**: 支撑压力线差1-2个tick，止损就触发/止盈就错过。TradingView的magnetic drawing让任何用户3秒画准。  
**损失**: 用户画线不准 → 策略执行偏差 → 亏钱 → 怪工具 → 流失。

#### 2.6 无图表布局保存/切换 ▶ 每次都要重新配置
**现状**: 图表配置随页面关闭丢失  
**用户痛点**: 用户在不同交易场景（短线看1m+5m, 波段看D+4H）需要不同布局。每次切换都重新设置周期和指标，极低效。  
**竞品对标**: TradingView Chart Layouts, Futu"图表方案"。

---

### 🟡 P2 — 锦上添花的差异化武器

#### 2.7 无复盘/回放前端 ▶ QTE-50已做回放引擎但前端未接
**现状**: PlaybackDataBridge 已完成（R262)，但个股详情页没有回放控制器  
**用户痛点**: 盘后复盘是高手与散户的核心差异。无回放 = 用户只能静态看历史K线，无法"重历"当日行情。这本来是QUANT MOO的差异化武器。  
**损失**: 错失让用户依赖本产品的最高粘性功能。

#### 2.8 无多品种对比叠加 ▶ 用户无法做相对强度分析
**现状**: 单图只看一只股票  
**用户痛点**: 专业trader常年叠加SPY/QQQ看相对强弱，叠加行业ETF看板块轮动。TradingView的compare功能是付费用户最爱功能TOP3。  
**竞品对标**: TradingView compare symbol, Futu"叠加对比"。

#### 2.9 无快捷下单面板 ▶ 用户看图和下单分离  
**现状**: 个股详情页无任何交易面板入口  
**用户痛点**: 看图发现机会 → 需要切换到交易页面 → 输入代码/价格 → 下单。多步操作中机会已失。Robinhood的"图上下单"是它成功的核心UX创新。  
**竞品对标**: Robinhood chart-trade, Webull quick trade widget, Futu闪电下单。

## 三、按人类真实使用习惯的设计建议

### 3.1 用户心智模型：三阶段决策流程

```
观察阶段 (5-10s)  →  分析阶段 (30-120s)  →  决策阶段 (3-10s)
┌──────────────┐    ┌──────────────────┐    ┌─────────────┐
│快速扫一眼     │    │深入看多周期+指标  │    │确定入场/出场 │
│今天涨跌多少   │    │画线/看支撑压力   │    │下单/设止损   │
│什么原因       │    │对比大盘/板块     │    │              │
└──────────────┘    └──────────────────┘    └─────────────┘
   → 需要"一屏概览"    → 需要"深度工具"      → 需要"即时行动"
```

### 3.2 对应设计策略

| 阶段 | 用户需求 | 当前缺失 | 建议功能 |
|------|----------|----------|----------|
| 观察 | 秒懂今天发生了什么 | 新闻标记、事件线 | 📍 K线新闻标记线 |
| 观察 | 秒懂涨跌幅度 | 盘口、买卖档 | 📍 迷你DOM |
| 分析 | 多周期共振 | 仅单周期 | 📍 三周期同列 |
| 分析 | 精准价位分析 | 无磁吸画线 | 📍 智能吸附绘图 |
| 分析 | 对比相对强弱 | 无叠加 | 📍 品种对比叠加 |
| 决策 | 快速下单 | 无交易面板 | 📍 图上下单浮窗 |

## 四、详细打磨建议（按实现成本排序）

### 🔨 Tier 1: 快速见效 (2-4h/项，立即提升用户体验)

#### T1-1: 键盘快捷键系统
```
空格键 → 播放下一个自选股
1-9 → 切换周期 (1=1m, 2=5m, 3=15m, 4=30m, 5=1h, 6=4h, 7=D, 8=W, 9=M)
Tab → 切换指标叠加 (MA→EMA→BOLL→无)
Ctrl+Z → 撤销上一个画线
R → 显示/隐藏画线
T → 趋势线工具
H → 水平线工具
F → 斐波那契回调
Esc → 取消当前工具/关闭弹窗
+/- → 缩放
← → 左移 ←(加速) Shift+←
→ → 右移 →(加速) Shift+→
```
**ROI**: 极高。零UI成本，老trader立即感知。

#### T1-2: 图表顶部"快看条" (Quick Glance Bar)
```
┌─────────────────────────────────────────────────────────┐
│ AAPL 185.32 ▲+2.15 (+1.17%)  今开183.50  最高186.10   │
│ 量 45.2M │ 换手0.8% │ 振幅2.4% │ [AI判断: 强势突破]  │
└─────────────────────────────────────────────────────────┘
```
替代当前散落在页面各处的数据，一屏搞定"观察阶段"。

#### T1-3: 画线磁吸 (Snap-to-Price)
```
实现策略:
- 鼠标拖动时，自动吸附到最近的 OHLC 价位 (±N px 容忍度)
- 趋势线端点自动吸附到K线高低点
- 显示吸附价位浮标（如"184.35 支撑位"）
```
**ROI**: 极高。TradingView的核心差异化体验。

#### T1-4: 图表事件标记线 (Chart Event Markers)
```
垂直虚线 + 图标标记:
📰 标志色 = 新闻情绪 (红=利空/绿=利好)
💰 财报发布日期
📊 经济数据发布时间
🏛️ 央行利率决议
```
后端bridge已有数据源 (dedup-engine, newsapi-manager)，只需前端渲染。

## 七、核心结论

> **QUANT MOO不是缺少数据，是数据没"落地"到用户眼前。**
>
> 后端已有: AI情绪/异动归因/崩盘检测/多家broker/dedup/推送，但个股详情页是最后1公里——用户做决策的界面。
>
> **如果一个trader在看到K线上涨时，需要切换3个页面才能知道为什么涨、能不能追、怎么下单——你的产品再好，他也跑了。**
