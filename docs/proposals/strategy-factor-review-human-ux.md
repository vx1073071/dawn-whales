## 一、🔴 致命问题

### 1.1 策略创建入口太多 — 6 种模式让人困惑

**当前**: `StrategyPage.tsx` 定义了 6 种创建方式:
```
null | 'ai' | 'template' | 'form' | 'condition' | 'closedLoop' | 'adaptive'
```

**人类问题**: 用户打开策略页面，看到 AI/Template/Form/Condition/ClosedLoop/Adaptive 六个选项。

人类根本不理解这些分类：
- "Condition" 和 "Form" 有什么区别？
- "ClosedLoop" 是什么？
- "Adaptive" 又是什么？
- "Template" 和 "AI" 我应该选哪个？

**行业对比 (TradingView / QuantConnect)**:
- TradingView: "Create Strategy" → 一个入口 → 写 Pine Script 或选择模板
- QuantConnect: "Create Algorithm" → 一个入口 → 选择 Language + Framework

**建议**: 
1. 统一为 3 个入口: **从模板开始** / **AI 帮我创建** / **手动编写**
2. 把 Form/Condition/ClosedLoop/Adaptive 折叠到"手动编写"的子步骤中
3. 默认显示 3 个大卡片，不要全部展开

### 1.2 策略因子分析对普通人来说是天书

**当前**: `FactorExposurePage.tsx` 展示因子暴露矩阵，包含:
- p-Value, t-Stat, significance 星号
- 因子相关性矩阵
- 月度残差

**人类问题**: 99% 的用户不知道 p-Value 是什么、t-Stat 怎么看。

这不是数据问题，是呈现问题。普通交易者关心的是:
- "我的策略赚的是 Beta 还是 Alpha？"（一句话结论）
- "最大风险因子是什么？"（一个列表）
- "最近3个月因子暴露变了吗？"（趋势图）

**建议**:
1. 顶部增加 **一句话总结**: "你的策略 60% 收益来自市场 Beta（被动跟随大盘），40% 来自 Alpha（主动能力）。最大风险因子是动量（+0.45暴露）。"
2. 因子名不用学术术语，用中文: Market→大盘走势, Size→小盘效应, Value→价值偏好, Momentum→追涨杀跌, Volatility→低波偏好
3. 暴露值用颜色+条形图，不用数字表格

### 1.3 回测结果无法"一键对比"

**当前**: 回测完成后展示一堆数字 (夏普/回撤/胜率/年化)。用户想改一个参数再跑 → 结果覆盖了上一个。

**人类期望**: "上一次" 和 "这一次" 并排对比，像手机跑分一样。

**建议**: 
- 每次回测保存为快照
- 右侧面板显示最近5次回测对比表
- 参数改动高亮 (MA周期: 20 → 14, 绿色)
- 收益变化清晰显示 ("+3.2% vs 上次")

## 二、🟡 功能缺失

### 2.1 无策略"健康评分"

**人类期望**: 像体检报告一样，给策略打个分。

**当前**: 散落在多个面板的指标，需要逐个查看。

**建议**: 策略健康评分卡 (0-100分):
- 收益质量 (30分): 夏普 >1.5 = 30, >1.0 = 20, <0.5 = 5
- 风险控制 (25分): 回撤 <15% = 25, <30% = 15, >50% = 0
- 稳定性 (20分): 月度胜率 >60% = 20
- 因子暴露 (15分): 无极端暴露 = 15
- 适应性 (10分): 多市场/多周期有效 = 10

### 2.2 无"策略到期提醒"

**人类场景**: 策略参数设定3个月后过期。但没人记得。

**建议**: "你的 MA 金叉策略参数已使用 95 天，建议重新优化" → 一键跳转优化页面。

### 2.3 无策略分享/社区

**人类习惯**: Discord/Telegram 群分享策略截图。

**建议**: "导出为可分享图片" 按钮 → 包含策略名称/收益率曲线/夏普/最大回撤/参数 → 带水印和二维码。

### 2.4 因子模板市场为空

**当前**: TemplateBrowser 存在但内容为空壳（196字节）。

**人类期望**: 像 App Store 一样浏览预置策略模板。

### 2.5 优化结果不可"一键采纳"

**当前**: StrategyOptimizerPanel 展示优化后的参数，但需要手动记住再切回策略页面修改。

**建议**: "采纳最优参数" 按钮 → 一键更新策略 → 自动回测验证。

## 三、🟢 人类UX打磨

### 3.1 策略创建流程太长

**当前**: 选模式 → 填参数 → 选标的 → 设风控 → 保存 → 回测 → 看结果 → 优化。8 步。

**人类期望**: 3 步。选模板 → AI 帮忙调参 → 一键上线。

**建议**: 学习 Robinhood 的极简设计。默认隐藏高级选项，折叠在"高级设置"里。

### 3.2 回测进度无感知

**当前**: 回测运行时，用户看不到进度条，不知道要等多久。

**建议**: 进度条 + 预估剩余时间 ("正在回测 2023年1月 ~ 2026年6月... 45% 预计剩余 12 秒")

### 3.3 因子页面是"数据倾倒"

**当前**: FactorExposurePage 一次性展示所有因子数据。

**人类期望**: 渐进式展开。先看概述 → 点开某个因子 → 看详细 → 看趋势 → 看相关性。

**建议**: 
- 页面顶部: 综合因子评分雷达图
- 点击雷达图上的点 → 展开该因子的时间序列图
- 点击"与同业对比" → 展开对比表格

### 3.4 无策略标签/分类

**人类场景**: 用户有 20 个策略，想找"适合港股的"。

**当前**: 平铺列表，无筛选/分类/搜索。

**建议**: 标签系统 (趋势/反转/套利/事件驱动) + 市场标签 (港股/美股/加密)

### 3.5 策略改了参数之后不知道"更好还是更坏"

**当前**: 跑完新回测 → 展示独立结果 → 用户要记住之前的数字来对比。

**建议**: 每次参数变更自动触发 mini 回测 (只在当前K线区间跑 1 年) → 绿色箭头表示改善，红色箭头表示变差。

## 四、架构问题

### 4.1 30+ 策略组件 — 无统一导航

策略页面有 30+ 个子组件，用户不知道哪个在哪个页面。

**建议**: 统一策略工作台 (StrategyWorkbench) 带侧边栏:
- 我的策略 (列表)
- 创建策略 (3 入口)
- 回测分析
- 因子分析
- 优化器
- 模板市场

### 4.2 StrategyPage @ts-nocheck + 6 个子组件全是空壳

子组件 (AICreator/BacktestPanel/FormCreator/ModeSelector/MyStrategies/StrategyDetail/TemplateBrowser) 都只有 194-206 字节 — 空壳。

**建议**: 要么实现，要么删除。空壳组件造成混淆。
