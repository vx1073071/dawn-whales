## 一、概覽

經審查 35+ 組件、14 個 hooks、7 個 broker 面板、28 個 engine 文件後，從人類打開軟件到完成一筆交易的完整路徑出發，識別出以下問題：

---

## 二、P0 — 阻塞性問題 (用戶無法完成核心任務)

### P0-1: K線圖時間軸無法顯示日期標籤 🔴
**位置**: `KLineChartPro.tsx` line 163 — `timeVisible: true, secondsVisible: false`
**問題**: 當用戶縮放到 <20 根K線時，lightweight-charts 顯示的是時間(09:30)而非日期(6月12)。交易員需要知道某根K線是哪一天的。
**修復**: 在 timeScale 中添加 `tickMarkFormatter` 根據可見範圍動態顯示日期/時間
**工時**: 0.5h

### P0-2: 沒有"切換到當前標的"的全局入口 🔴
**問題**: 用戶在任何面板（深度/掃描/資金流）看到一個標的，想點擊切換 K 線圖查看，但**沒有任何點擊跳轉機制**。只能手動在 K 線圖搜索框中輸入代碼。
**修復**: 所有 chart/broker 組件的 symbol 文本做成可點擊鏈接，觸發 ChartContext.setSymbol()
**工時**: 2h

### P0-3: 券商連接失敗沒有引導修復 🔴
**位置**: `BrokerManagerAndPortfolio.tsx`, `WatchlistV2.tsx`
**問題**: 券商斷線後只顯示紅色圓點。用戶不知道為什麼斷了、怎麼修。沒有"點擊重連"、"檢查API Key"、"查看日誌"的操作路徑。
**修復**: 
- 每個斷線券商行添加"重連"按鈕
- 添加"查看錯誤日誌"鏈接
- 斷線超過 30s 自動彈出通知
**工時**: 3h

### P0-4: 指標子圖與主圖不同步 🔴
**位置**: `KLineChartPro.tsx` sub-pane 渲染部分
**問題**: MACD/RSI/KDJ 子圖在用戶滾輪縮放平移時不會跟隨主圖同步。子圖的時間軸獨立，出現主圖顯示6月1-12日，子圖顯示6月5-12日的情況。
**修復**: 子 pane 需要 `chart.subscribeCrosshairMove` 同步時間軸，或使用 `pane.getTimeScale().setVisibleLogicalRange()` 與主圖同步
**工時**: 3h

## 三、P1 — 體驗缺陷 (用戶能完成任務但很痛苦)

### P1-1: 沒有右鍵菜單 🟡
**問題**: 整個應用大量使用 onClick 但沒有任何 onContextMenu。交易員習慣在 K線圖上右鍵 → "添加提醒"/"在此價格下條件單"/"切換到1小時圖"。
**建議組件**:
- KLineChartPro: 右鍵 → "在此價格設置提醒" "添加水平線" "複製價格"
- WatchlistV2: 右鍵 → "查看深度" "添加到自選" "移除"
- OrderBookWaterfall: 右鍵 → "在此價格下限價單"
**工時**: 4h

### P1-2: 雙擊行為不一致 🟡
**問題**: 
- KLineChartPro: 雙擊無反應
- IndicatorPanel: 雙擊展開參數面板
- DrawingToolbar: 無雙擊行為
**建議**: 統一雙擊行為 — 在主要視圖雙擊 = 重置視圖（fitContent）
**工時**: 1h

### P1-3: 拖拽排序缺失 🟡
**位置**: `WatchlistV2.tsx`
**問題**: 自選列表不支持拖拽排序。交易員習慣把最關注的標的拖到頂部。
**修復**: 使用 antd Table 的 `components` + `react-dnd` 或簡單的箭頭按鈕
**工時**: 2h

### P1-4: K線圖沒有成交量加權平均價(VWAP)會話線 🟡
**問題**: VWAP 目前在 overlay indicators 中是可用的，但它顯示的是累積整個數據集的VWAP。日內交易員需要的是**當日VWAP**（每個交易日重置），是日內交易的基準線。
**修復**: 添加 `sessionVWAP` 指標選項，按日期分組計算
**工時**: 2h

### P1-5: 所有面板缺少"複製到剪貼板"功能 🟡
**問題**: 交易員看到一個價格、一個PNL數字想複製，必須手選→Ctrl+C。沒有"點擊複製"的快捷方式。
**修復**: 所有價格和數值添加 onClick → navigator.clipboard.writeText()
**工時**: 2h

### P1-6: 指標面板與K線的參數不同步 🟡
**問題**: IndicatorPanel 可以調整 MA 週期（20→50），但 KLineChartPro 寫死了 period=20。用戶改參數不會生效。
**位置**: `KLineChartPro.tsx` indicatorLines useMemo — `calcSMA(processedData, 20)` 寫死 20
**修復**: IndicatorPanel 的 onParamsChange 回調傳遞到 KLineChartPro，動態重算
**工時**: 3h

### P1-7: 市場掃描/篩選結果不能快速切換到K線 🟡
**位置**: `MarketScanner.tsx`
**問題**: 掃描出 20 個放量幣，用戶想逐個看K線。必須複製代碼→切換到K線頁→粘貼→回車。效率極低。
**修復**: MarketScanner 每行結果添加"📈"按鈕，點擊直接跳轉 K線圖並設置 symbol
**工時**: 1h

### P1-8: Alert 提醒沒有"暫停所有提醒"的全局開關 🟡
**位置**: `AlertPanel` 在 `AlertAndFundFlow.tsx`
**問題**: 用戶在密集交易時段可能被提醒轟炸。需要一個"靜音1小時"的全局開關。
**修復**: 在 AlertPanel 頂部添加全局啟用/禁用切換 + 定時靜音
**工時**: 1h

### P1-9: 熱力圖/掃描沒有自動刷新開關 🟡
**問題**: MarketScanner、HeatmapTreemap 使用靜態數據。用戶不知道數據是什麼時候的、是否需要手動刷新。
**修復**: 添加"自動刷新: 每30秒"的開關和最後更新時間顯示
**工時**: 2h

### P1-10: SignalDashboard 跟單按鈕沒有二次確認 🟡
**位置**: `EnhancedPanels.tsx` 的"跟單"按鈕
**問題**: 點擊"跟單"直接觸發，沒有確認彈窗顯示"你將以15%利潤分潤跟單AlphaQuant，是否確認？"
**修復**: 點擊後彈出 Modal 顯示：信號源名稱、分潤比例、風險等級、最近30天收益、確認/取消
**工時**: 2h

## 四、P2 — 優化建議 (用戶可以用但可以更好)

### P2-1: 暗色主題是唯一方案，沒有淺色模式 🟢
**問題**: 所有組件硬編碼深色 `bg-[#0d1117]`。白天強光下交易員偏好淺色。
**建議**: 使用 CSS 變量 + ThemeContext，所有顏色從 `var(--bg-primary)` 等讀取
**工時**: 6h

### P2-2: 鍵盤快捷鍵不完整 🟢
**現有**: `useKeyboardShortcuts.ts` 支援 1-9 切換頁面 + Ctrl+B/N/K
**缺失**:
- `Space` 暫停/播放 TickTimeline
- `← →` K線左右平移 (已被 lightweight-charts 處理)
- `+/-` 縮放 (已被處理)
- `F` 全屏
- `Escape` 關閉彈窗/取消畫線
**工時**: 2h

### P2-3: 畫線工具沒有吸附( snapping) 🟢
**位置**: `DrawingToolbar.tsx` + `lwc-drawing-adapter.ts`
**問題**: 畫趨勢線時沒有自動吸附到K線的 OHLC 價格點。手工精確定位非常困難。
**建議**: 在 lightweight-charts 的 primitive 中檢測鼠標附近最近的 OHLC 點，自動吸附
**工時**: 4h

### P2-4: 沒有聲音反饋 🟢
**問題**: 套利機會出現、訂單成交、止損觸發 — 全部只有視覺提示，無聲音。交易員不盯盤時收不到。
**建議**: 
- 套利 >0.5%: 短提示音
- 訂單成交: 確認音
- 止損觸發: 警告音
- 設置頁可調節音量/關閉
**工時**: 3h

### P2-5: 滾動性能問題 🟢
**問題**: TickTimeline 在 5000 條記錄時用 DOM 渲染，流暢度不夠。
**建議**: 使用虛擬滾動 (react-window 或自定義 visible window)，只渲染可見的 50 條
**工時**: 3h

### P2-6: 沒有"導出截圖"功能 🟢
**問題**: 交易員想分享K線圖給朋友/群組，必須截圖→裁剪→發送。
**建議**: 每個圖表組件添加"📸 截圖"按鈕，使用 html2canvas 或 chart.getCanvas()
**工時**: 3h

### P2-7: OrderBook 深度沒有聚合模式 🟢
**問題**: 加密貨幣 OrderBook 有 20 檔報價，但許多價格檔位只有 0.0001 的差別。交易員想看按 0.5%/1% 聚合的大檔位視圖。
**修復**: OrderBookWaterfall 添加聚合倍數選擇器 (1x/5x/10x/50x)
**工時**: 2h

### P2-8: K線圖沒有持倉標記 🟢
**問題**: 用戶在 K線圖上看不到自己的買入點/賣出點。無法直觀判斷盈虧。
**建議**: KLineChartPro 接收 `positions: {time, price, side}[]` prop，在圖上繪製買入(▲)/賣出(▼)標記
**工時**: 3h

### P2-9: 回放面板沒有"跳到下一根K線"的逐幀播放 🟢
**位置**: `ReplayAndMicrostructure.tsx`
**問題**: ReplayPanel 只有連續播放和拖拽進度條。回測策略時需要逐根K線前進，觀察每根的反應。
**修復**: 添加"▶|"逐幀前進按鈕
**工時**: 1h

### P2-10: 微結構面板數值缺少解釋 🟢
**位置**: `ReplayAndMicrostructure.tsx` MicrostructurePanel
**問題**: 顯示 VPIN=0.342、Kyle λ=2.34×10⁻⁶ 但沒有 tooltip 解釋這些數值的含義和正常範圍。非量化背景的用戶看不懂。
**修復**: 每個指標添加 `?` tooltip 顯示："VPIN>0.5=高信息交易概率，<0.2=正常"
**工時**: 2h

## 五、視覺一致性檢查

| 問題 | 位置 | 影響範圍 |
|------|------|---------|
| 字體大小不一致 (7px/8px/9px/10px/12px 混用) | 所有組件 | 閱讀疲勞 |
| 間距不統一 (p-2/p-3/p-4/gap-1/gap-2/gap-3 混用) | 所有組件 | 視覺混亂 |
| 邊框顏色有 `#30363d` 和 `#1c2333` 混用 | 所有組件 | 邊界不明確 |
| 滾動條未自定義 (瀏覽器默認) | 所有 overflow-y-auto | 與暗色主題不搭 |
| 表格 header sticky 在部分組件缺失 | MarketScanner, WatchlistV2 | 長列表 header 消失 |

**建議**: 制定一份 CSS 變量規範，所有組件引用的 4 個基礎色 + 3 個字體大小 + 2 個間距。全局一次性替換。**工時**: 4h

## 六、用戶旅程審查: "打開軟件到完成一筆交易"

### 當前路徑
1. 打開軟件 → 看到 mock 數據 (沒有券商正在連接的視覺提示)
2. 想切換標的 → 不知道在哪輸入 (沒有統一的 symbol 搜索框)
3. 看到K線 → 想加 MACD → 點 IndicatorPanel → 勾選 → 看到子圖
4. 看到套利機會 → 想交易 → 沒有"一鍵下單"按鈕 → 需要切到訂單頁
5. 下單 → 沒有確認券商 → 不知道訂單走到了哪個交易所

### 理想路徑
1. 打開軟件 → BrokerStatusBar 顯示連接進度 → 連接完成 → 顯示默認標的K線
2. **全局搜索框 (Ctrl+K)** → 輸入"BTC" → 自動補全 → 回車 → 所有面板同步切換
3. 右鍵 K線 → "添加 MACD" → 即時顯示 → 拖拽調整子圖高度
4. ArbitrageMonitor 套利行 → **"一鍵套利"按鈕** → 彈窗確認券商和價差 → 執行
5. 下單按鈕顯示 **[Binance] 買入 BTC** → 點擊前清楚知道目標券商

**差距分析**: 需要全局搜索框 + 套利一鍵下單 + 下單券商確認 + 開機自動連接券商。**工時**: 8h

## 八、結論

項目代碼量巨大 (35+ 組件, 282h 開發)，核心功能完整。當前最大的用戶體驗問題是**組件之間缺乏有機連接**——K線、深度、掃描、套利是各自獨立的孤島，而不是一套協同工作的交易工作站。三批打磨共約 **55h**，可以將產品從"功能齊全的開發工具"提升為"交易員願意每天使用的專業終端"。
