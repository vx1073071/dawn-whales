### 4. 多头时间框架 (MTF) 缺失 — 交易员刚需 #1

```
竞品对标:
  TradingView: 右键 → "Apply to all timeframes" (一键)
  ThinkorSwim: Flex grid (4 屏同步)
  Futu: 时间框架联动开关

当前 QUANT MOO: 
  切换时间框架 → 所有画线/指标丢失
  每条线只属于一个时间框架
  用户用日线画的支撑→切到周线→线没了

交易员真实行为:
  "日线看趋势，小时线找入场，15 分钟决定点" ← 这句话每个交易员都会说

```

**建议**: 
1. 画线时间框架持久化 (日线画的线在 4H/1H/15m 都能看到，可选)
2. 多时间框架仪表盘 (4 屏联动)
3. 画线属性里加 "可见时间框架" 选择器

**增收**: 多屏同步属于 Pro 功能 +$2,500/月
