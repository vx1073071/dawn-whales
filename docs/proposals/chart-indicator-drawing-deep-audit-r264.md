## 二、人类实际使用习惯 — "散户在图表上到底干什么"

### 2.1 散户的图表使用路径

基于TradingView/富途/moomoo/Webull用户行为研究：

```
Step 1: 打开股票 (3-5s)
  → 第一眼看K线颜色（红还是绿？）
  → 看均线（多头排列还是空头排列？）
  → 看成交量（量大还是量小？）

Step 2: 叠加指标 (5-15s)  
  → 90%的散户只会叠加1-3个指标（MA+MACD是最常见的组合）
  → 他们不是"选指标"——他们是"用别人推荐的指标组合"
  → 如果有一个"一键加载专家指标组合"的按钮——点击率>60%

Step 3: 画线 (15-60s)
  → 散户只画3种线：趋势线(60%)、水平支撑/阻力(30%)、斐波那契(5%)
  → 他们画线不是为了"分析"——是为了"记住这个位置"
  → 他们最需要的不是"68种画线工具"——是"自动画出关键位置"

Step 4: 寻找形态 (如果还继续看，60%用户会)
  → 散户认识3-5种形态：头肩顶/底、双顶/底、三角形
  → 他们不是"手动识别"——是"AI请帮我看看这是什么形态"
  → 看见形态的第一反应："到价提醒"

Step 5: 设提醒/下单 (仅20%用户到达这一步)
  → "价格到了我画的那条线——通知我"
  → "AI说有头肩顶——到颈线提醒我"
```

### 2.2 "3秒定律"与"15秒定律"

| 时间 | 用户需求 | 我们是否满足 |
|------|---------|:----------:|
| **3秒** | 看到K线颜色+今日涨跌+均线排列 | ⚠️ KLineChartPro可以——但StockKLineDeep是mock |
| **5秒** | 叠加常用指标（一键） | ❌ 需要手动一个一个加 |
| **10秒** | 看到关键价格位置（支撑/阻力是否画好了） | ❌ 要手动画——AI画线有引擎但未接入 |
| **15秒** | 如果在这个页面上，用户开始考虑"要不要买/卖" | ❌ 此时应出现"下单/加自选/设提醒/AI分析"按钮 |

### 2.3 散户 vs 专业用户 — 分层的真相

| 用户层 | 占比 | 图表使用方式 | 付费意愿 |
|--------|:---:|-------------|:------:|
| **纯看客** | 40% | 只看日线K线+1条均线。不画线。 | 不付费 |
| **自助玩家** | 35% | MA+MACD+RSI。偶尔画趋势线。会看形态。 | 愿意为"一键分析"付费 |
| **技术流** | 15% | 4-6个指标叠加+多周期对比+画画线+成交量分布。 | 愿意为"高级指标/Volume Profile"付费 |
| **专业玩家** | 10% | 多图布局+全指标+全画线+DOM+Heatmap+回放。 | 愿意为所有Premium功能付费 |

**关键洞察**: 自助玩家(35%)是**最大收入池**——他们不是"不付费"，是"只愿意为'省时间'付费"。一键AI画线=省了他们手动画10分钟=值1USDT。

### 5.3 收费设计原则

1. **"感觉免费，用着用着付费"** — TradingView的精髓。基础功能全部免费，用户用习惯了→碰到"查看Volume Profile→免费试用1次→还想看→Premium"。

4. **失败免费** — 延续v17.6原则。AI分析失败=不扣费。这建立了信任→信任=持续付费。
5. **画线=付费转化节点** — 用户画的每根线都是一个"潜在提醒/潜在策略/潜在分享"。画线行为本身免费——但围绕画线的增值服务付费。

## 六、人类习惯驱动的优化清单

### 6.1 "3秒"体验优化

```
当前: 打开个股→看到空白K线（因为StockKLineDeepV2是mock）
      → 需要手动加载指标→需要手动画线→需要手动找形态

应该: 打开个股→K线自动加载真实数据→均线自动叠加（MA5/10/20/60）
      → AI画线自动显示（支撑/阻力/趋势虚线）→右上角显示指标读数面板
      → 看到AI提示："检测到三角形整理形态，突破方向待确认"
```

### 6.2 "一图看懂"原则

——用户打开一页能看到的信息量——

| 当前页面 | 应增加的 |
|---------|---------|
| K线图 | ✅ 已有 |
| 均线 | ✅ 已有(需手动叠加) |
| 成交量 | ✅ 已有（底部子图） |
| 指标读数 | ❌ 加：图表右侧数字面板 MA5=142.3, RSI=62.4 |
| AI画线 | ❌ 加：自动显示的虚线（趋势+支撑+阻力） |
| 形态标注 | ❌ 加：半透明标注区域 |
| 关键价格 | ❌ 加：今日高/低/开标记线 |
| 你的持仓 | ❌ 加：如果你持有此股票→标记你的成本线 |

### 6.3 "滑手指南" — 移动端手势

如果后续做移动端：K线图上**左右滑=切换股票**（不是切换周期）。这是富途/moomoo的核心体验——在"个股详情"里左右滑可以快速浏览自选列表的每一只股票图表。**不用返回自选列表。**

## 八、一个核心理念

> **散户来QUANT MOO不是为了"画线"——是为了"知道我该不该买卖"。**
>
> 图表、指标、画线、形态——这些都是**工具**。
> 工具本身不赚钱。**工具帮他做的决策**赚钱。

所以我们不应该建"工具超市"——然后让用户自己挑。我们应该做的是：

```
用户打开股票 →
AI已经画好了关键线 →
AI已经识别了形态 →
AI已经把50个指标的关键读数都提取了 →
AI说："根据你的策略—这只股票现在处于{状态}—建议{action}—置信度{X}%"

然后用户自己决定要不要买卖。
```

**这个画面——才是最赚钱的。**
