## 一、港美股特有因子 (HK/US Stock Native) — 35个

### 1.1 🇭🇰 港股专属 (12个)

港股有独特的市场结构：做空机制、AH股、warrant、牛熊证。这些因子在聚宽/米筐也没有：

```
HK-01. AH溢价率          — (H股价格×汇率)/A股价格-1，-30%~+50%，极品折价/溢价信号
HK-02. 南向资金净流入     — 沪深港通南下资金净买入额/市值，南下资金最聪明的钱
HK-03. 港股通持股比例     — 南向持仓/总股本，>5%=南向认可，>10%=定价权转移
HK-04. 北水连续流入天数   — 连续净买入天数，>5天=强烈看多信号
HK-05. 沽空比率           — 当日卖空额/成交额，>20%=极度悲观，<5%=看多
HK-06. 沽空比率变化        — 5日沽空率-20日沽空率，空头力量变化方向
HK-07. 衍生品持仓异动     — 牛证/熊证街货量突变，杀牛/杀熊信号
HK-08. Warrant隐含波动率   — 权证IV相对历史波动率的溢价，情绪指标
HK-09. 恒指成分股权重变动  — 被动基金调仓带来的资金流预测
HK-10. 港股IPO首日表现     — 近3个月新股首日平均涨跌幅，市场热度
HK-11. 板块轮动强度        — 科技vs金融vs地产的相对强弱，港股板块轮动
HK-12. 私有化概率          — 市值<净资产+P/B<1+大股东增持，潜在私有化标的
```

**人类故事**: 
- AH溢价率: "同一家公司，香港比A股便宜30%——这是个机会还是陷阱？"
- 沽空比率: "市场上有20%的成交是在做空这支股票——他们在赌什么？"

### 1.2 🇺🇸 美股专属 (13个)

美股有独特的期权市场、13F披露、做市商机制:

```
US-01. 期权Skew           — OTM Put IV - OTM Call IV，尾部风险定价，>5=恐慌
US-02. Gamma挤压潜力      — 高Gamma+低流通股，GME式的Gamma squeeze预测
US-03. 0DTE期权占比        — 0日到期期权/总期权量，日内赌博情绪
US-04. 13F机构持仓变化    — 最新季度13F vs 上季度，机构增持/减持
US-05. Citadel/Virtu做市流 — 做市商净头寸方向（如有数据源），庄家动向
US-06. Meme Stock热度     — Reddit WSB提及次数+Google Trends，散户抱团信号
US-07. 拆股预期            — 股价>$500+历史拆股模式，拆股利好
US-08. 回购加速度          — 本季回购额/上季回购额-1，回购增速
US-09. 卖空利息率          — 借券做空的年化成本，>50%=极度拥挤做空→逼空风险
US-10. SPAC合并进度        — De-SPAC完成度/时间，SPAC套利
US-11. 板块ETF资金流       — XLK/XLE/XLF资金净流入，板块轮动信号
US-12. 季节性效应          — 同月历史胜率（1月效应/圣诞rally/5月卖出）
US-13. 盈利惊喜            — 实际EPS-预期EPS，财报季核心驱动力
```

**人类故事**: 
- 期权Skew: "市场愿意为下跌保险支付比上涨保险贵5倍的价格——恐慌在蔓延"
- 卖空利息率: "做空这支股票每年要付60%的利息——空头正在被挤爆的边缘"

### 1.3 🌏 跨市场通用 (10个)

适用于港股+美股+其他发达市场的因子:

```
XM-01. 市值因子暴露        — 相对市场的大小盘Beta，风格轮动
XM-02. 流动性因子          — Amihud非流动性指标，小票流动性折价
XM-03. 特质波动率          — 剔除市场和行业后的残余波动，彩票型股票识别
XM-04. 协偏度              — 与市场收益的非线性关系，崩盘保护能力
XM-05. 最大回撤恢复天数    — 从历史最大回撤恢复到新高所需天数，韧性因子
XM-06. 52周高点距离        — 当前价/52周最高-1，锚定效应行为因子
XM-07. 机构vs散户持仓比    — 机构持股/散户持股，成熟度指标
XM-08. 分析师覆盖变化      — 覆盖该股的分析师数量变化，关注度因子
XM-09. 目标价离散度        — 分析师目标价标准差/均值，不确定性指标
XM-10. 股息贵族年限        — 连续分红年数，>25年=股息贵族(dividend aristocrat)
```

## 二、🪙 加密货币专属因子 (Crypto Native) — 30个

### 2.1 链上数据 (On-Chain) — 12个

加密世界独有的数据维度，传统金融没有:

```
CC-01. NVT比率             — 市值/链上交易量，加密世界的PE指标，>150=高估
CC-02. MVRV比率            — 市值/已实现市值，>3.7=顶部，<1=底部（历史准确度极高）
CC-03. 交易所净流入         — 转入-转出交易所的BTC/ETH，>大量流入=抛压
CC-04. 稳定币交易所存量     — USDT/USDC在交易所余额，弹药库→购买力
CC-05. 矿工持仓变化         — 矿工地址余额30日变化，矿工投降/积累
CC-06. 长期持有者供应量     — >155天未动的币占比，>80%=底部积累
CC-07. SOPR                — 花费产出利润率，>1=卖出获利，<1=割肉
CC-08. 活跃地址增长率       — 30日新地址增速，网络采用率
CC-09. Gas费趋势           — ETH gas费MA趋势，网络拥堵=繁荣
CC-10. TVL增长率            — DeFi总锁仓量30日变化，生态健康度
CC-11. 交易所储备金证明     — 交易所钱包余额趋势，FTX事件后的信任指标
CC-12. 巨鲸交易笔数         — >$1M交易笔数30日均值，机构动向
```

**人类故事**:
- MVRV: "历史上每次这个指标超过3.7，比特币都在12个月内见顶——现在是3.2"
- 稳定币存量: "交易所里躺着$45B的稳定币，这是等待发射的弹药"

### 2.2 衍生品市场 (Crypto Derivatives) — 10个

永续合约+期权市场：

```
CD-01. 资金费率             — 永续合约多头付空头的费率，>0.1%/8h=过热，<0=恐慌
CD-02. 多空比               — 全网多单/空单比例，>2=拥挤做多
CD-03. 未平仓合约OI变化     — OI 24h变化率，+20%=新资金入场，-20%=大规模平仓
CD-04. 期权最大痛点         — 最大期权未平仓行权价，到期日磁吸效应
CD-05. 25Delta风险逆转      — 25Δ Call IV - 25Δ Put IV，专业交易者情绪
CD-06. BTC Dominance变化    — BTC市值占比30日变化，山寨季信号
CD-07. 永续合约基差         — 永续价格-现货价格，>2%=强烈看多
CD-08. 清算热力图           — 各价格区间清算密集度，流动性真空区
CD-09. 期权期限结构         — 近月vs远月IV差，事件风险定价
CD-10. Taker买卖比          — 主动买/主动卖量，市场即时方向
```

**人类故事**:
- 资金费率: "现在做多每小时要付0.15%——这就像持有成本每天3.6%，市场已经过热"
- BTC Dominance: "比特币占比从60%跌到48%，山寨币的春天要来了"

### 2.3 加密基本面 (Crypto Fundamentals) — 8个

```
CF-01. 开发者活跃度         — GitHub commits 30日均值，项目生命力的根本
CF-02. 开发者集中度         — Top 10开发者贡献占比，去中心化程度
CF-03. 代币解锁时间表       — 未来30/90天解锁量/流通量，抛压预期
CF-04. 协议收入             — 30日协议费用收入，加密世界的"营收"
CF-05. P/F Ratio            — 市值/协议年化收入，加密PE，<20=低估
CF-06. 通胀率               — 年化新增供应/流通量，>10%=高通胀代币
CF-07. 质押收益率           — 年化Staking收益，无风险利率锚
CF-08. 治理提案活跃度       — 30日内治理提案数+投票参与率，社区活力
```

**人类故事**:

## 四、加密货币特有的UX设计

### 4.1 24/7 实时因子

加密永不收盘 → 因子需要实时更新:
- 资金费率每8小时自动刷新
- 链上数据每10分钟（出块时间）
- 衍生品数据每1分钟

在UI上显示"🟢 实时" vs "🟡 15分钟前"。

### 4.2 加密特有的风险提示

加密因子比股票因子更不稳定:
```
MVRV: 历史上从<1回升到>3.7的平均时间是18个月
资金费率: 极端值(>0.2%)的平均持续时间是4-6小时
注: 加密市场高波动，因子信号可能与股票市场有不同的有效周期
```

### 4.3 加密因子"牛熊周期"标注

加密市场的4年周期（比特币减半）影响所有因子:
- 当前周期阶段: 🟢 牛市早期 / 🟡 牛市中段 / 🔴 牛市顶部 / 🔵 熊市
- 每个因子显示"历史上在牛市中段的表现"
- 周期判定来源: 减半后天数 + MVRV Z-Score + 200日均线
