## 二、认证

### 两步认证

```
Step 1: 获取 MetaApi Token
  POST https://mt-provisioning-api-v1.agiliumtrade.ai/v1/users/access_token
  Body: { email, password }
  → { access_token }

Step 2: 添加 MT5 账户
  POST /users/current/accounts
  Body: { login, password, server, name }
  → { accountId }

Step 3: 部署/连接账户
  POST /users/current/accounts/{accountId}/deploy
  等待 → deployed
  等待 → connected (WS 连接就绪)
```

### DAWN WHALES 配置

```typescript
interface MT5Config {
  metaApiToken: string;
  accountId: string;
  server: string;     // "ICMarketsSC-Demo"
  login: number;
  useReal: boolean;
}
```

## 三、核心 REST 端点

### 3.1 行情

```
GET /users/current/accounts/{accountId}/symbols/AAPL/current
→ { symbol, bid, ask, time, tickSize, contractSize, digits, ... }

GET /users/current/accounts/{accountId}/historical-market-data/symbols/AAPL/candles?timeframe=1h&limit=100
→ [{ time, open, high, low, close, volume }]
```

### 3.2 账户

```
GET /users/current/accounts/{accountId}/account-information
→ { balance, equity, margin, freeMargin, marginLevel, leverage, ... }
```

### 3.3 下单

```
POST /users/current/accounts/{accountId}/trade
{
  symbol: "BTCUSD",
  type: "ORDER_TYPE_BUY",
  volume: 0.1,
  stopLoss: 58000,
  takeProfit: 65000,
  comment: "DAWN WHALES signal"
}
→ { orderId, positionId }
```

### 3.4 订单类型

| 类型 | 常量 | 说明 |
|------|------|------|
| 市价买 | ORDER_TYPE_BUY | 立即成交 |
| 市价卖 | ORDER_TYPE_SELL | 立即成交 |
| 限价买 | ORDER_TYPE_BUY_LIMIT | 低于现价 |
| 限价卖 | ORDER_TYPE_SELL_LIMIT | 高于现价 |
| 止损买 | ORDER_TYPE_BUY_STOP | 高于现价 |
| 止损卖 | ORDER_TYPE_SELL_STOP | 低于现价 |

## 四、WebSocket 实时推送
