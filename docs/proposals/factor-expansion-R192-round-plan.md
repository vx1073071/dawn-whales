**预处理管线v2规格**:
- 行业中性化: 分行业OLS回归→残差(去行业偏)
- 排名归一化: 百分位法 / Z-score(可选) / Min-Max(可选)
- 缺失值: MAD中位数插值
- 极端值: MAD±5σ截尾

**参数敏感性分析**:
- 窗口: 3M / 6M / 12M
- 阈值: ±1σ / ±1.5σ / ±2σ
- 输出: 3×3=9格IC矩阵
- 过拟合: 同一因子不同窗口IC标准差>0.05 → 过拟合警告
- 最优参数: 9格中IC均值最高的一组
