## 二、消息源 — 打磨建议

### 🔴 P0 问题：中文源严重不足
当前只有 3 个中文源（雪球/CLS/华尔街见闻），但**中国用户是DW的核心付费群体**。

**建议**:
```
1. 接入东方财富股吧热帖 (免费, JSON接口)
   - 个股吧的高赞帖 = 散户情绪晴雨表
   - 人习惯: 中国人买股票前95%会看股吧
   
2. 接入同花顺i问财 (免费搜索)
   - "最近5天机构净买入最多的股票"
   - 人习惯: 散户喜欢"问"，DW应成为"答"的地方

3. 接入抖音/快手财经大V内容 (RSS聚合)
   - 财经短视频标题→情绪信号
   - 人习惯: 短视频已成为中国散户第一信息源
```

### 🟡 P1 问题：社交源全部不可用
Reddit（403）+ StockTwits（404/timeout）在无认证环境下全挂。

**建议**:
```
4. 增加 X(Twitter) 财经KOL监控
   - Free API: api.twitter.com/2/tweets/search/recent (100条/月免费)
   - 预置50个顶级财经KOL账号列表
   - 监控"突发财报/并购/政策"关键词
   - 人习惯: Elon一条推让TSLA波动3%，DW必须抓到

5. Discord 财经频道接入
   - 免费Bot API, 监控#trading #stocks #crypto频道
   - 人习惯: 年轻人用Discord交易，Reddit之外的第二大散户聚集地

6. 社交源降级策略 (当前完全无)
   - Reddit 403 → 自动切到PushShift/Raddit mirror
   - StockTwits 404 → fallback到Twitter搜索该ticker
```

### 🟢 P2 增强：个性化新闻

## 三、因子系统 — 打磨建议

### 🔴 P0 问题：因子太多，用户不知道怎么用
149个因子文件，但用户面对因子列表时严重决策瘫痪。

**当前最严重的问题**: DW把"专业"理解成了"多"，但用户要的是"精"。

**建议**:
```
9. ★★★ "明星因子"精选 (最重要的建议)
   - 从149个因子中筛选12个"明星因子"放在首页
   - 每个明星因子自带"一句话人话解释"+"历史IC"+"适用市场"
   - 例如: "12月动量: 过去一年涨得好的股票未来1月大概率继续好(IC=0.08)"
   - 人习惯: 人最多记住7±2个东西，12个是极限
   - 💰 12个免费，解锁全部149个收3U/月

10. "因子发现"引导式体验
    - 问3个问题→推荐3个最适合的因子
    - Q1: 你交易什么市场? (美股/港股/A股/加密)
    - Q2: 你持仓多久? (日内/波段/长线)
    - Q3: 你更看重什么? (收益/稳定/进攻)
    - 人习惯: 填表比研究149个因子简单100倍

11. 因子可视化大改 (目前基本没有)
    - 每个因子一张"因子收益曲线" (vs 基准)
    - IC热力图 (按月/年)
    - 因子拥挤度仪表盘 (多少人同时用这个因子)
    - 人习惯: 看到一条上升的曲线 = 想交易
```

### 🟡 P1 问题：因子计费体验差
当前按"使用因子"计费，用户感觉被"扣费"而非"购买价值"。

**建议**:
```
12. 因子订阅制 (不是按次)
    - 基础因子包 (12明星) = 免费
    - 进阶因子包 (50因子) = 5U/月
    - 专业因子包 (149全量+自定义) = 12U/月
    - 人习惯: Netflix订阅心理 — 一次付费无限使用 > 每次扣费的心痛

13. "因子试吃"体验
    - 每个因子可免费回测1次(限30天数据)
    - 看到回测结果 → 付费解锁完整数据
    - 人习惯: "先尝后买"转化率是直接付费的3-5倍
```

## 四、策略模板 — 打磨建议

### 🔴 P0 问题：模板到实盘路径断裂
当前：选模板 → 看描述 → 手动配置 → 不知道能不能赚钱 → 放弃。

**建议**:
```
14. ★★★ "一键回测→一键部署" (最赚钱的功能)
    - 选模板 → 自动填入默认参数 → 点"回测" → 看到5年收益曲线
    - 满意 → 点"部署" → 自动创建策略→连接实盘→开始跟单
    - 全程≤3步，≤30秒
    - 人习惯: 人放弃的临界点是"需要我做超过3步"
    - 💰 模板免费，部署到实盘收10U一次 (或2U/月订阅)

15. 社交证明嵌入模板页
    - "已有1,247人使用此模板"
    - "本周收益Top5用户: +12.3%, +8.7%, +7.2%..."
    - "XXX(用户)用此策略本月赚了3,200U"
    - 人习惯: 从众心理 = 最强的转化驱动力
```

### 🟡 P1 问题：模板分类不对
当前按"趋势/均值回归/动量/价值/多因子/期权"分类→**用户不是这样想的**。

**建议**:
```
16. 按"场景"而非"学术类别"分类
    当前的 → 应该变成:
    "趋势跟踪" → 📈 "追涨型" (我想在涨的股票上加仓)
    "均值回归" → 🔄 "抄底型" (我想找跌多了的股票)
    "动量" → 🚀 "追强势" (我想买市场最强的)
    "多因子" → 🧠 "AI推荐" (我不知道选什么,帮我选)
    "期权" → 🎯 "对冲型" (我有持仓,想保护利润)
    人习惯: 人对"场景"的理解速度是"学术术语"的10倍
```

### 🟢 P2 增强：模板市场
```
17. 用户创作模板 (UGC)
    - 用户可保存自己的策略为"模板"
    - 发布到市场 → 其他用户可订阅 (创作者分成30%)
    - 人习惯: 抖音/YouTube模式 = 平台抽成,创作者留存
    - 💰 这是一个新的收入引擎: 平台抽70%模板订阅费

18. "模板PK"功能
    - 两个相似模板同场PK，对比回测收益率曲线
    - 人习惯: 对比让人"感觉在做研究"→ 更愿意付费
```

## 五、AI 集成 — 打磨建议

### 🔴 P0 问题：AI是"功能"不是"伙伴"
当前：AI做情绪分析 → 给一个分数 → 用户看到分数。像用计算器，没有"对话感"。

**最大机会**: DW应该有一个**AI交易伙伴**，用户可以像跟朋友聊天一样问问题。

**建议**:
```
19. ★★★ "DW Copilot" — AI交易对话伙伴 (核心建议)
    用户: "我应该买AAPL吗?"
    AI: "让我看看... AAPL当前$182.5，市盈率28倍。
         最近3条重要新闻: 
         ① 供应链报告显示iPhone需求超预期 (+)
         ② 分析师目标价从$195上调至$210 (+) 
         ③ Q2财报将在2周后发布 (⚠️事件风险)
         因子信号: 12月动量看涨, 价值因子中性
         综合建议: 偏多，但建议等财报后再加仓 [详细分析]"
    
    - 不是冷冰冰的分数，是"对话"
    - 用户可以追问: "如果财报不及预期会跌多少?"
    - AI调用回测引擎回答: "过去8次财报不及预期平均跌-4.2%"
    - 人习惯: 任何交易者都有一个"导师/朋友"角色,DW应该成为这个角色
    - 💰 免费版: 每天3个问题, 付费版: 无限 + 深度分析 8U/月
```

```
20. AI 主动推送 (不是被动响应)
    当前用户必须主动打开DW才能看到AI内容。
    
    应该是:
    - "⚠️ 你的持仓COIN出现异常: 24h跌15%，关联新闻3条 → 点我查看分析"
    - "📊 你关注的NVDA本周有3个分析师大行上调目标价 → 点我看详情"
    - "🔔 你持仓的TLT: 利率决议前24h历史波动率上升40% → 建议设置止损"
    
    人习惯: push notification是移动端最高打开率的功能(40-60%)
```

### 🟡 P1 问题：AI输出没有"可信度"
当前AI结论没有"来源"，用户不信。

**建议**:
```
21. 每条AI结论附带"可验证证据"
    "AAPL看涨, 置信度72%"
    ↓ 用户不信
    "AAPL看涨, 置信度72%
     依据: ① 12月动量因子IC=0.08 (历史有效)
           ② 最近5篇新闻情绪均值+0.7 (偏正面)
           ③ 机构净流入5日累计+$1.2B (聪明钱看多)
     [查看数据来源] [质疑此结论]"
    
    人习惯: "带证据的建议"比"裸建议"被采纳率高4倍
```

```
22. "AI可质疑"机制
    每条AI建议下面放一个按钮: [🤔 我不认同]
    用户点击→可以写原因→系统收集反馈→优化模型
    人习惯: 人对AI的态度是"先用再怀疑"，给出口可以留住用户
```

### 🟢 P2 增强：AI学习的"我"
```
23. AI了解"我的风格"
    - 记录用户的交易历史 (持仓时间/盈亏/胜率)
    - 分析"你是抄底型还是追涨型"
    - 以后推荐时匹配风格: "你偏向低吸，这个模板适合你"
    - 人习惯: 个性化的东西让人感觉"被理解"
```

## 九、人类使用习惯黄金法则

研究发现的所有建议背后的共同原则：

```
1. 3步法则
   任何功能，用户超过3步就会放弃。
   → 模板: 选→回测→部署 (3步)
   → 因子: 问3题→推荐→使用 (3步)

2. 社交证明
   人看到"别人在用"比"功能强大"更有说服力。
   → 每个模板显示"XXX人使用中"
   → 每个因子显示"本周Top3收益"

3. 对话 > 仪表盘
   人更喜欢"问问题得到答案"而不是"看仪表盘自己分析"。
   → AI Copilot是下一代的界面形态
   → TradingView正在做这个（他们Blog提到了AI）

4. Push > Pull
   用户不会主动打开DW看新闻。
   但push通知打开率40-60%。
   → "你今天持仓的3条重要新闻" push

5. 先尝后买
   免费试用的转化率是直接付费的3-5倍。
   → 每个付费功能都要有一个免费"试吃"入口

6. 个性化 = 留存
   用户感觉"这个APP了解我"→ 不会卸载
   → AI学习交易风格
   → 新闻推送基于关注
```
