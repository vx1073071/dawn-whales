## 一、TradingAgents 项目概述

### 1.1 项目简介

TradingAgents 是一个**多智能体 LLM 金融交易框架**，模拟真实交易公司的动态运作。通过部署专业化的 LLM 驱动智能体，从基本面分析师、情绪专家、技术分析师，到交易员、风控团队，平台协作评估市场状况并制定交易决策。

### 1.2 核心架构

```
┌─────────────────────────────────────────────────────────┐
│                  TradingAgents 架构                      │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  分析团队 (Analyst Team)                                │
│  ├─ 基本面分析师 (Fundamentals Analyst)                 │
│  ├─ 情绪分析师 (Sentiment Analyst)                      │
│  ├─ 新闻分析师 (News Analyst)                           │
│  └─ 技术分析师 (Technical Analyst)                      │
│                                                         │
│  研究团队 (Research Team)                               │
│  ├─ 看多研究员 (Bullish Researcher)                     │
│  └─ 看空研究员 (Bearish Researcher)                     │
│      └─ 动态辩论机制 (Dynamic Debate)                   │
│                                                         │
│  决策团队 (Decision Team)                               │
│  ├─ 交易员 (Trader)                                     │
│  ├─ 风控团队 (Risk Management)                          │
│  └─ 投资组合经理 (Portfolio Manager)                    │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

### 1.3 技术栈

- **语言**: Python 3.13
- **框架**: LangGraph
- **LLM 支持**: OpenAI, Google, Anthropic, xAI, DeepSeek, Qwen, GLM, MiniMax, Ollama, Azure
- **数据源**: Yahoo Finance (全球市场)
- **特性**: 决策日志、检查点恢复、多市场支持

### 1.4 核心功能

1. **多智能体协作分析**
   - 4 个专业分析师智能体
   - 多空研究员辩论机制
   - 结构化决策流程

2. **决策记忆和学习**
   - 决策日志持久化
   - 历史决策反思
   - 经验教训传承

3. **检查点恢复**
   - LangGraph 状态保存
   - 中断恢复机制
   - SQLite 检查点存储

4. **多市场支持**
   - 美股、港股、A股
   - 日股、英股、印度股
   - 加密货币

### 4.2 API 设计

```typescript
// TradingAgents API 接口

// 1. 分析请求
POST /api/trading-agents/analyze
{
  "ticker": "NVDA",
  "date": "2026-06-08",
  "config": {
    "llm_provider": "openai",
    "deep_think_llm": "gpt-5.5",
    "quick_think_llm": "gpt-5.4-mini",
    "max_debate_rounds": 2
  }
}

Response:
{
  "decision": "BUY",
  "confidence": 0.85,
  "reasoning": "...",
  "analyst_reports": [...],
  "research_debate": [...],
  "risk_assessment": {...}
}

// 2. 获取分析历史
GET /api/trading-agents/history?ticker=NVDA&limit=10

// 3. 获取智能体状态
GET /api/trading-agents/agents/status

// 4. 配置智能体
PUT /api/trading-agents/config
{
  "agents": {
    "fundamentals_analyst": { "enabled": true, "model": "gpt-5.5" },
    "sentiment_analyst": { "enabled": true, "model": "gpt-5.4-mini" },
    ...
  }
}
```

### 5.3 合规风险

| 风险 | 概率 | 影响 | 缓解措施 |

| 数据隐私 | 中 | 高 | 数据加密 + 合规审查 |
