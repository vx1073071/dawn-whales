## 二、建议新增因子（按人类使用场景排列）

### 🏦 第一组：基本面深度因子 (Fundamental Deep-Dive)

> **人类场景**: "这家公司盈利质量高吗？会不会暴雷？财务造假风险大不大？"

| ID | 名称 | 计算逻辑 | 类别 | 信号方向 |
|----|------|----------|------|----------|
| `ACCRUALS` | 应计利润 | (净利润-经营性现金流)/总资产 | quality | 负向(高应计=低质量) |
| `EARNINGS_VARIABILITY` | 盈利波动率 | 过去20季度EPS变异系数 | quality | 负向(高波动=风险) |
| `GROSS_PROFITABILITY` | 毛利润率 | (营收-营业成本)/总资产 → Novy-Marx GP | quality | 正向 |
| `NET_PAYOUT` | 净派息率 | (股息+回购-发行)/市值 | yield | 正向 |
| `OPERATING_LEVERAGE` | 经营杠杆 | 固定资产/总资产 | quality | 负向 |
| `ASSET_TURNOVER` | 资产周转率 | 营收/平均总资产 | quality | 正向 |
| `CASH_FLOW_YIELD` | 自由现金流收益率 | FCF/企业价值 | value | 正向 |
| `DEBT_COVERAGE` | 利息覆盖倍数 | EBIT/利息支出 | quality | 正向 (>3=安全) |
| `EARNINGS_SURPRISE` | 盈利超预期 | (实际EPS-预期EPS)/预期EPS | growth | 正向 |
| `REVISION_RATIO` | 分析师上调比例 | 上调数/(上调+下调) | sentiment | 正向 |

### 📊 第二组：分析师情绪与市场共识

> **人类场景**: "分析师最近调高了目标价吗？多少人在看好这个？"

| ID | 名称 | 计算逻辑 | 类别 | 信号方向 |
|----|------|----------|------|----------|
| `ANALYST_MOMENTUM` | 分析师动量 | 近3月分析师评级变化(+1升级/-1降级) | sentiment | 正向 |
| `EARNINGS_REVISION` | 盈利修正 | 近1月EPS预测变化率 | sentiment | 正向 |
| `TARGET_PRICE_IMPLIED` | 目标价隐含空间 | (平均目标价-现价)/现价 | sentiment | 正向 |
| `ANALYST_DISPERSION` | 分析师分歧度 | EPS预测标准差/平均值 | sentiment | 负向(分歧大=不确定) |
| `RECOMMENDATION_CHANGE` | 评级变化方向 | 买入/持有/卖出比例月度变化 | sentiment | 正向 |

### 🌡️ 第三组：市场情绪与行为金融

> **人类场景**: "市场现在贪婪还是恐惧？是不是该反向操作了？"

|----|------|----------|------|----------|
| `FEAR_GREED_INDEX` | 恐惧贪婪指数 | 复合: VIX+PCR+新高新低比+多空比 | sentiment | 反向(高贪婪=卖出) |
| `PUT_CALL_SKEW` | 期权偏度 | 虚值PUT IV-虚值CALL IV | sentiment | 负向 |
| `HIGH_LOW_RATIO` | 新高新低比 | 52周新高/新低数量比 | momentum | 正向(>2=强势) |

| `SHORT_COVERING` | 逼空压力 | 卖空量变化率+借券利息 | sentiment | 正向(逼空中) |
| `SOCIAL_SENTIMENT` | 社交情绪 | 舆论情绪量化(积极/消极词频) | sentiment | 正向 |
| `MEDIA_ATTENTION` | 媒体关注度 | 新闻提及频次变化率 | sentiment | 反向(过热=即将回调) |

```
└─────────────────────────────────┘
```

### 4.2 因子超市 (Factor Marketplace)

按人类思维组织，不是按学术分类：

```
🛒 因子超市
├── 🔍 "我想找到能赚钱的公司"  → 质量因子套装
├── 📉 "我想避开会暴跌的股票"  → 低波动因子套装
├── 🚀 "我想抓住上涨趋势"      → 动量因子套装
├── 🏷️ "我想买便宜的好公司"    → 价值+质量双因子
├── 💰 "我想稳稳地吃分红"      → 股息+现金流
├── 🌍 "我在意环境和社会责任"  → ESG因子
├── 🛡️ "我在担心加息/衰退"    → 宏观对冲套装
└── 🎲 "我想赌一把小盘成长"    → 规模+成长
```

### 4.3 因子健康仪表盘

用户看到的不是裸数据，是健康报告：

```
🟢 动量因子: 信号正常，IC=0.12 (强)
🟡 价值因子: 近期衰减，建议观察
🔴 波动率: VIX飙升，防御模式已激活
🔵 质量因子: 稳定发挥，组合锚定器
```

## 八、结语

当前 44 个因子覆盖了 Fama-French 经典框架 + 主流技术指标，在散户导向的 AI 投资平台中已属领先。但真正的量化平台必须覆盖**基本面深度、分析师共识、市场情绪、宏观关联**四大维度。

建议 R184-R186 三期推进，最终达到 **101 因子**，配合因子卡片/超市/仪表盘的 UX 改造，让 quant-moo 的因子分析从"专业工具"进化为"人人都能用"的智能投资伙伴。

> *"不是因子越多越好，但该有的不能少。"*  
> *"用户不会问'这个股票的ROE和IC是多少'，用户会问'这家公司靠谱吗'"*
