## 🔍 一、消息源模块 — 调研结论与改进

### 🌐 行业基准 (2026)
- **南方基金 "AI 梦"** 把首页从"产品货架"重构为"AI 投资百宝箱"动态卡片，**用户首屏从 6 选项减到 3 卡片**
- **财通 ETF AI 比赛** 证明 "用 AI Agent 玩实盘" 是新流量入口
- **极客公园：电商 AI 操作系统化** → 金融也在做"持续运行的经营系统"，不只一次性查询

### ❌ 当前问题
1. **数据冗余**: `NewsFeedPanelV2` + `NewsDashboardPage` + `DailyBriefingPanel` + `BreakingNewsToast` + `SentimentStreamDashboard` + `MarketHeatmapPage` 6 个新闻组件，**用户不知道从哪进**
2. **消息源无健康度可视化**: JVS 做了 `SourceHealthDashboard`，但前端未集成
3. **付费墙突兀**: 新闻回测/事件策略收费 1.5U/次，**用户看不到免费预告就拒绝付费**
4. **缺乏"个人专属日报"**: 没有基于用户持仓的新闻自动筛选

### ✅ 优化建议 (按 ROI 排序)

#### 🏆 P0 - 立即实施 (本周可上线)
1. **新闻统一入口 `NewsHub`**: 把 6 个新闻组件聚合为单一 Tab，根据用户行为智能切换
   - 持仓用户 → 看持仓相关新闻
   - 关注行业用户 → 看行业聚合
   - 普通用户 → 看热门 Top10
2. **新闻源健康度条** (顶部小指示器): 5 个主源实时延迟/成功/失败率，绿色=健康，红色=降级
   - 直接复用 JVS `SourceHealthDashboard` 数据
   - 体现专业感，**让用户感受到"信息优势"** → 提高付费转化
3. **消息源 VIP 标记**: 5/40 个"机构专享"源免费预告 ("🔒 Bloomberg Terminal data, 1.5U 解锁本次回测")

#### 🎯 P1 - 2 周内
4. **个人化新闻日报订阅** (`PersonalNewsDigest`): 基于持仓+关注+浏览历史，每天 8AM 推送 5 条
   - 免费版：3 条，标题 + 来源
   - 付费版 (1U/天)：5 条 + AI 解读 + 一键加入监控
5. **新闻热度排行** (`NewsHotRank`): 24h/7d/30d 三档，模拟雪球/微博热榜心理
6. **多语言新闻源切换** (中/英/日/韩 4 国财经)，针对跨境用户

#### 💎 P2 - 月底
7. **新闻"作战室"模式** (`NewsWarRoom`): 大屏模式，15 屏联动
8. **新闻+情绪+因子三维联动**: 点击新闻 → 自动筛选相关因子 → 一键加入策略

## 🔍 二、因子模块 — 调研结论与改进

### 🌐 行业基准
- **广发金工 CogAlpha**: 把因子挖掘从"代码公式"升级为"智能体角色 (Agent Reversal/Agent Liquidity)"
- **展恒基金证金投资**: 用 Level-2 毫秒级订单簿数据建立"数据独特性"
- **私募指增**: 1251 只产品 5 月平均超额 3.08%，**66.51% 取得正超额** → 因子价值高

### ❌ 当前问题 (53 个因子组件！)
1. **严重重复**: `CrossMarketFactorCompare` + `CommodityFactorCard` + `KRSAMarketFactorCard` + `INEUFactorCard` + `JPTWFactorCard` + `MarketSpecificFactorCard` 6 个卡片类组件逻辑重叠
2. **"因子宇宙"无导航**: `FactorUniverseHub` + `FactorFinalHub` + `FactorFullPipeline` + `FactorSandbox` 4 个 Hub 入口混淆
3. **因子估值贵却不"贵"得明白**: 1U/因子扫描，**用户不知道这 1U 能赚回多少**
4. **没有"因子军火库"心智**: 普通用户打开 `FactorSelector` 看到 16 类不知道选啥
5. **缺因子组合回测对比**: 看单一因子 IC 不够，要看组合表现

### ✅ 优化建议

#### 🏆 P0 - 本周
1. **因子统一卡片 `FactorCardV2`**: 合并 6 个市场卡片为 1 个可配置组件，节省 1500+ 行代码
2. **因子智能推荐 `FactorRecommender`**: 基于用户持仓+风险偏好+回测表现 Top5
   - 卡片显示: 因子名 / 近 30 天 IC / 推荐理由 / "加入策略" 一键
3. **因子组合对比 `FactorComboCompare`**: 选 3-5 个因子 → 看组合回测 → 对比基准
   - **这是付费转化核心场景**，"试试看，1.5U 看组合效果" → 高 ARPU

#### 🎯 P1 - 2 周
4. **因子贡献归因 `FactorAttribution`**: 用户已有策略 → 显示哪些因子贡献了多少收益
   - 来自南方基金 "AI 自动归因" 启发
5. **因子生命周期**: 标记"衰退中 / 巅峰 / 新兴"三态，**用颜色+信号灯警示**
6. **"因子实验室" 引导**: 类似 TradingView Pine Script 教程式引导，5 分钟教用户写自己的因子

#### 💎 P2 - 月底
7. **AI 因子生成器** (`AIFactorGenerator`): 输入"我想找反转因子" → AI 写出 3 个候选 → 1.5U 验证
   - 直接对标广发金工 CogAlpha 思路
8. **因子商城**: 第三方创作者卖因子模板，平台抽 30% (L1) / 20% (L2) / 10% (L3)

## 🔍 三、策略模板模块 — 调研结论与改进

### 🌐 行业基准
- **量化私募 / 平台化**: 139 家百亿私募 → 用户需要"能复用的策略"而非"看 alpha"
- **创作者经济**: TikTok Shop 头部机构模式 → 策略创作者需要"长期内容关系+持续互动"
- **可灵 AI / 智谱**: AI 一键生成投资策略成新趋势

### ❌ 当前问题 (65 个策略组件！)
1. **入口混乱**: `StrategyPage` + `StrategyPage/` 子目录 (7 个) + `StrategyProfileCard` + `StrategyExpiryBanner` + 12 个对比/评估组件
2. **模板数量声称 83/104 但无验证**: `youdao-r242-done` 提到 26 个测试 + 8 事件类型，未在 UI 体现
3. **缺"创作者中心"**: 创作者发布流程散落在 `StrategyPublishForm` + `MarketplaceDetail`
4. **缺"策略漏斗"**: 发现 → 试用 → 付费 → 上线 没有引导流

### ✅ 优化建议

#### 🏆 P0 - 本周
1. **策略统一页 `StrategyV2`**: 把 65 个策略组件整理为 3 视图
   - 发现 (`Discover`): 模板库 + 热度 + 收益排行
   - 我的 (`My`): 草稿/运行中/已暂停/历史
   - 创作 (`Create`): 自然语言/表单/模板/AI 生成
2. **"5 分钟跟单" 引导**: 从发现 → 一键试用 (前 3 天免费) → 转化付费
   - 来自 ETF AI 比赛思路: 降低首次体验门槛
3. **策略"战绩卡" `StrategyBattleCard`**: 创作者主页显示该策略近 1M/3M/6M/1Y 收益曲线 + 最大回撤 + 跟单人数 + 收益分成
   - 类似游戏玩家的"战绩卡"，**刺激创作者发布更多策略**

#### 🎯 P1 - 2 周
4. **策略竞技场 `StrategyArena`**: 公开策略 PK，每日/周/月冠军 → 上首页 + 流量倾斜
5. **策略一键复制** (`StrategyClone`): 点"复制" → 改名字 → 改 3 个参数 → 上线，5 分钟完成
6. **策略回测对比**: 选 3 个策略 → 同一时间区间对比 → "哪个更适合我"

#### 💎 P2 - 月底
7. **AI 策略生成 (自然语言)**: "我想做低回撤+每月 2% 收益的港股策略" → AI 生成 3 个模板 → 1.5U/个
   - 已有 `AIAdvisorPage`，需要从建议升级为生成
8. **创作者激励**: 跟单分成 70/80/90% (已 v17.6)，加**周榜/月榜现金奖**

## 🔍 四、AI 模块 — 调研结论与改进

### 🌐 行业基准
- **南方基金 AI 梦**: 千人千面 (个性化) 是核心
- **极客公园 / StoreClaw**: AI 从"工具"变"操作系统"
- **2026 共识**: 配套生态变现 > 月卡订阅 (千问×淘宝/豆包×抖音/文心×京东/元宝×美团)

### ❌ 当前问题
1. **AI 入口分散**: 13 个 AI 组件 (AIAssistant/AICost/AIDraw/AIStrategy/AIHistory/AIFeedback/AIParameter/AIAdvisory/...)，用户不知道用哪个
2. **成本面板** (AICostDashboard) 做了但用户看不到价值对等
3. **AI 反馈评分** (AIFeedbackRating) 数据未用于训练/优化闭环
4. **无"AI 军师"心智**: 应该是用户打开 App 第一个入口 (像 NotebookLM)
5. **无 AI 智能体 (Agent) 协作**: 单点 AI 而非多 Agent 协同 (虽然 4 个 Agent 在后端)

### ✅ 优化建议

#### 🏆 P0 - 本周
1. **AI 统一入口 `AIHub`**: 把 13 个 AI 组件聚合为 1 个对话式入口
   - "AI 助手" (对话)
   - "AI 自动" (任务执行: 画线/形态/参数)
   - "AI 复盘" (历史查询)
   - "AI 计费" (透明成本)
2. **AI 输出"价值锚定"**: 每次 1U 收费时显示 "≈ 一杯咖啡 / ≈ 一次新闻订阅 / 帮你省 X% 时间"
3. **AI 反馈→训练闭环**: 用户 👎 → 立即记录 → 周报给 PM → 优化 Prompt

#### 🎯 P1 - 2 周
4. **AI 智能体 (Agent) 协作可视化**: 用户能看到 "4 个 AI Agent 正在合作分析你的持仓"
5. **AI 每日投顾** (1U/天 → 提升到 2U 含新闻): "今天你持仓的 3 个风险+2 个机会"
6. **AI 教程式引导** (OnboardingAI): 5 分钟 "5 个 AI 技巧" 教学 → 5 任务解锁 (共 5U 试用)

#### 💎 P2 - 月底
7. **AI 个性化训练**: 收集用户偏好 (高分红/低估值/小盘) → 定制 AI 回答风格
8. **AI 跟单顾问**: 你关注的 10 个高手调仓 → AI 解释为什么 → 你决定跟不跟
9. **AI 公开课**: 把"AI 如何选股"做成 30 节公开课 → 流量 → 转化

## 💰 五、变现与商业化优化 (核心赚钱！)

### ❌ 现状
- 5 项付费功能，~3,250U/月预估
- 月卡/订阅=0 (v17.6 永久锁定)
- USDT 单边收入
- 散户用户为主，价格敏感

### ✅ 优化方向

#### 1️⃣ 提升 ARPU (每用户收入)
- **场景包** (而非单点功能):
  - "新手包 9.9U": 7 天 AI 早报 + 3 次回测 + 1 次事件策略
  - "深度包 49.9U": 30 天全功能 + 1 次 1v1 投顾视频
  - "大户包 499U": 季度 + 定制 AI 因子 + 私享策略群
- **行业包**: "港股新手包" / "加密玩家包" / "美股长线包" → 提高决策深度

#### 2️⃣ 提升转化率
- **免费试用 → 付费**:
  - 新闻回测: 免费看前 30 天数据 + 1 次 1.5U 试算 → 50% 转化
  - AI 早报: 免费 3 天 → 订阅 1U/天
  - 风险扫描: 免费 1 次 → 收费 1U/次
- **付费墙放对位置**: 不在"打开就收"而在"用户已投入 2 分钟看完标题后"

#### 3️⃣ 提升留存
- **每日活跃激励**: 连续 7 天登录 +0.5U 积分
- **周报/月报推送**: 显示"你本周用 AI 赚了 X 元" (回测假设收益)
- **社区绑定**: 创作者发策略 → 跟单者关注创作者 → 双边留存

#### 4️⃣ 创新收入源
- **数据 API 收费**: 机构客户 (1,000U/月起) 订阅情绪/回测数据
- **白标服务**: 给券商/基金做白标新闻终端 (5,000U/月)
- **教育内容**: "AI 选股 30 讲" 99U → 引流

## 👥 六、人类使用习惯优化

### 调研要点
- **东亚用户**: 偏好"信息密度高+功能强" (雪球/同花顺/富途) 
- **西方用户**: 偏好"简洁+任务流" (Robinhood/Trading212)
- **付费习惯**: 单次付费 > 月卡 (尤其加密用户)
- **决策时长**: 用户停留 90s 内决定是否付费

### ✅ 关键 UX 改造
1. **首屏 3 秒原则**: 用户打开看到 3 个核心: ① 当前持仓盈亏 ② 今日 Top3 新闻 ③ 1 句 AI 建议
2. **暗色优先 (Dark Mode First)**: 92% 用户用暗色 (CFA Trader 调研)，目前有 Toggle 但默认亮色
3. **动效反馈 (Microinteraction)**:
   - 因子选中 → 数字飞入
   - 策略回测完成 → 烟花动效
   - 收费扣款 → 透明流水滚动
4. **键盘流优化**: Power user 用 `Ctrl+K` 搜功能，`Ctrl+B` 买/卖 (已做 Hotkey 系统 28 个)
5. **移动优先**: 90% 用户用手机 → 重点打磨 `MobileFactorSelector` `MobileDashboardLayout` `RiskMobileAdapter`
6. **通知分级**: 紧急 (VIX>30/突发新闻) > 重要 (策略信号) > 提示 (日报) > 营销
7. **错误友好**: 网络断 → 显示"重试" + 离线缓存数据
8. **"专业感"细节**: 显示 "数据源: Reuters/Bloomberg" 而非"数据源: API"
