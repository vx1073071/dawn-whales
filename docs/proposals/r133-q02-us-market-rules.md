## 一、交易时段

## 二、做空规则

### 卖空基本条件

| 条件 | 说明 |
|------|------|
| 券商支持 | IB/Tiger/Schwab 均支持做空 |
| 股票可做空 | 需券商有库存 (locate shares) |
| 保证金账户 | 必须 (现金账户不可做空) |
| 最低保证金 | 做空金额 × 150% (Reg T) |

### Uptick Rule (上涨抛空限制)

- 个股日内跌幅 ≥10%: 触发 SSR (Short Sale Restriction)
- 触发后: 仅限价格 ≥ 当前 national best bid 时允许做空
- SSR 有效期: 当日 + 次日 (共2个交易日)

### 硬做空股票

| 筛选 | 方法 |
|------|------|
| IB | `isShortable()` 返回 `shortableShares` |
| Tiger | 查询 `short_available` |

### quant-moo 风控

```
做空下单前:
  1. 检查 isShortable (券商API)
  2. 检查 SSR (不能低于 best bid)
  3. 检查保证金 (≥150% 做空金额)
  4. 检查价格 (不低于 $5.00, SEC Penny Stock Rule)
```

## 三、T+2 结算

### 结算时间线

```
Day T (交易日): 下单成交 → 合约生效
Day T+1:        清算所处理
Day T+2:        资金/股票交割 → 可提现/可划转
```

### 影响

| 场景 | T+2 影响 |
|------|---------|
| 卖出股票 | 资金 T+2 才可用 |
| T+0 再买 | 可用 (未结算资金可再交易) |
| 提现 | T+2 后才能提取 |
| 转仓 | T+2 后才能转移 |
| 分红除权 | Ex-Date = T+2 前一日 |

### quant-moo 实现

```
getAccount():
  cashBalance:      可用现金 (已结算)
  buyingPower:      购买力 (含未结算资金)
  unsettledCash:    未结算资金 (T+1/T+2)
```

## 四、熔断机制

### 个股熔断 (LULD)

|--------|----------------------|------|
| Tier 1 | ±5% (5分钟暂停) | ±5% |

## 五、PDT 规则 (Pattern Day Trader)

| 规则 | 说明 |
|------|------|
| 触发条件 | 5个交易日内 ≥4 次日内交易 (同日买卖) |
| 适用账户 | 保证金账户 |
| 最低资产 | 触发后需维持 $25,000 |
| 违反后果 | 账户限制 90 天 (只能卖不能买) |

### quant-moo PDT 监控

```
跟单执行前:
  dayTradeCount = countDayTrades(userId, 5 days)
  if dayTradeCount >= 3 && accountType === 'margin' && equity < $25,000:
    warn("接近PDT限制: {dayTradeCount+1}/4")
  if dayTradeCount >= 4:
    reject("已达PDT限制, 暂停今日跟单")
```

## 六、最低价格规则

| 规则 | 说明 |
|------|------|
| Penny Stock | 价格 < $5.00 需要特殊账户权限 |
| 最低下单价 | $0.0001 (SEC Rule 612) |
| 最小价格变动 | $0.01 (≥$1.00) / $0.0001 (<$1.00) |
