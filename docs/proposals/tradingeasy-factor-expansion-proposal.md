## 二、建议新增 70+ 因子 (按6大新建类别)

### 2.1 📊 技术指标类 (Technical Indicators) — 12个

人类使用频率最高的因子类别（50%+交易者日常使用）:

```
F01. KDJ             — 随机指标(K/D/J三线)，A股最常用短线指示
F02. Williams %R     — 超买超卖，比RSI更敏感
F03. CCI             — 商品通道指数，多市场适用
F04. Parabolic SAR   — 抛物转向，趋势跟踪止损
F05. SuperTrend      — 超级趋势，加密货币交易者最爱
F06. Ichimoku Cloud  — 一目均衡表，日股/AH股交易者必备
F07. 均线乖离率       — (价格-MA)/MA，判断超涨超跌
F08. 布林带宽度       — (上轨-下轨)/中轨，波动率突破信号
F09. 趋势强度指数     — ADX的改进版，带方向
F10. 价格通道突破     — Donchian Channel 突破信号
F11. 成交量加权MACD   — VWAP MACD，量价结合的MACD改进
F12. 资金流量指标MFI  — 量价综合，识别资金进出
```

**盈利**: KDJ/CCI/P-SAR 是免费Tier0引流因子（高频搜索）；SuperTrend/Ichimoku 是 Tier1 付费因子。

### 2.2 💰 基本面类 (Fundamental Quality) — 15个

专业投资者核心需求，每个因子都是独立的研究工具:

```
F13. ROA             — 总资产回报率，更全面的盈利能力
F14. ROIC            — 投入资本回报率，巴菲特最爱的指标
F15. 毛利率趋势       — (本期毛利率-上期毛利率)，利润质量边际变化
F16. PEG             — 市盈率/增长率，成长股估值核心
F17. 自由现金流收益率  — FCF/市值，真金白银vs会计利润
F18. Piotroski F-Score — 9项基本面评分(0-9)，学术验证的价值因子
F19. 应计利润比率     — (净利润-经营现金流)/总资产，盈利质量
F20. 经营现金流/利润  — 利润含金量，>0.8为健康
F21. 研发投入比       — 研发/营收，科技股成长潜力
F22. 毛利率稳定性     — 5年毛利率标准差，护城河指标
F23. Altman Z-Score  — 破产风险评分，信用风险因子
F24. Beneish M-Score — 财务造假概率，避雷神器
F25. 股息增长率       — 3年股息CAGR，红利成长
F26. 回购收益率       — 净回购/市值，美股最有效的因子之一
F27. 机构持仓集中度   — 前10机构持仓占比，聪明钱跟随
```

**盈利**: ROIC/F-Score/Z-Score/M-Score 是 Tier2 专业因子（$49/月订阅解锁）。

## 三、人类使用习惯 — 因子组织重构

### 3.1 当前问题: 44个因子平铺 → 新人不知所措

现状: `MOM_12M/MOM_1M/VOL_60D/RSI_14/QUAL/VAL/GRO/...` 无层次。

### 3.2 建议: 三级因子体系 (模仿Robinhood的渐进式)

```
⭐ 常用因子 (12个)           — 新人默认显示
   MA/MACD/RSI/KDJ/PE/PB/ROE/DIV/量比/振幅/换手率/Beta
   每个因子: 一张卡片 → 中文名+一句话+最近表现

🔍 进阶因子 (40个)           — 一键展开
   按类别分组: 趋势(8)/动量(8)/波动(6)/价值(6)/质量(8)/成长(4)

🧪 实验因子 (剩余)           — 默认隐藏，搜索可见
   另类数据/高频/行为类 → 需要时可搜索启用
```

### 3.3 因子"故事化"展示 — 每个因子一个故事

不要只展示 `IC=0.045`。每个因子都配"一句话故事":

| 因子 | 数学 | 人类故事 |
|------|------|---------|
| ROIC | (NOPAT/投入资本) × 100% | "每投入100元，公司能赚回多少？超过15%才算优秀" |
| Z-Score | 1.2A+1.4B+3.3C+0.6D+1.0E | "这个公司有多大可能破产？<1.8是危险区" |
| PEG | PE/盈利增长率 | "你为1%的增长付了多少倍市盈率？<1才是便宜" |

### 3.4 因子"社交化" — 用户之间的因子对比

```
"您的因子组合收益率在成长型投资者中排名前30%"
"您偏好的因子(MOM_12M)在过去一周被128位用户加入自选"
```
