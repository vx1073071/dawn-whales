## 二、人类使用习惯分析

### 2.1 交易者心理模型

基于行为金融学和平台用户研究，交易者在使用策略模板时遵循以下心理路径：

```
1. 认知阶段 (Recognition)
   └─ "这个模板听起来像什么？" → oneLiner ≤80字 ✅

2. 评估阶段 (Evaluation)
   └─ "这个模板适合我吗？" → marketScope + failureCheck ✅
   └─ "历史表现如何？" → winRate/sharpe/backtestSummary ⚠️ 缺可视化

3. 决策阶段 (Decision)
   └─ "我现在要付费吗？" → AI触发点定价 ✅
   └─ "如果不好用怎么办？" → 止损规则 ✅ + 退费机制 ⚠️ 未显式展示

4. 执行阶段 (Execution)
   └─ "怎么配置参数？" → PARAM_FILL AI触发 ✅
   └─ "怎么开始交易？" → 创建策略流程 ✅

5. 监控阶段 (Monitoring)
   └─ "这个策略还在工作吗？" → FACTOR_DIAGNOSE ✅
   └─ "什么时候该放弃？" → failureCheck ⚠️ 需主动提醒
```

### 2.2 当前UX差距

| 阶段 | 问题 | 影响 | 优先级 |
|------|------|------|--------|
| **评估** | 回测结果缺乏可视化对比 | 用户无法直观比较模板 | 🔴 P0 |
| **决策** | 退费机制未显式展示 | 用户担心付费后无法退款 | 🔴 P0 |
| **监控** | 失效条件无主动提醒 | 用户可能在失效策略上继续亏损 | 🟡 P1 |
| **执行** | 参数填充缺乏上下文解释 | 用户不理解AI推荐的原因 | 🟡 P1 |

## 三、AI收费功能审查

### 3.1 当前计费架构

```typescript
// ai-billing.ts (R145)
AI_PRICE_TABLE = {
  AI_DRAW_LINES:     1 USDT,
  AI_CHAT:           1 USDT,
  AI_PARAM_FILL:     1 USDT,
  AI_PATTERN_RECOG:  1 USDT,
}

// TemplateEngine.ts (R204)
AI_TRIGGERS = {
  BACKTEST_READ:     1 USDT,
  PARAM_FILL:        1 USDT,
  OPTIMIZE:          1.5 USDT,
  FACTOR_DIAGNOSE:   1 USDT,
  ALT_DATA:          2 USDT,
}
```

### 3.2 计费流程审查

**✅ 优点:**
1. **静默计费** — 无弹窗，点击即扣费，减少决策摩擦
2. **先扣后调** — 防止API调用失败后用户白嫖
3. **幂等键** — 防止重复扣费
4. **失败退费** — DeepSeek调用失败自动退款

**⚠️ 问题:**

| 问题 | 描述 | 风险等级 | 建议 |
|------|------|---------|------|
| **退费窗口不明确** | 用户不知道多久内可以申请退费 | 🟡 中 | 显式展示"7天内可申请退费" |
| **退费入口隐藏** | 退费需要联系PM，无自助入口 | 🔴 高 | 增加自助退费按钮 (失败后24h内) |
| **计费记录不透明** | 用户无法查看历史AI消费明细 | 🟡 中 | 增加"AI消费记录"页面 |
| **降级链成本不透明** | 用户不知道用的是哪个模型 | 🟢 低 | 可选：显示"本次使用V4Pro/V4Flash" |

### 3.3 计费心理学优化

基于微交易心理学研究，建议以下优化：

#### 优化1: 价格锚定 (Price Anchoring)

**现状:**
```
回测解读: 1 USDT
参数填充: 1 USDT
优化建议: 1.5 USDT
```

**问题:** 用户无法感知"1 USDT"的价值。

**建议:** 增加对比锚点
```
回测解读: 1 USDT (≈ 专业分析师10分钟工作量)
参数填充: 1 USDT (≈ 节省2小时手动调参)
优化建议: 1.5 USDT (≈ 专业量化团队1小时咨询)
```

#### 优化2: 套餐折扣 (Bundle Discount)

**现状:** 所有AI服务独立计费，无套餐。

**建议:** 增加"策略启动包"
```
策略启动包 (首次使用模板):
  ├─ 回测解读 (1 USDT)
  ├─ 参数填充 (1 USDT)
  └─ 因子诊断 (1 USDT)
  
  原价: 3 USDT
  套餐价: 2.5 USDT (省17%)
```

#### 优化3: 消费上限保护 (Spending Cap)

**现状:** 无单日消费上限。

**建议:** 增加可选消费上限
```
[ ] 启用每日消费上限 (默认关闭)
    └─ 上限金额: [ 5 USDT ▼ ]
    └─ 达到上限后: [ 暂停所有AI服务 ▼ ]
```

## 五、人类使用习惯优化建议

### 5.1 模板发现体验

**现状:**
```
TemplateBrowser
  ├─ 分类筛选 (momentum/mean_reversion/breakout/...)
  ├─ 搜索框
  └─ 模板卡片 (name + description + risk)
```

**问题:**
1. 用户不知道哪个模板适合自己
2. 模板描述过于技术化
3. 缺乏个性化推荐

**建议: 增加"策略匹配向导"**

```
[ 策略匹配向导 ]

Q1: 你的风险偏好是？
  ○ 保守型 (年化目标<10%, 最大回撤<15%)
  ○ 平衡型 (年化目标10-20%, 最大回撤15-25%)
  ○ 激进型 (年化目标>20%, 最大回撤>25%)

Q2: 你主要交易什么市场？
  □ 美股
  □ 港股
  □ 加密货币
  □ 商品期货

Q3: 你的投资周期是？
  ○ 短线 (<1周)
  ○ 中线 (1周-3月)
  ○ 长线 (>3月)

[ 匹配结果 ]
  推荐模板: 美股动量突破 (匹配度 92%)
  推荐理由: 适合激进型 + 美股 + 短线
  
  [ 查看详情 ] [ 直接使用 ]
```

### 5.2 模板详情页优化

**现状:**
```
模板卡片
  ├─ 名称 + 描述
  ├─ 分类标签
  ├─ 风险参数 (SL/TP/Pos)
  └─ 因子推荐
```

**建议: 增加以下模块**

```
模板详情页
  ├─ 基础信息 (现有)
  ├─ 📊 历史表现 (新增)
  │   ├─ 年化收益: 18.5% (95% CI: 12-25%)
  │   ├─ 夏普比率: 1.8
  │   ├─ 最大回撤: 22%
  │   ├─ 胜率: 62%
  │   └─ vs 标普500: +8.5% (超额收益)
  │
  ├─ 🎯 适用场景 (新增)
  │   ├─ 最佳市场环境: 牛市/震荡市
  │   ├─ 最差市场环境: 熊市
  │   └─ 推荐持仓周期: 2-4周
  │
  ├─ ⚠️ 风险提示 (新增)
  │   ├─ 止损规则: 跌破20日均线
  │   ├─ 失效条件: 连续3月夏普<0.5
  │   └─ 退费政策: 7天内可申请退费
  │
  ├─ 🤖 AI增强 (现有)
  │   ├─ 回测解读 (1 USDT)
  │   ├─ 参数填充 (1 USDT)
  │   └─ 优化建议 (1.5 USDT)
  │
  └─ 📈 用户评价 (新增)
      ├─ 平均评分: 4.2/5 (128条评价)
      ├─ 最新评价: "在2024年牛市中表现很好"
      └─ [ 查看全部评价 ]
```

### 5.3 策略监控体验

**现状:**
```
MyStrategies
  └─ 策略列表 (name + status + P&L)
```

**问题:**
1. 用户不知道策略是否还在有效工作
2. 失效条件无主动提醒
3. 缺乏策略健康度指标

**建议: 增加"策略健康仪表盘"**

```
策略健康仪表盘

[ 策略名称: 美股动量突破 ]

健康评分: 72/100 (良好)
  ├─ 因子IC: 0.045 (健康)
  ├─ 夏普比率: 1.2 (正常)
  ├─ 最大回撤: 18% (正常)
  └─ 信号频率: 3次/周 (正常)

[ ⚠️ 警告 ]
  因子IC连续2周下降 (0.06 → 0.045)
  建议: 运行因子诊断 (1 USDT)

[ 操作 ]
  [ 运行诊断 ] [ 查看历史 ] [ 停止策略 ]
```

## 九、总结

### 核心发现

1. **架构健全** — 88模板 + 四铁律 + AI触发 + 11市场标签，技术基础扎实
2. **计费合理** — 静默计费 + 失败退费 + 幂等键，符合微交易最佳实践
3. **UX差距** — 退费不透明、回测无置信区间、失效无提醒，需优化

### 关键建议

1. **P0: 退费自助化** — 增加自助退费按钮 + 消费记录页面
2. **P0: 回测透明化** — 增加置信区间 + 过拟合警告
3. **P1: 发现智能化** — 增加策略匹配向导
4. **P1: 监控主动化** — 增加策略健康仪表盘 + 失效提醒

