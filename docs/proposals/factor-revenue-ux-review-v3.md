## 三、🟢 人类UX缺失（8项）

### 3.1 因子百科卡片 — 功能全但不可发现

**现状**: `FactorCard.tsx` 有 hover→popover，但用户不知道哪些因子可以 hover。

**建议**: 因子名旁边加 `ⓘ` 图标（点击或悬停），更直观。

### 3.2 因子信号灯 — 无全局视角

**现状**: 单因子可以看 IC 衰减趋势。

**建议**: 增加"因子全景"视图 — 所有因子信号灯并排（红/黄/绿），一眼看到哪些因子在衰减。

### 3.3 LaTeX公式 — 学术但不实用

**现状**: `FactorFormula.tsx` 使用 MathJax 渲染公式。90% 用户看不懂 `β_MKT = Cov(R_i, R_m) / Var(R_m)`。

**建议**: 公式折叠在"数学定义"下，默认显示"一句话解释"。

### 3.4 信号时间线 — 无交互

**现状**: `SignalTimeline.tsx` 甘特图显示信号线。

**建议**: 点击信号线 → K线图跳转到对应时间点 + 显示当时因子值。

### 3.5 策略分享导出 — 无水印无二维码

**现状**: `StrategyShareCard.tsx` 导出图片。

**建议**: 添加水印"quant-moo" + 二维码"扫码试用" → 病毒传播。

### 3.6 参数 mini 回测 — 结果无对比

**现状**: `MiniBacktest.tsx` 显示绿/红箭头。

**建议**: 箭头上方显示具体数值变化："+3.2% 收益 / -1.5% 回撤"。

### 3.7 工作台侧边栏 — 6入口但无快捷键标注

**现状**: `StrategySidebar.tsx` 6 个入口。

**建议**: 每个入口标注快捷键（Ctrl+1~6），hover 显示。

### 3.8 回测进度条 — 无预估准确度

**现状**: `BacktestProgressBar.tsx` 显示百分比+预估时间。

**建议**: 第一遍显示"校准中…"，第二遍显示精确预估。"剩余 ~8秒（±2秒）"。
