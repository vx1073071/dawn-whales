# TradingEasy v1.9.0 GA — 完整使用手册

## 一、产品简介

TradingEasy 是一个 AI 驱动的量化策略社区平台。
4 个 AI Agent (基本面/技术面/情绪面/宏观) 像圆桌会议一样协作分析股票，
创作者发布策略信号赚 USDT，用户订阅跟单。

### 核心技术
- **4Agent AI**: 4个AI分析师协作讨论，投票生成 BUY/SELL/HOLD 信号
- **7大市场**: 港股/美股/新加坡/日本/澳洲/加拿大/马来西亚
- **30+因子**: Fama-French/Barra/自研/北水/期权PCR/机构持仓等
- **20+模板**: 网格/DCA/海龟/布林/期权跨式/市场中性等
- **25+指标**: MA/EMA/MACD/RSI/Ichimoku/CCI/VWAP等
- **AI画线**: 趋势线/支撑阻力/通道/斐波那契/江恩
- **AI形态**: 头肩/双底/旗形/楔形/吞没 20+种形态自动标注
- **IU/UX**: 深色+浅色双主题 / 9语言 / 1366×768响应式 / 私行金配色 / WCAG AA可访问

### 三产品架构 (永久)
1. **落地页** (TradingEasy.com) — 静态展示，介绍+下载
2. **桌面端** (Electron) — 创作者+用户唯一入口
3. **服务器** (/api + /admin) — AI+计费+钱包+许可证

## 二、快速开始

### 安装
1. 访问 https://TradingEasy.com
2. 下载对应平台版本: Windows(.exe) / macOS(.dmg) / Linux(.AppImage)
3. 安装并启动

### 注册
1. 打开桌面端，点击"注册"
2. 填写邮箱+密码 (无KYC)
3. 完成注册，进入主界面

### 充值 USDT
1. 进入"钱包"页面
2. 点击"充值" → 获取 TRC-20 地址
3. 从交易所/钱包转入 USDT (充值0手续费)
4. 到账后余额更新

## 三、创作者指南

### 创建策略 (3种方式)

**A. 模板一键套用** (最简单)
1. 点击"新建策略" → "从模板"
2. 选择模板 (如: 双均线港股版)
3. 选择股票 → 系统自动加载参数
4. 点击"回测" → 查看历史表现
5. 满意后点"发布"

**B. AI协作创建** (特色)
1. 点击"AI协作"按钮
2. 选择分析模式:
   - 标准 (2Agent, 1.0 USDT/次) — 技术+情绪
   - 高级 (3Agent, 1.5 USDT/次) — +基本面或新闻
   - 旗舰 (4Agent, 2.0 USDT/次) — 全圆桌
3. 选择股票 → 4Agent 开始分析 (约30-90秒)
4. 查看分析结果: 投票BUY/SELL/HOLD + 各Agent理由
5. 保存策略或继续修改

**C. 手动创建** (高级)
1. 选择因子 (30+可选)
2. 调整权重和参数
3. 选择技术指标 (25+)
4. 回测验证
5. 发布

### 策略参数说明

| 参数 | 作用 | 新手建议 |
|------|------|----------|
| 仓位比例 | 策略占总资金% | 5%-20% |
| 止损 | 亏损多少自动卖出 | 5%-15% |
| 止盈 | 盈利多少自动卖出 | 10%-30% |
| 持仓周期 | 买入到卖出时间 | 1天-1月 |
| 因子权重 | 每个因子的重要度 | 系统默认 |

### 发布策略

1. 策略回测通过 → 点击"发布到市场"
2. 设置订阅价: 1-1000 USDT/月
3. 填写策略说明
4. 上架 → 用户可浏览订阅

### 分成规则

| 等级 | 创作者% | 平台% | 晋升条件 |
|------|---------|-------|----------|
| L1 新人 | 70% | 30% | 注册默认 |
| L2 中阶 | 80% | 20% | 100订阅者或1000 USDT收益 |
| L3 头部 | 90% | 10% | 1000订阅者或10000 USDT收益 |

## 四、用户指南

### 浏览信号广场
1. 进入"信号广场"
2. 筛选: 按市场/风格/收益率/风险等级
3. 查看策略详情: 历史表现/胜率/回撤/夏普比率

### 订阅策略
1. 选择喜欢的策略 → 点击"订阅"
2. 按月付费 (创作者定价，1-1000 USDT/月)
3. 付费后自动收到信号推送

### 收到信号后
1. 桌面端收到推送: "00700 腾讯 BUY 目标385 止损365"
2. **自己去券商App手动下单** (平台不代下单)
3. 也可以配置自动交易 (见下方)

### 自动交易
1. 在"交易"页面配置券商账号 (Futu OpenD 或 IBKR)
2. 选择策略 → 设置风控参数
3. 启用自动交易开关
4. 策略触发→自动下单 (仅桌面端在线时)
5. **手续费**: 0.1% taker / 0.02% maker / 0.04% taker (平台收)

### 风险管控
- 单日亏损上限 (默认2%)
- 单标的仓位上限 (默认20%)
- 自动交易暂停条件
- 模拟盘→实盘切换确认

## 六、P2P转账

### 发起转账
1. 进入"钱包"→"转账"
2. 输入对方用户ID和金额
3. 确认 → 系统扣除 0.3% 手续费
4. 对方收款 → 对方扣除 0.3%

### 冻结与申诉
- 转账后进入14天冻结期
- **正常交易**: 1-5分钟到账 (冻结期内可用)
- **争议申诉**: 冻结期内提交，4选1原因:
  A. 收款方未确认
  B. 对方未按约定
  C. 账号异常
  D. 其他 (需填写说明)
- 买方取消自动解锁
- 管理员仅系统异常时手动解冻

## 七、4Agent AI协作

### 4个Agent角色
| Agent | 分析什么 | 数据来源 |
|-------|----------|----------|
| 基本面 | 财报/利润/估值 | Yahoo Finance + 东方财富 |
| 技术面 | K线/指标/趋势 | quant-strategy + Alpha Vantage |
| 新闻 | 实时新闻/政策 | NewsAPI + 东方财富新闻 |
| 宏观 | 利率/汇率/宏观 | Yahoo macro + 自研多源 |
| 情绪 | 社交媒体情绪 | StockTwits + Reddit + 自研 |

### AI协作流程
1. 选股票 → 选Agent数量 → 付费 → 开始
2. 4Agent各自分析 (20-90秒)
3. 圆桌辩论 (2轮)
4. 投票: BUY/SELL/HOLD/分数
5. 生成信号 → 可保存/发布

### LLM
- 默认: DeepSeek V4 Pro (折后)
- 备选: V4 Flash → MiniMax M3 自动降级
- 缓存命中 ≥90%，单次成本 $0.016

## 十、常见问题

**Q: 平台能看到我的券商账号吗？**
A: 你的券商账号在你的电脑本地，平台服务器不存储。

**Q: AI分析准确率多高？**
A: 历史胜率约55-65%，不保证收益。AI信号 = 参考，需自己判断。

**Q: 为什么我的AI分析结果和别人不同？**
A: 每次分析受实时数据和Agent投票影响，结果会变化。

**Q: 提现多久到账？**
A: TRC-20通常5-30分钟。大额需人工审核。

**Q: 可以退款吗？**
A: AI分析完成后不退款。订阅可随时取消，当月有效。
