## 场景清单

### 场景 1: Dashboard 总资产概览
- **文件**: `scene01-dashboard.png`, `scene01-equity.png`
- **内容**: 应用启动后的主界面，总资产/现金/市值/今日盈亏 4 卡片，净值曲线
- **时长**: 50 秒

### 场景 2: Market 行情页面
- **文件**: `scene02-market.png`, `scene02-kline.gif`
- **内容**: 股票列表、K-line 图表、周期切换
- **时长**: 50 秒

### 场景 3: Strategy 策略模板
- **文件**: `scene03-strategy.png`, `scene03-new-strategy.png`
- **内容**: 15+ 策略模板、新建策略表单、参数配置
- **时长**: 60 秒

### 场景 4: Backtest 回测执行
- **文件**: `scene04-backtest.png`, `scene04-equity.gif`
- **内容**: 回测进度、年化收益/夏普/最大回撤、净值曲线
- **时长**: 60 秒

### 场景 5: TradeDashboard 交易台
- **文件**: `scene05-trade.png`, `scene05-pnl.png`
- **内容**: Paper/Real 模式切换、持仓列表、订单历史、每日盈亏
- **时长**: 60 秒

### 场景 6: RiskDashboard 风控面板
- **文件**: `scene06-risk.png`, `scene06-emergency.gif`, `scene06-kelly.png`
- **内容**: 7 个风控指标、紧急停止按钮、Kelly 建议仓位
- **时长**: 60 秒

### 场景 7: AlertCenter 告警中心
- **文件**: `scene07-alert.png`, `scene07-alert-detail.png`
- **内容**: 告警列表、级别颜色、确认机制
- **时长**: 50 秒

### 场景 8: Settings 配置页面
- **文件**: `scene08-settings.png`, `scene08-brokers.png`
- **内容**: Futu/Moomoo/IB 券商配置、风控配置
- **时长**: 50 秒

### 场景 9: Sidebar 导航 + 多语言
- **文件**: `scene09-nav.gif`, `scene09-english.png`
- **内容**: 12 页面导航切换、语言切换（如可用）
- **时长**: 40 秒

### 场景 10: Installer 安装流程
- **文件**: `scene10-*.png`, `scene10-install.gif`
- **内容**: .exe 图标、安装向导、启动验证
- **时长**: 60 秒

### 场景 11: WebSocket 实时数据
- **文件**: `scene11-ws.gif`, `scene11-risk-pnl.png`, `scene11-disconnected.png`
- **内容**: 实时价格更新、连接断开恢复
- **时长**: 60 秒

### 场景 12: Paper Trading 模拟下单
- **文件**: `scene12-order.gif`, `scene12-positions.png`, `scene12-history.png`, `scene12-allocation.png`
- **内容**: 模拟下单、持仓更新、订单历史、资产分配
- **时长**: 70 秒
