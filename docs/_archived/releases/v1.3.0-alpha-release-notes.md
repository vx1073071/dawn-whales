## 🎉 v1.3.0-alpha：商业化首版

v1.3.0-alpha 是 TradingEasy 首个商业化版本，引入**按次付费 + 平台抽成**。

### 新增功能

- **按次计费**: 3 档定价（1.0/1.5/2.0 USDT）
- **新创作者福利**: 首 3 次免费
- **USDT 充值**: TRC-20 通道
- **平台抽成**: L1(70/30) L2(80/20) L3(90/10)
- **模拟执行**: AI 信号→模拟订单全链路
