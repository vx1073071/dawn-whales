## 📖 升级指南

### 从 v0.13.0 升级

#### 步骤 1: 备份数据

```bash
# 备份配置
quant-moo --backup-config

# 备份数据
quant-moo --backup-data
```

#### 步骤 2: 下载新版本

- Windows: `quant-moo-Setup-1.0.0.exe` (85MB)
- macOS: `quant-moo-1.0.0.dmg` (92MB)
- Linux: `quant-moo-1.0.0.AppImage` (78MB)

#### 步骤 3: 安装

**Windows**:
```powershell
# 双击运行安装程序
.\quant-moo-Setup-1.0.0.exe

# 或使用命令行静默安装
.\quant-moo-Setup-1.0.0.exe /S
```

**macOS**:
```bash
# 打开 DMG 文件
open quant-moo-1.0.0.dmg

# 拖拽到 Applications 文件夹
# 或使用命令行
cp -R "quant-moo.app" /Applications/
```

**Linux**:
```bash
# 添加执行权限
chmod +x quant-moo-1.0.0.AppImage

# 运行
./quant-moo-1.0.0.AppImage

# 或创建桌面快捷方式
./quant-moo-1.0.0.AppImage --install
```

#### 步骤 4: 验证

```bash
# 检查版本
quant-moo --version
# 应输出: 1.0.0

# 运行健康检查
quant-moo --health-check

# 检查性能
quant-moo --performance-check
```

#### 步骤 5: 恢复数据（如需要）

```bash
# 恢复配置
quant-moo --restore-config

# 恢复数据
quant-moo --restore-data
```

### API 变更

#### 新增 API

1. **风险评分 API**
   ```typescript
   interface GetRiskScoreRequest {
     portfolioId: string;
   }
   
   interface GetRiskScoreResponse {
     score: number;
     level: 'low' | 'medium' | 'high';
     factors: RiskFactor[];
   }
   ```

2. **审计日志 API**
   ```typescript
   interface GetAuditLogsRequest {
     startDate: string;
     endDate: string;
     action?: string;
   }
   
   interface GetAuditLogsResponse {
     logs: AuditLog[];
     total: number;
   }
   ```

3. **合规性报告 API**
   ```typescript
   interface GenerateComplianceReportRequest {
     startDate: string;
     endDate: string;
     rules?: string[];
   }
   
   interface GenerateComplianceReportResponse {
     reportId: string;
     status: 'COMPLIANT' | 'NON_COMPLIANT' | 'PARTIAL';
     score: number;
   }
   ```

#### 废弃 API

无废弃 API，所有 v0.13.0 API 在 v1.0.0 中继续支持。

### 配置变更

#### 新增配置

```json
{
  "riskControl": {
    "enabled": true,
    "threshold": 0.8,
    "alertDelay": 500
  },
  "audit": {
    "enabled": true,
    "retentionDays": 90,
    "hashAlgorithm": "sha256"
  },
  "compliance": {
    "enabled": true,
    "autoGenerateReports": true,
    "reportFrequency": "weekly"
  },
  "monitoring": {
    "enabled": true,
    "alertChannels": ["email", "webhook"],
    "alertThreshold": 0.9
  }
}
```

#### 配置迁移

v0.13.0 配置自动迁移到 v1.0.0，无需手动修改。

## ⚠️ 已知问题

### 轻微问题

1. **部分视频教程缺失**
   - 影响: 用户体验
   - 计划: v1.0.1 添加
   - 临时方案: 参考文档说明

2. **部分截图待更新**
   - 影响: 文档完整性
   - 计划: v1.0.1 更新
   - 临时方案: 参考文字说明

### 限制

1. **AI 助理依赖 LLM**
   - 限制: LLM 不可用时使用模板响应
   - 缓解: 模板覆盖主要场景
   - 计划: v1.1.0 支持本地模型

2. **实时数据依赖网络**
   - 限制: 离线时无法获取实时数据
   - 缓解: PWA 缓存历史数据
   - 计划: v1.1.0 增强离线功能

3. **多账户同步**
   - 限制: 多账户数据不自动同步
   - 缓解: 手动导出/导入
   - 计划: v1.1.0 添加云同步
