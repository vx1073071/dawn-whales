# TradingEasy v0.7.0 Release Notes

**版本**: v0.7.0
**发布日期**: 2026-06-06
**代号**: Multi-Broker
**上一版本**: v0.6.0

---

## 概述

v0.7.0 是 TradingEasy 的第一个**多券商可用**版本。在 v0.6.0 的基础上，我们完成了 Interactive Brokers (IB) 适配器骨架、策略-券商绑定、多券商 UI 集成，并大幅扩展了测试覆盖。从此，TradingEasy 不再局限于单一券商——你可以在同一个平台上管理 Futu、Moomoo 和 IB 三家券商的账户。

---

## 新特性

### 多券商支持

- **Interactive Brokers (IB) 适配器** (`electron/broker/ib-adapter.ts`, 1,768 行)
  - IB Gateway/TWS TCP 连接骨架（port 4001/7496）
  - 12 个美股合约映射：AAPL、MSFT、GOOGL、NVDA、TSLA 等
  - Mock 行情推送 + K 线数据生成器
  - 支持 MARKET / LIMIT / STOP 订单类型

- **策略-券商绑定** (`StrategyBrokerSelector.tsx`)
  - 创建策略时可选择执行券商（Futu / Moomoo / IB）
  - 订单自动路由到指定券商适配器
  - UI 实时显示当前策略绑定的券商状态

- **多券商 UI 集成**
  - Dashboard 顶部 `BrokerStatusBar`：显示当前活跃券商和连接状态
  - Sidebar 底部 `AccountSummary`：跨券商资产汇总（Futu $XXX | Moomoo $XXX | IB $XXX）
  - Settings 页面新增「券商设置」Tab：配置各券商连接参数

### 测试覆盖大幅提升

- **总测试数**: 149 → **259** (+110, +74%)
- **测试文件**: 7 → **11** (+4)
- **新测试**:
  - `nl-parser.test.ts` (42 tests)：中文自然语言指令解析全覆盖
  - `strategy-engine.test.ts` (29 tests)：策略状态机/信号生成/错误恢复
  - `multi-broker-ipc.test.ts`：多券商 IPC 消息路由/账户聚合/订单分发
  - `e2e-multi-broker.test.ts` (13 tests)：跨券商端到端验证

### Moomoo 真实 TCP 连接

- Moomoo OpenD 真实 TCP 连接（port 11211）
- 二进制协议解析器
- Auto-fallback 到 Mock 模式（连接失败时自动降级）

## 已知限制

1. **IB 适配器为 Mock 模式**：真实 IB Gateway 连接需要 IB 账户和 TWS/Gateway 软件，当前版本提供 Mock 数据以确保 UI 可用。
2. **Moomoo 实盘验证进行中**：R28 正在进行真实 OpenD 验证，文档将后续补充。
3. **OpenDBaseAdapter 重构推迟**：Futu/Moomoo 代码复用基类计划在 R29 实施。
4. **语言切换器集成状态**：i18n 配置已就绪，但 UI 切换器可能未完全集成到所有页面。

## 升级指南

### 从 v0.6.0 升级

1. 备份 `data/` 目录（持仓、订单、策略数据）
2. 卸载旧版本
3. 安装 `TradingEasy Setup 0.7.0.exe`
4. 启动后进入 Settings → 券商设置，配置 Futu/Moomoo/IB 连接参数
5. 创建策略时选择目标券商

### 首次安装

1. 下载 `TradingEasy Setup 0.7.0.exe`
2. 运行安装向导
3. 启动应用
4. Settings → 券商设置 → 配置至少一家券商
5. Dashboard → 确认连接状态为绿色
