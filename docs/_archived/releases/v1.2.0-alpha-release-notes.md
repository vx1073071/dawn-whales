## 🎉 重大更新

### AI 协作功能 (AI Collaboration)

v1.2.0-alpha 推出了全新的 **AI 协作功能**，通过 4 个专业 AI Agent 协作分析，帮助创作者生成高质量交易策略。

#### 核心特性

- 🤖 **4 Agent 协作**: 基本面/情绪/新闻/技术分析师协作分析
- 💰 **成本可控**: 单次分析成本低至 0.016 USDT（约 0.12 元人民币）
- 🔄 **智能降级**: 主模型不可用时自动切换到备用模型
- 📊 **高质量输出**: 多维度分析，生成可执行的交易策略

#### 3 档定价方案

| 档位 | Agent 数 | 价格 | 适用场景 |
|-----|---------|------|---------|
| 标准档 | 2 | 1.0 USDT | 日常策略分析 |
| 高级档 | 3 | 1.5 USDT | 重要决策分析 |
| 旗舰档 | 4 | 2.0 USDT | 重大投资决策 |

#### 技术架构

- **自研架构**: TypeScript 原生集成，0 协议依赖
- **默认 LLM**: DeepSeek V4 Pro (折后，99% 缓存折扣)
- **降级链**: V4 Pro 折后 → V4 Pro 原价 → V4 Flash → MiniMax-M3
- **缓存命中率**: ≥90%
- **单次成本**: ≤0.02 USDT

## ✨ 新增功能

### 1. AI 协作面板 (AICollaborationPanel)

全新的 AI 协作界面，支持：
- 选择档位 (标准/高级/旗舰)
- 输入策略需求
- 实时显示分析进度
- 查看 4 Agent 分析结果
- 保存策略到策略库

### 2. Agent 状态可视化 (AgentStatusVisualizer)

实时显示 4 Agent 的工作状态：
- 基本面分析师状态
- 情绪分析师状态
- 新闻分析师状态
- 技术分析师状态
- 辩论进度

### 3. 成本预估器 (CostEstimator)

实时预估 AI 协作成本：
- 根据档位显示成本
- 显示缓存命中率
- 显示月度预算使用情况

## 🔄 升级指南

### 从 v1.1.0-beta 升级

1. **备份数据**
   ```bash
   # 备份策略库
   cp -r ~/.quant-moo/strategies ~/.quant-moo/strategies.backup
   ```

2. **下载新版本**
   ```bash
   # Windows
   download quant-moo-1.2.0-alpha.exe
   
   # macOS
   download quant-moo-1.2.0-alpha.dmg
   
   # Linux
   download quant-moo-1.2.0-alpha.AppImage
   ```

3. **安装新版本**
   ```bash
   # Windows
   quant-moo-1.2.0-alpha.exe
   
   # macOS
   open quant-moo-1.2.0-alpha.dmg
   
   # Linux
   chmod +x quant-moo-1.2.0-alpha.AppImage
   ./quant-moo-1.2.0-alpha.AppImage
   ```

4. **配置 LLM**
   ```
   设置 → AI 协作 → LLM 配置
   
   默认 LLM: DeepSeek V4 Pro (折后)
   API Key: [你的 API Key]
   ```

## 🔄 降级链机制

### 默认降级链

```
1. DeepSeek V4 Pro (折后) ← 默认 (99% 缓存折扣)
   ↓ (不可用时)
2. DeepSeek V4 Pro (原价) ← 备用 1 (96.6% 毛利)
   ↓ (不可用时)
3. DeepSeek V4 Flash ← 备用 2 (99.5% 毛利)
   ↓ (不可用时)
4. MiniMax-M3 ← 兜底 (0 成本, 自家模型)
```

### 降级触发条件

- 网络超时 (>10s)
- 服务不可用 (HTTP 5xx)
- 配额用尽 (HTTP 429)
- 认证失败 (HTTP 401/403)
