## 🎯 关键特性

### 1. PWA 支持 (Progressive Web App)
- Service Worker + Manifest 配置
- 4 种缓存策略 (stale-while-revalidate / network-first / cache-first)
- 安装提示 + 离线访问
- shortcuts + standalone mode

### 2. 移动端导航
- 5-tab bottom bar (Dashboard/Strategy/Market/Portfolio/More)
- More menu overlay (Orders/Backtest/Marketplace/Settings)
- 触摸优化 + Badge counters
- 44px 最小点击区域

### 3. Onboarding 引导
- 5 步引导流程 (Welcome → Connect → Create → Backtest → Trade)
- localStorage 持久化
- 跳过选项
- 进度条 + 步骤指示

### 4. RiskEngineV3 (风险引擎升级)
- 多券商账户聚合 (aggregateAccounts)
- FX 折算 (USD/CNY/EUR/SGD/JPY → HKD)
- 30s 缓存 + forceRefresh 绕过
- 保证金率 + 风险等级 (safe/warning/danger)
- 投资组合风险敞口 (sector/geography/assetClass)
- HHI 集中度风险指标
