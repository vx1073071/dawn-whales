## 🎯 核心特性

### 🎛️ PerformanceMonitor 性能监控 (JVS)

- **CPU/内存/延迟/QPS 实时采集**: 自动采集系统性能指标，支持多账户对比
- **性能告警规则引擎**: 灵活配置告警阈值 (CPU > 80% / 内存 > 90% / 延迟 > 500ms)
- **性能趋势分析 (线性回归)**: 1h/1d/7d 趋势可视化，提前预警
- **多账户性能对比**: 横向对比多个账户的策略性能
- **文件**: `electron/engine/performance-monitor.ts` (991L, 57 tests)

### 🌊 实时数据流增强 (JVS)

- **WebSocket 数据流优化**: 心跳检测、自动重连、指数退避 (1000ms→60s)
- **实时数据聚合 (多源融合)**: 5 优先级队列 (quote=1 / kline=2 / depth=3 / tick=4)
- **数据质量实时监控**: 完整性/及时性/准确性三维评分
- **异常检测 (z-score/IQR)**: 实时检测价格/成交量突变
- **环形缓冲区**: 5000 ticks per symbol，自动丢弃最旧
- **批处理窗口**: 100ms dispatch，平衡延迟与吞吐
- **文件**: `electron/engine/realtime-data-flow.ts` (1167L, 51 tests)

### 🖥️ 性能监控大盘 UI (JVS)

- **实时性能指标仪表盘**: CPU/内存/延迟/QPS 折线图
- **多账户性能对比图表**: 横向柱状图 + 雷达图
- **性能告警历史**: 最近 20 条告警，可关闭/确认
- **性能趋势可视化**: 时间范围选择器 (1h/1d/7d)
- **文件**: `src/components/dashboard/PerformanceMonitorPanel.tsx` (1211L)

### 🪟 PC 沉浸式多面板布局 (ML)

- **3 预设布局**: 单面板 / 横向双栏 / 4 宫格
- **可拖拽分隔条**: 鼠标拖动调整面板大小
- **布局记忆**: localStorage 持久化用户偏好
- **面板插槽**: top-left / top-right / bottom-left / bottom-right
- **文件**: `src/components/layout/MultiPanelLayout.tsx` (212L)

### 🔬 A/B 策略对比器 (ML)

- **双策略并排**: 左右分屏同步时间轴
- **4 维雷达图**: 胜率 / Sharpe / 最大回撤 / 收益
- **6 指标对比表**: 收益/夏普/回撤/胜率/年化波动/Calmar
- **资金曲线叠加**: SVG 多曲线对比
- **文件**: `src/components/strategy/StrategyComparer.tsx`

### 🔔 桌面通知桥接 (ML)

- **策略信号通知**: 买入/卖出信号实时桌面弹窗
- **止损/止盈触发**: 风险事件即时提醒
- **风控告警推送**: 集中度/回撤/杠杆告警
- **历史记录**: 最近 20 条通知
- **声音控制**: 可静音模式

## 📦 安装与升级

### 新安装

```bash
git clone https://github.com/vx1073071/tradingeasy.git
cd dawn-whales
git checkout v0.9.1-alpha
npm install
npm run dev
```

### 从 v0.9.0 升级

```bash
git fetch origin
git checkout v0.9.1-alpha
npm install
npm run dev
```

### 桌面通知权限

桌面通知功能需要用户授权。首次触发时会弹窗请求权限，请选择"允许"以启用实时策略信号提醒。
