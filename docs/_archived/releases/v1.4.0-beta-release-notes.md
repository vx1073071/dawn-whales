## 🎉 v1.4.0-beta：多市场扩展

v1.4.0-beta 从港股扩展到 **A 股 + 美股**，引入信号广场和云端部署。

### 新增功能

- **A 股 + 美股**：完整交易链路
- **云端 OpenD**：远程部署
- **碎股**：A 股 1-99 股 / 美股 1 股起
- **信号广场**：策略信号发布/订阅/排名

### 永久支付规则

**仅 USDT 积分**。充值 0 手续费 / 提现 0.1%。无 Stripe/信用卡。

## 信号广场快速指南

### 发布信号

策略编辑页 → 「发布到信号广场」

### 订阅信号

信号广场 → 搜索/筛选 → 一键订阅 → 跟单执行

### 信号质量评分

每信号显示 7 日表现：胜率 / 夏普 / 最大回撤
