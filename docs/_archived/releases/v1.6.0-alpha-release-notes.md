# 4Agent 数据源真实接入指南

**版本**: v1.6.0-alpha  
**更新时间**: 2026-06-09  
**作者**: youdao  

---

## 1. 概述

v1.6.0-alpha 移除所有 MOCK 数据，4Agent (基本面/技术面/情绪/宏观) 全部接入真实数据源。

### 10 数据源

| Agent | 数据源 | 覆盖 |
|-------|--------|------|
| 基本面 | em-mx-finance(中) + Yahoo Finance(美) | A/港/美 |
| 技术面 | quant-strategy(自研) + Alpha Vantage(美) | A/港/美 |
| 新闻 | em-mx-news-search(中) + NewsAPI(美) | 中/美 |
| 情绪 | 微博/雪球(中) + StockTwits/Reddit(美) | 中/美 |
| 宏观 | 自研多源 + Yahoo macro | 全球 |

---

## 2. 多源交叉验证

每个 Agent 至少 2 个数据源，A 源失败自动降级到 B 源。

```
基本面: em-mx-finance → Yahoo Finance (降级)
技术面: quant-strategy → Alpha Vantage (降级)
```

---

## 3. 数据源状态

| 状态 | 说明 |
|------|------|
| ONLINE | 正常 |
| DEGRADED | 部分失败，降级运行 |
| OFFLINE | 全部失败，提示不可用 |

### 质量评分

创作者面板可查看当前数据源状态和质量评分。
