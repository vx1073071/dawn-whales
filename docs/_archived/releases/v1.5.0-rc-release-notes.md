## 🎉 v1.5.0-rc：服务器化 + 防破解

v1.5.0-rc 完成关键防破解架构：AI/计费/钱包/许可从桌面端迁移到 `/api`，桌面端变遥控器。

### 🔒 防破解核心

- **AI Gateway `/api`**：DeepSeek key 仅在服务端，桌面端纯粹转发
- **计费云端验证**：扣费由服务端执行，桌面端无法跳过
- **钱包服务端管理**：私钥不暴露在客户端
- **许可证系统**：激活码 + 7 天试用 + 吊销

### 架构变更

```
v1.4.0: 桌面端(全功能) → 破解 = 白嫖
v1.5.0: 桌面端(遥控器) → /api(核心) → 安全
```

### 桌面端清理

- 删除 AI key 硬编码
- 删除本地计费/钱包逻辑
- 删除后台管理 UI → 独立 `/admin`
- 保留：策略计算 + Futu OpenD + 缓存
