## 二、🚨 致命缺陷：人类认知断崖

### 2.1 「学术墙」— 用户在第3屏弃用

**场景**: 用户做完因子发现向导，兴奋地看到"您的因子IC=0.045，IR=0.72"。

**人类反应**: "这数字好还是不好？0.045 IC 对我来说意味着什么？"

**当前问题**:
- `FactorExposurePage.tsx` 直接展示 p-Value、t-Stat、显著性星号
- `FactorFormula.tsx` 展示 `β_MKT = Cov(R_i, R_m) / Var(R_m)` （90%用户看不懂）
- `dawn-factor-framework.ts` 输出了大量中间计算指标，但是没有一行"翻译成人类语言"

**行业标杆对比**:
- **JoinQuant 因子看板**: 每个因子先给出"一句话结论"再展示数据
- **Bloomberg Terminal**: "This factor is currently in the 85th percentile of historical effectiveness"
- **Robinhood**: 所有复杂数据默认折叠，只显示"你的策略比大盘好/差 X%"

**具体建议 —「翻译层」**:

在 `factor-summary-engine.ts` 增加 `humanize()` 方法:
```typescript
// 当前输出
{ factor: "MOM_12M", ic: 0.045, ir: 0.72, pValue: 0.003 }

// 期望输出
{
  oneLiner: "动量因子目前有效（IC=0.045，好于历史上70%的时间）",
  strength: "中等偏强",
  reliability: "稳定（IR>0.5）",
  warning: null,
  actionHint: "当前权重可维持，建议每30天复查一次"
}
```

### 2.2 「碎片化工作流」— 8次页面跳转

**场景**: 用户想做一个完整的因子策略:

```
当前路径 (8次跳转):
  ① StrategyPage (6种模式选择) → 
  ② FactorDiscoveryWizard (选因子) →
  ③ FactorCompareDashboard (对比) →
  ④ StrategyOptimizerPanel (优化) →
  ⑤ BacktestPanel (回测) →
  ⑥ FactorExposurePage (看暴露) →
  ⑦ StrategyComparer (对比) →
  ⑧ 手动回 StrategyPage 修改参数
```

**人类期望**: 像一条河，顺流而下。

```
理想路径 (1个Workbench, 0次跳转):
  FactorLab (统一工作台)
  ├─ 左侧面板: 因子库 (44个，可搜索/筛选)
  ├─ 中间面板: 当前工作区 (拖入因子 → 自动构建组合)
  ├─ 右侧面板: 实时反馈 (IC/IR/相关性/回测即时预览)
  └─ 底部: 一键 "AI优化 → 回测 → 上线" 进度条
```

**具体建议**: 新建 `FactorLab.tsx` 统一工作台，把6个空壳组件（AICreator等）的 slot 用真实内容填充。

### 2.3 「反馈延迟」— 改了参数不知道效果

**当前**: 用户调完因子权重 → 点"回测" → 等30秒 → 看结果 → 发现不对 → 回去改 → 再等30秒。

**人类习惯**: 像拧音响旋钮，拧多少听到多少变化。即时反馈。

**行业对比**: Figma的实时预览、TradingView的策略回测即时叠加到K线。

**具体建议 —「Live Mini-Backtest」**:
- 用户拖动 `FactorWeightSlider` → 最近1年mini回测自动触发 → ＜3秒出结果
- 绿色箭头/红色箭头实时显示变化方向
- 仅在用户满意后点击"完整回测(3年)"才做全量

### 3.2 收费心理设计（不是简单加个按钮）

**错误做法**: "AI优化建议 (1.5 USDT)" — 用户看到价格就走。

**正确做法 —「渐进式免费→付费」**:

```
Step 1 (免费): 健康评分: 52分 "你的策略存在2个风险点"
  → 用户好奇是什么风险

Step 2 (免费): 展开诊断面板 "动量因子IC加速下降，拥挤度处于警告水平"
  → 用户看到具体问题，产生焦虑

  → 用户已经投入注意力，付费转化率 15-25%

  → 交叉销售，转化率 30-40%（已付费用户）
```

**关键原则**: 
- 免费展示"有什么问题"（钩子）
- 付费展示"怎么解决"（价值）
- 不让用户在决策前看到价格（先建立需求）

## 四、🧠 人类认知UX — 6项深度打磨

### 4.1 「新手→专家」渐进式学习路径

**当前**: 因子系统对所有用户一视同仁。新手和老手看到同样的学术数据。

**人类学习行为**: 
- 第1天用户: "什么是IC？我只想知道这策略能赚钱吗"
- 第7天用户: "IC和IR有什么区别？哪个更重要？"
- 第30天用户: "为什么动量因子的IC最近下降了？是衰减还是拥挤？"

**建议 — 3级信息披露**:

| 级别 | 目标用户 | 展示内容 | 触发条件 |
|------|---------|---------|---------|
| L1 速览 | 所有人 | 一句话结论 + 红绿灯 | 默认页 |
| L2 分析 | 7天+ | IC趋势图 + 因子对比 | 点击"了解更多" |
| L3 深度 | 30天+ | 完整学术指标 + 原始数据 | 点击"专家模式" |

### 4.2 「因子百科全书」— 每个因子都是故事

**当前**: `FactorCard.tsx` 有 hover popover，但内容偏技术。

**建议**: 每个因子有一个"人类故事":

```
┌─ 动量因子 (MOM_12M) ──────────────────────────┐
│                                                  │
│ 📖 一句话: "过去12个月涨得好的股票，倾向于继续涨"     │
│                                                  │
│ 🏆 历史战绩: A股过去5年IC=0.045 (中上水平)         │
│ ⚠️ 注意: 在风格切换时容易失效                       │
│ 🌍 最适合: 趋势明显的市场（牛市/熊市前期）            │
│ 🌧️ 最弱时: 震荡市中表现差                          │
│ 🔗 好搭档: 低波因子（互补，降低回撤）               │
│ 🚫 冲突: 价值因子（逻辑相反）                       │
│                                                  │
│ [查看详细数据]  [AI分析当前状态(1U)]                │
└──────────────────────────────────────────────────┘
```

### 4.3 「因子健身房」— 因子组合模拟器

**人类类比**: 健身房的器械区。用户想"试试这个组合效果如何"。

**建议**: 
- 拖拽因子到"训练区" → 实时显示IC/相关性/最大回撤
- 预设"训练计划": 动量+低波 / 价值+质量 / 小盘+动量
- 一键"开始完整回测"

### 4.4 「因子社交」— 对比和分享

**当前**: 用户做完因子分析，无法与任何人对比或分享。

**人类心理**: 
- "我的动量因子IC得分如何？" — 没有对比基准
- "朋友圈看看大家都在用什么因子" — 无社交功能

**建议**:
- **因子排行榜**: "当前最热门因子 Top 10"（基于社区使用数据）
- **我的因子 vs 平均**: "你的动量因子IC超过85%的用户"
- **分享卡片优化**: `StrategyShareCard.tsx` 加水印"Dawn Whales" + 二维码

### 4.5 「智能提醒」— 因子需要养

**当前**: 因子衰减/拥挤检测在引擎中有 ⚠️，但用户不会天天去看。

**人类习惯**: 设好就不管了。

**建议 —「因子保姆」**:
```
每日/每周推送:
  📊 因子健康日报 (2026-06-14)
  🟢 动量因子: 正常 (IC=0.043)
  🟡 价值因子: 衰减中 (IC从0.038→0.025) → [查看详情]
  🔴 小盘因子: 过度拥挤 (82%分位) → [AI诊断(1U)]
```

### 4.6 「后悔药」— 回测记录天然存档

**当前**: 修改参数后，旧回测结果被覆盖。

**人类心理**: "刚才那个参数跑出来是多少来着？" — 后悔了想回去看。

**建议**:
- 每次回测自动保存为"快照"，可命名可对比
- 快照列表: "上周五的版本 (夏普2.1)" / "今天上午的版本 (夏普2.4)"
- 一键恢复到任意快照

5. **没引导** — 新手不知道从哪开始
