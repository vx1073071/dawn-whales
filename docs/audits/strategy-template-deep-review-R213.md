## 一、执行摘要

44模板体系框架扎实（1984行，权重全部100%，四铁律完整，TSC 0），但从**人类真实使用习惯**角度看，存在 6 大类问题——其中 3 项为 🔴 急修项。

### 核心发现：用户只花 6 分钟研究就下单

Forbes 2025 研究: 零售投资者平均仅花 **6分钟** 研究一只股票就做出交易决策。这意味着：

> ❌ 用户不会认真读200字的四铁律和180字的止损规则  
> ❌ 用户不会对比5个因子组合的差异  
> ❌ 用户不会在3个AI触点中理性选择"我需要哪个"  
> ✅ 用户会**凭感觉选一个顺眼的，点一下，看结果，对了继续，错了放弃**

**我们的模板体系是为"理性分析师"设计的，而不是为"6分钟决策的散户"设计的。**

## 二、🔴 P0 急修项（影响用户留存与合规）

### 2.1 四铁律违规 — `humanLine` 超长 (2/44)

```typescript
// crypto-eth-btc-rotation — 84字, 超过80字限制
"ETH/BTC汇率>0.07+ETH gas费上升→ETH强于BTC时超配ETH，BTC强时超配BTC..."

// au-asx-resource-franking — 86字, 超过80字限制  
"买入澳洲矿业巨头(BHP/RIO/FMG)+银行股(CBA/NAB)，吃矿价上涨..."
```

**影响**: 四铁律是创作者审核的 #1 检查项。自己官方模板违反，审核标准形同虚设。

**修复**: 将以上2条压缩至 ≤80 字。

---

### 2.2 四铁律违规 — `marketScope` "全市场通用" (21/44 含"全市场")

21个模板在 `marketScope`、`humanLine` 或 `failureCheck` 中出现了"全市场"字样。四铁律 #3 明确要求"标明具体市场，不能全市场通用"。

**问题模板示例**:
| 模板ID | 含"全市场"字段 |
|--------|--------------|
| `hk-reit-yield` | humanLine: "适合喜欢收租不喜欢折腾的全市场保守派" |
| `xm-fx-hedge` | marketScope: 含 `all_markets` 语义 |
| `ai-arbitrage-engine` | failureCheck: "全市场套利窗口关闭" |

**影响**: 
- 策略本身跨市场是合理的（套利/对冲），但必须逐一列出，不能用"全市场"一词
- 平台文档承诺(v17.9) "不能全市场通用"，存在合规风险

**修复**: 将"全市场"替换为具体市场列表。

### 2.3 AI计费透明度缺失 — 用户不知不觉花完余额

**现状问题**:
```
用户打开 hk-ah-premium 模板 → 看到3个AI按钮:
  [AI回测解读 1U] [AI参数优化 1.5U] [替代数据解锁 2U]
  → 点了第一个 → 花1U → 回测结果不好
  → 点第二个 → 花1.5U → 优化结果一般  
  → 点第三个 → 花2U → 解锁替代数据
  → 合计: 4.5U 花完，策略还没开始交易
```

**数据**: 
- 31个模板(70%)只有3个AI触发点 → 3次点击=3.5-5U
- 13个模板有4个AI触发点 → 4次点击=4.5-6U
- 加上 `blind_box_unlock`(1U×2) + `backtest`(1U) + `optimize`(1.5U) = 用户可能在**交易前花 8-12U**

**修复方案**:
1. **总费用预览**: 模板详情页顶部显示 "此模板AI增值功能合计: X USDT"
2. **智能推荐1个**: 不是并列3-4个按钮，而是AI根据用户画像推荐**最适合的1个**先试
3. **首次半价**: 新用户首次使用某个AI触点 = 半价(0.5U)，用过一次后恢复原价
4. **"套餐"按钮**: 一键购买全部AI功能 = 原价 4.5U → 套餐 3U (节省33%)

## 三、🟡 P1 核心打磨项 (v2.2.0)

### 3.1 AI触发点分布严重不均

| 触发点 | 覆盖模板数 | 占比 | 问题 |
|--------|:---------:|:---:|------|
| AI因子深度诊断 (1U) | 40/44 | 91% | 过度集中，几乎每个模板都有 |
| AI回测解读 (1U) | 33/44 | 75% | 同上 |
| AI参数优化 (1.5U) | 20/44 | 45% | 只有半数模板有 — 收入漏了 |
| AI信号推送 (0.5U) | 18/44 | 41% | **最高频收入源但覆盖最低** |
| 替代数据解锁 (2U) | 12/44 | 27% | 最贵但最少 — 收入潜力未挖掘 |
| AI健康检查 (1U) | 8/44 | 18% | 对"买了不管"的用户极有价值 |
| AI压力测试 (2U) | 2/44 | 5% | 机构用户必点，散户也应该看到 |

**建议**: 
- 信号推送(0.5U) → 加到至少 35/44 模板 (每天0.5U×30天=15U/月/模板 — **这是订阅级收入**)
- 替代数据(2U) → 加到至少 25/44 模板 (最高单价)
- 健康检查(1U) → 加到至少 30/44 模板 (适合初级用户"定期体检")

---

### 3.2 无用户能力分层 — 初级用户看不懂，高级用户不过瘾

**现状**: 44模板难度分布为 ⭐1:6个, ⭐2:14个, ⭐3:14个, ⭐4:11个 — **看似分散，实则不匹配用户**。

**问题**:
- ⭐1的模板(hk-reit-yield, hk-ipo-flip等) 名字看起来简单，但因子组合(hk-ipo-flip含6因子!) 让新手恐惧
- ⭐4的模板(ai-arbitrage-engine, ai-hedge-enhanced) 描述太技术化，高级用户会说"就这？"
- 没有**引导式晋级路径**: 用户不会自然地从⭐1升到⭐4

**对照组**: 
- **Futu牛牛**: 用户分三级 — "新手看推荐"→"进阶用筛选器"→"专业写脚本"
- **TradingView**: 策略模板按"热门"→"社区评分"→"策略复杂度"三维排序

**建议修复**:
```
用户等级体系:
  🟢 小白 (注册<7天 + 交易<5笔) → 推荐⭐1-2的4个模板 + 每个配"一句话解释"
  🟡 进阶 (注册>7天 + 交易≥5笔) → 展示⭐2-3模板 + AI健康检查醒目
  🔴 专业 (交易≥50笔) → 全量⭐4-5模板 + 自定义因子权重
  🏆 创作者 → 上传自己的模板 → 收取打赏
```

### 3.3 DeepSeekChat 只有 13/44 模板有 — 用户体验断层

`DeepSeekChatConfig` 是 v2.1.0 的核心差异化功能（对话式AI调参），但只覆盖了 29.5% 的模板。

**问题**: 一个用户先用 `ai-momentum-chaser`(有DeepSeekChat, 可以"对话调整参数")，然后切换到 `hk-ah-premium`(无DeepSeekChat, 只有静态按钮) —— 体验严重降级。

**建议**: v2.2.0 为**所有 44 模板**添加 DeepSeekChatConfig:
- 非AI模板: 简化版 (systemPrompt 用模板名+一句描述)
- AI模板: 保持现有完整版
- 统一交互模式: 用户不需要知道"这个模板可以聊那个不能聊"

### 3.4 模板分类体系混乱 — `category` vs `MarketTag`

```typescript
// 现状: category字段值混乱
category: 'hk' | 'crypto' | 'us' | 'cross' | 'commodity';
```

**建议**: 统一 `category` 和 `MarketTag`，或者 `category` 改为从模板的 `marketScope` 自动推导。

### 3.5 `expectedHoldingDays` 格式极不统一

```
'5-20天' | '1-3天' | '90-365天' | '7-21天' | '30-90天' | '14-60天' |
'1-2天' | '14-90天' | '7-90天' | '180-730天' | '3-14天' | '7-30天' |
'30-180天' | '1-7天' | '1-21天' | '实时监控' | '1-14天' | 
'自动执行' | '上市首日-7天' | '7-60天'
```

**建议**: 标准化为 `{min: number, max: number, unit: 'day'|'month'|'year'}`，同时保留人类可读字符串。

## 四、🟢 P2 体验增强项

### 4.1 模板发现体验 = 0

**现状**: 44个模板平铺在策略列表页。用户无法:
- 按"我适合什么"筛选（风险偏好/资金量/时间投入）
- 看到"别人也在用"的社交证据
- 对比两个模板的差异

**建议**:
1. **个性推荐问答**: 3个问题 → 推荐3个模板
   - Q1: 你的本金是？(<1万 / 1-10万 / >10万)
   - Q2: 你每天能花多少时间？(<5分钟 / 5-30分钟 / >30分钟)
   - Q3: 你能接受亏多少？(<5% / 5-20% / >20%)
2. **模板对比工具**: 选择2个模板 → 并排对比 (因子数/难度/总成本/AI功能/适用市场)
3. **社交信号**: 显示"XX 人正在使用此策略"

---

### 4.2 模板从"静态处方"升级为"动态生命体"

**现状**: 模板是静态JSON — 创建后不变。

**业界趋势**: TradingView Pine Script 策略可以被社区 fork/改进/评分。eToro 的 Popular Investors 策略随市场变化调整。

**建议**:
1. **模板健康度指标**: 每个模板实时显示 "因子信号灯" (🟢3/5个因子发出买入信号 → 该模板现在有效)
2. **模板失效自动提醒**: 当一个模板的 `failureCheck` 条件被触发时 → 推送通知 "你的策略可能失效"
3. **模板版本演进**: 支持 `version: 'v1.0' → v1.1 → v2.0` 的升级路径，用户可一键迁移

---

### 4.3 回测数据是 placeholder — 缺乏说服力

**现状**: 所有 44 模板的 `backtestSummary` 字段是占位文本。

```typescript
backtestSummary?: string;  // Placeholder until real backtest runs
```

**影响**: 
- 用户选择模板时缺乏核心决策依据 (年化收益率、最大回撤、夏普比)
- 纯靠"模板名字好听"选择 → 高 abandon rate
- eToro 数据: 回测数据质量是策略选择 #1 因素 (67% 用户优先看回测)

**建议**: v2.2.0 为所有 44 模板**跑一次完整回测**，存储真实指标。

---

### 4.4 模板→交易的下游路径太长

**用户心智模型**: "看到模板 → 点一下 → 开始赚钱"

**实际路径**: 
```
选择模板 → 阅读四铁律(可能看不懂) → 决定是否跑回测(1U) 
→ 决定是否AI优化(1.5U) → 决定是否解锁替代数据(2U) 
→ 决定是否AI诊断(1U) → 配置参数 → 连接API Key 
→ 检查余额 → 启动交易
```
**9 步，4 个付费决策点。** 每一步都是流失点。

**建议**: "懒人模式" 一键流:
```
[一键启动] → 扣5U套餐 → 自动回测+优化+配置 → 开始交易
```
> 富途牛牛AI选股: "输入金额→一键配置→开始"。用户不需要理解因子权重。

### 5.1 当前收入模型分析

| 模板类型 | 数量 | 平均AI触点 | 人均理论收入 | 实际转化估计 |
|----------|:---:|:---------:|:----------:|:----------:|

| DeepSeekChat | 13 | +对话 | +1-5U/次 | 0.5-2U (50%) |

### 5.2 收入增长建议

| 策略 | 预期增量 | 实现难度 |
|------|:-----:|:-----:|
| AI信号推送覆盖率 41%→80% | +40% 月活收入 | 🟢 低 (加字段) |
| 替代数据覆盖率 27%→60% | +25% 单次收入 | 🟢 低 |
| 模板使用"套餐价" | +15% 转化率 | 🟡 中 (需前端) |
| AI健康检查覆盖率 18%→70% | +20% 留存收入 | 🟢 低 |
| 创作者模板上架加速 | +30% 平台抽成 | 🟡 中 (需推广) |

### 5.3 关键认知: 信号推送是订阅级收入

```
0.5U/条 × 每天1条 × 30天 = 15U/月/用户
15U/月 × 100活跃用户 = 1,500U/月被动收入
```

**当前仅 18/44 模板(41%)有信号推送。→ 加到 40/44(91%) = 订阅收入翻倍。**

信号推送的"懒人价值": 用户不需要每天登录看策略 — 推送告诉他"该行动了"。
