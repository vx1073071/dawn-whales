#### 23. Dogs of the Dow / 高股息狗股 (🟢入门 — 价值类)

| 项目 | 内容 |
|------|------|
| **一句话** | "买股息率最高的10只股票，每年调整一次——最简单的价值策略" |
| **人类使用场景** | 台湾存股族最爱: "0056高股息ETF的核心逻辑就是这个" |
| **适用市场** | 🇭🇰🇺🇸🇹🇼🇸🇬🇦🇺 |
| **持仓周期** | 年度调仓 |
| **核心因子** | DIVIDEND_YIELD, PAYOUT_RATIO, DEBT_EQUITY |
| **入场** | 选股息率最高的Top N (N=10-20), 排除股息率异常高(>15%=危险)的 |
| **出场** | 股息率跌出Top N→卖出 / 股息率<3%→卖出 |
| **止损** | 个股-30% / 股息率翻倍(可能有问题) |
| **风险** | 低(大盘蓝筹+股息保护) |
| **人话** | "就像买收租的房子——不管房价怎么颠，每年租金稳稳的。但别买租不出去的那种" |

#### 24. Growth at Reasonable Price (GARP) (🟡进阶 — 多因子)

| 项目 | 内容 |
|------|------|
| **一句话** | "找业绩增长不慢、但估值不贵的成长股——既要又要" |
| **人类使用场景** | PEG<1 的股票 = 彼得林奇经典策略 |
| **核心因子** | EARNINGS_GROWTH, PEG_RATIO, ROCE, REVENUE_GROWTH |
| **入场** | PEG<1 + 季度营收增速>15% + ROE>15% |
| **出场** | PEG>1.5 / 季度营收增速跌至个位数 |
| **止损** | -15% 拖尾止损 |
| **风险** | 中 |

#### 25. Earnings Surprise Hunter (🟡进阶 — 事件驱动)

| 项目 | 内容 |
|------|------|
| **一句话** | "财报超预期后买入——利用PEAD(盈余公告后漂移)效应" |
| **人类使用场景** | 每季财报季: "EPS比预期高20%→跳空高开→还在继续涨" |
| **核心因子** | EARNINGS_SURPRISE, POST_EARNINGS_DRIFT, GUIDANCE_CHANGE |
| **入场** | 超预期>10% + 上调指引 → 公告后次日开盘买 |
| **出场** | 持有30天 / 下一季财报前卖出 |
| **止损** | -8% |
| **学术** | Ball & Brown (1968), *PEAD效应* |
| **人话** | "财报揭晓那天，市场有时反应不够快——好公司给好消息，股价还得多涨几天" |

#### 26. Small-Cap Value (🟡进阶 — 价值)

| 项目 | 内容 |
|------|------|
| **一句话** | "最被忽视的小公司 = 最大的超额收益" |
| **核心因子** | MARKET_CAP, P_B, P_E, P_S |
| **入场** | 市值<市场Top 30% + 低P/B(<1.0) + 正盈利 |
| **出场** | P/B>1.5或市值超过中位数 |
| **学术** | Fama & French (1992), *三因子模型* |
| **人话** | "大公司被所有人盯着——小公司的价格经常错得离谱" |

#### 27. Pairs Trading (配对各易) (🔴专业 — 统计套利)

| 项目 | 内容 |
|------|------|
| **一句话** | "两只长得像的股票，一只涨了一只没涨→买便宜的→等它们重新对齐" |
| **人类使用场景** | Coke vs Pepsi、建行vs工行、台积电vs三星 |
| **核心因子** | PAIRS_SPREAD, CORRELATION |
| **入场** | 价差>2σ(标准偏差) + 相关性>0.8 |
| **出场** | 价差回归均值 / 持有20天未回归 |
| **止损** | 价差扩大至3σ |

#### 28. Grid Trading (网格交易) (🟢入门 — 均值回归)

| 项目 | 内容 |
|------|------|
| **一句话** | "设定价格上下限, 把资金分成N份, 跌了就买一份, 涨了就卖一份——机器自动做T" |
| **人类使用场景** | 港股/加密散户最爱的自动化策略: "上下限内反复收割" |
| **核心因子** | VOLATILITY, SUPPORT_RESISTANCE |
| **入场** | 当前价在20日布林带内→按网格间距布单 |
| **出场** | 价格破上下限→暂停 / 手动停止 |
| **人话** | "像一个自动收银机——价格上下波动时自动低买高卖" |

#### 29. Dollar Cost Averaging (智能定投) (🟢入门 — 长期)

| 项目 | 内容 |
|------|------|
| **一句话** | "每月固定金额买入——但比普通定投聪明: 跌得多买得多、涨得多买得少" |
| **人类使用场景** | 日本NISA账户(20-30岁)、台湾0050定投族 |
| **核心因子** | VOLATILITY, PE_HISTORICAL_PERCENTILE |
| **入场** | 每月/每周定投 / PE分位<30%→加大投入 / PE分位>80%→减少投入 |
| **出场** | 长期持有(>3年) / PE>90%分位→全部卖出 |
| **风险** | 极低 |
| **人话** | "像存钱一样买股票——低估时多存一点，高估时少存一点" |

#### 30. Market Timer (大类资产轮动) (🟡进阶 — 多因子)

| 项目 | 内容 |
|------|------|
| **一句话** | "股票贵了买债券、债券贵了买商品——永远持有当下最便宜的资产" |
| **核心因子** | GDP_BETA, CROSS_ASSET_CORR, VOLATILITY_REGIME |
| **入场** | 月动量最强的大类资产(股票/债券/商品/黄金/现金) |
| **出场** | 月度调仓到新最强资产 |
| **人话** | "不去预测明天涨跌——只问: 现在什么东西最便宜?" |

#### 36. Funding Rate Carry (资金费率套利) (🟢入门 — 加密独有)

| 项目 | 内容 |
|------|------|
| **一句话** | "永续合约里做多的人每8小时给做空的人发钱——你把钱收到口袋里" |

| **人话简版** | "你拿着现货，同时在合约市场做空等量——两边价格绑定，但空头永远在收钱" |
