## 一、安全防线深度审查（已完成）

### 1.1 防御矩阵总览

```
                    输入层              输出层              行动层
                ┌──────────────┐  ┌──────────────┐  ┌──────────────┐
L5 角色/合规    │ 角色切换检测   │  │ 角色冒充拦截   │  │ @aiForbidden  │
L4 系统/产品    │ 指令注入检测   │  │ 产品定价拦截   │  │ 行动白名单     │
L3 数据/隐私    │ 数据脱敏清洗   │  │ 敏感数据拦截   │  │ IPC权限分级   │
L2 资金/安全    │ 金额模糊化     │  │ 资金信息拦截   │  │ 扣费隔离       │
L1 注入/攻击    │ Prompt注入拦截 │  │ 系统信息拦截   │  │ 数据源异常拒绝 │
                └──────────────┘  └──────────────┘  └──────────────┘
                  ✅ 已完成          ✅ 已完成          ✅ 已完成
```

### 1.2 各层详细评估

**L1: Prompt注入防护** ✅ 优秀
- 5层输入防御 (已知模式→角色切换→数据提取→指令嵌入→异常长度)
- 正则覆盖全面 (50+注入模式)
- 硬/软阻断分级合理
- **缺失**: 无多语言注入模式 (仅中英文), 无对抗样本测试记录

**L2: 资金信息隔离** ✅ 优秀
- 输入端: sanitizeForAI 剥离USDT金额/钱包余额 → `[金额]`/`[已隐藏]`
- 输出端: 9个FUNDS_PATTERNS拦截精确数值
- walletBalanceUSDT从AI请求中移除 (仅用于计费网关)
- **缺失**: 无"模糊但有用"的中间输出 (如"余额勉强够"比"[已隐藏]"更有帮助)

**L3: 数据脱敏** ✅ 良好
- 输入: 11类敏感数据正则脱敏 (API Key/JWT/信用卡/身份证...)
- 输出: 6类敏感数据拦截 (email/phone/SSN/JWT...)
- **缺失**: 无PII检测置信度评分 (假阳性时用户不知道发生了什么)

**L4: 行动边界** ✅ 优秀
- @aiForbidden装饰器 + assertNotAICaller运行时检测
- 10个AI caller pattern (ai-factor-advisor/agent-fundamentals...)
- blockedHistory审计日志 (最近20条)
- **缺失**: 无测试模式 (开发时AI无法正常调试)

**L5: 产品防护** ✅ 良好
- 定价信息拦截 (price_quote/tier_exposure/free_trial)
- 角色冒充检测 (human_persona/licensed_pro/guarantee/system_admin)
- 金融免责声明自动注入
- **缺失**: 无A/B测试能力 (无法验证拦截准确性)

## 二、AI幻觉: 最大的未覆盖风险 🔴

### 2.1 什么是LLM09 Overreliance？

> 用户过度信任AI输出，未经人工验证就采取行动。在金融领域，这意味着：**AI说了某个因子的IC是0.05，用户就基于这个数字投入资金。如果AI幻觉了一个错误的IC，用户的资金就暴露在风险中。**

### 2.2 当前状态：零幻觉检测

审核发现，当前系统中**没有任何**以下机制：

```
❌ 无IC/Sharpe/年化收益的交叉验证 (AI输出 vs 引擎计算)
❌ 无不确定性标注 (AI说"IC为0.05"时不附带置信度)
❌ 无来源引用 (用户不知道AI的数据从哪来)
❌ 无事实核验管道 (AI输出后无反查步骤)
❌ 无"AI可能出错"的主动提示 (除免责声明外)
```

### 2.3 行业对标：其他平台如何处理幻觉

| 平台 | 策略 | TradingEasy差距 |
|------|------|----------------|
| **Bloomberg** | 所有AI输出附带数据来源 + 可点击验证 | 无来源引用 |
| **Robinhood** | AI只做"导航"不做"建议"，精确数字通过UI组件展示 | AI直接生成建议 |
| **富途牛牛** | AI分析标注"置信度: 高/中/低" | 无置信度 |
| **QuantConnect** | 回测结果与AI解读并排展示，用户可对照 | AI独立输出 |
| **ChatGPT (OpenAI)** | "ChatGPT can make mistakes"每个对话底部 | 仅免责声明 |
| **Perplexity** | 每条声称附带来源链接 | 无来源 |

### 2.4 建议：三层幻觉防御

```
Layer 1: 事实锚定 (Fact Anchoring)
  AI生成每个数值声明 → 与引擎实时计算结果对比
  偏差 >20% → 触发"数据可能不准确"标注
  偏差 >50% → 阻止输出，提示"AI结果与引擎计算不一致，请重试"
  
  示例:
  AI: "动量因子的IC为0.045" 
  → 引擎查证: 实际IC = 0.042
  → 偏差 = 7.1% (<20%)
  → 正常输出 + 🔗 [查看引擎计算结果]

Layer 2: 不确定性量化 (Uncertainty Quantification)
  每个AI输出附带置信度标签:
  🟢 高置信 (>80%)  — 历史数据充足，4Agent一致
  🟡 中置信 (50-80%) — 部分数据缺失，Agent有分歧
  🔴 低置信 (<50%)  — 数据不足或Agent严重分歧
  
  低置信输出强制附带: "此建议置信度较低, 请结合您的判断"

Layer 3: 可追溯性 (Traceability)
  每条分析附带:
  🔗 使用的因子: [MOM_12M, ROE_TTM, VOL_60D]
  📊 数据日期: 2026-06-15 (实时) / 2026-03-31 (财报滞后)
  🤖 分析Agent: fundamentals[0.6], technical[0.3], macro[0.1]
  📈 回测验证: [查看最近30天回测对比]
```

## 三、人类UX问题深度诊断 🟡

### 3.1 最大的UX问题: 用户不知道AI"为什么"

走查代码后发现，当前AI回复是**黑盒**的：

```typescript
// ai-factor-advisor.ts — 当前输出结构 (简化)
{
  intent: 'momentum_following',
  recommendations: [{ factorId: 'momentum_12m', recommendedWeight: 0.22, reason: '...' }],
  backtestPreview: { expectedReturn: 18.5, expectedSharpe: 1.42 }
}
```

用户看到的是**结论**，不是**推理过程**。这在金融领域是致命的——用户不会盲信一个没有推理过程的建议。

### 3.2 用户心智模型 vs 实际体验

```
用户期望的AI对话 (像跟分析师聊天):
"我觉得科技股会涨，帮我选几个因子"
→ AI: "根据你过去的偏好(你偏爱成长型+低回撤)，我筛选了3个因子：
    1. 动量(12月) — IC 0.045, 最近30天持续上升↑
    2. 盈利收益率 — 当前市场估值偏低，价值因子回归概率高
    3. 低波动 — 作为防守锚，防止单边下跌
    这三个组合起来Sharpe 1.42，略高于你现有策略的1.35。
    但⚠️动量因子已经拥挤(crowding=0.72)，如果市场反转可能回撤较大。
    你想调整吗？我可以换一个不拥挤的替代因子。"

实际体验 (当前):
"输入查询 → 转圈3秒 → 出来一堆JSON结构 → 用户不知道发生了什么"
```

### 3.3 具体UX改进建议

**A. 渐进式输出 (Progressive Disclosure)**

```
不要一次输出全部结果。分3步展开:

Step 1 (即时显示): 我理解了你的需求: "高成长+低波动"
Step 2 (2-3秒后): 正在分析... 
  ✓ 已评估 8/44 个因子
  ✓ 已匹配 3 个候选组合
  ✓ 正在验证数据源...
Step 3 (最终): 完整分析结果 (带置信度+来源)
```

**B. 解释性输出 (Explainable AI)**

```
每个因子推荐附带:
📊 为什么选这个因子?
  "动量(12M)的IC在过去60天稳定在0.04-0.05之间，
   且与你的'高成长'目标匹配度达85%"

⚠️ 有什么风险?
  "这个因子在过去3次美联储议息周都出现了回撤，
   当前拥挤度为72%(偏高水平)"

🔄 有什么替代?
  "如果你担心拥挤，可以试试'盈利动量(EP_MOM)'，
   相关性低0.3但IC相近"
```

**C. 可控性 (User Agency)**

```
AI输出后用户应能:

✅ [采用这个方案] — 一键导入FactorLab
✅ [微调权重] — 拖动滑条调整因子权重, AI即时重新计算
✅ [换掉这个因子] — 点击某个因子 → 显示3个替代 → 一键替换
✅ [加防守因子] — AI推荐降低回撤的因子
✅ [回测验证] — 一键跑30天回测看效果
❌ 当前: 只能看, 不能操作。用户读完就走了。
```

**D. 假阳性降级路径**

当前若prompt被误判为注入攻击，用户看到的是硬阻断：

```
当前:
⚠️ 消息未发送。你的输入包含AI无法处理的内容。

改进后:
⚠️ 你的问题我们暂时无法直接回答。
  
  可能是因为:
  • 你问了系统配置相关的问题 → [试试这样问]
  • 你问了其他用户的数据 → [了解隐私政策]
  • 这可能是误判 → [转人工] [用模板提问]
  
  你可以换个方式问: [建议改写的问题]
```

## 四、营收转化优化 💰

### 4.1 "为什么付费"的moment缺失

当前freemium设计: 免费看问题 → 付费看答案。但这忽略了关键一步：
**用户需要先相信"AI真的知道我遇到的问题"，才会付费。**

```
当前漏斗:
  免费: 因子列表 (干巴巴的8个因子)
    ↓ (这是断崖！用户不知道付费后能得到什么)
  付费: 完整分析 (1 USDT)
    ↓
  转化率: 预估 <5%

改进漏斗:
  免费: "你的策略在最近30天跑输基准3.2%，这些因子可能拖了后腿..."
    ↓ (具体问题 + 暗示解决方案)
  付费预览: "以下是AI发现的3个改进方向（方向名称+一句话描述+预期提升）"
    ↓ (清晰价值 + FOMO)
  付费: 完整分析 + 权重调整 + 回测对比 (1 USDT)
    ↓
  转化率: 预估 15-25%
```

### 4.2 AI分析后的"啊哈时刻"

用户付费后最怕的是"就这？"。必须确保付费后的第一屏有冲击力：

```
付费后第一屏应该是:
┌──────────────────────────────────────────┐
│ 🔍 你的策略有3个可改进的地方              │
│                                          │
│ 1. 动量因子权重过高 (45%)                 │
│    → 最近30天动量IC下降至0.028 (-38%)    │
│    → 建议降至30%                         │
│                                          │
│ 2. 缺少质量因子防守                       │
│    → 你的最大回撤比同类策略高3.2%         │
│    → 加入ROE质量因子可降至同类水平        │
│                                          │
│ 3. 因子拥挤度警报                        │
│    → 2个因子拥挤度>70%，有踩踏风险        │
│                                          │
│ [一键优化] [逐项调整] [回测验证]         │
└──────────────────────────────────────────┘
```

### 4.3 免费钩子的"上瘾"设计

```
每天1次免费"迷你诊断" → 培养习惯 → 想要更多 → 付费

迷你诊断 (免费, 每天1次):
  "你的策略今天健康评分: 72/100 (B级)
   拖累最大的因子: 低波动 (贡献-2.1%)
   改善最快的行动: 替换为'最小波动'因子"

完整诊断 (1 USDT):
  全部分析 + 权重优化 + 30天回测 + 风险分解
```

## 五、信任建设机制 🤝

### 5.1 当前信任赤字

用户对AI的不信任来源于：
1. 不知道AI怎么得出这个结论（黑盒）
2. 不知道AI有没有说错话（无验证）
3. 不知道AI引用的数据是不是最新的（无来源）

### 5.2 信任建设五步骤

**Step 1: 数据时效性标注**

```
每个因子IC标注数据日期:
  momentum_12M  IC: 0.045  📅 2026-06-15  (实时)
  roe_quality   IC: 0.042  📅 2026-03-31  (最新财报, 滞后75天)

滞后数据自动警告:
  ⚠️ "此因子的数据基于2026-03-31的财报，已滞后75天。
      市场在此期间可能有重大变化。"
```

**Step 2: 4Agent共识度显示**

```
当前4个Agent (fundamentals/technical/sentiment/macro) 独立分析后orchestrator投票。

用户应看到:
  ┌─────────────────────────────────────┐
  │ Agent共识度: 🟢 高 (4/4 一致)        │
  │                                     │
  │ fundamentals: 🟢 推荐动量因子         │
  │ technical:    🟢 推荐动量因子         │
  │ sentiment:    🟢 推荐动量因子         │
  │ macro:        🟢 推荐动量因子         │
  │                                     │
  │ vs.                                  │
  │                                     │
  │ Agent共识度: 🔴 低 (2/4 一致)        │
  │ fundamentals: 🟢 推荐价值因子         │
  │ technical:    🔴 建议观望 (趋势不明)  │
  │ sentiment:    🟢 推荐价值因子         │
  │ macro:        🔴 建议减仓 (利率风险)  │
  │                                     │
  │ ⚠️ Agent分歧较大，建议降低仓位        │
  └─────────────────────────────────────┘
```

**Step 3: 决策追溯**

```
用户做的每个AI辅助决策记录:
  📋 2026-06-15 09:30
  你采用了AI推荐的因子组合: 动量(30%)+质量(25%)+低波(20%)
  当时AI预测: Sharpe 1.42, 年化 15-20%
  当前实际 (7天后): Sharpe 1.38, 年化 14.3%
  📊 跟踪: 偏差 -2.8%, 在预期范围内

这让用户能"回头验证AI靠不靠谱" → 积累信任 → 持续使用
```

**Step 4: AI信心衰减曲线**

```
AI对自己的预测标注"有效期":
  "此分析基于今日收盘数据，有效期至明日9:30。
   市场大幅波动(>2%)后建议重新分析。"

超期分析自动标记:
  "此分析已超过24小时(标记时间: 昨天 14:30)
   建议 [重新分析] (1 USDT)"
```

**Step 5: "踩"的反馈闭环**

```
每条AI回复底部:
  ✅ "有帮助"  ❌ "不准确"

踩了之后弹出:
  "哪里不对？"
  □ 数据过时了
  □ 建议不合理
  □ 没回答我的问题
  □ 其他: [____]

→ 反馈进入训练/调优流程
→ 24h内不准确率 >30% → 自动暂停该类型AI建议
```
